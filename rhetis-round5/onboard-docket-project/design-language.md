# Onboard Docket — replica에서 추출한 요소 문법

이 문서는 고정된 1280×720 replica의 실제 HTML 수치를 읽어 작성했다. replica 소스·PNG·PDF는 수정하지 않는다. 색 값은 외부 style의 책임이며, 아래 색 이름은 지도에 정한 팔레트 역할이다.

| 항목 | 실제 기준과 라이브러리에서 유지한 관계 |
|---|---|
| 페이지 | 바깥 중성 면 `--n-3`, 1188×590 종이 `--page`, 14px 모서리. 얇은 상단 레일과 넓은 종이 여백 |
| 머리글 | 좌측 58px 장 번호, 48px 제목. 본문 Noto Sans KR의 -0.7px 자간과 제목의 더 촘촘한 자간을 구분 |
| 단순 구획 | 1px 구분선 `--n-4`, 옅은 카드 `--n-1`, 진한 글자 `--ink`/`--n-8`. 표면을 추가하기보다 정렬과 선으로 분리 |
| 번호 목차 | 937px 요소 안에서 두 열, 64px 행, 16px 행 간격, 35px 열 간격. 번호 원 56px, 번호20px/700, 이름22px |
| 세부 카드 | 576×101 면의 26.91% 지점에 세로 구분선. 제목19px/600, 설명16px. 요소 내부 여백32/28px의 비율을 보존 |
| 아이콘 카드 | 364×142 면, 28px 가로 여백과 17px 세로 여백. 오른쪽 아래 58px 아이콘 칸, 제목22px/400, 설명16px |
| 조용한 카드 | 279×90의 제목14px·설명13px와 311×117의 설명16px. `.quiet` 안에서 실제 존재하는 부품에 따라 구성 |
| 수평 순서 | 196px 연한 원, 원 안 70px 그림 자리, 16×50px 삼각 화살표, 원 아래 이름21px·설명17px. 365px 요소 높이를 기준으로 비율화 |
| 세로 순서 | 122px 행, 234px 왼쪽 채움 블록, 20×10px 아래 노치. 이름19px/650, 설명16px, 블록 안 번호27px/700 |
| 숫자 지표 | 235px 멤버, 34px 간격. 왼쪽 이름19px/보조12px, 오른쪽 숫자43px/700+단위30px. 배경 없이 가는 분리선만 사용 |
| 인라인 강조 | 본문 안의 네모난 검은 띠는 `--ink` 위 `--page`. 캡슐 라벨은 `--n-9` 위 `--page`와 구별 |
| 인용 | 첫 문장35px/1.55, 뒤 편지17px/1.7, 서명19px와 Nanum Pen36px. 따옴표와 글자 사이 비대칭 여백47:25 |
| 맺음말 | 1083×48 연한 중성 캡슐, 가운데21px 문장. 강한 채움의 독자 변형은 계약에 없으므로 만들지 않음 |

주 강조의 채움은 `--a1`/`--a1-on`, 강조 글자는 `--a1-7`, 두 번째 진한 채움은 `--a2-7`/`--page`다. 동일 역할은 요소마다 바꾸지 않는다. 검은 인라인 강조와 회색 라벨도 별도 역할을 유지한다.

요소 루트는 size container다. 본래 크기를 상한으로 두고 자신의 상자나 멤버 폭·높이에 비례해 줄인다. 원형 순서는 폭이 좁으면 연결 관계를 유지한 세로 흐름으로 바꾸고 부차적 설명을 숨긴다. 멤버 수가 많은 순서는 설명과 제목 크기를 한 단계 내려 전체 관계를 읽게 한다. 제목과 핵심 숫자는 숨기지 않는다.

replica에 없는 차트와 관계도는 이 덱의 작은 원형 표식, 얇은 선, 캡슐 끝, 중성 면, 절제된 글자 위계를 확장해 설계했다. 원래 없는 꾸밈 카드나 페이지 배경을 요소에 덧씌우지 않는다. 불가능한 패널·복합 도형은 `GAPS.md`에만 제안 마크업과 함께 남긴다.
