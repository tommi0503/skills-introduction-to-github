# Seedmark 디자인 언어 — ROUND5

21장 원본과 불변 replica의 실제 도형·타이포를 위에서 아래로 다시 읽었다. 결과는 관측 디자인39종이며, 원형이 없는 일반 라이브러리 채우기를 제거했다. 모든 논리요소의 위치·크기·부품·문구 길이와 연결은 map.json에 기록했다.

원본은 가는 선과 큰 여백을 기본으로 한다. 본문은 Noto Sans KR350, 제목은44px, 보조 제목은26–28px, 본문은16.5–18px와 약30px 행간을 사용한다. 수치42px·64px 계층은 부모만이 아니라 자식 b/fig까지 측정했다. 모양별 글자 상한과 cqw/cqh 하한을 함께 사용해 큰 칸에서도 원본 위계를 유지한다.

선택 강조는 납작한 면, 양끝의 짧은 세로 선과 원형 점을 함께 가진다. 표지 점30px, 일반 제목 점14–16px로 차이가 난다. 직사각 label은26px 높이/5px 모서리이며, 큰 캡슐과 원은50% 또는 충분히 큰 공유 반경으로 그린다. 카드의 가는 규칙선, 회색 본문면, 짙은 알약과 겹친 원형 아이콘은 각 독립 디자인의 실제 위치 비율을 소유한다.

색은 외부 팔레트 자리로 옮긴다. 기본 바탕=--page, 본문/짙은 면=--ink, 역상 글자=--page, 강조 면=--a1-2-soft, 얇은 보조선=--n-2/--n-3, 보조 문구=--n-7, 사진 placeholder=--n-1이다. 데이터 계열은--a1/--a2/--a3 및 해당 on/깊은 단계로 구별한다. 원본의 흰·검정·연두 숫자값은 요소 CSS에 고정하지 않고 assets/source-palette.css에서 공급한다.

연결선은 연결한 전체 멤버를 소유한 flowchart/network/steps/timeline이 그린다. 원통 저장소, 노드 발자국, grouped bar의 범주·계열, pie의 slice, BEP와 범례는 해당 의미 소유자 안에 둔다. foundation panel은 텍스트와 차트의 제목·기간·범례·캡션을 묶고 실제 비율을 가진다. 페이지별 좌표 API나 요소를 움직이는 페이지 CSS는 없다.
