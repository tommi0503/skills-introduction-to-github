# Vectorbox 디자인 언어 · ROUND5

선택 도구의 bounding box가 반복 문법이다.1px 얇은 윤곽, 모서리의7px 정사각 또는14×6/6×14 직각 핸들, 무반경 직사각 면을 쓴다. 굵은 원형 outline과 열린 선 아이콘은 전략 카드, 채운 원은 순서·관계 노드, 불규칙 burst는 큰 비율 수치에 쓰인다. 관계선은 얇고 연속적이며 단계 연결만 점선 화살표다.

공유 간격은12/24/36px, 기본 stroke1px, 작은 swatch radius6px이다. 실제 측정값은 요소 안의 cqw/cqh 비율로 옮기고 폰트는8–256 범위 type 토큰 또는 그 토큰 경계의 clamp를 쓴다. 카드의 제목·설명 시작은 길이에 따라 바뀌지 않으며, 선택 프레임 안의 수치는 시각적 중심에 놓인다. 서로 다른 원형 시각형은 `.quiet/.line` 조건으로 숨기지 않고 별도 디자인 폴더로 구분했다.

페이지 상단의 짧은 세로 강조 rail과 영문 kicker, 큰 중량 제목, 우상단 진행 점이 공통 장치다. 정상 페이지의 잘린 선택 프레임은 foundation vector, 여러 요소의 paired composition은 foundation panel이다. 요소는 페이지 번호나 fixture 이름을 참조하지 않는다.

색은 외부 style의 자리다. 배경=`--page`, 본문=`--ink`, 제목·핸들·주요 계열=`--a1`, 주요 계열 위 글자=`--a1-on`, 작은 강조 글자=`--a1-7`, 검은 비교 계열=`--a2`, 보조 계열=`--a3/--a4`, 조용한 선=`--n-3/--n-4`, 중간 무채색 채움=`--n-5/--n-6`, 설명=`--n-7/--n-8`, placeholder=`--n-1`이다. 원본 파랑·검정·연파랑은 `assets/source-palette.css`가 공급한다. 요소 CSS에는 색 리터럴이 없다.
