# ROUND5 검수 기록

불변 replica12장과 기존 v2 디렉터리는 수정하지 않았다. ROUND5 사용자 전문과 README를 끝까지 읽고, 사용자 전문이 허용한 독립 디자인 폴더·자유 부품·foundation panel/vector·차트 확장을 적용했다.

기존5개 표현 불가 디자인은 모두 복구했다. 페이지를 통째로 요소에 옮기지 않고, 카드의 독립 시각형7종·세로 범례·묶음 차트·다중 조각 링·독립 중심을 가진 사각 외곽 관계도로 분리했다. 기존 원형 없는49개 일반 요소는 삭제했다. map은 도구의 DOM잔여물 목록을 없애고71개 논리 소유자·페이지 장치·배경을 위에서 아래로 기록한다.

첫 시트 검수 뒤 실제 페이지에서04 연도 라벨이 지나치게 작음을 확인했다. foundation의 `.group` 컨테이너를 차트 내부 부품이 상속하면서 `cqw` 기준이 각 범주로 축소된 문제였으며, 차트가 소유한 `.group`을 `container-type:normal`로 고쳐 전체 플롯 기준을 되찾았다. 숫자 y눈금은 `--max`의0·1/5·2/5·3/5·4/5·1로 계산하고, 위쪽 공유 토큰 여유로100 라벨을 칸 안에 넣었다. 원문에 없는 막대 값 주석은 quiet 상태에서 접근성 DOM에만 유지한다.

04의 검은 선택 프레임 아이콘이 강조색으로 남아 있던 문제는 caption 기본형의 ink와 tone1 강조형으로 분리해 고쳤다.11의 callout은 공유 여백 토큰으로 양쪽을 inset하여 원본의869×239에 가까운865×240 프레임이 됐다.04의 두 배지 쌍은 foundation의 재사용 패널로 묶어 제목 영역과 겹치는 원형 위치를 복구했다.

시각 차이는 남아 있다.02 오른쪽 목차 열은 그리드 폭 때문에 약30px 오른쪽이며,06의 그래프는 원본보다 위쪽 노드가 약26px 아래이고 원 지름이 약10px 작다.10 링은 약16px 크고, 오른쪽 예산 카드가 약47px 오른쪽이다. 새 페이지별 좌표 API나 장면 CSS를 만들지 않고12×6 whole-owner 배치를 사용한 결과다.04의 아래 배지·캡션은 약8–13px 아래다. 이 차이를 표현 불가 GAP으로 기록하지 않았다.

아이콘은 실제 Lucide를 불러오므로 원본의 복잡한 기어, 신분증의 채운 초상, 동전 묶음, 가운데 쌓인 사다리꼴과 실루엣이 다르다. 시트의 빈 icon 슬롯은 공식 preview 방식의 점선 원이며 조립본에서 실제 아이콘을 확인했다. 사진2장은 원래 요청대로 회색 placeholder다.

10의 도넛은 불변 replica의 면적25/30/15/10/10/10을 사용한다. 외부 원문 범례는 여섯 항목 모두25%여서 산술적으로150%가 되지만, 자료의 불일치를 고치거나 문구를 바꾸지 않았다. slice의 `--v`/누적 시작각과 접근성 name/b는 실제 면적을 나타내며 외부 범례는 원문 주석이다.

새 fixture는 원본 문구를 쓰지 않은 한국어 업무 예시다. 기존 모범 fixture의 reserved 이름을 모두 철회했으므로 원문 상태를 임의로 바꾼 것처럼 등록하지 않았다.36개 fixture에 다른 멤버 수(아젠다6/8, 표3/5행, 링4/6조각, 묶음 막대3/4범주, 범례4/6개)와 긴 제목·설명을 넣었다.

마지막 수정 뒤18개 디자인의36개 모드 시트,18개 원형 대조,12개 페이지 대조,10개 foundation 렌더를 직접 열었다. 총440개 허용 칸에서 자동 geometry·대비·실제 폰트 로딩 후보0이다. 정적 검사와 계약 검사는 모두0이다. 최종 파일 해시와 fingerprint는 `round5-review.json`에 있다. 중간에 foundation fixture를 추가하는 동안 실행 중이던 시트가 fingerprint 변경을 감지해 중단한 기록이 있으며, 그 중간 결과는 최종으로 쓰지 않고 모든18개를 다시 렌더했다.
