# Design language

바깥면·둥근프레임·가느다란상단세칸·한순위강조와반대면카드가대조된다. 1px선,16pxcorner/8px내부corner,8/16/32px여백,32px두줄표제,작은영문kick와18pxcard이름의위계를쓴다.

색의역할은덱전체에서한번정한다.

- 페이지 내부 바탕 = `--page`
- 본문 = `--ink`
- 상단 강조/하단 glow/화살표/영역선 = `--a1`
- 강조 면 위 글자 = `--a1-on`
- 흰 카드/그림 위 반대 면 = `--n-9`
- 흰 카드 위 글자 = `--page`
- 그림 자리 = `--n-3`
- 바깥 회색 = `--n-5`
- 가는 규칙선 = `--n-6`
