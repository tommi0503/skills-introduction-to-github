# Dockside 디자인 언어 — 새 측정과 새 CSS 기준

원본 30장과 불변 replica DOM을 측정했다. 앱의 흰색 인셋 면, 세로 rail과 하단 dock, 짧고 진한 chapter 캡슐, 단어별 강조, 넓은 여백이 공통 어휘다. 실제 원본 색은 host palette의 역할에만 남기고 요소 CSS에는 색상값을 넣지 않았다.

| 규칙 | 관찰/구현 |
|---|---|
| 선 | 카드·사진·원형의 밝은 rim 2px. 기본 연결선과 분리선 1px. 핵심 관계 선은 최대 3px. |
| 모서리 | 일반 인셋 20px, 작은 인셋 10px, 연락·키워드·번호·이름표 캡슐 999px. 큰 원은 완전한 원으로 유지한다. |
| 면 | `--page`의 밝은 rim, `--n-1`의 부드러운 면, `--n-2`의 낮은 그림자. 채움이 있는 면은 `--a1-1-soft` 등 역할로만 표현한다. |
| 여백 | 기본 24px, 작은 간격 12px, 큰 간격 48px. 원본의 실제 복합 요소는 측정한 비율로 자체 크기를 제한하고, 빈 공간을 억지로 채우지 않는다. |
| 제목 | Pretendard Variable 600, 본문 400. 페이지 제목 60px/1.14, 자간 −1.5px. 요소 제목은 18–26px, 원형 도표 수치는 52px와 작은 단위 24px. |
| 본문 | 16px/1.55, 자간 −0.5px. 좁은 칸은 계약 type-step과 clamp로 12px까지 내리고, 필수 문장을 감추는 대신 정직한 min을 지정한다. |
| 강조 | 기본 제목 `--ink`, 강조 단어·수치 `--a1-7`, 선택 캡슐 채움 `--a1`/글자 `--a1-on`. 보조 단계는 `--a2-*`·`--a3-*` 역할을 사용한다. |
| 구분선 | `--n-3`, 축·배경은 중립 역할. 색상은 데이터와 강조의 자리이며 디자인의 고정 색이 아니다. |
| 장식 | 사진·3D 아이콘·기기 화면은 연회색 seat. SVG/CSS로 가능한 대각 반투명 밴드는 foundation이 그린다. 검은 원형 이동 버튼은 `--ink` 바탕과 `--page` 도형이다. |
| 연결 | 원형 steps의 검은 이중 chevron, 계단 timeline의 얇은 세로 분리선, hub의 점선 외곽, hierarchy·mindmap의 둥근 직교 가지는 각각 전체 멤버를 가진 단일 요소가 소유한다. |

원본에 없는 39개 요소도 같은 선·인셋·캡슐·원형·타이포 위계를 사용한다. 별개 의미의 다이어그램을 .tone-N으로 바꾸지 않았고, 원형 steps와 계단 timeline은 서로 다른 계약이다. 새로운 flowchart는 시작/종료 캡슐·판단 도형·직교 화살표, cycle은 원형 경로·화살표, network는 좌표 사이 실제 선분을 그린다. 데이터·멤버 수·부품 유무 외의 페이지 식별 조건은 사용하지 않았다.
