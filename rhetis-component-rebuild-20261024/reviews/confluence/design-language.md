# Design language

17px흰면패널과안쪽강조header,원형번호medallion,중앙의두꺼운ring과얇은십자축을쓴다. 1px선,8px내부corner,10/20/40px여백,800굵기의중심단어와700/750굵기의field·라벨을구분한다.

색의역할은덱전체에서한번정한다.

- cyan 강조 채움 = `--a1`
- blue 강조 채움 = `--a2`
- 대조 글자 = `--a1-on / --a2-on`
- 흰 패널/중앙 ring = `--page`
- 기본 글자 = `--ink`
- 보조 설명 = `--n-7`
- 가는 선 = `--n-3`
- 옅은 위 바탕 = `--a1-1-soft`
- 옅은 아래 바탕 = `--a2-1-soft`
