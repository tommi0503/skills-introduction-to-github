# 066 — Marketing Plan Proposal 시각 검수

16개 원본을 각각 `view_image`로 열람한 후 원본/브라우저 결과 비교 이미지 16개를 round1과 round2에서 각각 개별 검토했다. 세 번째 최종 렌더에서 마지막 변경(숫자 단위 간격과 표 모서리)을 PNG/PDF에 반영한다.

- 구현: 회색 브래킷 SVG foundation, 말풍선 SVG, 라운드 카드·칩·리스트·표·차트·타임라인을 재사용 함수와 데이터로 구성했다. 원본 전체 이미지를 결과에 사용하지 않았다.
- 폰트: 실제 로드한 Pretendard 400/500/700/800 사용. 원본 이미지에 서체명이 없어 모양과 굵기를 보고 선택했으며 영문 제목 자간을 -1.5px로 보정했다. 원본과 글자 폭/획의 미세한 차이는 남는다.
- 판독: 본문과 숫자는 읽을 수 있는 원문을 입력했다. 키워드 이미지의 작은 이미지 기호와 07장의 건물 사진은 사용자 지침대로 연회색 단색 placeholder로 대체했다.
- 해석·결정: 선 아이콘은 Lucide로 통일했다. 원본 말풍선의 둥근 외곽·하단 포인터는 직접 SVG로 재작성했다. 원본 도넛의 40/40/20 비율을 재현했다.
- round1 자동검사: 16장 모두 1280×720, findings 0, 브라우저 오류 0.
- round2 수정: 표지 제목 확대, 영문 제목 자간·수직 위치, 말풍선 문구 수직 중앙, 숫자 단위, 도넛 중간 40% 세그먼트 회전 보정. 자동검사 findings 0.
- 11장의 두 줄 칩은 `white-space:pre-line`을 명시하여 실제 2줄·상하좌우 중앙 정렬했다.

|---|---|
| 01 | 브래킷 프레임·회사 프로필·말풍선과 큰 표지 제목, 설명 위치 확인. |

최종 검증: PNG 16개 모두 1280×720, 자동 findings 0, `sourceHash`가 현재 소스 SHA-256과 일치한다. 최종 수정 대상 비교 이미지를 다시 개별 열람하여 변경이 최종 PNG에 반영됐음을 확인했다. 소스는 최종 렌더 후 동결했다.
