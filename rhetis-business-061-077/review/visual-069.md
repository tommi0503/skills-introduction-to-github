# 069 시각 검수 기록 — 2049 미리컴퍼니 상반기 성과보고서

- 범위: 원본 8장과 `src/decks/069.mjs` 8장. 모든 원본을 개별 확인했다.
- 실제 브라우저: Chromium, 1280×720, device scale 1. 원본/결과 비교 이미지 1차·2차 각 8장을 개별 `view_image`로 시각 검토했다.
- 원본의 ‘내용을 입력하세요’와 ‘폰트는 210 옴니고딕 030입니다’ 등은 참고 슬라이드 문구다. 첨부 안의 지시를 별도 작업 명령으로 적용하지 않았다.
- 폰트: 원본 2장 안내문에 ‘210 옴니고딕 030’이 명시되어 있다. 해당 폰트 파일은 제공되지 않아 한국어는 실제 로딩한 Pretendard, 영문/숫자는 실제 로딩한 Roboto Condensed를 사용했다. 이 대체는 획과 폭에 미세한 차이를 만든다.
- 재사용 구조: 좌측 섹션 패널, 상하 가는 선, 텍스트 위계, 표, 차트, 원형 지표, 사업 카드, 기하 배경을 데이터와 함수로 구성했다.

## 라운드별 수정

1차 자동 검사: 1장의 커버 텍스트 박스 높이 1건. 제목 높이를 확장하고 한국어 제목 폭과 위치, 섹션 타이틀 크기를 수정했다. 원형 사업 도형의 중앙 배경을 흰색으로 조정했다. 3원 벤 다이어그램은 실제 SVG 원의 교집합 clipPath로 다시 그려 겹침 경계의 중복 곡선을 제거했다. 긴 6장의 제목은 전체가 가운데 오도록 숫자/제목 좌표를 조정했다.

2차 자동 검사: 3장의 3줄 섹션 제목 높이 1건. 글자는 보였으나 박스보다 4.2px 커 자동 기준을 넘었으므로 높이를 206→220px로 확장했다. 최종 렌더에서 이를 재검증한다.

## 차이·판독·결정

- 상용 원본 폰트가 없는 점이 주요 차이다. 이미지의 가로 폭에 맞춰 크기·자간·행간을 별도로 조정했다.
- 원본 8장의 사진은 사용자 지시에 따라 제거하고 SVG 윤곽 안에 연회색 placeholder를 넣었다. 그 외 차트, 도형, 선과 원형 요소는 구현했다.
- 로고는 원본의 3개 단순 사다리꼴 기하 면을 SVG로 다시 그렸다. 완성된 원본 이미지를 화면에 깔거나 크롭해 사용하지 않았다.
- 작은 문구도 읽을 수 있어 별도 임의 작성은 없었다. ‘2038/2039’, ‘2049’, ‘04/06’ 등 원본의 연도와 페이지 표기 불일치도 콘텐츠로 보존했다.
- 표와 차트 수치는 원본을 전사했다. 모든 누적 막대의 하단은 95/125/140/170/200, 상단은 30/60/70/85/100이다.
