# 064 시각 검수 기록 — 2080 워크샵 결과보고서

- 범위: 원본 18장, 재현 데이터 `src/decks/064.mjs` 18장. 모든 원본을 개별 `view_image`로 확인했다.
- 비교 방식: Chromium 1280×720 렌더, 원본/결과 좌우 비교 이미지를 1차 18장·2차 18장 각각 개별 확인했다. 3차는 최종 산출물 확인이다.
- 사용자 지시와 참고 문서 구분: 원본 안의 ‘내용을 입력해 보세요’ 등의 문구는 슬라이드 콘텐츠로 보존했으며 작업 명령으로 해석하지 않았다.
- 실제 로딩 폰트: Pretendard 400/500/600/700/800. 원본 파일에 폰트 메타데이터가 없어 보이는 획과 폭에 맞춰 선택했다. 특정 원본 폰트와 완전 동일하다고 주장하지 않는다.
- 공통 구조: 헤더, 타이틀, 카드, 캡션, 오렌지 불릿, 화살표, 로고, 그라데이션 막대 등을 파일 내부 함수로 재사용. 원본 이미지를 결과에 포함하지 않는다.

## 라운드별 수정

1차 자동 검사에서 9장의 긴 본문 한 줄, 13장의 인용문 줄바꿈이 텍스트 박스를 넘었다. 본문 폭·크기·자간·높이를 조정했다. 개별 비교로 공통 타이틀 크기를 37→40px, 커버 제목 폭, 헤더 하단 곡률, 작은 진행 화살표 비율을 수정했다. 막대 그라데이션 SVG ID 충돌로 회색 막대가 주황색으로 보이던 문제를 각 막대 고유 ID로 해결했다. 12장의 불릿 간격과 17장의 두 줄 불릿 간격도 원본에 맞게 조정했다.

2차 자동 검사: 18장 전체 텍스트 박스 초과·캔버스 초과·폰트 로딩·chip 중심 오류 0건. 17장의 단순 상하 화살표는 최종에 SVG로 구현했다. 최종 렌더에도 모든 수정이 반영되었는지 소스/HTML/PNG 해시와 자동 리포트를 확인한다.

## 차이·판독·설계 결정

- 대체 범위는 사용자 요청에 따른 사진, 3D 일러스트와 이미지 아이콘이다. 이 부분은 의도적으로 원본과 다르다.
- 읽을 수 있는 원문을 재입력했다. 별도로 판독할 수 없어 임의 작성한 주요 문구는 없다. 사소한 구두점·공백은 이미지 판독 기준으로 정리했다.
- 그래프·파이·배경·로고는 원본 래스터를 크롭해 쓰지 않고 벡터와 데이터로 다시 만들었다. 파이는 원본의 48/37/10/5, 막대는 25/20/7/5/3, 만족도는 20/25/40/50/55 및 10/15/30/40/45를 보존했다.
- 원본의 사진/3D 표현을 제외한 시각 구조는 재현했지만 원본의 렌더러/폰트 정보가 없어 픽셀 단위 완전 일치로 판정하지 않는다.
