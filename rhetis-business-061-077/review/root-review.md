검수일: 2026-10-19. 사용자 첨부 8개 덱 117장 전체를 대상으로 제작했습니다. 첨부 README 전체를 먼저 읽고 계약으로 적용했으며, 참고 이미지 안의 설명문은 UI 콘텐츠로 구분했습니다. 기존 저장소 작업은 보존하고 별도 폴더를 사용했습니다.

## 개별 시각 검수와 통합 결과

각 담당 에이전트가 원본과 실제 Chromium 렌더를 나란히 놓은 비교 이미지를 전장 개별 검토했습니다. 원본 재현은 덱마다 2회 비교·수정과 최종 내보내기 범위에서 확정했습니다. 주 에이전트도 061 17장, 064 18장, 065 18장, 066 16장, 069 8장, 071 20장, 073 18장, 077 2장을 각각 원본과 비교했습니다. 연락처 시트는 전체 탐색과 전달 용도로만 사용했습니다.

061의 헤더 배지·색·중앙 정렬·일정 줄바꿈, 064의 제목 위계·오렌지 화살표·표와 차트, 065의 선형 물결·단위·소제목, 066의 브래킷 프레임·말풍선·두 줄 칩, 069의 좌측 타이틀과 표·도넛, 071의 부분 강조·퍼널형 내용 배치·인용·카드와 073의 접힌 종이·표·포지션 맵·숫자 라벨을 확인했습니다. 077은 영문 타이틀의 무게·폭과 목차선을 확인했습니다.

새로 발견된 마지막 소스 타입 문제는 071/14의 오른쪽 예산 라벨 4개였습니다. 굵기 자리에 정렬 옵션 객체가 들어간 호출을 400 굵기+정렬 옵션으로 바로잡고 해당 덱의 최종 PNG·PDF를 갱신했습니다. 빌드에도 숫자 굵기·글자 크기 검증을 추가했습니다. 재조립 117장도 각 담당자가 전장 개별 검토했고, root는 차트·표·목차 보존과 전장 픽셀 비교로 통합 확인했습니다.

## 라이브러리

독립 컬렉션 `business-prism`에 공유 토큰 63개, foundation 3 fixture, 31요소 80 fixture를 작성했습니다. 디자인은 8개 참고 덱의 정돈된 판넬, 얇은 선, 네이비·블루·시안과 주황 강조를 재해석했습니다. atlas/miri의 디자인을 복사하지 않았습니다. 전 요소의 data-el 범위·타입 단계·금지 리소스·클래스·fixture 구조를 별도 정적 검사했습니다.

라이트/다크 83개씩 개별 시각 검수, 선언 최소 칸 텍스트 경계 검사와 대비 검사를 수행했습니다. root는 커버·막대/선 차트·6멤버 순환도·허브·요금제·긴 표·3집합 벤다이어그램을 추가 확인했습니다. 순환도 화살촉이 모두 오른쪽을 향하던 부분은 링의 노드 사이로 옮기고 시계방향 접선으로 보완했습니다. 3/6멤버×2모드 4장과 최종 라이브러리 166 PNG·PDF를 갱신했습니다.

## 최종 자동 검사

- 전 234장 재현/재조립: 1280×720, 텍스트 경계·영역 초과·부모 잘림·폰트 로드·칩 광학 중앙·JS 오류 검사.
- 칩 내부 span은 폰트의 잉크 경계가 line-height보다 클 수 있어, 잘림 판정은 실제 칩 컨테이너 경계를 기준으로 했습니다. 광학 중앙은 Canvas의 실제 glyph bounding metrics로 확인했습니다.
- 원본 재현·재조립 DOM에는 원본 이미지를 표시하는 img/image 태그가 없습니다.
- 실제 폰트 파일과 굵기를 로드하고 document.fonts.ready 이후 캡처했습니다.
- 원본 재현/재조립 PNG, HTML, source SHA-256을 비교해 최종 수정 반영 여부를 확인했습니다.
- 재조립 101장은 재현본과 RGB 픽셀 동일, 나머지 16장은 placeholder 가장자리의 극소 안티앨리어싱 차이입니다. 최대 평균 RGB 차이는 0~255 척도에서 약 0.000621입니다.
- PNG·PDF 개수와 규격, ZIP의 최상위 구조와 CRC 및 SHA-256은 `verification.json`, `archives.json`에 기록합니다. 실제 GitHub 업로드본 재다운로드 검사는 `github-download-verification.json`에 별도 기록합니다.

## 남는 차이와 판단

사진·이미지 아이콘·복잡한 입체 도형·기기 화면의 회색 placeholder는 요청에 따른 변경입니다. 단순 SVG 배경의 곡률·농도, Lucide의 획과 아이콘 세부, 미확정 원본 폰트의 비례에 차이가 남습니다. 특히 065의 촘촘한 물결과 073의 종이 접힘은 직접 그린 벡터 근사입니다. 069 원본의 상용 폰트 `210 옴니고딕 030`은 미제공되어 Pretendard+Roboto Condensed로 대체했습니다. 작은 문구는 읽히는 범위에서 전사하고, 판독되지 않는 부분은 같은 자리의 자연스러운 한국어 비즈니스 문장으로 작성했습니다. 덱별 구체적 수정·해석은 `visual-*.md`에 남겼습니다.

재조립 초기에는 콘텐츠를 새 그리드로 자동 재배치하는 안을 검토했으나 차트 축과 표 항목의 관계가 바뀌어 폐기했습니다. 최종본은 원본 데이터·배치·타이포 역할을 유지하면서 실제 컬렉션 card/pill/frame과 foundation 구조로 조립했습니다. 최종 ZIP에는 최종 렌더만 포함합니다.
