# 061 / 077 라이브러리 정확 재조립 최종 검수

## 최종 방식

최종 재조립은 collection의 card / pill / frame / foundation CSS 및 DOM 계약을 실제로 사용하며, 원본 재현 scene의 좌표·타이포그래피·역할 정보를 page overrides로 전달한다. 카드·배지·프레임으로 콘텐츠를 다시 렌더하며 원본 raster를 화면 배경으로 사용하지 않는다. 직접 재현본과 동일한 콘텐츠·컴포넌트 데이터를 공유하여 차트 수치, 표의 행/열, 일정의 월별 관계와 반복 설명을 보존한다.

최종 검수에서 `comparisons/final/assembly/061/slide_03.jpg`~`slide_19.jpg` 17개 파일을 모두 개별 view_image로 열람했다. 연락처 시트로 검수를 대체하지 않았다. 잘림·영역 초과·누락·추가 중복·비정상 공백·구조 훼손을 발견하지 않았다. 원본 대비 의도된 사진 placeholder, Lucide 대체 아이콘, 글꼴/반투명 장식 차이는 직접 재현본과 동일하고 `visual-061.md`에 기록되어 있다.

## 077 검증

`comparisons/final/assembly/077/slide_01.jpg`, `slide_02.jpg` 두 비교이미지를 각각 개별 view_image로 열람했다. 두 최종 PNG 모두1280×720이며 잘림·영역초과·누락·중복·구조 문제가 없다. `automatic-final-assembly-077.json`:2장, 브라우저 오류0건, 발견사항0건. `renders/final/replica/077`와 `renders/final/assembly/077`의 평균 RGB 픽셀차는 두 장 모두0이다.

|---|---|
| 01 | 표지 제목2행, DATE필드, 격자와 연락처3열 유지. 정상 |
| 02 | 목차5개 및 설명, 빈 목차3행, 체크박스와 구분선 유지. 이전 cover 오인/목차누락 해소 |

원본 대비 미세한 서체 glyph/격자색 차이는 직접 재현본과 동일하며 `visual-077.md`에 기록되어 있다. 마지막 제목위치/크기 수정이 최종 재조립 PNG에도 반영된 것을 확인했다.

## 초기 전략 검토 이력

초기 semantic-grid 휴리스틱 재배치에서는 061/04 숫자리스트 잘림, 061/10 차트 라벨 오인, 061/11 표 관계 상실, 061/17 월별 일정 병합, 077/02 목차를 표지로 오인하는 문제가 있었다. 이 전략은 폐기되었고 최종 결과물에는 사용하지 않는다. 위의 정확 재조립은 콘텐츠 관계와 원래 geometry를 보존하여 해당 문제를 해결했다.
