# 검수 방법

담당별 1차 실제 Chromium 캡처 → 각 원본/결과 비교를 별도로 열어 검토 → 담당 수정 → 2차 실제 캡처 및 개별 검토 → 주 에이전트의 최종 통합 캡처와 202개 개별 비교 순서로 진행합니다. 덱 전체 비교는 담당 2회와 통합 1회, 총 3회입니다. 자동 감사와 폰트 견본 확인은 전체 덱 비교 회차에 포함하지 않습니다.

글자 폭은 실제 DOM Range, 높이는 폰트의 실제 잉크 하단을 측정합니다. 칩은 실제 Canvas 글자 경계를 이용해 시각적 중심을 보정하고 ±1.2px 기준으로 확인합니다. 지정한 폰트 굵기와 스타일에 맞는 실제 FontFace가 로드됐는지도 검사합니다. 원본 접지 경계를 가로지르는 요소는 같은 경계에서 자르며 이를 일반 텍스트 넘침과 구분하여 기록합니다.

단순 벡터와 도형은 종이 가장자리까지 이어지는 경우가 있어 자동으로 경계 교차 목록을 추출하고 개별 비교에서 의도한 도형 잘림인지 확인합니다. 사진·복잡한 그래픽의 회색 대체와 정확한 원본 서체를 확인할 수 없는 차이는 담당 기록과 최종 관찰에 남깁니다.

마지막 캡처의 디자인 데이터 해시, 공통 렌더러 해시, 참고 이미지 해시, 결과 PNG 해시를 현재 소스 및 파일과 대조합니다. 빌드된 앱 전체 202개 경로를 실제 브라우저로 다시 열어 자동 검사합니다. 결과 ZIP 내부 CRC와 모든 PNG 크기를 확인하며 업로드 이후 GitHub에서 실제 다운로드한 ZIP도 해시·CRC·내부 SHA256SUMS로 검사합니다.
