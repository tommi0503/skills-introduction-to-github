# 최종 통합 검수 기록

참고 이미지 52장을 바탕으로 리플렛 26종의 원본 접지 구성을 유지했습니다. 3단 23종과 2단 3종을 접지면 150장 및 펼침 52장, 총 202장으로 렌더했습니다. 모든 결과 PNG는 1280×720이며 종이의 비율은 동일한 배율로 유지합니다.

담당 6명은 분리된 데이터 파일과 화면을 맡아 원본을 개별 열람하고 두 차례 실제 브라우저 비교·수정을 수행했습니다. 주 에이전트는 최종 202개 비교 이미지를 각각 열어 확인했습니다. `primary-review.json`은 각 화면의 관찰·비교 이미지 해시·PNG 해시·정의 해시를 담습니다. 전체 미리보기는 탐색용입니다.

마지막 통합에서는 실제 서체 굵기와 기울임 파일, 원본의 줄바꿈, 한자 로딩, 손글씨 획을 보정했습니다. 독서 토론회 주소를 덮던 회색 대체 영역을 원본 외곽에 맞춰 줄였습니다. 도서관 표지의 단순 복숭아색 도형 및 색상 점은 SVG/CSS로 복원했습니다. 변경한 화면은 다시 캡처하고 비교 이미지를 개별 확인했습니다.

빌드된 앱의 전체 202개 경로에서 실제 폰트·굵기·스타일 로딩, 텍스트의 폭과 잉크 하단, chip의 시각적 중앙 ±1.2px, 대체 이미지에 의한 글자 가림, 페이지 크기, 브라우저 오류, 원본 이미지의 UI 사용 여부와 최종 소스/PNG 해시를 검사했습니다. 예기치 않은 오류는 0건입니다. 접지선을 가로지르는 원본 요소와 종이 가장자리 도형의 의도한 잘림은 별도 경계 목록에 기록했습니다.

사진과 복잡한 이미지의 단색 대체로 원본과 큰 색상 차이가 발생하는 화면이 있습니다. 원본의 흰 글자가 회색 대체 위에 있는 곳은 색상 보존으로 대비가 낮습니다. 정확한 폰트 이름이 확인되지 않는 장식 글꼴·손글씨·로고의 글리프, 일부 SVG/Lucide 윤곽은 근사이며 담당 기록과 개별 관찰에 남겼습니다. 원본의 반복된 문구와 숫자 모순은 보존했습니다. 담당 기록상 판독 불가 텍스트의 임의 대체는 0건입니다.

ZIP CRC가 정상이어도 내부 PNG 026·044의 IDAT가 잘린 문제가 있어 동일 Canva 템플릿 공개 미리보기로 복구한 참고본을 비교에 사용했습니다. 살아 있는 상단 픽셀의 일치 검증과 복구 URL·해시는 provenance에 기록하고 업로드 원본 바이트를 보존했습니다. 첨부 README·CSV는 출처 자료로 취급했습니다.
