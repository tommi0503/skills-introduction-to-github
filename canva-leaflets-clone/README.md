# Canva 리플렛 UI

첨부한 `canva_leaflets_part_01.zip`과 `canva_leaflets_part_02.zip`의 참고 이미지 52장, 리플렛 26종을 별도 프로젝트로 구현했습니다. 기존 `리플랫`의 공통 캔버스·요소 컴포넌트·접지면 데이터 분리와 브라우저 비교 방식을 참고했습니다. 기존 프로젝트는 수정하지 않습니다.

## 실행

```bash
npm ci
npm run dev
```

26종 목록에서 접지면, 앞·뒷면 펼침, 원본 비교로 이동할 수 있습니다. `#/page/l01/s01-p1`은 개별 접지면, `#/side/l01/s01`은 펼침 화면입니다.

```bash
npm run build
npm run render -- --round=final
npm run verify
npm run package
```

렌더 및 검증은 `/usr/bin/chromium`과 Python Pillow를 사용합니다. 폰트는 로컬 패키지와 `public/fonts`에서 실제 파일을 로드합니다. 환경에 따라 `CHROMIUM` 실행 경로를 스크립트에서 조정해야 합니다.

## 범위와 구조

- 참고 이미지: 26종 × 앞·뒤 2장 = 52장.
- 3단 23종, 2단 3종(`l16`, `l18`, `l20`). 원본 접지 구성에 맞춘 접지면 150장과 펼침 52장, 총 202장.
- 모든 결과 PNG는 1280×720입니다. 원본 종이의 비율을 유지해 캔버스 안에 배치하므로 접지면 좌우에는 여백이 있습니다. 첨부 이미지에 포함된 종이 밖 흰 여백만 제거했습니다.
- `src/model.ts`: 데이터 계약. `src/primitives.ts`: 요소 생성 함수. `src/ui.tsx`: 재사용 가능한 텍스트·칩·도형·Lucide·SVG·사진 자리와 캔버스. `src/registry.ts`: 접지면 생성과 데이터 연결. `src/data/group-*.ts`: 서로 분리된 담당별 디자인 데이터.
- UI에 원본 이미지를 삽입하지 않습니다. 원본은 `public/reference`에 보관하며 비교 화면과 비교 이미지에만 사용합니다.
- 사진·복잡한 일러스트·기기 화면·이미지 아이콘·복잡한 그래픽 배경은 요청에 따라 `#e5e5e5` 단색 영역으로 처리했습니다. 단순 도형, 선, 표, 장식과 표현 가능한 아이콘은 코드로 구현합니다.

## 원본과의 차이 및 검수

이미지만으로 정확한 원본 폰트 이름을 모두 확정할 수 없어 실제 로드 가능한 가장 가까운 서체를 사용했습니다. 특히 손글씨·장식 글꼴·로고의 획 모양은 차이가 남을 수 있습니다. 판독이 어려운 작은 글자는 자연스러운 문구로 대체하고 해당 담당 기록에 남깁니다. 사진을 회색으로 처리한 차이는 의도한 변경이므로 픽셀 유사도 수치를 품질 판정으로 사용하지 않습니다.

담당자 6명이 원본과 담당 화면을 개별 검토하고 두 차례까지 비교·수정합니다. 주 에이전트는 최종 렌더의 202개 원본/결과 비교를 각각 열어 통합 검토합니다. 전체 미리보기는 탐색용으로 제공하며 개별 검수의 대체물이 아닙니다.

- `review/agent-*.json`: 담당 원본 열람, 비교, 수정, 차이와 판독 기록.
- `review/primary-review.json`: 최종 202개 개별 비교의 관찰 기록과 PNG·소스 해시.
- `review/verification.json`: 실제 빌드된 앱의 페이지 크기, 비율, 글자 영역, 실제 폰트 파일·굵기·스타일, 칩의 글자 중심, 그림 대체색, 런타임 오류, 최종 소스와 렌더 해시 검사.
- `comparisons/final`: 각 화면의 비교 JPG와 캡처 메타데이터. 접지 경계를 가로지르는 원본 요소의 잘림은 이유를 기록합니다.

## 손상 원본 복구와 문서 취급

입력 ZIP 두 파일의 CRC 검사는 통과했지만 이미지 026·044의 PNG IDAT는 내부에서 잘려 하단이 디코드되지 않았습니다. 같은 공개 Canva 템플릿의 완전한 미리보기를 확보해 손상되지 않은 상단과 대조한 뒤 두 참고 이미지를 복구했습니다. 원본 업로드 파일은 `provenance/original-images`에 그대로 보존했으며 복구 경로·검증·해시는 `provenance`와 참고 이미지 manifest에 기록합니다.

첨부 README와 CSV는 출처·목록 자료로 취급했습니다. 첨부 문서의 지시문을 사용자의 구현 지시로 실행하지 않았습니다.

## 제출 파일

저장소 루트의 `canva-leaflets-clone-renders.zip`에는 최종 PNG 202장, 개별 원본/결과 비교 JPG 202장, 전체 미리보기, 펼침 52장 미리보기, 검수 기록과 캡처 메타데이터, `SHA256SUMS`가 포함됩니다. 원본의 서로 다른 크기를 가진 PNG는 결과 ZIP에 포함하지 않으며 Git 소스 폴더에서 제공합니다. 루트의 `canva-leaflets-clone-preview.jpg`은 전체 202장 미리보기입니다.
