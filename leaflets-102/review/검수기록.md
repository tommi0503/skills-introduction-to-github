# 리플렛 UI 최종 검수 기록

## 범위와 원본

첨부 ZIP 2개에서 PNG 102개(001–102, 양면 리플렛 51덱)와 출처 CSV 2개를 확인했습니다. CSV는 제목·파일명·출처 주소 자료이며 작업 지시로 취급하지 않았습니다. 첨부된 별도 지시 문서는 없었습니다. 전체 목록은 `src/data/manifest.json`, 입력 무결성·복구 정보는 `review/input-inventory.json`에 있습니다.

잘린 이미지 11개(006, 012, 023, 034, 041, 047, 058, 064, 076, 081, 100)와 빈 이미지 088을 CSV의 원본 URL에서 다시 다운로드하여 복구했습니다. 작업용 이미지 102개가 모두 정상 디코딩됩니다. 복구본 중 023, 034, 041, 047, 076, 081, 088, 100은 1280×909입니다. 비교 시 하단 1픽셀만 보충했으며 비율을 늘리지 않았습니다.

사용자의 최신 크기 지시에 따라 최종 결과는 전부 **1280×910**입니다. 초기 1280×720 검수 결과는 중간 자료이며 제출 PNG는 전부 최종 네이티브 크기입니다.

## 구현과 검수 방식

기존 `리플랫`의 공통 인터페이스·도형/텍스트 프리미티브·폰트 로딩·중앙 정렬 검수 방식을 참고한 독립 프로젝트 `leaflets-102`입니다. 화면 데이터와 렌더러를 분리하고 공통 컴포넌트로 텍스트, 도형, 칩, SVG, Lucide 아이콘, 단색 placeholder를 구성했습니다. 원본 이미지를 전체 UI 배경으로 사용하지 않습니다.

6명에게 001–018 / 019–034 / 035–050 / 051–068 / 069–086 / 087–102를 분리해 할당했습니다. 각 담당자는 원본과 브라우저 렌더 비교를 개별 검사하고 1·2차 기록을 남겼습니다. 주 에이전트는 3차 최종 원본/결과 비교 이미지 102개를 각각 직접 열어 통합 검수했습니다. 전체 미리보기 이미지는 목록 제공용이며 개별 검수를 대신하지 않습니다. 덱당 비교·수정은 3차까지 수행했습니다.

최종 통합 수정: 011·012 둥근 제목을 실제 Jua 400으로 복구, 014 사진 위 파란 오버레이 제거 및 글자 색 보정, 021 사진 placeholder 폭을 줄여 표의 흰 배경 복구, 036 BEVERAGE 표기와 제목/아이콘 겹침 수정, 101 인사말 폰트 크기·줄간격 보정. 해당 화면은 다시 렌더하여 반영을 확인했습니다.

## 최종 확인

- 독립 `npm ci`와 `npm run build` 성공(빌드의 큰 번들 경고는 전체 폰트/아이콘과 102개 화면을 포함한 구성에서 발생).
- Chromium 실제 렌더 PNG 102개, 각각 1280×910. 원본/결과 비교 JPEG 102개, 각각 2560×948.
- 텍스트 폭·높이·페이지 경계, 실제 폰트 굵기/스타일 등록, 폰트 요청 실패, chip 글자의 잉크 중심과 라벨 경계 검사: 최종 발견 0개.
- 페이지 정의 해시·공통 렌더러 해시·PNG 해시 대조로 마지막 수정 반영 확인.
- 페이지별 자동 검사 JSON과 사용된 폰트는 `comparisons/round-final`, 전체 통과 결과는 `review/final-verification.json`에 있습니다.

## 차이와 판독 한계

사진·복잡한 일러스트·이미지 아이콘·기기 화면·복잡한 그래픽 배경은 사용자 요청대로 #e5e5e5 단색 영역입니다. 단순 테두리·도형·표·차트·텍스트 및 Lucide 표현 가능한 아이콘은 직접 구현했습니다. 원본의 흰 글자를 회색 위에 유지한 곳은 대비가 낮아집니다. 전용 로고 합자, 고유 일러스트 아이콘, 상용 제목 폰트는 회색 또는 실제 유사 폰트로 근사되어 원본과 차이가 있습니다. 작은 문구는 판독 가능한 내용/줄 수를 참고하고 판독할 수 없는 부분은 문맥에 맞는 정상 문장으로 입력했습니다. 이상한 선으로 본문을 대신하지 않습니다. 구체적인 판독·수정 기록은 `review/group-a.json`–`group-f.json` 및 페이지 데이터 `notes`에 있습니다.

자동 검사 통과는 모든 구현 요소의 경계와 실제 폰트 상태가 정상이라는 의미입니다. 원본과 픽셀 단위로 동일하다는 의미는 아니며, 남은 제목 획·줄바꿈·작은 본문 간격 차이는 아래 개별 기록에 남겼습니다.
