# 시각 검수 기록

원안 D/A/A/v3/A/v3/A/v3/v3/E/A/D의 원본 이미지 12장과 통합본 12장을 확인했습니다. 본문 타이틀을 같은 위치에 놓고 E10의 상단 우측 부제를 공통 부제 위치로 옮겼습니다. 도식·설명용 UI·시장 산식·미확정 정보 표기를 유지했습니다.

통합 후 시안 12장을 전부 브라우저 렌더로 확인했습니다. 와이어프레임 7장의 밝은 B2B 카드 위 흰 글자를 진한 회색으로 수정했고, 표지의 날짜 표기를 정리했습니다. 색상만 달라진 와이어프레임도 같은 배치와 실제 도식을 유지합니다. PDF의 텍스트와 도식은 확대 가능한 벡터입니다.

뷰어는 한 덱을 바로 열고, 같은 페이지의 시안·와이어프레임을 두 패널로 비교합니다. 메모는 원안 출처와 페이지를 표시하고 브라우저에만 저장합니다. 글꼴 로딩이 완료되면 슬라이드를 표시합니다.

자동 검사에는 원안 매핑·대본/주석 보존, 텍스트 경계·겹침, Pretendard, 2px 고정 수치·짝수 줄높이, 섹션 좌표, 단색 이미지, 로컬 링크, 키보드·모바일·메모·내보내기, PDF 페이지 수·텍스트를 포함합니다. 관리형 Chromium이 file:// 탐색을 제한하므로 상호작용 검사는 로컬 HTTP에서 수행합니다. 배포본 자체는 상대 경로·일반 스크립트를 사용하고 원격 자산이나 fetch에 의존하지 않습니다.
