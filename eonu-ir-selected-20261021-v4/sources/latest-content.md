## 외주 전달 메모

1. 초반은 한 아이의 이야기로 문제와 솔루션을 쉽게 보여주고, 삼각형으로 세 사람의 필요를 정리한다.

3. 삼각형은 동일하게 재사용한다. 솔루션에서는 ① 의료진 → EONU, 스케일업에서는 ② 환자 → EONU를 강조한다.
4. 데모는 의료진 세팅 → 환자·보호자 사용 → 의료진 확인 순서. EONU에 남긴 기록의 백그라운드 분석과 전달 전 확인·통제를 보여준다.
5. EMR 옆 화면에서 확인하는 것과 EMR 시스템 연동은 다르다. 초기 데모의 병렬 화면이 실제 EMR 연동 완료를 뜻하지 않게 한다.
6. 화면은 구현된 기능과 계획 화면을 구분한다. 의료진 확인 절차만으로 안전성이 검증됐다고 표현하지 않는다.
7. 뉴스는 문제의 보조 근거. 2023년 소아 단독 내원 관련 보도는 진료거부·보호자 책임 논란을 다루므로 설명 부족이나 발생 증가를 직접 입증하는 자료로 쓰지 않는다.
8. 아이 사례는 재구성한 예시로 표시한다. 실제 특정 아이의 발언·행동으로 확정해 표현하지 않는다.
9. B2G는 공공 구매자가 있는 계약을 뜻한다. 의료봉사·민간시설 인터뷰는 실증 접점으로 구분한다.
10. TAM·SAM·SOM의 각 범위와 산정 근거는 후속 계산으로 채운다. 연구지원금·동일 공급 계약·미래 하드웨어 매출을 소프트웨어 시장에 중복 합산하지 않는다.
11. 팀·투자 요청에서 고객 확보 방법, 비용, 기간과 목표를 연결한다. API·서버 원가는 시장 규모나 CAC와 구분한다.
12. 기관명·로고, 실증·계약과 법적 검토의 표현은 실제 상태와 사용 범위를 확인해 반영한다.
