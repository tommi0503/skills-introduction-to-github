# Design language

Strong horizontal heading and footer bands, a369px reading sidebar and a68px outer gutter organise the page.1px grid rules are exposed. Rounded capsules and circular carriers supply the only broad curves, with one ranked accent carrying the point. The source Oswald heading is approximated with the allowed Noto Sans variable width axis at 75%, without scaling or font aliasing; the remaining glyph-height difference is declared as a font gap. Do Hyeon supplies the rounded display voice, and business body stays Pretendard. Tables have a measured quarter-width label column, and the hub uses a134px core with169×44px capsules. There are no soft shadows.
