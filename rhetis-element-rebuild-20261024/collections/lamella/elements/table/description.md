# Point-column comparison grid

Replica16 supplies five equal columns, an ink first header, an accent point header, nine centered data rows, alternating quiet fills and thin vertical and horizontal rules. The point column stays colored through a small blank continuation below the last row. This23.5/488 continuation is source geometry, never an invented data row.

Source OCR gives inconsistent per-cell font sizes. The reusable design retains the measured hierarchy by semantic role: larger first/point headers, a slightly larger point column and smaller remaining values. It does not reproduce arbitrary cell-specific font overrides. `.pick` marks all cells of the point column; `.num` uses tabular figures. The element counts header columns and body members. The dense source fixture needs6×4 or4×6, while a three-column, four-row comparison needs4×2 or3×3. No content is hidden.
