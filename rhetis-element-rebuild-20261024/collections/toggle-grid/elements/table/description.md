# Subsection-and-label table

Replica09 supplies a full-width accent subsection header, a quarter-width ink label column and open pale body cells. Fine neutral5 rules divide the rows. The source label weight is500; the value text uses400 with selected bold phrases. Replica11 is the same design with an explicit two-line label. Replica08 has an explicit empty thead and centered body values, a real structural alternative selected only by the absence of header rows.

The source header/body height ratio, 66px value inset and asymmetric11/13px vertical padding become element-relative units. Width caps and natural wrapping preserve content at smaller sizes. The two-row fixtures have a3×2 minimum; the longer headerless three-row fixture has a3×3 minimum. `.pick` and `.num` remain contract cell features. No text is hidden.
