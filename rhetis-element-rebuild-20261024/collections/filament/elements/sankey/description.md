# Proportional flow

No Sankey appears in the replica. Page 07 supplies 12-radius service fields, 300-weight names, and 250-weight value figures.

A source-side distribution bus joins each ribbon. Labels occupy their own readable area, so a zero-share outcome keeps its name and figure without a fictitious band. Each terminal outcome receives one row-height unit. A direct band is 60% of that unit multiplied by its source share; a second split multiplies that thickness again by its local share. Every band in one diagram therefore uses the same value scale. Only the actual child count controls row allocation. No semantic field is hidden.
