# Service-panel architecture

The replica contains no stacked architecture. This inferred design extends replica07's178×121service surfaces:12px rounds,14/15px inner space,25px light display titles,17px bold lower labels and6px inter-panel air. Each architecture layer is a single accent surface, with a light upper name and stronger module labels below. Module text remains centered inside its contract chip slot.

Two to five layers and one to five modules adapt by member count. Labels wrap at narrow widths and are never hidden. Three layers need3×3; five long layers need6×4or3×6. Shared palette roles replace source red/cream.
