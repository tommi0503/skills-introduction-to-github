# Split-accent comparison table

Derived from replica page09: a narrow label column, two solid accent headers, open page-colored body cells and fine horizontal rules. Body labels use a stronger weight; values align near the top of each row. The first header cell remains an explicit empty corner.

The point column uses `.pick` on its header and body cells. Its header occupies accent role2, while other data headers use role1; body fills remain the page surface as in the replica. Numeric cells support `.num`. Font sizes follow the table height with width-based caps; long words wrap rather than clip. The source-shaped three-row fixture has a3×3 minimum, and the denser four-row comparison has a4×4 minimum. No secondary copy is hidden.
