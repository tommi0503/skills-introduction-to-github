# Replica 20–24 review

- 원본 5장을 각각 직접 열고, 독립 HTML을 실제 Chromium에서 렌더해 원본|replica 비교 PNG 5장을 각각 열어 확인했다.
- 비교·수정: 초기 비교 뒤 표의 행 높이(44.5px), 표 머리글(50px), 22번 좌우 표 폭(531/547px)을 교정했다. 주 에이전트의 공통 제목 폰트 교정 후 최종 파일을 다시 렌더했다.
- 20번 사진 4장과 상단 브랜드 이미지 로고는 사용자 규칙에 따라 연회색 단색 placeholder로 대체했다. 브랜드 글씨는 실제 텍스트이다.
- 20번 본문·키워드, 21–22번 표 및 요약, 23번 설명문, 24번 축·범례는 판독 가능해 원문을 사용했다. 지어낸 문구 없음.
- 23번 선 그래프의 데이터는 원본 점 위치를 읽어 전/후 [2.1,4.2,6,7.5,7.8] / [2.3,4.6,7,8.3,8.7]로 역산했다. 24번 막대/선은 원본 좌표를 기준으로 역산했다. 원본 데이터 파일이 없으므로 소수점 수치는 해석이다.
- 23번 글자와 24번 차트 라벨은 로컬 Pretendard Variable을 실제 로드했다. 본문 폭이 원본과 가까운 Pretendard를 유지하며 공통 제목은 주 에이전트가 Noto Sans KR로 교정했다.
- 단순 차트는 HTML SVG로 직접 구현했다. 전체 이미지 배경 사용 없음. 차트 내부 선 굵기·원형 라벨의 글자 렌더링은 원본과 수 px 차이가 남는다.
- 자동검사: 5장 모두 viewport 1280×720, PNG 1280×720, document.fonts.check('16px "Pretendard Variable"') true, 페이지 밖으로 나간 텍스트 0개. 키워드 3개는 flex 양축 중앙 정렬이다.
- 공통 shell의 제목/장 번호가 원본보다 약 8px 아래로 보이는 점을 전달했고, 주 에이전트가 title translateY(-8px), chapter padding-bottom 16px로 보정했다. 수정된 common.css 시각 08:00:04 이후 PNG 08:00:20 재렌더를 확인했으며 최종 비교 PNG 5장도 각각 다시 열어 확인했다.
