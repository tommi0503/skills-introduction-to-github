# 23번 조립본 충실도 재검수

원본과 replica23을 다시 직접 확인한 뒤, 조립본의 누락을 수정했다. 처음 조립본에서 빠졌던 중립 비교선, 두 원형 00 말풍선, 중앙 오른쪽 화살표와 원문 문장 접두사를 모두 복구했다.

- HTML 편집 파일: `briefing-tab-review/reassembled/slide_23.html` 하나. 기존 foundation/요소 계약 마크업과 data-el을 사용했다. 페이지 전용 CSS, 새 클래스, SVG를 추가하지 않았다.
- 차트 담당과 조율하여 같은 grid 칸에 인접한 두 `.lines`가 중립 비교선/강조선을 공유하는 일반 패턴을 추가했다. max10과 원본 점 좌표에서 읽은 두 증가 추세를 사용한다. 숫자 b는 구조를 유지하되 원본처럼 값 텍스트를 비워 뒀다. 0/2/4/6/8/10 축과 월 라벨을 복원했다.
- 카드 담당과 조율하여 text-only quiet reading card(368px 선 길이 제한), figure-only quiet/on 원형 말풍선, 빈 from/to delta 화살표를 일반 패턴으로 구현했다. 요소 fixture에서도 검수할 수 있도록 담당자가 관련 패턴을 추가한다.
- 설명 카드는 제목22px/본문16px, 본문 행간27.2px로 원문의 네 문단과 줄바꿈을 유지했다. 판독 불가로 새로 지어낸 문장은 없다.
- 조립본을 실제 Chromium에서 렌더하고 원본|조립본 비교 PNG를 개별 확인했다. 마지막 축0, 최상단 그리드, 본문 행간 교정까지 최종 렌더에 반영했다.
- 실제 1280×720 viewport 및 PNG, 폰트 로드 성공, 화면 밖 텍스트 및 client/scroll 텍스트 잘림0개를 확인했다.

## 남는 작은 차이

원본 플롯 x144..628/y293..595에 대해 조립 플롯 x144..628/y294..594이다. 원본 설명 카드 x812/y236/w368/h398에 대해 조립 x814/y238/w368/h396이다. 낮은 원형 라벨 중심은 약5px, 높은 원형 라벨 중심은 약1–5px 차이다. 화살표는 grid 배치 때문에 원본보다 오른쪽·아래로 약6px 차이가 있다. 폰트 렌더링·얇은 선의 안티앨리어싱 차이가 남는다.

공통 스타일 팔레트의 원본 파랑 복원 및 공통 제목 조정은 주 에이전트가 통합 적용한다. 최종 패키징 전 공통 수정이 포함된 전체 페이지를 다시 렌더해야 한다.

최종 추가 확인: 공통 title52px, 원본 파랑 style, 두 말풍선의 포인터 위치 교정을 반영한 PNG를 다시 렌더하여 비교 이미지를 직접 열어 확인했다. `reassembled/slide_23-checks.json`에 폰트·1280×720·잘림0 검사를 기록했다.
