# Replica 25–30 검수 기록

원본 6장을 각각 1280×720으로 직접 열어 확인했고, Chromium 실제 렌더 뒤 2560×720 원본|replica 비교 PNG를 페이지별로 열어 검수했다. 초기 비교와 수정 후 비교를 수행했고 공통 폰트 변경도 최종 PNG에 반영했다. 모든 페이지 document size 1280×720, 폰트 로딩 성공, 화면 밖 DOM 요소 0개.

- 공통 심볼 로고는 이미지 아이콘이므로 연회색 placeholder로 대체했다. MIRICOMPANY 글자는 구현했다.
- 25: 가로 막대 값 20/40/35/10/50/30과 축·세 설명 띠를 구현했다. 첫 비교에서 막대가 10px 아래로 어긋나 수정했다.
- 26: 막대와 점·면 차트의 동일 데이터 및 그리드·축 라벨 구현. 첫 비교에서 오른쪽 플롯이 좁아 수정했다. 그라데이션 면은 SVG로 직접 구현했다.
- 27: 도넛 구간에 원본 숫자 20/40/35/10/50을 유지했다. 합이 155이므로 합155에 대한 각도로 해석했다(퍼센트로 오독하지 않음). 테이블 및 연결선·칩 라벨 구현. 구간 숫자 테두리는 생략하여 텍스트 렌더 차이가 남는다.
- 28: 파이 20/30/50%와 레이블 연결선을 직접 구현했다. 레이블 숫자 위치를 두 번째 비교에서 조정했다.
- 29: 사람 도형과 10단위 원형 비율을 벡터·HTML로 구현했다. 원본 비율 숫자는 정확한 condensed 폰트를 식별할 수 없어 표준 글꼴 표의 Freesentation과 좁은 자간으로 근사했다. 폰트·화면 변형은 사용하지 않는다.
- 30: 표지 좌표, 라운드 종이, 푸른 세로 아이콘 탭, THANK YOU 크기를 맞췄다. 단순 아이콘은 Lucide와 같은 선형 벡터로 직접 구현했다. 로고심볼은 회색 placeholder.
- 읽을 수 없는 문장을 새로 만들지 않았다. 확인 가능한 원본 문구를 유지했다.
- 남은 차이: 공통 원본 글꼴 식별 불가로 Noto Sans KR 근사, 차트 세부 레이블은 Pretendard Variable, 약간의 획 두께·앤티앨리어싱·그림자 차이. 원본의 브랜드 심볼은 의도적으로 대체됨.
