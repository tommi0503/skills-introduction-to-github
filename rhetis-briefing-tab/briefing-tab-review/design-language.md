# Briefing Tab 디자인 언어

원본 덱 078_1ivzi의 20–30번 이미지 11장을 먼저 replica로 구현하고 개별 대조한 뒤 추출했다. 색 이름은 디자인의 일부가 아니다. 라이브러리 시트에서는 계약의 기준 팔레트가 적용된다.

## 형태와 구획

- 1280×720 캔버스. 낮은 대비의 바깥 바탕 위에 둥근 종이판이 놓인다. 원본 여백 좌우46, 위38, 아래38px. 종이판 반경14px, 상단 챕터 띠 반경12px.
- 상단 띠는 가로로 길고 얇다. 페이지 장식은 이 띠와 제목의 수직 구분선으로 한정한다. 표지에서는 같은 띠를 오른쪽 세로 탭으로 회전시킨 배치를 쓴다. 화면 자체를 기울이거나 늘리지 않는다.
- 큰 장 번호와 제목 사이에 1px 수직선, 제목 아래 1px 수평선. 요소 내부도 1px 선으로 구획한다. 차트 연결선1px, 주요 데이터 외곽2px.
- 표·막대는 사각형에 가까우며 작은 모서리4px. 설명 띠·카드 반경8–14px. 소형 칩은999px 알약이다. 장식용 과장된 테두리·별·잎은 없다.

## 간격과 위계

- 기본 간격8px, 보통16px, 큰 간격24px. 카드 내부24px, 좁은 칸은16→8px 단계. 큰 페이지 간격은 기본 단위의 배수로 만든다.
- 제목 글꼴은 로컬 Noto Sans KR, 본문은 Pretendard Variable. 원본 폰트 메타데이터가 없어 획과 실측 폭으로 선택했다. 제목50px은 계약 단계52px와 자간-.04em 조합으로 실측 폭을 맞춘다. 장 번호60px, 본문16–20px, 소제목24px, 데이터32–60px, 작은 라벨12–16px.
- 제목700, 이름600–700, 본문400, 라벨500. 제목 자간-.02em, 본문-.01em. 행간 제목1.2, 본문1.6, 라벨1.3.
- 작은 칸에서 타이포는 단계로 축소한다. kick을 먼저, note를 그다음 숨기며 이름과 수치는 유지한다. 칩은 flex/grid 양축 중앙 정렬한다.

## 색의 자리

| 원본 역할 | 팔레트 자리 |
|---|---|
| 외곽 바탕 | `--n-2` |
| 종이판 | `--page` |
| 제목·기본 문장 | `--ink` |
| 조용한 설명 띠·카드 | `--n-1` |
| 표 선·구획선 | `--n-3` |
| 부연 문장 | `--n-7` |
| 장 번호·강조 단어 | `--a1-7` (작은 글자 대비 확보) |
| 챕터 띠·강한 탭 | `--a1-7`, 위의 글자 `--page` |
| 활성 칩·막대·단일 주요 데이터 | `--a1`, 위의 글자 `--a1-on` |
| 비교 데이터 | `--n-8` / 조용한 면 `--a1-2-soft` |
| 추가 시리즈 | 순서대로 `--a2`, `--a3`, `--a4` |
| 상태 의미 | `--good`, `--warn`, `--bad` |

## 이미지에 없는 요소를 확장하는 법

관계도는 종이판 위의 얇은 연결선과 작은 둥근 라벨로 표현한다. 프로필·가격·조직도도 중립 면, 작은 반경, 한 곳의 강조만 쓴다. 차트는 얇은 회색 그리드·직선형 플롯·작은 원형 포인트를 공유한다. 데이터는 조작하지 않고 마크업의 수치를 읽는다. 면적·길이·각도는 실제 값을 반영한다. 구조를 보여주는 기하를 제외한 장식은 추가하지 않는다.

## 조립 시 제한

foundation의 12×6 그리드만 쓰므로 원본의 자유 좌표와 몇 px 차이가 난다. 다중 구간 파이는 누적 비중을 가진 기존 donut 요소를 같은 칸에 겹쳐 구성한다. 복합 막대/선과 두 계열 선도 같은 칸에 놓고 공유 축을 한 번만 그린다. 원본을 재현하려고 새 클래스나 페이지 전용 CSS를 만들지 않는다. 이 차이는 review-notes에 따로 기록한다.


## 자연 높이와 복합 구성

설명 띠와 표는 stack에서 본문 길이와 행 수에 따라 자연 높이로 쌓아 원본의101px 띠와45px 표 행을 보존한다. 3개 POINT 패널은330px/간격13px의 문서 묶음이다. 사진과 글의 spread는11:13 비율과40px 사이 간격을 쓴다. 세부 수치를 가진 복합 구성도 새로운 클래스 없이 기존 계약 요소와 숫자 데이터로 표현한다.
