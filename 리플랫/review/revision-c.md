# l49–l60 재검증 및 개선

원본 `public/reference/l49`–`l60`의 앞·뒷면과 기존 `comparisons/final`의 전체 펼침면 24쌍을 먼저 실제 이미지로 비교했다. 기본 원, 배지, 지도, 테두리가 회색 이미지로 바뀐 부분과 본문 대비·줄바꿈·숫자 폭·서체 획의 차이를 중심으로 `src/data/patch-c.ts`를 수정했다.

| 종 | 구체적으로 바꾼 부분 | 남는 차이 |
| --- | --- | --- |
| l49 | 상담 순서와 조언의 녹색 원 배경을 되살리고, 원 위에 Lucide 아이콘을 배치했다. 표·헤더의 녹색 선과 원의 크기·레이어 순서를 수정했다. | 복잡한 농업 장면·삽화는 회색 자리 표시자로 남는다. 원본의 세밀한 그림 아이콘은 일반 Lucide 도형과 다르다. |
| l50 | 둥근 사진 자리, 말풍선 꼬리, 전화 원형 배지를 복원했다. 프로그램 번호를 녹색 원과 별도 제목 칩으로 분리하고 영문 연락처 서체를 수정했다. | 현장 사진과 인물 그림은 회색이다. 말풍선 곡선은 원본에 가까운 기본 도형이다. |
| l51 | 보라색 인용부호 장식과 깃털, 프로필 구획, 제작참여 좌우 선, 프로그램 표·구분선을 보강했다. 본문과 작은 안내의 굵기·폭을 조정하고 실제 없는 한글 이탤릭 요청을 제거했다. | 피아노·프로필 사진·복잡한 배경은 회색이다. 원본 깃털과 장식 획의 세부는 Lucide와 다르다. |
| l52 | 주문 안내의 갈색 기본 배경색과 밝은 글자 대비를 복원했다. 팔각형 이중틀, 중심 베지어 이중 프레임, 주소·문의의 장식 명패, 이야기 카드의 굴곡 윤곽, 가격 카드 선·모서리, HACCP 글자를 다시 만들었다. | 사진·한과 그림·복잡한 질감은 회색이다. 명패·문양의 미세한 선과 곡률은 근사치다. |
| l53 | 원본에서 채취한 크림·연두 기본 색상, 둥근 이미지 윤곽, 잎 아이콘과 하단 칩을 복원했다. 헤더 구획을 원본의 각진 면으로 조정했다. | 복잡한 전원 풍경과 인물 그림은 회색이다. 원본의 그림 질감은 구현하지 않았다. |
| l54 | 민트 원·사각 배경과 농업 아이콘을 복원했다. 본문 색·강조 굵기·줄바꿈을 조정하고 표지의 곡선 영문을 개별 편집 가능한 글자로 배치했다. | 온실·밭 사진과 상세 농부·시설 삽화는 회색이다. 곡선 영문은 원본 자간·기울기의 근사치다. |
| l55 | 기하학적 지도 도로와 교차선·위치 표시를 수정했다. 기울어진 무료교육 배지, 말풍선 꼬리, 흰 점 격자, 작은 장식을 복원했다. 기본 파랑을 원본의 밝은 색으로 맞추고 중복 지도·와이파이 아이콘을 제거했다. | 사진·복잡한 삽화·QR은 회색이다. 지도는 편집 가능한 도로 중심선이며 일부 미세한 지형 차이가 남는다. |
| l56 | 실제 로드한 Sunflower의 300·500 획을 비교한 뒤 축제 영문의 혼합 굵기를 적용했다. 본문·강조 색과 줄바꿈, 노랑 배경, 음표·잎·공지 삼각형을 수정했다. | 복잡한 축제·악기 그림은 회색이다. 원본 서체 파일이 없으므로 외형이 가까운 실제 로드 서체를 사용했다. |
| l57 | 전화와 운영시간의 강제 폭 맞춤을 제거해 자연스러운 숫자 폭·굵기로 바꿨다. 사진 원형 윤곽, 지도 사선·교차선, 말풍선과 상단 잘린 탭을 복원했다. 파랑을 원본의 밝은 색으로 수정했다. | 인물 사진·복잡한 삽화·QR은 회색이다. 일부 지도 선과 손그림 기호는 기본 도형으로 근사했다. |
| l58 | 날짜의 강제 폭 맞춤을 제거하고 굵기·간격을 수정했다. 작품명과 영문 제목을 분리해 겹침을 없앴다. 노랑·파랑 별 장식과 보라 반원, 작품 구분 점선을 복원하고 실제 없는 한글 이탤릭을 제거했다. | 전시 작품·사진·복잡한 표지 그래픽은 회색이다. 인용문은 실제 제공되는 바른 한글 획을 사용하므로 원본의 기울기와 다르다. |
| l59 | 편집 가능한 지붕선과 화살표·준비서류·시설 아이콘을 복원했다. 원문 본문과 소제목의 굵기·크기·문단을 조정하고 잘못 더한 표지 지붕 장식을 제거했다. | 시설 사진·인물·복잡한 풍경 배경은 회색이다. 기본 지붕선과 아이콘의 세부는 원본과 다르다. |
| l60 | Sunflower 500의 실제 획으로 표지·지원 제목을 조정하고 두 줄 제목의 폭·자간을 고쳤다. 핵심가치와 장식을 분리하고 전구·손 아이콘, 원본 노랑, 지원 칩 색·별도 윤곽·긴 제목 폭·본문을 수정했다. 불필요한 작은 칩 테두리를 제거했다. | 사진과 청소년 단체 삽화는 회색이다. 지원 아이콘과 손그림 장식은 Lucide로 근사했다. |

검수는 `node scripts/render.mjs --round=revision-c l49 ... l60`으로 진행했다. 첫 수정 출력과 후속 수정 출력에서 24쌍 전체 펼침면을 실제로 열어 비교했고, 마지막에는 12종의 6패널 contact 이미지도 모두 열어 확인했다. 이 과정에서 전화번호 줄바꿈, 표지 제목 줄바꿈, 겹친 지도 기호, 가려진 원형 배지, 프레임의 내부 좌표 축척과 곡선 영문 마지막 글자 오류를 고쳐 같은 회차로 재출력했다. 마지막 4종(l51·l52·l58·l60)의 서체·HACCP·점선·칩 수정 후 출력도 다시 확인했다.

최종 각 종 출력은 6패널·2펼침면 모두 자동 검사 `0 findings`이며 `npm run typecheck`도 통과했다. 원본 전체 배경 이미지를 사용하지 않았다. 사진·복잡한 그림·QR·그래픽 질감의 회색 자리 표시자는 요구된 처리이며, 기본 색면·도형·테두리·본문은 편집 가능한 요소로 유지했다.

서체 검증: 이전 Figtree 요청과 설치 CSS의 `Figtree Variable` 가족명 불일치로 대체 서체가 사용될 수 있었음을 확인했다. 공유 별칭은 root에서 수정했다. l56·l60은 실제 렌더링한 여러 서체의 획을 비교해 Sunflower를 선택했으며, 한 가지 400 face만 제공되는 장식 서체에는 400을 명시했다. l51의 Noto Serif KR 한글과 l58의 Pretendard 한글에는 실제 이탤릭 face가 없으므로 합성 이탤릭을 요청하지 않는다.
