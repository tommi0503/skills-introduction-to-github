# 통합 최종 검수

각 담당자는 12종씩 6명으로 총 72종을 구현하고 원본과 비교·수정하는 2회 검수를 마쳤습니다. 통합 담당자는 3차 final 회차에서 72개 비교 contact의 원본·구현 접지면 432쌍 전부를 시각 검토했습니다. 수정된 화면은 같은 final 회차에서 다시 출력해 제출물에 반영했습니다. 새 4차 비교 회차를 생성하지 않았습니다.

## 검증 방법

일반 글자와 칩은 각 페이지의 실제 폰트 파일·한글 subset을 로드한 뒤 두 animation frame 후 캡처했습니다. 432개의 접지면과 144개 펼침면의 글자 넘침, 칩 실제 잉크 중심, 원본 통째 배경 삽입 여부, 폰트 요청 오류를 검사했습니다. Canvas letterSpacing이 normal이면 이전 글자 간격을 유지하는 검증기 오류를 0px 초기화로 수정했고 l16의 4개 칩이 실제로는 올바른 중심임을 독립 metric 계산으로 확인했습니다. inkFit의 높이는 line box 대신 원본 목표 잉크 영역을 검사합니다.

`verification.json`은 최종 화면 정의 및 공유 렌더러 SHA-256이 모든 캡처와 동일한지, 72종/432페이지, 실제 생산 빌드의 갤러리·6면/2면 이동·원본 비교, 동일한 캔버스, 비율 보존, 실제 font 파일, 단색 placeholder와 JavaScript 오류를 검증합니다. ZIP에는 page crop 및 PNG SHA-256 manifest가 있고 압축 CRC와 모든 PNG 크기를 확인합니다.

## 원본 자료에 따른 차이

작은 WEBP에는 실제 폰트 메타데이터가 없습니다. 제목·본문의 가장 가까운 실제 설치 폰트와 굵기를 선택했으며 원본의 모든 서체가 정확히 동일하다고 단정하지 않습니다. 복잡한 이미지·그래픽 배경은 요청한 회색 placeholder입니다. 손글씨·복잡한 브랜드 표식은 실제 가까운 폰트 또는 이미지 placeholder를 사용했습니다. 일부 곡선 문자 배치는 가로 텍스트로 표현했습니다. 작은 판독 불가 문구는 자연스러운 대체 문구이며 회색 선으로 숨기지 않았습니다. 담당자별 구체적인 대체 기록은 group-a~f.md에 있습니다.
