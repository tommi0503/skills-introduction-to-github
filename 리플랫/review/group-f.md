# Group F — l61–l72

Scope: 12 brochures, 24 original spreads, 72 separate fold panels. Every original 121–144 was individually opened before implementation. All panel pages retain their native aspect ratio, upright within a uniform 1280×720 output canvas.

## Implementation

Each spread uses native 1280×909 coordinates. Text is authored from the readable original, rather than leaving the fragmented OCR output. Reusable helpers build tables, maps, ink-centered chips, numeric charts, headings, body paragraphs, progress rings and source surfaces. Solid rectangle backgrounds, borders and rounded cards remain editable. The full reference image is never included in a rendered page.

Photographs, complex doctor/children/Jesus illustrations, QR codes, certification logos, brushed/gradient/dotted/checker/flower backgrounds use solid #e5e5e5 image placeholders. Lucide supplies simple stethoscope, clipboard, syringe, heart, wallet, package, map, telephone, fingerprint and discussion icons. Explicit text uses the actual loaded Pretendard weights, Black Han Sans display font, Jua and Nanum Pen Script. Original unreadable microcopy is written as coherent copy, never text-shaped grey lines.
