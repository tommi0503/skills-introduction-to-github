# 그룹 E: l37–l48

- 범위: 073–096번 원본 24장, 12종 3단 브로셔. 앞·뒷면 각각 3접지면으로 분리한 72페이지.
- 최초 분석: 원본 24개를 각각 직접 열어 배치, 여백, 사진 영역, 제목, 본문, 가격표와 일정을 확인했다.
- 구현: 원본 좌표 데이터로 텍스트·상자·테두리·표·Lucide 아이콘을 구성했다. OCR 오검출이 많아 원문을 수동으로 입력했다. 원본 이미지를 결과 화면에 삽입하지 않았다. 사진·복잡한 일러스트·QR·그래픽 배경은 #e5e5e5 단색으로 대체했다.
- 판독 불가능한 작은 카페 설명 등은 자연스러운 관련 문구를 작성했다. 문구를 회색선으로 대신하지 않았다.
- 실제 로드 폰트: Pretendard Variable, Jua, Do Hyeon, Noto Serif KR, Tinos, Lilita One, Montserrat Alternates, Montserrat Variable, Roboto Condensed Variable, Bodoni Moda Variable, Nanum Pen Script. 원본의 전용 폰트가 특정되지 않은 경우 가까운 실제 서체를 사용했다. 자동 글자 폭 늘리기를 해제하고 실제 폰트 크기로 렌더한다.
- 펼침면의 1/3을 각각 잘라 동일한 1280×720 캔버스 중앙에 비율을 보존해 배치한다. 페이지 회전은 없다. 원본에 있는 센터 홍보의 세로 장식 문구만 독립 텍스트 요소를 회전한다.

## 비교 1

24개 펼침면을 각각 원본/구현 비교 이미지로 직접 확인하고, 12개 접지면 비교 그리드의 72개 접지면을 확인했다.

- l37: 배우 사진 위치, CAST 및 배우명 배지, 안내표와 가격 타이포그래피를 비교했다.
- l38: 가을축제 제목 줄바꿈, 행사 시간표, 주차 안내, 시간 칩과 지도 영역을 비교했다.
- l39: 가격, 구이 구성, 선물포장 항목, 아치형 카드와 정렬을 비교했다. 흰색 카드의 위 모서리만 둥글게 수정했다.
- l40: 프로그램 시간과 본문 기준선을 원본 위치에 맞추고, 일정 타임라인을 복원했다.
- l41: 원두 품목, 가격 행, 두 개의 카페 소개 면, 메뉴 사진 범위를 비교했다.
- l42: 연극 소개, 시놉시스, 반복 추천사, 출연자 사진과 정보 표를 비교했다.
- l43: 사진 위 캡션 배경을 사진 뒤가 아닌 위에 표시하고, 수치·영문 제목·사선 없는 프레임을 확인했다.
- l44–l45: 센터 소개 과정, 요금표의 실제 셀과 줄바꿈, 서비스 카드, QR와 사진 범위를 비교했다.
- l46–l47: 금융 점검 항목, 금융 전략, 단계별 카드, 표, 아이콘, 사진과 그래픽 배경의 대체 영역을 비교했다.
- l48: 오케스트라 가격표와 공연 프로그램의 셀, 출연진 설명, 영문 세리프 제목과 구성을 비교했다.

## 비교 2

수정한 24개 펼침면을 각각 다시 직접 대조하고 12개 접지면 비교 그리드의 72개 접지면을 다시 확인했다. 에이전트의 시각적 비교는 두 차례이며, 이후의 같은 review-2 렌더 갱신은 자동 검사에만 사용했다. 최종 3차 시각 비교는 부모 에이전트가 담당한다.

- 제목과 본문을 폭에 강제로 늘리던 inkFit를 모두 해제했다. 영문 제목은 실제 굵기가 있는 서체로 맞추고, Tinos의 불필요한 굵기를 줄였다.
- 칩의 좌우 정렬을 중앙으로 수정하고 실제 글자 중심을 검사했다. 뮤지컬의 검은 캡션과 배우 배지 모서리, 금융의 분홍 태그 배경을 원본에 맞췄다.
- Noto Serif KR의 긴 한 줄이 자동으로 꺾이는 문제를 확인했다. 각 폰트·굵기·실제 문자열을 모두 로드하고, geometricPrecision을 적용한 실제 DOM의 nowrap 폭을 측정해 크기를 조정했다. Canvas 측정만으로 판단하지 않았다.
- 일반 본문과 굵은 제목을 분리했다. 카페의 CAFE/MIRIDANG 제목을 별도 크기로 분리했고, 연극 추천사·소개 및 오케스트라 본문의 줄간격을 조정했다.
- 실제 글자의 칠해진 범위에 맞게 텍스트 요소 높이를 조정했다. 일반 텍스트의 위치·크기·줄간격과 줄바꿈은 유지했다. 범위를 늘리는 조정으로 가려진 글자를 만들지 않는다.
- 센터의 세로 장식 문구를 원본 방향과 위치에 복원했다. 1280×720 페이지 캔버스는 수평으로 유지했다.

## 검증 범위와 한계

사진·복잡한 일러스트·그래픽 배경이 회색으로 바뀌는 차이는 사용자 지정 구현 기준이다. 글꼴 이름을 원본에서 특정할 수 없는 경우 가장 가까운 실제 폰트를 사용하므로 글자의 세부 윤곽까지 동일하다고 주장하지 않는다. 작은 원본에서 확인할 수 없는 문구는 읽을 수 있는 자연스러운 본문으로 작성했다.

최신 review-2 자동 갱신 결과: l37–l48의 72개 접지면 및 24개 펼침면에서 텍스트 폭 초과, 칠해진 글자 높이 초과, 칩 시각 중심 이탈이 모두 0건이었다. 24개 SidePatch에 독립 UI 요소 1,269개와 이미지 대체 영역 138개를 정의했다. TypeScript 검사 및 production build가 통과했다.
