# l13–l24 개선 재검수

`patch-d.ts`만 수정했다. 원본과 기존 final의 펼침면 24장을 모두 실제 이미지로 비교했고, revision-d의 펼침면 24장과 contact 12장을 두 번의 개선 검수 안에서 확인했다. 두 번째 검수에서 발견한 제목 잉크 크기, 같은 단어를 가진 일정 본문의 위치 변경, CAST chip 높이, 제목 높이 문제를 교정하고 같은 revision-d 폴더에 다시 출력했다. 부모 검수의 l17 serif 지적과 추가된 실제 Russo One400도 반영했다.

사진, 상품, 복잡한 장식 일러스트와 QR은 #e5e5e5 자리 표시자다. 원본 UI 전체 이미지는 사용하지 않았다. 단순 책·지도·막대 차트·카드·접기 심볼·선·곡선과 텍스트는 실제 도형, SVG, Lucide와 실제 로드한 폰트로 구현했다. 출력 화면 1280×720과 원본 지면의 균일한 축척을 유지했다.

검증: 두 번째 전체 렌더와 마지막 부모 피드백·Russo One·단순 지도 추가를 같은 revision에서 재출력했고, 12종 각각 6패널·2펼침면의 findings는 모두 0이다. 지도 명칭의 텍스트 높이도 추가 교정했다. `npx tsc -p . --noEmit`은 통과했다. 전체 지면 비교 24장·contact 12장과 마지막 변경한 l16/l17/l21의 펼침면을 실제 이미지로 확인했다.

통합 검수 후 l15의 서명체 네 문구만 추가 교정했다. 실제 로드된 Pinyon Script와 Allura의 specimen을 비교하여 원본의 큰 기울기와 연결선을 가진 Pinyon Script400을 선택했다. l15 재출력은 6패널·2펼침면·0 findings이고, 원본과 재출력 양면을 실제 이미지로 재확인했다. TypeScript 검사도 다시 통과했다.
