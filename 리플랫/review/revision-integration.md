# 품질 개선 및 재검증 — 2026-10-06

사용자의 재검증·개선 요청에 따라 서브 에이전트 6명이 각각 12종을 맡아 72종 전체를 다시 검토했다. 각 담당자는 원본 24장과 앞·뒷면 비교 24쌍, 접지면 비교 contact 12장을 실제로 열어 두 차례 수정·검수했다. 통합 담당자는 새 final 출력의 72개 contact에 있는 432개의 원본·구현 접지면 쌍 전체를 직접 시각 검토했다. 자동 검사 0건을 원본과 동일하다는 증거로 취급하지 않았다.

## 실제로 발견하고 고친 문제

- Variable 폰트의 CSS family 이름과 지정 이름이 달라 일부 제목에 폴백 폰트가 적용되었다. 실제 family alias를 연결하고 Latin 폰트에는 명시적인 한글 동반 서체를 지정했다.
- 실제로 없는 italic·weight 조합을 사용하던 제목과 인용문을 로드된 face로 교정했다. 서명체는 Allura/Pinyon Script, SINEDU는 Russo One, 좁은 가을 행사 서체는 Sunflower의 실제 파일을 사용했다.
- OCR 초안의 축약·누락·잘못 읽힌 문구, 무의미한 회색 막대, 잘못된 줄바꿈을 원본 판독 또는 자연스러운 대체 문구로 다시 구성했다.
- 단순 지도·표·아이콘 배지·계단·장식 프레임·물결·책 도형·카드 구획을 재사용 가능한 벡터 및 UI 데이터로 보완했다.
- 잘못된 배경색과 가려지는 레이어, 숫자 폭, 라벨·칩·배지 정렬 및 본문 밀도를 교정했다.

통합 시각 검수에서 추가로 발견한 l15 연결 서명체, l28 단순 4잎 꽃, l29 제목 굵기, l32/l42 동일 원본의 서명체 일관성, l61/l67 흰 본문과 회색 인물 구획 겹침, l10 누락된 일러스트 placeholder를 수정하고 해당 final 출력도 다시 확인했다. l17의 제목을 원본에 맞는 serif로 유지하고 INFO만 sans로 적용했다.

## 최종 증거

- `revision-a~f.md`: 72종별 구체적인 수정과 남는 차이.
- `font-verification.json`: 한글·영문 샘플을 각각 검사한 실제 family/weight/style 조합, 전체 데이터 및 렌더러 SHA-256.
- `verification.json`: 모든 최신 캡처와 소스의 해시 일치, 전체 페이지 수·크기·단일 배율, 실제 폰트, 칩 잉크 중심 및 글자 넘침, JavaScript 오류, 생산 빌드의 갤러리/접지면/펼침면/원본 이동 확인.
- `revision-inventory.json`: 첫 제출 이후 72종별 데이터 변경 여부 및 비교 근거.
- `leaflet-review.zip`: 최종 원본·구현 접지면 비교 72장 및 검수 기록.
- `leaflet-before-after-1.jpg`, `leaflet-before-after-2.jpg`: 원본 / 첫 제출 / 개선본 3열 비교 8사례. 첫 제출 PNG는 이전 Git 제출 ZIP에서 추출한 실제 출력이다.

432개의 독립 접지면과 144개의 펼침면 PNG를 전부 새로 출력했다. 모든 캔버스는 1280×720이며 원본 접지면의 종횡비를 유지했다. 원본을 구현 배경에 통째로 깔지 않았다.

## 남는 차이

원본 WEBP에 정확한 서체 메타데이터가 없어 가까운 실제 서체를 선택한 제목·손글씨에는 획 모양 차이가 남는다. 일부 곡선 문자·장식·로고는 기본 기하 또는 Lucide 근사이다. 사진·기기·복잡한 일러스트·그래픽 배경은 요청에 따라 단색 #e5e5e5로 대체했으며 해당 배경 위 흰 글자는 원본보다 대비가 낮아질 수 있다. 판독 불가 작은 글은 자연스러운 안내문으로 작성했고, 각 담당 기록에 구체적인 대체를 명시했다. 픽셀 단위 완전 일치라고 주장하지 않는다.
