# 021 폴더링 프레젠테이션 검수

README 계약을 끝까지 읽고, slide_02–slide_11 원본 10장을 각각 열어 확인했습니다. 발표용 폴더 탭, 짙은 남색 선, 살구·분홍·황토·민트 팔레트, 둥근 상단 모서리, 굵고 둥근 제목을 편집 가능한 scene 데이터로 재현했습니다.

## 페이지별 해석과 차이

- 02: 4개 카드, 연결선과 원형 노드, 전 문구 재현. 원본 손 모양·연결망·연필 아이콘은 Lucide로 치환. 복합 원형 IMPLEMENT 아이콘은 편집 가능한 중첩 링 SVG로 재현.
- 03: SWOT 4분면과 퍼즐 조각을 직접 SVG로 그림. 원본과 같은 텍스트 구성.
- 04: 강점 2열 설명과 20/40/70/80/100 면적 그래프 재현. 그래프는 SVG 벡터와 편집 가능한 값 라벨.
- 05: 약점 면적 그래프, 감소 콜아웃, 우측 설명 2단 재현.
- 06: 7/12/16/23 둥근 막대 그래프 및 설명 카드 재현.
- 07: 표와 50/30/20 도넛 차트 재현. 원본의 강조된 2배는 전체 결론 문장 안에 포함.
- 08: 커피 추출 사진 전체를 지시대로 연한 회색 placeholder로 변경. 우측 반투명 남색 구역과 문구는 보존.
- 09: 카페와 스마트폰 사진 2장을 연한 회색 placeholder로 변경. 사진 속 글자는 기기 화면 이미지에 해당하여 재현 제외.
- 10: 양쪽 7행 참고문헌 표 모두 재현. 작은 원본의 일부 띄어쓰기·구두점은 일반적인 한국어 참고문헌 표기법에 맞추어 정리.
- 11: 폴더 탭 실루엣과 제목·팀·학생정보 재현. 원본 동그라미 숫자 3은 Unicode ❸으로 표현.

실제 폰트: NanumSquareRound / Jua를 요청하여 원본 본문과 제목의 서체 언어를 반영. 복잡한 사진을 제외한 원본 전체를 결과 배경으로 사용한 곳은 없습니다.

## 시각 검토

1차: 원본 10장 개별 확인 후 좌표·선·색·표·그래프 값을 대조하여 제작.
2차: Chromium 1280×720 렌더 10장을 원본과 나란히 놓은 개별 비교 이미지로 전부 검토했습니다. 우측 탭의 색 순서가 활성 장별로 달라지는 점을 교정했고, 마지막 좌측 탭의 겹침 순서도 수정했습니다. slide_08 설명이 네 줄로 감기던 2건을 세 줄로 조정했습니다. 가로·세로선 렌더 누락은 공통 렌더러의 0px 치수 문제로 확인하여 주 에이전트에게 수정 요청했습니다. 최종 통합 렌더에 이 수정과 폰트·테두리 교정을 반영합니다.

최종 보정: 별도 공개 제목 폰트 후보의 배포 URL이 404여서 실제로 확보한 Jua를 사용했습니다. 원본보다 가는 제목의 차이는 굵기 900, 외곽 음영, 한글 제목 +4px 및 세로 +6px로 보정했습니다. 흰색 4P 제목은 남색 3px 외곽효과, 마지막 감사 제목은 가로 중심 +30px로 원본에 맞추었습니다. 추가 폰트에 대한 추정은 폰트 메타데이터 부재로 확정할 수 없으며 원본과의 남는 차이로 기록합니다.
