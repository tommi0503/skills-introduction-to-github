# 주 에이전트 통합 검수

참고 이미지 7덱82장과 첨부 README 전체를 먼저 확인했습니다. 각 담당 에이전트가 모든 원본을 개별 열람하고 Chromium의 원본/결과 비교를 페이지별로 검토했습니다. 덱별 기록과 라이브러리 32요소(31+foundation) 양모드64개 개별 시각 검수 기록을 함께 보존합니다.

주 에이전트는 021/04, 022/06, 028/14, 030/09, 031/06, 033/05, 034/03의 비교 이미지를 개별 열람하며 공통 구조와 핵심 차트·표·타이포를 통합 검토했습니다. 모든82장은 최종 치수·텍스트·chip·이미지 미사용 검사 및 재조립 픽셀 비교로 확인했습니다. 연락처 시트만으로 페이지 검수를 대체하지 않았습니다.

주 검수에서 SVG 가로선 높이0 때문에 선이 약23px 아래 그려지는 공통 렌더 버그를 발견해 `svg{display:block;position:absolute}`로 수정했습니다. 제목·문단을 포함한 재현본 검사는 수정 후 경고0건입니다. 재조립 DOM의 wrapper를 포함한 Range 검사에서 허위 넘침이 발생해 실제 텍스트 노드의 Range를 검사하도록 고쳤으며 PNG 픽셀 비교도 병행했습니다.

라이브러리 검수의 실제 수정: figure 행간, 좁은 funnel, 가격표 추천 tag, pill 세로 스트레치, matrix 축 라벨, Venn 중앙 겹침과3중교집합, hub 대각 연결선, hierarchy 가로 연결선, cycle3–6노드 배치, stack안 차트 높이, preview.frame 선택자 충돌. 최소 칸에서 장문이 넘치는 일부 요소는 반응형 여백·타입 단계를 줄이고 정확한 최소 칸을 fixture에 명시했습니다. 최종 시트와 PNG를 다시 만들었습니다.

원본 재현은 덱별1차 비교/수정, 최종 통합 비교/공통 수정으로 최대3회 이내에 제한했습니다. 이후 실행은 PDF/최종 파일의 일치·해시와 자동 검사 검증을 위한 것입니다. 세부 수치의 근거는 `verification.json`, 각 모드 `final/*.json`, `final-render-hashes.json`입니다.
