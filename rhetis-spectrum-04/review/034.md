# 034 개별 시각 검수

- README 전체를 읽었다. 원본 5장 모두 1280×720으로 개별 열람하고 Chromium 원본/결과 비교 5장도 각각 검토했다.
- 사진·3D 원환·큐브·원뿔·파형 장식은 연회색 단색 placeholder로 대체했다. 평면 배경 그라데이션과 편집 가능한 표·차트·선·문자는 직접 구현했다.
- 원본의 정확한 서체 이름은 확인할 수 없어 실제 로드한 Pretendard 200/500/800을 사용했다. 영문 보조 문구도 동일 계열을 사용한다.
- 에이전트 비교 1회 후 수정하고 메인 최종 통합 렌더로 2회째 확인한다.

| 페이지 | 개별 확인 및 수정 |
|---|---|
| 01 | 보라색 배경, 노란 가는 제목, 흰 굵은 제목, 좌하단 담당자와 상단 고정 문구의 위치 확인. 원본보다 제목이 좁은 문제를 글자 크기·자간으로 수정. 3D 그래픽 3자리는 회색 처리. |
| 02 | 좌측 921px 분할, 질문 3행, 우측 2행 문구 확인. 큰 따옴표는 글꼴에 따른 모양 차이를 없애기 위해 평면 SVG로 직접 작성. 질문 글자 폭과 크기를 보정. |
| 03 | 4개 둥근 성과 카드의 동일 너비·날짜·가로 구분선과 배경 사진 자리 확인. 제목의 가는 부분/굵은 부분의 크기를 원본에 맞춰 수정. |
| 04 | 좌측 588px 인물 사진 자리, 우측 제목, 겹치는 2개 그림자 카드와 대표명 위치 확인. 굵은 제목과 뉴스 문구 폭을 수정. 하단 설명의 긴 점은 원본 문구의 실제 마침표이며 가짜 글자 선이 아니다. |
| 05 | 5개 막대, 상승 연결선과 노드 5개, 우상단 설명 카드 확인. 큰 제목의 폭을 보정. 차트는 수치·편집 가능한 SVG/상자이며 원본 그래픽을 사용하지 않았다. |

초기 자동 검사에서 나온 장식 따옴표의 글꼴 메트릭 초과는 SVG 전환으로 해결했다. 원본의 그라데이션 글자는 단색 보라로 근사했다. 최종 텍스트 넘침·폰트·페이지 크기는 메인 자동 검사로 재확인한다.
