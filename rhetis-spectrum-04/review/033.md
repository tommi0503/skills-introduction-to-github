# 033 개별 시각 검수

- README 전체를 읽고 형식 계약과 사용자 요청을 구분했다. 원본 11장 모두 1280×720으로 개별 열람했다.
- 실제 Chromium 렌더의 원본/결과 비교 이미지 11장을 각각 검토했다. 에이전트 검수 1회와 통합 최종 검수의 2회 절차를 사용한다.
- 실물 사진, 직물·목재 텍스처, 인물은 요청에 따라 연회색 단색 placeholder로 대체했다. 원본 이미지를 렌더에 사용하지 않았다.
- 원본 서체 이름은 이미지에서 확정할 수 없어 실제 로드한 Bodoni Moda 400/900와 Pretendard 300을 사용했다.
- 회색 사진 자리 위의 흰 문자는 읽기 어려워 01·10·11의 표지/헤더 문자를 브랜드의 갈색으로 바꾸었다. 사진 부재에 따른 의도적인 차이다.

| 페이지 | 개별 확인 및 수정 |
|---|---|
| 01 | 큰 영문 제목이 2행으로 감긴 것을 확인하고 폭 1000px·100px 크기로 조정했다. 부제와 하단 룰의 위치 유지. |
| 02 | 사진 594×363의 위치, 목차 타원 라벨, 세 범주의 세로 간격 확인. Bodoni의 큰 상하 메트릭에 맞게 텍스트 상자를 확장. |
| 03 | 우측 두 사진 자리와 하단 한국어 3행의 구성을 비교. 제목 크기를 65px로 조정해 원본 폭에 가깝게 수정. |
| 04 | 296px 너비의 중앙 사진 자리, 좌측 2행 제목, 우측 3개 기준의 위치 확인. 제목 상자 높이를 확장. |
| 05 | 4개 카드의 이미지·캡션 경계와 여백 확인. BRAND MOOD가 줄바꿈된 문제를 폭 600px로 수정. |
| 06 | 제품 소개와 2×2 정보 패널의 테두리·구분선 확인. 향수 아이콘은 Lucide FlaskRound로 대체. |
| 07 | 3열×5행 표와 아래 문구 패널 확인. 우측 ORDINARY DAYS를 한 줄로 고치고 제목 크기를 조정. 원본의 'Rainy Daym light' 철자는 유지. |
| 08 | 좌측 3개 목재 텍스처 자리를 단색 처리. 우측 3개 가치 패널과 중앙 연결선을 확인. |
| 09 | 640px 사진 분할, 제목 아래 세로 룰과 3개 고객 유형의 줄바꿈 확인. |
| 10 | 상단 목재 사진 자리와 중앙 문구·직접 작성한 벡터 모서리 장식 확인. 상단 우측 영문 라벨을 한 줄로 수정. |
| 11 | 사진 전체를 연회색 처리하고 한 줄 제목과 THANK YOU·양쪽 선의 위치 확인. |

큰 서체의 DOM Range 높이 초과는 실제 Bodoni 메트릭을 수용하도록 텍스트 상자를 확장해 수정했다. 마지막 변경은 메인 통합 최종 렌더로 확인한다.
