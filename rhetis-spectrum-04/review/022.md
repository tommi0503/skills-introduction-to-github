# 022 — 마케팅팀 스터디 회의록

## 원본 확인 및 구현 결정

- 참고 이미지 9장을 각각 원본 크기로 열어 확인했다. 장면 크기는 모두 1280×720이다.
- 모눈 배경, 넓은 노란 제목 띠, 검은 외곽선, 파랑·분홍·노랑 강조와 그림자를 공통 디자인 언어로 읽었다.
- 텍스트와 도형은 편집 가능한 scene data로 구성했다. 모눈, 폴더, 웃는 얼굴 및 원형 차트는 단순 벡터 도형이다.
- 사진 3장은 요청에 따라 원형 회색 placeholder로 대체했다. 창 삽화는 재사용 window/picture/folder 구조로 그렸다.
- 영문 제목은 Bebas Neue, 굵은 한글은 Pretendard 900, 본문은 Pretendard를 사용한다. 원본의 정확한 폰트 파일은 제공되지 않아 글자 형태가 가장 유사한 로드 가능한 폰트로 해석했다.

## 브라우저 비교 1회 및 수정

통합 브라우저 렌더의 9개 비교 이미지를 각 장씩 열어 원본과 나란히 확인했다. 연락처 시트로 대체하지 않았다.

- 01: 창 위치와 크기는 거의 일치했다. 제목 폭과 굵기가 부족해 한글을 Pretendard 900으로 조정하고 100px 및 좁은 자간을 적용했다. 커서와 휴지통 아이콘의 사각 배경을 제거했다. 작은 사진 아이콘은 원본처럼 분홍 바탕으로 수정했다.
- 02: 버튼 위치·길이·색·텍스트 중심을 확인했다. 제목 폭을 원본에 맞추도록 크기와 자간을 조정했다.
- 03: 타겟 카드의 크기와 색, 본문 위치를 확인했다. 오른쪽 안내 문구를 원본의 3줄 줄바꿈으로 명시했다. 연결선 누락은 공통 렌더러의 0 높이 선 처리 수정으로 해결된다.
- 04: 일정 아이콘 박스·설명·연도 위치를 확인했다. 일정점의 네모 배경을 제거하고 원본의 별 모양 마커를 단순 SVG로 수정했다. 아이콘 내부의 미세 형태는 Lucide 표현으로 남긴다.
- 05: 도넛 30/30/40 구성과 위치, 레이블을 확인했다. 큰 폰트 글리프의 세로 측정값이 박스를 넘는 자동 경고를 해결하기 위해 영문 텍스트 박스의 높이만 늘렸다.
- 06: 막대 값과 위치를 확인했다. KPI 한글의 폭·굵기를 보정했다. 기준선은 공통 선 렌더러 수정으로 복원된다.
- 07: 인물 placeholder의 원형 크기, 색 테두리, 카드 크기와 중심 정렬을 확인했다. 구분선은 공통 선 렌더러 수정으로 복원된다.
- 08: 일정 막대와 날짜를 확인했다. 기존 날짜와 막대 좌표는 유지했다. 제목 크기와 자간을 보정했다.
- 09: 축소 창의 제목 바를 원본처럼 22/32px 높이로 수정하고 컨트롤 버튼도 비례 축소했다. 그림 프레임의 비율을 실제 칸에 맞추고 마지막 창 그림의 바탕/산 색을 분홍/파랑으로 보정했다. 빈 파란 말풍선 2개는 box로 표현해 빈 chip 측정 경고를 없앴다.

자동 검사 13건은 큰 영문 글리프 범위가 작게 잡힌 텍스트 박스를 넘은 11건과 빈 chip의 중심을 잘못 측정한 2건이었다. 글자 크기를 줄여 숨기지 않고 텍스트 박스 높이 확장 및 빈 장식의 box 전환으로 수정했다. 마지막 수정의 최종 브라우저 반영 확인은 주 에이전트의 통합 최종 렌더에서 수행한다.

남는 차이: 정확한 원본 폰트 파일이 제공되지 않았고 일부 시스템 아이콘의 세부 획은 Lucide 기준이다. 원본 사진은 의도한 회색 placeholder이며, 임의의 사진으로 교체하지 않았다.
