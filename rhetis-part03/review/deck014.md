# 014 네온색의 세련된 기업 경영 보고서

원본 PNG 20개를 각각 열어 텍스트, 좌표, 색, 정보 위계를 확인했습니다. 공통 왼쪽 내비게이션, 브랜드 표기, 회색 패널, 네온 하이라이트와 본문 표를 재사용 가능한 요소 데이터로 구성했습니다. 모든 슬라이드 기준 크기는 1280×720입니다.

## 구현 판단과 원본 차이
- 11번의 원형 사업 사진 3개는 요청에 따라 연한 회색 단색 placeholder로 교체했습니다.
- 1, 7, 15번의 복잡한 네온 곡면은 CSS 그라데이션과 타원형 곡선으로 직접 재구성했습니다. 원본의 빛 번짐과 곡률은 근사치입니다.
- 브랜드 심벌과 특수 픽토그램은 Lucide 아이콘으로 대체했습니다. 6번 SWOT은 둥근 사분면 패널로 재구성했습니다.
- 13번 게이지와 레이더 차트는 선·다각형, 막대형 지표는 개별 요소로 구현했습니다.
- 읽을 수 있는 한국어와 수치는 원문을 옮겼습니다. 보고서 데이터의 원본 내부 불일치(예: 목표 대비 달성률)는 디자인 재현을 위해 유지했습니다.

## 검사
- TypeScript 정적 검사 통과: 기존 app-ui-clone TypeScript 도구로 deck014.ts 단독 검사.
- 원본 개별 열람 20/20 완료.
- Chromium 실제 브라우저 렌더 20/20 완료. 1차 개별 결과와 원본 확인 후 2차 수정, 3차 최종 렌더까지 총 3회 이내로 진행했습니다.
- 원본/결과 개별 나란히 비교 이미지 20개를 각각 열어 검토했습니다. `renders/review2/014-slide_XX-compare.jpg`에 저장했습니다.
- 1차 발견: 표지 곡면 색 면적 과다, SWOT 모서리, 마일스톤 긴 문장 줄바꿈, 레이더 외곽 미폐쇄, 정책 문구 줄바꿈. 2차에 수정했습니다.
- 글자 영역 자동 검사에서 큰 제목과 칩의 폰트 메트릭 높이 부족을 발견해 박스 높이를 조정했습니다. 마지막으로 8번 목표 수치 크기를 59px→56px로 조정했으며 통합 최종 렌더에서 재확인합니다.
- 20개 PNG 모두 1280×720 확인. 주요 표·패널 및 chip 텍스트 중심 확인.
- 남은 시각 차이: 배경 네온 곡률/광량, 브랜드 심벌, 특수 픽토그램, 게이지의 진행 호 길이, 작은 사람 도형/차트 보조선. 화면 구성과 실제 텍스트를 유지했습니다.
