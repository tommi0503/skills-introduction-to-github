# Seedmark 디자인 언어

원본 072 덱의 21장을 각각 관찰하고 독립 replica를 먼저 만들었다. 색상명은 replica 관찰 기록에서만 사용하고 라이브러리는 팔레트의 자리로 표현한다.

| 반복 규칙 | 원본 관찰 | 컬렉션 규칙 |
|---|---|---|
| 선 | 1–2px의 얇은 중립선, 일부 핵심 테두리만 진하게 | 기본 `--stroke`, 면의 경계 `--n-3`, 핵심 경계 `--ink` |
| 모서리 | 카드 약 14–16px, kicker 약7px, 의미 강한 캡슐은 완전한 타원 | `--radius:16px`, `--radius-sm:7px`, 캡슐999px |
| 여백 | 좌우84px, 상단64px, 섹션 제목74px, 제목134px, 본문281px | margin-x84px; gap24px/12px/36px; pad32px |
| 위계 | 아주 작은 페이지 가구, 작은 영어 kicker, 가벼운 한글 제목, 굵은 명사·수치 | 본문18/행간1.65, 이름28, 수치40, 제목44, 표지96; 실제 Noto Sans KR |
| 강조 | 제목 한 구절의 사각 highlighter, 좌우 수직선과 좌상·우하 점; 그 밖은 검정 캡슐 | 구절 면 `--a1-2-soft`, 선·점 `--ink`; 핵심 캡슐 `--ink`/`--page`; `.on`은 계약에 따라 `--a1`/`--a1-on` |
| 면·선 | 흰 바탕과 얇은 윤곽이 우선, 아주 연한 중립 면으로 보조 정보 구분 | 기본 `--page`, 보조 카드 `--n-1`, 차트 나머지 `--n-3`; 시리즈 `--a1`…`--a4` |
| 장식 | 의미 없는 장식 없음. 작은 점은 강조구절 끝점, 원은 지표·집합·단계에만 사용 | 점·캡슐·원은 정보 역할이 있을 때만 사용 |

큰 칸에서는 구성원의 제목 시작선을 맞추고 본문을 중앙 쪽으로 분산한다. 작은 칸에서는 글자와 간격을 단계적으로 낮추며, 극소 칸에서 kick 다음 note 순으로 생략한다. 사진은 단색 회색 placeholder이고 라이브러리 seat는 번호가 있는 정사각형·원형 자리를 유지한다. 다크 모드에서도 단계의 의미가 유지되도록 모든 색은 팔레트 역할을 참조한다.
