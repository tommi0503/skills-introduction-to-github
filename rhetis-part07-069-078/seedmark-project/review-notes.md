## 원본→replica / replica→재조립의 차이 구분

- 원본→replica: 사진·인물·이미지 로고는 요청대로 연한 회색 자리로 대체했다. 원본 폰트의 정확한 이름을 확인할 수 없어 실제 로드한 Noto Sans KR을 사용했다. 일부 영문 폭과 작은 문구의 줄바꿈, 추정한 차트 값·곡률이 다르다. slide_13/14/20의 눈금 없는 차트 값은 상대 높이를 읽은 값이며 실제 관측 데이터라고 주장하지 않는다.
- replica→재조립: 제목과 카드·도넛·주요 문구를 유지하며, 재사용 가능한 계약 마크업의 조합으로 만들었다. 새 페이지 CSS나 좌표용 inline position/transform은 넣지 않았다. 요소 내부의 group/stack와 반응형 치수를 이용해 정수 칸 안에서도 원래 폭과 간격을 복원했다. 일부 작은 아이콘·차트 획과 본문 줄 폭은 여전히 차이가 있으며 완전 동일하다고 표시하지 않는다.
- 09 내부 flowchart는3열로 구성하고 공유 토큰 산술로302/431/302px 폭을 맞췄다. 실제 브라우저 x84/424.5/894px이다. 원통은98px 폭과128px 전체 높이(실린더 면112px+겹친 라벨)를 갖는다. 지그재그선의 화살촉과 Lucide 아이콘의 획 모양은 원본과 차이가 있다.
- 18은12열×4행 내부 flowchart를 사용한다. 콘트롤러/클라우드 행 간격은 원본92px에 가깝고 작은 기기3개와 출력경로를 보존했다. 세로·꺾인 배선의 위치와 일부 아이콘 도형은 원본과 다르다.
- 21은 foundation의 기존 .overrides 페이지 변형으로 body 하단을649px까지 열었다. 중앙열과 파이 지름360px, 중심(640,469), 하단649px를 실제 브라우저에서 확인했다. 다른 페이지의 body는 바꾸지 않는다. 30% 면의 글자/아이콘은 최종 source 복원에서 원본처럼 page(흰색)로 맞췄다. 일반 라이브러리 fixture의 대비 규칙은 유지한다.

## 최종 통합 검수의 계약 해석

- 필수 모범 fixture는 data-el의 컬렉션 접두사만 바꾸고 마크업·데이터·배치 값을 보존했다. 이 때문에 card-4의 원문 문자 아이콘과 callout-stack의 농업 문구는 일반 아이콘·비즈니스 문장 규칙의 예외로 남겼다. 새 아이콘은 빈 data-icon 방식만 사용했다.
- 모범 fixture 외의 최상위 배치는 12×6으로 정규화했다. 일반 prose-pair/prose-quiet의 농업 문구는 한국어 비즈니스 문장으로 교체했다. 일반 bullet fixture의 --v:104와104%는 계약 범위0–100을 지키도록96과96%로 함께 수정했다.
- 요소 시트는 제공된 기준 팔레트로 검수했다. 재조립은 원본 색을 공급하는 외부 source-palette, type-steps, JSON tokenDefaults 공급 파일을 사용한다. 이 파일은 페이지별 디자인 CSS를 추가하지 않는다.
- 독립 HTML의 기본 여백을0으로 맞추고, 로컬 글꼴과 Lucide 런타임을 넣었다. 이는 Rhetis가 제공하는 렌더 환경을 재현하는 공급부이며, 컬렉션 ZIP에는 CSS·JSON·MD·HTML만 있다.
- 페이지 PNG는1280×720, 원본과의 좌우 비교 PNG는2560×720이다. 요소 시트는 fixture 수에 따라 높이가 달라 실제 크기를 build-verification.json에 기록했다.
- 원시 overflow 후보에는 글꼴의 잉크가 line box를5–7px 넘지만 overflow:visible로 읽히는 경우가 포함된다. 별도 검수에서는 실제 잘리는 조상 영역과 주어진 칸의 범위를 확인했다.
- 제공된 팩에는 Rhetis 반입 엔진이 없어 upstream intake는 실행하지 않았다. 제공 preview CLI, 독립 정적 계약 검사, 실제 Chromium 출력과 ZIP 검사를 사용했다.

## 요소 시트 최종 개별 검수와 기능 보정

- 56개 요소와 foundation의 라이트·다크 PNG를 요소별로 각각 열어 검수했다. 전체 연락처 시트로 대체하지 않았다. 이후 실제 최소 칸과 12×6에서 28 fixture × 2 모드 × 2 크기, 총112개 브라우저 화면을 별도 확인했다.

- 최소 칸에서 달력 셀, 100단위 waffle, 인물 avatar, funnel 마지막 단계와 pyramid 꼭짓점의 실제 영역 초과를 수정했다. 높이가 한 칸인 모범 figure-waffle 두 개는 foundation stack에서 가로로 배치해 데이터와 문구를 모두 유지한다. bare callout seat도 정사각형으로 맞췄다. Balance의 음수 기울기와 bullet 목표 마커는 기존 동작이 올바른 것을 확인해 보존했다.
