# Crossrail 검수 기록

## 최신 검수의 기준

초기 재조립에서는 원본 도형과 정보 구성을 표준 요소 하나로 일반화했다. 사용자 지적을 받고 이 판단을 철회했다. 아이콘·연결 높이·본문·역방향·중앙 도해·다중 비중을 삭제하거나 바꾼 상태는 최종본으로 인정하지 않았다. 이 문서는 그 초기 해석을 대체한다.

원본 30장과 replica, 재조립의 개별 좌우 비교를 실제 Chromium에서 확인했다. 가장 먼저 지적된 10번은 원본 화살표 y320–399, 아이콘 행 y415, 이름 구분선 y488·542, 본문 y565를 기준으로 복원했다. 이후 같은 원칙을 30장에 적용했다. `qa/pass2-NN-compare.png`, `qa/pass3-NN-compare.png`는 수정 과정 증거이며, 제출본의 compare 폴더는 마지막 소스로 주 에이전트가 다시 렌더한다.

## 글꼴과 문구

이미지에는 글꼴 파일명이 없다. 원본 잉크의 너비·높이를 비교해 README 허용 표의 Noto Sans KR을 한국어 제목·본문에, Pretendard Variable을 영문 kicker·페이지 번호에 실제 로드했다. font-face는 100–900 가변 굵기를 등록했다. replica도 같은 실제 글꼴로 수정했고, review ZIP 내부에서 작동하도록 폰트 경로를 프로젝트 안의 `../assets/fonts/`로 고쳤다.

읽히는 본문은 축약하지 않고 보존했다. 09의 두 번째 설명과 29의 군집 설명, 24의 ‘원 그래프와’도 원본을 다시 읽어 바로잡았다. 24 원본 설명은 실제 원본 크기에서 네 줄이며 그 줄바꿈을 보존했다. 05의 작은 비전 설명 가운데 ‘비전으로 설득하고 싶은 부분은’은 흐린 원문을 문맥에 따라 읽은 부분이다. 원본의 20xx·00000·00% 같은 예시 값은 그대로 유지했다.

## 허용된 차이와 한계

사진·복잡한 아이콘 이미지는 요청대로 연한 회색 단색 자리다. 단순 아이콘은 실제 Lucide로 대체했다. 원본의 채워진 심볼과 선형 Lucide의 실루엣·채움은 다르다. 글자 안티앨리어싱과 24의 얇은 수치 외곽선도 원본 raster와 완전히 같지는 않다.

공유 12×6 그리드에 배치한 뒤 요소 안의 계약 CSS로 원본 기하를 복원했다. 일부 공통 제목·작은 본문의 잉크 너비, 자연 줄바꿈, 1–수 px 구성선 위치에는 raster와 차이가 남는다. 이 차이를 정보·아이콘·도형 삭제의 이유로 사용하지 않았다.

## 계약과 자동 검수

56개 요소에 독립 범위 CSS와 JSON·설명·fixture가 있다. 모범 fixture 28개는 data-el 접두사 외의 마크업과 데이터를 그대로 유지했다. card-4의 원문 ✹는 이 정확 보존 요구에 따른 예외이며, 새 아이콘은 빈 data-icon만 쓴다. 일반 fixture의 잘못된 --v:104 및104%는 루트 통합에서96으로 함께 수정한 상태를 보존했다.

원본 복원용 새로운 구성도 fixture에 넣었다. rich steps 3/4/5개, 세로 아이콘 steps, 반원·오각형·중앙 원 hub, 복합 원그래프, 주석형 막대 조립, 분할 roadmap, 실제 달력, 원형 사진, 수치 capsule 카드와 축 legend를 최소 칸과 12×6에서 검사할 수 있다. 기존 fixture는 덮어쓰지 않았다.

요소 시트는 제공된 기준 팔레트의 라이트·다크로 그린다. 원본 색은 외부 `source-palette.css`, JSON 기본값은 `source-defaults.css`가 공급하며 기하 페이지 CSS를 추가하지 않는다. 컬렉션 ZIP은 CSS·JSON·MD·HTML만 포함한다. CSS line/area는 임의 값의 이전점과 현재점을 CSS Anchor Positioning으로 연결하며 fixture 값에 따른 특수 분기를 쓰지 않는다.

현재 정적 검사: 요소 CSS 56개, 모범 fixture28개, 일반 fixture173개, 오류0·경고0. 마지막 source SHA에 대한 라이트·다크 실제 clipping·대비·페이지 크기·폰트·최종 렌더 일치 검수는 주 에이전트의 통합 보고서를 함께 본다. 제공 팩에는 upstream Rhetis 반입 엔진이 없으므로 제공 preview CLI와 독립 검사·Chromium 렌더로 검증한다.

## 마지막 대비 역할 보정

최소 칸의 실제 대비 검사에서 발견한 kicker·quiet kick·hub 보조어·legend 비중·pill 이름의 옅은 text 역할은 n7로 높였다. on headline의 note는 a1-on을 상속하며, roadmap의 일반 막대 면과 달력 일요일도 기준 팔레트에서 읽히는 역할로 교정했다. 원본의 의도적인 낮은 대비는 외부 source-palette에서 색 변수의 역할만 다시 매핑하여 보존하며 기하·폰트·fixture는 바꾸지 않았다. 주석형 막대 축은 별도 sibling이 그린 진한 패널 위에 겹쳐 있으므로 조상 배경만 보는 대비 탐지의1:1 후보와 실제 화면을 구분한다.

주 에이전트의 최종 원본 잉크 대조에서 표지01 제목은10px, 목차02·개요03 제목은6px 아래에 있던 replica 추정 좌표를 보정했다. 10 등 공통121px 제목 좌표는 이미 원본 잉크와 맞아 이동하지 않았다. 03의 사진 위 흰 패널 본문에만 외부 source 팔레트로 원본 #555를 공급했다.

## 페이지별 제목 잉크 기준선

원본과 최신 replica·조립본을60번 실제 브라우저 렌더하고 x96–450/y125–215 ROI에서 배경 median과 전경색으로 첫 잉크 행을 추출했다. 일부 원본은 제목이6–7px 높은 별도 기준선이며, 단일 공통 header를 전체 이동하는 것은 맞지 않았다. 각 페이지 실측 delta를 반대로 적용했다. kit의 namespaced length `--crossrail-head-offset`은 기본0이며 해당 source 페이지의 제목에만 공급한다. 06·10처럼 이미 일치하는 제목과 모든 본문·아이콘·도형 좌표는 이동하지 않는다. replica는 각자의 실측 top만 수정했다. 근거는 `qa/title-baselines-canonical.json`이다.

주 에이전트의 마지막30장 개별 삼중 대조에서 요청한 source 보정도 반영했다. 06 tier 사선을 삼각 외곽선으로 맞추고, 07 note를 원문 세 줄로 고정했으며, 08은 원본의 두 가로 구성선만 둔다. 12의 bullet과 세로선, 13의70px 아이콘·66px capsule·90px 간격, 14의22px 화살촉, 15 사진 뒤 가로선을 복원했다. 24 replica의 네 줄 문구가 재차 감기지 않도록 글상자 폭을 수정했다. 26의 두 번째 긴 막대는 중간 accent 역할이고 첫·마지막 lane에는 연한 타임레일을 둔다. 29 사선 화살표는 버전1 원 뒤에 가리고 표의 설명은 원본 navy 역할을 외부 provider로 공급했다. 신규 source 구조11개도 추가 fixture로 드러내 최종 검수 대상에 포함했다.
