# Meridian Deck — 디자인 언어

원본 `074_1iz0w_파랑_모던_비즈니스_제안서_설명` 30장을 각각 확대 확인하고, 독립 HTML replica를 먼저 만든 뒤 추출한 규칙이다. 샘플 컬렉션에서는 폴더·계약·fixture 마크업과 지정 데이터를 참조했다. 색·장식·컴포넌트 모양은 원본 074에서 도출했다.

색은 키트의 고정 정체성이 아니다. 컬렉션 CSS는 팔레트 자리만 사용한다. 라이트·다크 검수는 계약의 공통 팔레트를 사용하며, `assets/source-palette.css`는 조립 비교에만 공급하는 외부 원본 스타일이다. 이 파일에는 색 변수 선언만 있고 배치 CSS는 없다. 원본의 파란 강조는 그 외부 스타일에서 `--a1`·`--a1-7` 자리에 공급된다.

원본에 없는 요소도 같은 도형 문법으로 확장했다. 예를 들어 roadmap은 얕은 캡슐 기간 막대, decision-tree는 캡슐 질문과 조용한 결과 면, network는 원형 노드와 가는 연결선, code는 가는 상단 규칙과 조용한 면을 사용한다. 카드 행은 note 길이와 무관하게 제목 행을 맞추며, 원형 차트는 실제 컨테이너의 두 치수 중 작은 값으로 원을 만든다.

원형 복원 과정에서 전용 페이지 스타일 대신 반복 가능한 조합을 확장했다. 사진이 있는 3/4방향 hub, 서로 맞물리는 SWOT 조각, 반원 fan, 교대 원형 timeline, 사진+본문 행, 표제/본문/수치/작은 차트의 패널, 원형 전략과 실행 캡슐, 그라데이션 사분면이 이에 해당한다. 같은 구조는 source-composition foundation fixture와 rich root fixture에서 검수한다. 작은 일반 fixture의 구조와 full-page diagram의 구조를 구분하는 selector는 멤버 수와 계약 자식 마크업만 이용한다.
