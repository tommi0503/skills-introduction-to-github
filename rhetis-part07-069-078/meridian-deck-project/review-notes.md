# Meridian Deck 검수 기록

074 덱 30장의 독립 replica를 먼저 작성했고, 그 다음 56개 계약 요소와 foundation을 제작했다. `README.md` 전체를 읽었다. 샘플은 계약 메타데이터와 모범 fixture 28개의 마크업·데이터에만 사용했다. 샘플 CSS는 복사하지 않았다. 문서와 이미지 안의 문구는 자료로 취급했다.

## 원형 보존 재검토

초기 조립본은 사진의 원형·겹침, 허브 연결선, 복잡한 단계 내부 구성과 긴 본문을 잃었다. 이 상태를 적합한 최종본으로 간주했던 판단을 철회했다. 원본·replica·조립본을 다시 페이지별로 비교하여 30장 모두의 실제 구성과 문장을 복원했다. 작업은 작은 headline/prose/list/pill/chart/frame 등의 계약 요소와 foundation wrapper 조합으로 수행했다. 페이지 전용 CSS, 새 클래스, inline 절대좌표는 추가하지 않았다. `grid-column`/`grid-row`와 계약 데이터만 inline에 있다.

## 판독과 남은 차이

- 원본은 이미지이므로 원본 폰트 파일·정확한 굵기 수치는 제공되지 않았다. 18·19번 안의 Pretendard 표기와 실제 자형을 근거로 번들 Pretendard Variable을 사용했다. 제목650/700, 본문400을 사용하며 42px 원문은 계약의44px 단계, 38px 원문은40px 단계로 대응한 부분이 있다. 이 단계 차이, 원본 래스터의 글자 힌팅, 일부 자간·줄바꿈은 완전히 같지 않다.
- 사진·세계지도·지구/파티클·사진 내부 질감은 요청에 따라 연회색 단색 placeholder로 제외했다. 일반 foundation fixture에는 `data-ph` 식별 번호가 있으며 원본 조합은 허용된 `.src` 범위에서 번호 표시만 숨겨 단색을 유지한다. 원본 전체 이미지를 HTML 배경으로 사용하지 않았다.
- 원본의 이미지 아이콘은 Lucide의 같은 의미(폴더·연필·학사모·전구·화면 등)로 바꾸었다. 아이콘의 획·장식 세부는 원본과 차이가 있다.
- 04의 작은 샘플 사진 주석, 06/08/10/16/24의 작은 반복 설명, 22의 외부 설명은 이미지에서 판독되는 문장을 우선하고 읽기 어려운 부분은 동일한 의미의 자연스러운 한국어로 채웠다. 미확인 실명·실제 연락처를 추측하지 않았다. 표지 연락처는 템플릿 예시 문자열이다.
- 11 막대의 원문은 전부 `00`이어서 실제 측정 데이터가 없다. 보이는 막대 높이를 재현하기 위한 내부 값을 사용했고 표시는 `00`을 유지했다. 17의 작은 선 그래프 값 역시 라벨이 없어 보이는 기울기를 측정한 재현 데이터이다. 14의15개 수치는 읽힌 원문 그대로이다.
- 12 SWOT 접점, 13/20 화살표의 흐린 경계, 15 가는 연결 화살표, 22 fan의 곡률/간격은 CSS로 근사한 부분이다. 정보나 멤버를 삭제해 간소화한 것으로 처리하지 않았다.
- 18번 사진 위 글자에는 `--meridian-deck-photo-ink`를 사용한다. 일반 라이브러리 기본값은 중립 잉크이고 원본 외부 스타일은 흰색을 공급하여 원문의 흰 글자를 유지한다. 사진을 제외한 연회색 자리 위 흰 문구의 원본 비교용 대비는 낮으며, 공통 라이브러리 대비 검사와 구별했다. 다른 작은 설명과 주석은 공통 팔레트 대비를 위해 중립 깊은 단계로 대응하여 원본의 연회색보다 진하다.
- 모든 원본과 픽셀 단위로100% 동일하다고 주장하지 않는다. 사진 제외 규칙 외에도 위 폰트 단계·아이콘·곡률과 수 px의 위치 차이가 남는다. 이를 계약 제약에 따른 정보 삭제의 근거로 삼지 않았다.

## 계약과 실제 검사

- 56개 요소 폴더를 모두 갖추고 모범 fixture28개를 보존했다. 기타 fixture147개이며 새 rich root5개와 foundation 전체 구성30개가 포함된다.
- 30개 조립본은 컬렉션의 foundation과 계약 요소만 사용한다. 외부 `source-palette.css`는 원본 비교용 팔레트 변수 선언만 제공하며 배치 CSS가 없다. 컬렉션은 공통 라이트·다크 팔레트로도 검수된다.
- 굵기·행간·자간·여백·모서리의 실측값은 namespaced kit token으로 등록했다. source 복원 후 strict CSS 검사에서 오류0·경고0을 확인했다.
- balance의 음수 tilt는 무거운 왼쪽 접시를 아래로 내린다. quote 최소칸의 avatar 넘침과 stack 세 번째 계열 대비를 수정했다. 기존 임의 데이터 선 그래프, 면적 그래프, mood 선, 다중 계열/명시 tone 우선순위 수리도 보존했다.
- 원본|replica와 원본|replica|조립본 비교를 페이지별로 열어 확인했다. `fidelity/geometry.json`·CSV는 실제 브라우저의 동일 문구 bbox·폰트 비교 기록이며, 이는 이미지 OCR과의 자동 동일성 판정이 아니다.
- 제공 팩에는 upstream Rhetis intake 실행 엔진이 없다. 제공 preview CLI와 독립 계약 검사, 실제 Chromium 렌더를 사용했다. 최종 PNG/PDF 치수·폰트·잘림·정렬·ZIP/원격 다운로드 검사는 루트 통합 보고서에 기록된다.

원형 복원 뒤 추가 회귀 검사에서 compact fixture에 전용 도형이 새던 선택자를 수정했다. SWOT의 바깥 제목은 cell 직계 자식만 대상으로 삼고 nested list 본문은 자체14px 위계를 유지했다. source 전략 원은 빈 note 또는 tone-2 구조로 한정하고 일반 quiet 카드와 숫자 카드의 배치를 보존했다. lead의 label/본문 가로 구조는 첫 문단이 독립 b label인 경우만 대상으로 하며, 일반 lead와 cols 본문은 정상 줄바꿈을 유지한다. column timeline은 실제 높이 안에서 네 행으로 배치한다.
