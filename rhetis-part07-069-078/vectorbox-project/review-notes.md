# Vectorbox · 069 검수 기록

## 범위와 순서

원본 slide_02–13의12장과 README 전체를 확인했다. 원본을 각각 확대해 읽고, 라이브러리 CSS를 쓰기 전에1280×720 독립 replica HTML을 만들었다. 예시에서는 폴더 구조·계약 마크업·fixture 데이터·메타데이터만 사용했고 디자인 CSS는 가져오지 않았다. 컬렉션은 kit, foundation,56개 요소를 포함한다. 필수 golden28개를 보존했고, 일반 fixture142개에 원본 구조의 단독 root/group fixture15개를 추가했다. foundation에는 기본2개와 원본 완성페이지12개가 있다.

replica와 조립본은 모두 실제 Chromium에서 렌더해 원본과 나란히 한 장씩 확인했다. replica2회 비교에서 제목·아이콘·핸들을 수정했다. 초기 조립본의 일반화로 원본과 달라진 부분을 재검토한 뒤, 원본 기하·폰트 실측을 기준으로3단계의 비교와 수정을 진행했다. 원본 이미지 전체를 배경으로 사용한 페이지는 없다.

## 판독과 결정

- 원본의 폰트 파일명은 이미지로 확정할 수 없다. 초기 replica에는 Pretendard Variable과 Montserrat를 사용했다. 조립본의 한국어 제목과 마지막 문장은 제공 폰트의 canvas 잉크 너비·높이를 비교해 Noto Sans KR로 조정했다. 원본의 정확한 폰트임을 주장하지 않는다.
- slide_05는 `표율적인 운영`, slide_08 kicker는 `EXPETED RESULTS`로 판독했다. 오타로 보이지만 원문 표기를 보존했다.
- slide_10 범례는 여섯 항목 모두25%라 합계150%다. 원본 그림의 구간은 약25/30/15/10/10/10이다. 그림 비율과 원문 범례를 각각 보존했다. 실제 share 값과 표시 문구가 다른 이유를 이 기록에 남겼다.
- 이12장에서는 판독 불가 문구를 새 한국어 문장으로 지어 넣은 곳이 없다. 전화·메일·주소·직함은 읽을 수 있는 원문을 사용했다.
- 마지막 페이지의 회의실 사진과 주가 이미지 두 곳은 지시대로 연한 회색 단색 placeholder다. 단순 인물·전화기·선택틀·연결선은 사진으로 분류하지 않고 요소/CSS/Lucide로 복원했다.
- replica 아이콘은 수작업 SVG 선화다. 조립본은 빈 data-icon 칸과 실제 로컬 Lucide 런타임을 쓴다. 원본 아이콘과 Lucide의 세부 곡률·선 수는 다르다.
- golden card-4의 문자 아이콘✹, callout-stack의 농업 문구와 원래 배치는 정확한 fixture 보존 요구를 우선했다. 일반 prose 문구는 비즈니스 문장으로 바꿨고, 일반 bullet fixture의104%는 계약 범위 안의96%로 수치와 표시를 함께 맞췄다.

## 요소 검수의 수정

- 공식 wrapper에 head가 없을 때 body가 짧은 제목 행에 들어가던 문제를 고쳤다.
- 긴 제목·note에 따라 카드 행의 시작점이 달라지는 문제를 공통 트랙으로 맞췄다. 원본 아이콘 카드의 별도 기하는 data-icon 구조로 범위를 제한해 golden fixture 정렬을 보존했다.
- source용 가로 steps 스타일이 세로 `.col`에 적용되던 회귀를 제외했다. 작은 mark와 설명은 해당 최소 칸에서 읽히는 크기로 조정했다.
- line은 실제 이전/현재 점의 anchor로 연결하고, 같은 값의 선분도 남긴다. area는 연속 polygon과 누적 순서로 면을 그린다. fixture 숫자를 CSS에 하드코딩하지 않았다.
- waterfall은 플롯 기준선 아래에 축 라벨을 놓는다. radar는 도형 clip을 pseudo-element로 옮겨 범례를 자르지 않는다.
- line 바깥 값·stack 값의 dark 대비, 코드 행 번호·주석·문자열, 채움 위 설명, slope 숫자 대비를 고쳤다. 작은 강조 글자에는 깊은 팔레트 단계를 쓴다.
- preview의 전역 small 스타일이 단위에 새지 않게 color:inherit를 적용했다.
- concentric4개 라벨, cycle 화살표 방향, network·mindmap·journey 연결점, funnel/pyramid 글자 잘림, sankey 비율, slope/dumbbell, sparkline, image-frame preview 충돌을 수정했다.
- balance의 양쪽 접시가 기울기 값을 따르게 했고 bullet 목표 표시는 막대 중앙의 짧은 표식으로 조정했다. callout-stack의 seat는 정사각형, person/quote의 작은 avatar와 waffle 사람 그림은 최소 칸에 들어가게 했다.

## 검사의 범위

정적 계약 검사는56개 CSS, golden28개와 추가15개를 포함한 요소185개의 root/group 구조와 토큰을 확인한다. 일반 fixture 수는157개, golden을 합한 element fixture 총수는185개다. foundation fixture14개는 완성페이지 형식이다. 실제 브라우저 CSS 지원과 기능 검사는 별도 QA JSON에 기록했다. 최소 칸부터12×6까지 라이트·다크로 검사하며, 완성페이지 fixture는 내부 grid 배치를 보존한다.

독립 HTML은 로컬 글꼴·Lucide와 외부 palette/type/tokenDefaults 공급부를 사용한다. 이는 렌더 환경이며 컬렉션 ZIP의 파일 종류는CSS/JSON/MD/HTML이다. 원본·replica·조립본 PNG는1280×720, 좌우 비교는2560×720이다. 시트는 fixture 수에 따라 높이가 다르다. 폰트의 line box를 넘어 보이는 잉크는 실제 overflow clip과 구분했다. 제공 팩에는 반입 엔진이 없어 upstream intake는 실행하지 않았으며, 제공 preview와 독립 계약 검사·Chromium 렌더를 사용했다.

## 04 차트 수치 주석의 계약 해석

원본04에는 막대 위의 수치 주석이 없고0–100 축과 눈금으로 값을 읽는다. bar 계약의 b값·--v 데이터는 삭제하지 않았다. 원본 전용 8개 막대의 bars.quiet 변형에서 b를1px clipping 방식으로만 시각 숨김 처리해 접근성 트리에는 남겼다. 이는 필수 .fig/.name을 숨긴 것이 아니며 기본·모범 bar fixture는 모든 값이 계속 보인다. 이 해석으로 원본에 없던8개 숫자 주석의 시각적 차이를 제거했다.
