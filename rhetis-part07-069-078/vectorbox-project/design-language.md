# Vectorbox · 069 디자인 언어

대상은 `069_1l1vx_파란색_깔끔_비즈니스_프로젝트_제안_기획서`의 slide_02–13, 12장이다. README 전체를 읽고, 원본을 각각 확인한 뒤 독립 replica를 먼저 만들었다. 예시 컬렉션의 CSS를 사용하지 않았다.

| 반복된 규칙 | 컬렉션의 구현 |
|---|---|
| 편집 화면에서 선택한 개체 같은 사각 프레임 | 1px 직각 경계, 네 모서리의 6px 두께 L자 핸들. 내부 아이콘 선택틀은 작은 정사각 핸들 |
| 큰 아이콘 원과 균등한 열 | 카드 mark와 단계 mark를 원형 채움 또는 15px 원형 테두리로 구성; 내부 선 아이콘은 약50–60% |
| 왼쪽 위 짧은 세로 선 | 8×44px 강조 rail, Latin kicker, 넓은 자간의 한국어 큰 제목 |
| 밝은 면과 무거운 제목 | 페이지 면은 장식 없이 유지하고 제목·수치에 무게를 집중 |
| 선·면의 역할 분리 | 선택 경계와 연결선은 얇게, 핵심 원·막대·수치 배지는 강한 면으로 강조 |
| 본문과 장식의 겹침 | foundation의 deco에 선택틀과 모서리 핸들, 화면 밖으로 이어지는 사각형. 마지막 두 사진만 회색 placeholder |

선은1px, 보조 강조선은2px, 선택 핸들은6px이다. 카드·표는 직각, 작은 범례 칩은6px 반경, 아이콘 원과 도넛은999px 반경이다. 간격 단계는12/24/36px이며 공유 토큰의 조합으로 조정한다. foundation의 기본 좌우 여백은91px, 본문은12×6 그리드다. 제목 옆까지 도식이 올라오는 페이지는 `.page.overrides`의 짧은 제목 행을 쓴다.

한국어 제목은 제공된 **Noto Sans KR** 52px/700, 자간4px로 원본 글자의 실제 잉크 너비와 높이를 비교해 맞췄다. Latin kicker와 MIRI PROJECT는 **Montserrat**다. 본문·도표·수치는 **Pretendard Variable**이다. 본문 요소 제목은26–28px, 설명은20–22px, 작은 칸은20/16px 단계다. 마지막 문장은 Noto Sans KR 72/100px의 두 단계 위계다. `--type-*` 크기와 글꼴·굵기·자간·행간의 공유 토큰을 사용한다.

색은 디자인의 소유물이 아니다. 아래는 팔레트의 자리다.

| 역할 | 팔레트 자리 |
|---|---|
| 페이지와 기본 글자 | `--page`, `--ink` |
| 주 강조 채움·아이콘 원·핸들·첫 시리즈 | `--a1` |
| 작은 강조 제목과 수치 | `--a1-7` |
| 강조 면 위 글자 | `--a1-on` |
| 가는 선택 경계 | `--a1-4-soft` |
| 선택한 표 열 | `--a1-3-soft` |
| 두 번째 이후 시리즈 | `--a2`–`--a4` 및 해당 soft 단계 |
| 예산의 같은 계열 구간 | `--a1-4-soft`, `--a1-3-soft`, `--n-6`, `--n-5`, `--ink` |
| 플롯 그리드·구분선·보조 면 | `--n-2`–`--n-4` |
| 부차적 설명·주석 | `--n-7`, `--n-8` |

원본 색은 외부 `assets/source-palette.css`가 색 변수만 공급한다. 배치나 요소 스타일을 넣지 않는다. 원본의 주 강조색은 실제 픽셀의 최빈값으로 맞췄다. 공식 요소 시트는 계약의 기준 라이트·다크 팔레트를 쓰므로 강조색 자체가 원본과 달라도 같은 형태·선·위계를 검수할 수 있다.

원본에 없는 Sankey, radar, code, 9-box 등은 동일한 얇은 경계, 직각 면, 둥근 강조점, 큰 숫자 위계로 확장했다. 장식을 모든 도식에 반복하지 않고 구조에 맞춰 선택 핸들이나 원형 노드를 사용했다. 6구간 예산 도넛은 새로운 클래스나 데이터 구조를 만들지 않고, 독립 one-share donut6개를 같은 그리드 칸에 겹친다. 각 share의 실제 값과 시작각을 공급하고, 투명한 나머지와 중앙 구멍을 사용하며 이름·수치는 범례로 모두 보여 준다.
