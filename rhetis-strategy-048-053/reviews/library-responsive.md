# 라이브러리 최소 칸 반응형 검수

## 범위와 결과

담당 요소는 `agenda`, `cycle`, `hub`, `list`, `metric`, `pill`, `pricing`, `steps`, `timeline`, `versus`의 10개 `element.css`다. fixture의 문장, 멤버 수, 최소 칸 주석과 계약 구조는 변경하지 않았다. 도구 스크립트도 변경하지 않았다.

기존 최소 칸 검사에서 보고된 **83개 glyph 경계 초과 문제를 0개로 해결**했다. 실제 Chromium으로 선언된 모든 최소 칸과 라이트·다크를 검사했으며, 최종 결과는 `204 minimum checks; 0 issues`다. 전체 크기 검사도 `85 fixtures × 2 modes; 0 issues`를 확인했다.

## 수정 내용

| 요소 | 원인과 수정 |
|---|---|
| agenda | 5~6개 항목의 큰 글자·행 간격으로 위아래 내용이 칸을 넘었다. 높이 450px 이하에서 제목 18단계·설명 14단계와 토큰 간격을 적용하고 번호 원을 작게 설계했다. 모든 설명은 유지한다. |
| cycle / hub | 최하단 노드의 `top:75%` + `height:27%`가 칸을 벗어났다. top을 73%로 수정하고 낮은 칸에서 내부 간격을 줄였다. cycle 화살표는 노드 안쪽으로 옮겨 장식도 칸 밖에서 잘리지 않도록 했다. |
| list | 5개 목록을 가운데 배치할 때 내용 높이가 칸을 넘었다. 낮은 칸에서 제목 20단계·설명 16단계와 작은 항목 내 간격을 적용했다. |
| metric | 중첩 `.stat`의 이중 padding으로 수치/단위가 분리되고 긴 설명이 넘쳤다. 내부 실제 폭에 따른 inline container를 지정하고 이중 padding을 제거했다. 수치와 단위는 한 줄을 유지하며, 제목은 단어 단위로 줄바꿈한다. 설명은 내부 폭 340px 미만에서만 숨긴다. |
| pill | size containment가 있는 칸에서 intrinsic 크기가 50×26px로 축소되었다. 배정된 칸 너비를 사용하고 높이는 공유 토큰으로 명시했다. 실제 3×6 / 6×3 칸에서 마크·문구의 시각 중심을 확인했다. |
| pricing / versus | 중첩 목록이 부모 전체 폭을 기준으로 반응해 좁은 개별 패널에서도 긴 설명을 유지했다. 각 plan/side의 실제 내부 폭을 container로 지정하여 340px 미만 패널에서만 note를 숨긴다. 이름과 가격/수치는 유지한다. |
| steps | 4개 세로 단계의 여백·번호·설명 크기가 높이를 초과했다. 낮은 칸에서 번호/글자/여백을 단계적으로 줄이고 제목과 설명에 명확한 가로 공간을 배정했다. |
| timeline | 세로 4단계는 날짜까지 유지하며 간격과 글자 크기를 조절했다. 가로 4~6개 최소 칸은 제목 18단계·설명 14단계로 내려 문구 밀도를 줄였고, 단어 줄바꿈과 기준선에 맞춘 연결점을 확인했다. |

담당 모든 요소에 범위가 지정된 `small { color: inherit }`를 추가하여 preview 외부 프레임의 회색 small 규칙이 다크 수치 단위의 대비를 깨지 않도록 했다.

## 실제 시각 검수와 반복 횟수

- 반응형 반복은 총 **3회**다. 첫 번째 수정으로 자동 문제는 0건이 되었고, 두 번째에서 수치 제목의 어절 줄바꿈과 cycle 장식 경계를 개선했다. 세 번째는 개별 시각 검수에서 발견한 가로 timeline의 과도한 텍스트 밀도와 연결점 기준을 개선했다.
- 담당 **31개 고유 fixture를 각각 실제 브라우저 캡처로 열어 최소 칸을 개별 검토**했다. 연락처 시트만으로 판정하지 않았다.
- 다크 모드는 10개 요소의 대표 복잡한 fixture를 각각 열어 대비·배경·번호·경계를 추가 검토했다. 마지막 변경된 timeline 2개, metric 4개 수치, cycle 6개 노드는 라이트·다크 모두에서 다시 확인했다.
- 브라우저 캡처는 모든 담당 fixture / 선언된 최소 칸 / 두 모드를 합해 **68개**다. 원래 픽셀 크기와 비율을 유지하여 회색 1280×720 canvas 중앙에 배치했다. 확대·늘이기·왜곡 없이 모든 PNG의 최종 크기가 **1280×720**임을 검사했다.
- 캡처 위치: `artifacts/library/responsive/`. 최소 칸 glyph 검사: `artifacts/library/minimum-audit.json`. 전체 크기 검사: `artifacts/library/audit.json`.

## 검수 한계

자동 최소 검사는 실제 glyph가 root 경계를 넘는지 검사한다. 본 검수에서는 해당 검사 외에 문구 밀도, 단위 줄바꿈, 노드 장식, pill 정렬도 따로 시각 확인했다. 340px보다 좁은 개별 패널에서 긴 설명이 숨겨지는 것은 계약에 맞춘 반응형 결정이며, fixture 원문은 그대로 보존되어 넓은 칸에서는 다시 표시된다.
