# 최종 통합 검수

참고 팩 README 전체를 먼저 읽고 사용자께서 계약으로 지정한 범위를 적용했다. 계약 원문은 `contract/REFERENCE-README.md`에 보존했다. 참고 ZIP에는 6개 덱 105장만 있으며 048은 05부터 시작한다. 다른 프레젠테이션·라이브러리 작업은 수정하지 않았다.

서브 에이전트 6명이 덱별 담당 파일을 분리해 모든 원본을 풀사이즈로 읽고, 덱당 총 3회 이하로 실제 Chromium 렌더·수정·개별 비교를 수행했다. 주 에이전트는 최종 원본/결과 비교 105개를 모두 장별로 열어 통합 검수했다. 연락처 시트만으로 판정하지 않았다.

## 직접 구현본과 조립본

직접 구현 105장과 실제 컬렉션 CSS를 로드한 조립본 105장을 실제 브라우저로 렌더했다. 최종 자동 검사는 210개 페이지, 실내용이 있는 가운데 정렬 라벨 2,116개를 검사하며 페이지 크기, 글자 경계, 영역 이탈, 로드된 폰트 상태를 기록한다. 빈 표 셀은 글자가 없으므로 정렬 검사에서 제외한다. 최종 `quality-audit.json`에 실패가 없어야 한다.

공통 렌더러의 가로·세로 0 크기 SVG, 음수 좌표 연결선, SVG 그라데이션, 실제 Lucide 경로, 조립본의 그림자 유지, 조립 DOM의 실제 글자 경계 측정을 보완했다. 글자 대신 선을 그리지 않았다. 모든 사진·복잡 이미지는 회색 자리표시자이며 참조 PNG를 렌더러가 읽지 않는다.

수치는 원문을 유지했고 덱별 판독/줄바꿈 판단은 각 `NNN.md`에 적었다. 원본 폰트 파일이 없어 동일 폰트라고 주장하지 않는다. 한글 본문/굵은 표지/라틴 표제의 차이를 실제 로드한 세 가지 폰트로 맞췄다. 050의 마지막 13–16 그라데이션 수정도 통합 렌더에 반영했다.

## 컬렉션

63개 공유 토큰, foundation 2개 fixture, 요소 31종·83개 fixture를 작성했다. 라이트/다크 전체 fixture 170건과 명시한 최소 칸 204건을 브라우저에서 검사했다. 담당 에이전트의 반응형 검수 후 주 에이전트가 31종을 각각 열어 확인했다.

통합 시각 검수에서 3–5개 순환/허브 노드의 편중, 조직도 자동 그리드의 잘못된 열 폭, tag의 intrinsic 폭 축소, timeline 선과 점의 수직 간격, 미리보기의 `.frame` 이름 충돌을 발견해 수정했다. 변경한 요소를 다시 개별 확인하고 최종 PNG·PDF를 재생성했다. 허브는 실제 노드 수에 맞춰 연결하고 조직도는 2·3·4개 가지에서 명시적인 동일 열 폭을 사용한다.

레퍼런스 048·053의 남색 얇은 규칙선, 051의 하늘색 둥근 표지·칩, 052의 밝은 분석 카드, 049의 회색 층위, 050의 주황 강조를 하나의 절제된 토큰 체계로 해석했다. 원본에 없는 pricing·funnel 등은 같은 선·여백·강조 어법으로 새로 설계했다. 다크는 별도 파랑 잉크 표면과 명도 쌍이며 반전 필터가 아니다.

남은 차이는 미제공 원본 폰트의 세부 획, 일부 아이콘의 Lucide 대체, 미세 그림자·투명도·그라데이션과 파동 위상이다. 원본 사진을 재현하지 않은 부분은 사용자 지시에 따른 placeholder이다. 공식 importer 실행은 참고 팩에 해당 도구가 없어 수행하지 못했으며, 이를 대신했다고 주장하지 않는다. 계약 파일·CSS 규칙·fixture 구조의 로컬 검증 결과를 함께 제공한다.
