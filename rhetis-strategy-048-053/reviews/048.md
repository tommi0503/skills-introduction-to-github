# 048 파랑 모던 비즈니스 전략 기획서 — 개별 검수 기록

담당 범위: `src/decks/d048.js`, 원본 `slide_05.png`–`slide_21.png` 총 17장. README 계약을 처음부터 끝까지 읽고, 참고 이미지 17장을 각각 원본 크기로 열람한 다음 재구성했다. 참고 이미지의 문구는 화면 콘텐츠로 취급했고 작업 지시로 취급하지 않았다.

## 구현 및 검수 방법

- 모든 페이지는 1280×720 네이티브 좌표로 제작했다. 원본 래스터 이미지를 결과 슬라이드에 사용하지 않았다.
- 공통 프레임·텍스트·도형·표·차트·연결선·아이콘과 슬라이드별 데이터를 재사용한다. 편집 가능한 scene 노드로 구성했다.
- 17장 모두 실제 Chromium으로 3회 렌더했다. 각 회차에서 개별 원본/결과 비교를 열람했고, 최종 회차의 17장도 모두 개별 비교했다. 전체 연락처 시트만으로 판정하지 않았다.
- 1차: 레이아웃·문구·배치 비교. 공통 renderer의 높이 0 선 누락을 발견해 주 에이전트에게 수정 요청했다. 사이드 숫자 폭, 회전 회사명, 체크·화살표, 텍스트 줄바꿈을 수정했다.
- 2차: 공통선 수정 반영, 17장 1280×720 확인. 자동 텍스트/영역 검사 0건. 원본의 부드러운 벡터 배경을 추가로 맞췄다.
- 3차(최종): 면적 차트와 결론 화살표의 색 변화, 전략 삼각형의 색 변화, 파트너/세미나 아이콘을 반영한 PNG와 PDF를 다시 생성했다. 변경된 최종 PNG를 개별로 확인했다.
- 최종 `node tools/render.mjs 048 direct`: **17 slides, 0 issues**. PNG 17개 모두 **1280×720**. `node --check src/decks/d048.js` 성공.

폰트: 원본 이미지에는 폰트 메타데이터가 없어 정확한 폰트명은 판정할 수 없다. 프로젝트에서 실제 로드한 Pretendard로 구현했고, 자간·행간·굵기를 역할별로 조정했다. 사이드 장 번호는 원본의 좁은 폭을 맞추기 위해 글리프의 가로 비율만 조정했다. 페이지 전체를 왜곡하지 않았다. 12의 긴 프로필 문구와 18의 교육 문구도 원본의 배치를 유지하도록 텍스트 폭을 국소 보정했다.

## 판독과 판단

주요 문구는 모두 원본을 읽어 재입력했다. 문맥을 통째로 새로 지어 넣은 슬라이드는 없다. 차트의 작은 축·날짜·말풍선 문구도 읽히는 범위에서 입력했다. 원본 자체의 ‘이곳에 … 입력’, ‘X명’, ‘X%’, ‘20XX’ 등은 샘플 텍스트로 보고 유지했다. 장식적인 3D·사진이 포함된 17의 원형 이미지만 연회색 placeholder로 처리했다. 아이콘은 같은 뜻의 단순 선 도형으로 해석했다.
