## 수행 결정

- 원본 좌표를 임의로 계약 격자에 단순화하지 않는다. 등록된 private 숫자 토큰으로 foundation의 본문 범위와 요소 내부 기하를 공급한다. 본문은 12×6이며 직접 자식에는 계약 grid 배치만 둔다.
- 원본 전체 이미지를 배경으로 쓰거나 페이지별 새 CSS로 우회하지 않는다. 관계 도해 수정은 컬렉션 요소 자체에 반영한다.
- 자동 검사 0은 시각 동일성의 근거로 사용하지 않는다. 렌더된 최종 PNG를 다시 본 뒤, 그 해시에 주 에이전트의 최종 승인을 연결한다.
- 원본 문구 삭제·축약·데이터 값/노드 자리 변경은 허용하지 않는다. 읽을 수 없는 작은 문구만 별도 명시한다.


## 최종 통합 검수

수정 전 baseline 판정은 위의 이력으로 보존했다. 최종 판정은 `final-approval.json`의 107개 PNG 세트에 연결된다. 주 에이전트가 원본별 전체 비교 회차에서 문구·구조·도형·위계를 검토하고, 수정 후 마지막 변경 화면을 단일 1280×720로 다시 열었다. 담당자는 각 덱의 양쪽 구현과 모든 native 요소 시트를 전수 재검수했다. 전 페이지의 최종 파일을 매번 새로 직접 열었다고 주장하지 않으며, 동일 SHA를 유지한 화면은 앞선 직접 검수와 불변 증거로 연결했다. `parent-final-seen.json`은 마지막 delta 검수에서 실제 재열람한 비교 PNG만 기록한다.

- 045: 연락처/제목 실측과 단독 페이지 프레임을 foundation으로 통합. 호스트 팔레트 CSS를 assets로 옮겨 실제 렌더 지문에 포함했다.
- 046: 전 장 누락 문구와 도형 복구 뒤 통계·순위·구획·연결을 재검토했다. 두 화살표의 실제 플랫폼 폰트 대체를 Lucide 선 SVG로 제거했다.
- 048: 접힌 프레임과 공통 제목 위계, 원 간 곡선의 접점/화살촉, Venn 쌓임 순서, 대각 허브와 마지막 CONTACT 위치를 수정했다. 마지막 영문 소제목의 x/baseline/자폭도 원본 ink bbox로 측정해 양쪽 구현에 반영했다.
- 050: 시장 규모 페이지의 세 원 좌표·반경·중첩 alpha와 수직 gradient를 복구했다. 네 표본의 원본 RGB와 양쪽 구현의 최대 차이는2다. 일반 요소의 실제 커넥터와 sparkline 선, 축/범례/값 관계도 고쳤다.
- 052: 조직 문화 페이지의 좌3/우2 비대칭, 다섯 아이콘과 연결선 종점, 표지 부제/메타의 실제 글자 폭을 복구했다. 원문이4/7인 유지보수 문구는 그대로 보존했다.
- 053: 표/계층/교집합 의미, 고리/지표 배치와 radar의 계열 이름·키·색 대응을 수정했다. 마지막 host 프레임 규칙을 foundation으로 옮긴 뒤 전체 페이지 및 native PNG SHA 불변을 확인했다.

재조립에는 컬렉션 foundation/요소 CSS와 호스트 custom properties만 사용한다. 직접 body 자식의 배치는 grid-column/grid-row이며, 모범 fixture에 원래 있는 --v/--max/--cols는 계약 데이터로 분리해 기록했다. 임의의 페이지 CSS는 허용하지 않았다. 실제 연결된 CSS가 최종 렌더 지문에 모두 포함되는지도 별도로 검사했다.

페이지 자동 검사에 남은14건은 글꼴의 여유 Range/긴 소유 상자와 의도한 장식 bleed다. 원래 경고를 삭제하지 않고 050/052의 page-audit-disposition.json에서 실제 ink·clipping ancestor와 함께 판정했다. 실제 글자 잘림이나 의도하지 않은 콘텐츠 영역 초과는 확인되지 않았다. 큰 합성 이미지 표시에서 의심됐던 누락은 단일1280 PNG로 재확인했으며, 실제로 없는 결함을 수정했다고 기록하지 않았다.

이는 픽셀100% 동일하다는 주장이 아니다. 요청한 회색 placeholder, Lucide 대체, 원본 폰트 메타데이터가 없어 가장 가까운 허용 실폰트를 선택한 부분과 rasterizer의 미세 차이는 각 덱 기록에 남긴다. 자동 검사0을 원본 동일성 점수로 해석하지 않았다.
