# Launchrail 048 — 디자인 언어

원본 30장을 먼저 독립 replica로 만든 후 추출했다. 디자인은 특정 색을 소유하지 않는다.

- 페이지는 두 겹의 1px 가는 선으로 둘러싼 서류철이다. 좌상단은 45도 접힘, 우상단은 경사진 어깨와 겹친 세 장의 탭이다. 표지의 커다란 원호는 페이지 밖으로 이어지지만 본문을 가리지 않는다.
- 기본 요소 면은 `--n-1`, 종이는 `--page`, 본문은 `--ink`다. 원본의 주 강조는 `--a1`, 보조 강조는 `--a2`로 옮긴다. 둘 중 하나를 강조하고 나머지는 `--n-*`와 `--a1-2-soft` 등으로 정돈한다.
- 제목 왼쪽의 작은 빈 원은 보조 강조 `--a2`의 8px 링이다. 본문 관계선은 1px `--n-6`; 차트 눈금은 1px `--n-3`; 강조 연결은 2px `--a1`의 점선이다.
- 직사각 면의 기본 반경은 20px, 조밀한 표와 조직 칸은 8px다. 카테고리·연도·번호는 캡슐과 원으로 구분한다. 캡슐의 글자는 수직·수평 중앙에 놓고, 길이가 길어지면 두 줄을 허용한다.
- 간격은 8·16·24·40px 단계다. 페이지 좌우 안전 여백 96px, 위 제목 96px, 본문 시작 약 196px, 아래 안전선 668px다. 큰 면은 중심 정렬하되, 다중 카드의 fig/name 시작선은 고정한다.
- Pretendard Variable, SUITE, Noto Sans KR, Freesentation을 실제 로드한다. 제목은 44단계/800(원본 호스트 42px), 카드 이름 20–26단계/500–700, 본문은 역할별 Pretendard·SUITE 16–22단계/300–600, 레이블 16–20px/500–700, 숫자는 40–56px/700이며 축·표·연락처의 좁은 숫자 역할에는 Noto Sans KR를 쓴다. 표지는 호스트 98px/800, 끝맺음은 호스트 126px/900이다. 본문 행간은 1.6, 이름은 1.3, 숫자는 1.1이다.
- 진한 주 강조 면의 글자는 `--a1-on`이다. 깊은 강조 단계는 `--a1-7`과 `--page`를 짝짓는다. 다크 모드에서 같은 위치 의미를 유지하며 회색 단계와 강조 단계를 별도 palette가 공급한다.
- 표는 꽉 찬 강조 헤더와 얇은 가로 구분선, 흐린 첫 열을 쓴다. 차트는 단순한 축과 원형 점, 둥근 끝 막대, 얇은 연결선을 쓴다.
- 순서도는 얇은 선 위 원/캡슐, 조직도는 위 루트에서 수평 분기, 허브는 중심 원과 외곽 캡슐, SWOT은 캡슐 면과 큰 한 글자 원형 마커다. 원본에 없는 56개 계약 요소도 이 문법을 따른다.
- 장식은 접힘·탭·링만 사용한다. 샘플 컬렉션의 장식, 배색, 형태는 복제하지 않는다.

재측정 API는 기존 부품의 좌표와 폭·높이를 정식 private 숫자 토큰으로 받는다. 간격·글꼴·행간·굵기·색의 실제 스타일은 키트와 팔레트에서 공급한다. 관계도는 원형 교환과 대각선 수상 구조를 각각 보존하며, 4분할 도넛은 추가 비율 데이터로 재사용한다.

18쪽 표 본문은 Freesentation 500, 20쪽 서비스 설명은 Pretendard 500, 수상·연락처·작은 축 숫자는 Noto Sans KR 500으로 실제 원본 글리프 폭과 굵기를 맞춘다. 17쪽 Venn은 중립 바탕 → 보조 강조 → 주 강조의 순서로 칠하며, 주 강조 60%와 보조 강조 71%의 투명 면이 교집합을 만든다.

일반 페이지 영문 소제목은 Freesentation700, 호스트 22px, 자간 +0.5px, 행간 1.3을 쓴다. 위치는 등록된 private dx/dy 숫자 토큰으로 원본의 같은 baseline에 정렬하며 공식 시트의 타입 단계는 contract/type-steps.json을 유지한다.
