# Cultureweave 046 검수 기록

## 범위와 제작 순서

046 덱의 원본 18장 전부를 개별 열람했다. 독립적인 1280×720 replica를 먼저 만들고, 반복되는 편집 문법을 design-language.md에 정리한 뒤 foundation과 56종 요소를 새 CSS로 구현했다. sample에서는 계약 마크업·fixture 데이터·폴더 형식만 사용했다.

## 강화 시각 검수

초기 재조립에서 실제 구성 손실이 발견되어 이전 동결을 철회했다. 부모 에이전트도 18장 원본과 조립본을 각각 원해상도로 열어 검수했다. 자동 검사 0건을 원본 동일 판정으로 사용하지 않는다.

- 01: 원래의 두 곡선 계열, 표지 분할선, 세 개 chevron, 상단 이름, 연락처를 복구했다. 제목 폭과 69px 행 높이를 측정했다.
- 02: 2줄 영문·첫 글자 강조·한국어 이름·우측 설명을 모두 유지했다.
- 03: 2×2 구획, 네 개의 서로 다른 선 장식과 원문 bullet을 복구했다. 영문은 실제 crop-fit에서 더 가까웠던 JoseonPalace 400/30px/+0.5px를 적용했다.
- 04: 한 개의 주황 패널과 그 안의 흰 통계 2행, 28px 숫자, 전체 sidebar, 원래 2년차 42% 한 개의 강조를 복구했다.
- 05: 세 개의 검정 pill 제목과 원문, 43%, 사람 픽토그램 두 행, 제안/수락 pill, 전체 세로 구획선을 복구했다.
- 06: 원본 사진 영역의 비정형 실루엣과 분리된 모서리 조각을 연회색으로 만들었다. 내부 사진 윤곽이나 번호는 넣지 않았다. 목적 card, 네 pill 항목, 제외 인원 placeholder를 유지했다.
- 07: 40/30/20/10 네 조각 도넛과 원문 설명, 40/60의 큰 수치, 259px 배경 track, 원본 값에 해당하는 직급별 gauge를 복구했다.
- 08: 실제 값 8/5/6/3과 균등한 0–10 눈금, 낮음/높음, 단일 최고값 강조, 오른쪽 3.4/3.1/2.7/2.4점의 28px 수치를 유지했다.
- 09: 좌우 분석 pill, 세로 구획, 세 막대씩과 설명을 유지했다.
- 10: 왼쪽 순위 1·2와 오른쪽 3·4·5, sidebar 52건 강조, VOICE와 원본에서 측정한 86×31px 세로 막대 파형, 인용 세 행을 복구했다.
- 11: 세 전략의 큰 제목과 구획선, 중앙 stem·끝점·삼각형, 작은 만족도 변화 문장, 큰 검정 결론을 복구했다.
- 12: 188px 간격으로 세 행의 원래 시작점을 반영했다. 70/17/65%와 소제목·설명, 중앙 구획, 1/2/3개 chevron을 유지했다. TEAM/EFFECT의 복잡한 3D만 회색으로 바꾸고 GROWTH의 단순 광선은 그렸다.
- 13: 원본 218px 열 간격, 각 단계·화살표·SOLUTION·bullet·결론의 y 좌표를 맞췄다. 마지막 강조는 색 글자만으로 표현했다.

- 18: 세로 주황 띠에서 검사/피드백 두 갈래와 오른쪽 네 상자로 이어지는 원래 구조를 복구했다. 16px 영문, 한국어, 별/궤도와 흰 곡선 장식을 각각 그렸다.

## 선 장식 구현과 불확실성

원본 전체 이미지는 배경으로 사용하지 않았다. cover는 두 계열의 회전 타원 21개씩을 원본 좌표에 피팅했다. 05는 가려지지 않은 배경을 12개 가로줄에서 측정하여 30개 선의 위치·밀도를 연속 cubic spline으로 연결했다. 내부 페이지는 독립된 숫자 행렬 토큰으로 같은 매끄러운 곡선을 배치한다.

분리된 작은 장식의 원본 색 선을 중심선 그래프로 추출해 얇은 벡터 리본으로 만들었다. 단순 픽셀 윤곽을 채운 첫 실험은 얼룩과 찢긴 면이 되어 자체 반려하고 최종 렌더에서 제거했다. 원본 압축에 의한 가는 선 가장자리와 교차점은 판독 불확실성이 있다. 원본 영문 글꼴의 이름은 확정되지 않았다. NanumMyeongjo와 JoseonPalace를 실제 로드하고 측정한 인상·폭에 따라 선택했으며, 글꼴이 완전히 동일하다고 주장하지 않는다.

## 내용과 팔레트 결정

원본의 20XX/X%/NN%/N개/키워드/TEXT는 템플릿 문구로 유지했다. 작은 일반 설명은 원문을 우선 옮겼고, 02 반복 설명·03 효과 문장·06 목적·12 상세 지표의 띄어쓰기와 조사는 문맥에 맞춰 정리했다. 검증된 기업 사실을 추가한 것은 아니다.

06 사무실·인물, 10 인물, 12 복잡한 3D는 요청에 따라 연회색 placeholder다. source 팔레트는 review/assets/host-custom-properties.css가 공급하며 collection에는 색의 자리만 있다. 재조립 HTML은 collection CSS와 계약 data-el만 사용한다. 각 page의 등록된 숫자 토큰은 실제 body 시작점·크기·12×6 track 길이·기하 행렬을 데이터로 공급한다. 페이지별 디자인 CSS는 없다.

## 56종 요소 기능 검수

native 라이트·다크 시트를 각각 읽으며 도넛의 타원화, hierarchy/decision-tree의 연결 단절, hub의 면 위 선 관통, journey의 끝점 불일치, timeline 점 분리, 3-set venn의 공통 교집합 부재, waterfall 합계 오류를 실제 화면에서 발견하고 고쳤다. balance의 빔·받침과 tilt 방향, bullet의 행별 목표 tick, line의 동일 값 구간, 누적 면·막대의 계열 구분, 4방향 flowchart/swimlane, code의 순차 행번호를 확인했다. 누적 막대에는 실제 계열 색과 일치하는 nested legend를 넣었다. 마지막 검수에서 가로 4계열의 기타 segment와 범례 색 불일치 및 생산 법인 label 줄바꿈을 고쳤다. 계약에 명시된 tone 변형은 각각의 중립·옅은 강조 팔레트 자리로 연결하고 on의 단일 강조를 보존했다. bubble의 기본점을 중립색으로 분리하고 radar의 세 계열 이름을 좌·우·중앙에 각각 놓아 겹침을 없앴다.

모범 fixture의 마크업·데이터는 보존했다. 두 callout의 원래 top-grid 위치는 구체적인 동일 마크업 요구를 우선했다. 비모범 sample의 옛 ul/li는 현재 .list[data-el]>.item>.name/.note 계약으로 정규화했다. 긴 이름과 note를 줄이거나 숫자·label을 숨겨 검사 결과를 만드는 방식은 사용하지 않는다.

최신 자동 검사 원본은 fixture-audit.json, integration-checks.json이다. 최신 브라우저가 읽은 실제 소스·폰트 해시는 render-source-audit.json에 기록한다. native 56종의 판정과 PNG 해시는 library-visual-audit.json에 기록한다. 이전 동결 및 이전 자동 검사 수치는 최종 승인 근거가 아니다. 부모의 추가 수정 중지 지시에 따라 현재 소스 버전을 동결한다. 이는 원본과 100% 동일하다는 시각 승인과 구분되며, 부모의 최종 통합 판정을 기다린다.

최종 CDP 실사용 폰트 감사에서 04·14의 브랜드 화살표 한 글자씩이 DejaVu Sans로 fallback하는 것을 확인했다. 두 문자를 빈 Lucide arrow-right icon span과 실제 선 SVG로 바꾸고, 글꼴 감사와 최종 페이지 렌더를 다시 실행했다.

최종 의존성 감사에서 호스트 팔레트 CSS를 assets/host-custom-properties.css로 옮겨 재현 소스 지문에 포함했다. CSS 바이트는 유지하고 18개 조립본 링크만 수정했다.


## 주 에이전트 최종 통합 판정

원본별 개별 비교 회차와 마지막 변경 화면 재열람 후, 최신 비교 PNG·소스·실제 폰트 지문을 최종 승인 기록에 묶었다. 자동 bounds 검사와 시각 검수는 별도 근거다. 사진·복잡 이미지의 요청된 회색 대체, Lucide 치환, 가장 가까운 허용 실폰트와 안티앨리어싱의 미세 차이를 픽셀100% 동일로 표현하지 않는다. 렌더 뒤 일반 호스트 CSS·팔레트 의존성과 컬렉션 복사본 SHA를 다시 확인했다.
