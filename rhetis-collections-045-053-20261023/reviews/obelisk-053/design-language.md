# Obelisk 053 디자인 언어

원본 재현 18장을 먼저 구현하고 개별 비교한 후 아래 규칙을 추출했다.

- 구조: 좌측 6px 연속 rail, 상단 73px 유틸리티 띠, 콘텐츠 좌우 80px. 본문은 수평 정렬된 직사각 모듈이며 원형 관계 노드만 곡선을 쓴다.
- 선: 표·분할은 1px. timeline은 3px, 그래프선은 2px. 장식은 커버의 잘린 건축 모자이크와 122px 강조 정사각형으로 제한한다.
- 모서리: 일반 면은 0–2px, 일정표 상자는 원본에서 8px이며 수치 모양 API로 이를 보존한다. 날짜칩은 999px, 관계 노드는 50%.
- 간격 단계: 12 / 24 / 40 / 80px. 카드 내부는 28px. chip·원형 배지는 광학 중심을 맞추며 반복 카드 제목의 시작점은 같게 유지한다.
- 글꼴: Pretendard Variable을 실제 로드. 원본 산세리프의 형태·중간 굵기에 가장 가까운 계약 글꼴로 결정. 제목 36, 섹션 60, 표지 약80, 본문16–20, 보조12–14. 제목600, 본문400.
- 강조 자리: 원본 선명 파랑 → `--a1`; 원본 navy → `--a1-9`; 카드 옅은 회색 → `--n-1`; 구분선 → `--n-3`; 일반 글자 → `--ink`; 강조면 글자 → `--a1-on`; 깊은면 글자 → `--page`.
- 면·선: 외곽 테두리보다 면 대비가 우선이다. 대표 멤버 하나에만 강조 채움을 주고 다른 멤버는 중립면을 쓴다. 표 헤더와 원노드는 깊은 강조 단계, 값 강조는 주 강조 자리를 쓴다.
- 덱에 없는 요소: 같은 각진 면, 수평/수직 머리선, 강조 원노드, 넓은 여백 문법으로 확장했다. 샘플 디자인 CSS는 복사하지 않았다.
