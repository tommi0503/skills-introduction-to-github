# Obelisk 053 검수 기록

## 범위와 계약

053 덱의 원본 18장 전체를 대상으로 독립 absolute HTML replica를 먼저 만들고 56개 계약 요소를 제작했다. 모든 원본과 replica, 조립본을 실제 Chromium에서 1280×720으로 렌더했다. 샘플에서 취한 것은 계약 마크업과 지정 fixture 데이터다. 샘플 디자인 CSS는 사용하지 않았다.

## 강화 시각 검수에서 거절한 초기 조립본

첫 조립은 격자에 맞추는 과정에서 원본의 목차 네 구획, 원형 도해의 실루엣, 상자 안의 제목·띠·통계 위계를 평탄화했다. 자동 잘림 검사가 통과해도 원본 재현에는 실패한 것으로 판정했다. 이 초기 산출물은 최종 결과에서 교체했다. 격자 추상화를 큰 시각 차이의 면제로 취급하지 않는다.

## 수치 데이터 API

foundation의 source canvas 모드는 1280×720 전체에 12열×6행을 유지한다. body의 직접 자식은 grid-column/grid-row만 선언한다. 중첩 계약 요소는 element.json에 등록한 private 숫자 토큰으로 지역 x/y/w/h, 문자 단계·광학 배율, palette 역할, 원의 수를 받는다. 모든 모양과 글자는 해당 요소 CSS가 그린다. 페이지 번호 선택자, 원본 통이미지, 페이지별 layout CSS를 쓰지 않았다. 독립 replica는 컬렉션 CSS를 불러오지 않는다.

## 글꼴·색·판독과 결정

원본에 폰트 파일명 정보가 없어 계약 목록의 Pretendard Variable을 실제 로드했다. 원본의 문구와 줄바꿈을 유지하며 glyph bounding box를 재측정했다. 예를 들어 04 메인 문장의 원본 bbox는 x=83..914/y=136..166, 수정본은 x=83..913/y=136..166이다. 색은 원본에서 측정한 선명 강조 #183ee9, 깊은 강조 #010251, 중립면 #f5f7f9를 review의 사용자 palette 데이터로 공급했다. 컬렉션 요소 CSS에는 색 리터럴이 없다.

사진·복잡한 이미지·로고·서명은 사용자가 허용한 연한 회색 자리로 대체했다. 도형과 차트는 직접 구현했다. 아이콘은 해당 의미에 가장 가까운 실제 Lucide 이름을 사용한다. 이미지 아이콘의 세부 픽셀과 Lucide의 획 모양은 다르다. 작은 문구 중 서명 아래 사진 안내는 판독 가능한 문구를 옮겼다. 고유 회사명·연도·수치는 자료의 표기를 유지했으며 오류처럼 보이는 연도도 임의로 현실 연도로 바꾸지 않았다.

## 최종 검사

최종 검사 숫자는 fixture-audit.json, structural-checks.json, integration-checks.json, render-source-audit.json에 기록한다. 마지막 PNG는 최종 CSS/HTML/폰트 해시와 함께 생성한다. 자동 검사 결과를 원본 시각 일치의 증거로 대신하지 않는다. 최종 승인 여부는 주 에이전트의 페이지별 시각 검수 결과를 따른다.

## 확정 radar 계열 결함 수선

주 에이전트가 마지막 native radar-5/8에서 기존 계열 이름이 top/left 동일 좌표에 겹치고 무톤 계열이 모두 a1이라 구별되지 않는 결함을 발견했다. 이전 radar 통과 판정은 이 결함을 놓쳤으므로 취소하고 수정 후 재판정했다. 이름은 원래 마크업을 유지한 아래 범례1/2/3칸에 각각 보이고, 첫 무톤 계열은 a1/비교는n-6, 명시 tone은 그대로 유지한다. 범례 key와 실제 polygon의 배경색은 같은 series 변수를 소비하며 브라우저 computed 색 일치도 검사했다.

3/5/8축×두 모드를 native 원해상도로 다시 읽고 기존 최소칸부터12×6까지144개 정수크기를 검사했다. 이름은 모두 보이며 이름끼리·축과 겹치지 않는다. 공식 preview HTML을 재생성하고 radar 시트2장과 전체PDF의 해당3페이지씩을 교체했다. 나머지112개 native 시트는 SHA가 동일함을 확인했다. 원본18페이지는 radar를 사용하지 않으므로 디자인·문구·배치를 바꾸지 않았다. 근거는 radar-series-audit.json이다.
