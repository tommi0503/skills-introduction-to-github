# Axisfold 052 디자인 언어

원본 20장을 개별 관찰하고 standalone replica를 먼저 만든 뒤 반복 규칙을 추출했다. 색은 호스트가 공급하는 팔레트 자리로만 정의한다.

|역할|형태·선·위계 규칙|팔레트 자리|
|---|---|---|
|상단 rail|높이42px의 긴 알약 끝이 가늘어졌다 원형으로 끝남. 원 안에 얇은 오른쪽 화살표.|채움 `--a4`, 글자/화살표 `--a4-on`|
|내지 제목|48px 산세리프, 약600 굵기, 미세한 양의 자간. 대개 좌측 번호+제목이며 인재상 페이지는 우측 묶음.|`--ink`|
|장표지|가는 장번호, 대형 굵은 영문, 화살표 badge와 한글 질문, 연결 모듈 사진 자리.|영문·본문 `--ink`, 표지 강조 `--a2`|
|본문/이름|본문은 가는 한글 산세리프16px 전후, 보통 24–25px 줄높이. 이름과 숫자는 별도의 굵기·시작 위치를 예약.|본문 `--ink`/`--n-7`, 이름 `--a2`/`--a3`|
|카드|8–16px 둥근 모서리, 얇은 경계, 넉넉한 내부 여백. 6카드 제품 페이지는 고유 높이를 유지하고 탭을 외곽 슬롯 안에 포함.|기본 `--page`/`--n-1`, 강조 `--a1`/`--a3-7`|
|번호 탭|모서리에 붙은 52px 둥근 사각형, 바탕과 같은 테두리로 면을 분리.|`--a2`와 `--a4-7`, 문자 `--page`|
|관계도|크기가 고정되는 정원형 core와 원형 마디. 1px 직각·방사 연결선과 작은 끝점. 면과 글자를 선이 관통하지 않음.|중심 `--n-9`/`--a1-7`/`--a1-8`, 글자 `--page`, 선 `--n-5`|
|Venn|2원은 교집합을 실제 렌즈로, 3원은 삼각 위치에서 4개의 교집합을 표시. 설명은 겹침을 피해 놓음.|`--a3-7`/`--a3-8`, `--a2`, `--a4-8`, `--a1-8`; 렌즈 `--a1-9`|
|순환|6단계는 분할 annulus와 작은 중심·바깥 설명. 4역량은 얇은 외원과 점선 내원·원형 노드.|`--a2`, `--a3-3-soft`, `--ink`, core `--a1-8`|
|데이터|모서리가 과장되지 않은 직사각 막대, 얇은 선·기준선, 별도의 상단 범례. 누적/증감/비율은 실제 데이터 기하로 표현.|`--a1`, `--a2`, `--a3-7`, `--a4-7`, 보조 면 `--n-1`|
|장식|둥근 사각 조각이 연결되어 꺾이거나 U를 만드는 기하. 일부 조각은 분리되어 주변 빈 공간에 위치.|밝은 장식 `--a4-2-soft`, 어두운 배경 장식 `--a1-3-soft`|
|사진 자리|원본 사진의 사각 모듈 외곽 윤곽을 유지하고 내용만 번호가 있는 연회색 placeholder.|`--n-2`|

여백 기본 단계는12/24/40px, 페이지 기준 여백은 좌우60/상하44px이다. 원본의 불균등 모듈은 foundation의 정식12열×6행 수치 토큰으로 표현한다. 이미지마다 새 CSS를 추가하지 않으며 요소 root는 계약 마크업과 `data-el` 범위 안에서만 그린다.

이미지에 없는 요소도 둥근 모듈·얇은 연결선·원형 중심·캡슐 라벨의 같은 문법으로 확장한다. 원본의 색을 컬렉션 CSS 안에 고정하지 않고, 라이브러리 라이트/다크는 공식 팔레트로 검사한다.
