# Vitreous 050 검수 기록

20장 원본을 각각 직접 관찰했다. 초기 replica와 초기 조립본에서 원문 축약과 도형 일반화가 발견되어 해당 판정은 폐기했다. 최종 비교는 그 PNG를 재사용하지 않고, 전체 원문·데이터·치수를 복구한 소스를 다시 렌더한 PNG로 한다. `visual-review.md`는 페이지별 실제 수선 목록이다.

## 원본 복구와 수정

- 03 Vision에 복제되었던 Mission 문장, 07 SAM/SOM 부제와 괄호 예시, 17 Phase별 예시, 18 서로 다른 기술/IP/깊이 설명을 원본을 재열람해 복구했다. 요약된 원문을 공통 문장으로 대체하지 않는다.
- 08을 서로 다른 반지름의 네 분면으로,20을35/15/20/30 네 분할로 복구했다. 원형 차트를 단일 점유율 도넛으로 축약했던 초기 구현을 폐기했다.
- 09 연결선과 종점·반원,13 성장 주석/큰 화살표,14 두 계열 영역/큰 가로막대/누적막대/증가 배지,17 곡선 상승 배경,18 세 아이콘과 가로선,19 세 아이콘 배지를 복구했다.
- 모든 사진·복잡3D 자리의 불필요한 숫자를 제거했다. 회색 자리 외의 텍스트/단순 도형/축/차트는 데이터와 컴포넌트로 구현했다. 원본 전체 이미지를 페이지 바탕으로 사용하지 않았다.
- 네이티브 원본|replica 대조에서 받은 20페이지 피드백을 한 차례에 묶어 수정했다. 05강조500/06번호40/07원명28,09모서리12/10첫16·나머지24,11약한 선·줄바꿈,12원명20,14축 잘림,15강조,18비율24·heading16/body14,19이름500·행간25를 양쪽에 적용했다.
- 원본 crop을 실제 글꼴로 렌더하여 비교했다. 측정 자료는 `text-measurements.json`/`numeral-measurements.json`이다. reference의 Noto Sans KR 실파일과 로드를 확인하고 portable font assets에 포함했다. 원본 글꼴 메타데이터가 없으므로 유사 glyph를 선택한 부분을 완전 동일하다고 임의 승인하지 않는다.

## 해석과 직접 결정

- 원본의 사진04/08/19,3D기어09는 지정된 연회색 placeholder다. 사진 위 원래 청색 overlay와 원래 caption은 유지했다. 이미지 아이콘은 의미가 같은 Lucide로 치환했으며, 단순 3-chevron과 차트·연결선은 직접 그렸다.
- 13의 `□□%`는 판독 실패를 숨긴 문구가 아니라 원본에 보이는 템플릿 placeholder다. `000`, `00%`, `20XX` 역시 실제 템플릿의 값으로 보존했다.
- 14 차트는 원본에 숫자 라벨이 없는 점/막대 위치를 측정했다. 선의 두 계열은8/22/47/60과2/13/20/41,가로막대16/37/60/73,누적 총35/54/69와 아래계열9/22/17로 읽었다. 20 영역값15/30/55/60/70도 그림의 높이에서 얻은 수치다. 이를 외부 사업 데이터로 해석하지 않는다.
- 18 제목이 기하학적 페이지 중심보다36px 오른쪽인 비대칭을 원본 그대로 보존했다. 05 세 캡슐의 서로 조금 다른 y 간격도 토큰 값으로 보존했다.
- 모범 `card-4.html`의 `✹`는 원문의 같은 마크업·데이터 요구를 우선하여 보존했다. 모범 밖 아이콘은 실제 Lucide 또는 단순 SVG다.

## 라이브러리 계약과 기능

56개 요소 전체, kit, foundation을 포함한다. 모범 fixture는 원문의 마크업·데이터를 보존했다. 비모범 fixture는 전부 최상위12×6으로 정규화하고, 옛 목록15개/42항목을 `.list>.item>.name/.note` 및 자기 data-el로 정규화했다. 긴 이름/긴 note/멤버 수/변형을 섞었다. 원본의 여백을 유지하려고 복잡한 요소의 최소 칸을 넓힌 경우 요소별 container 축소 단계도 남겼다.

기능 검수에서 balance의 실제 빔·지지대와 음수 tilt 방향, bullet의 실제 목표 tick, line의 같은 값 수평 연결을 보강했다. stack fixture에 계열별 tone과 동일 색의 nested legend를 추가했다. 범례 없이 같은 색으로 누적 계열을 표시하지 않는다. `frame[data-el]`은100% width/height로 미리보기 wrapper의360px 높이 침투를 막는다. 같은 행의 카드 이름/수치 높이를 예약하고, 작은 칸 반응형/대비/overflow는 전수 브라우저 검사한다.

## 최종 검수의 근거

자동 검사의0은 원본과 같다는 판정이 아니다. 요소별 native light/dark PNG 전체를 읽은 실제 근거와 해시는 `library-visual-audit.json`에 기록한다. 최종 페이지는 portable 동기화 후 다시 렌더하며 `render-source-audit.json`에 브라우저가 읽은 CSS/HTML/폰트 해시를 기록한다. 컬렉션 원본과 review/collection의 SHA 동일성, 최종 PNG1280×720,폰트/글자 경계,파일 무결성은 통합 검수에서도 확인한다. 최신 PNG의 최종 시각 승인은 통합 검수자가 확정한다.

## 최종 요소 기능 대조

56개 요소의 174개 fixture를 원래 1280×720 크기로 라이트·다크 각각 직접 열람했습니다. 자동 bounds 검사와 별개로 커넥터 및 데이터 관계를 확인했습니다. CSS anchor는 너비/높이 직접 계산에 지원되지 않는 위치를 inset 및 anchor-size 계산으로 고쳤습니다. mindmap 2·4·6개 가지, slope 양·음 기울기와 dumbbell, sparkline 24점 및 지표 내부 12점의 실제 선을 확인했습니다. hub는 각 spoke 원 테두리에서 코어까지 이어지며 글자를 관통하지 않습니다. sankey는 국내 796억→478/318억과 해외 488억→268/146/74억 두 단계 분할을 보존합니다. hierarchy·decision-tree·network·journey·swimlane·timeline·steps의 연결 방향과 선도 별도로 확인했습니다.

100칸 waffle은 단위가 겹치지 않게 정사각형 격자를 확보했고, treemap의 최소 15% 강제 폭을 제거해 46/31/15/8의 면적 관계를 보존했습니다. radar의 실제 축 개수와 다각형의 0~100 스케일을 맞추고, scatter의 tone 계열은 팔레트 자리별로 구분했습니다. pricing의 선택 tag가 없어도 제목·가격·항목 시작선은 같은 높이입니다. source 전용 private 수치 flag는 일반 fixture에 새지 않도록 기본값 0과 스타일 쿼리를 사용합니다.

슬로프 다섯 쌍의 실제 선 및 두 끝 값과 명칭을 유지하기 위해 해당 fixture의 최소 칸을 8×5로 조정했습니다. 축 라벨은 README의 좁은 칸 축 솎기 허용 규칙을 따릅니다. note/kick을 숨기는 소형 단계와 데이터명/숫자의 유지 여부는 구분했습니다.

07의 TAM/SAM은 원본 위·아래 RGB를 측정해 수직 gradient를 조정하고 TAM 85%·SAM 65% 배경 alpha로 원의 중첩도 복원했습니다. TAM은 a1과 page의 66→41% 혼합, SAM은 깊은 강조 a1-9와 page의 95→56% 혼합을 사용합니다. source07의 a1/a1-9는 원본 청색으로 공급합니다. replica와 컬렉션 요소는 같은 식이며 글자는 불투명하고 SOM 색은 유지했습니다. 이 수정은 회색 placeholder 예외와 무관한 직접 구현 도형의 명암 복원입니다.


## 주 에이전트 최종 통합 판정

원본별 개별 비교 회차와 마지막 변경 화면 재열람 후, 최신 비교 PNG·소스·실제 폰트 지문을 최종 승인 기록에 묶었다. 자동 bounds 검사와 시각 검수는 별도 근거다. 사진·복잡 이미지의 요청된 회색 대체, Lucide 치환, 가장 가까운 허용 실폰트와 안티앨리어싱의 미세 차이를 픽셀100% 동일로 표현하지 않는다. 렌더 뒤 일반 호스트 CSS·팔레트 의존성과 컬렉션 복사본 SHA를 다시 확인했다.
