# Vitreous 050 디자인 언어

이 문서는 원본 20장을 각각 관찰하고 standalone replica의 배치·원문·도형을 복구한 뒤 정리했다. 색은 디자인의 고정값이 아니라 아래 팔레트 역할로 공급한다.

- 타이포: 실제 로드한 Pretendard Variable이 페이지 제목 44/500, 본문 20/300의 기준이다. 제목 자간 −0.0055em, 본문 −0.02em, 줄 높이 1.17/1.4. 넓은 숫자·영문은 SUITE, 06 설명은 Noto Sans KR의 가는 획을 사용한다. 원본 crop 비교는 `text-measurements.json`, `numeral-measurements.json`에 기록했다. 글꼴 후보와 로드 상태를 실제 브라우저에서 확인했다.
- 제목 강조 = `--a1`, 읽기용 보조 강조 = `--a1-7`; 진한 면 위 글자 = `--a1-on`. 카드 유리 면 = `--n-1`과 `--page`의 혼합, 밝은 테두리 = `--n-1`; 축·눈금 = `--n-3`. 원의 깊이 차이 = `--a1-2-soft`부터 `--a1`까지의 단계다. series 순서는 `--a1`, `--a2`, `--a3`, `--a4`다.
- 면·선: 유리 패널은 좌상단에 흰 광택이 있고 우하단으로 옅어진다. 1px 경계, 매우 약한 투명 면, 겹친 캡슐/원의 중첩으로 구조를 만든다. 어두운 모드도 팔레트의 해당 역할을 사용한다.
- 반경: 큰 패널 24–28, 작은 설명 카드 12–14, 작은 KPI 8, 캡슐과 배지 999px/50%. 10페이지 첫 계단은 더 작은 상단 반경을 갖는다. 면마다 원본에서 실제로 다른 반경을 구분한다.
- 간격: 기본 단계 8/16/24/32/48. 1280×720의 페이지 좌우 여백53, 상단54; 브랜드175×50, 레일992×50, 사이8. 제목은 y152, 일반 콘텐츠는 y316선에서 시작한다.
- 원형 장식: 상단 한쪽에 붙는 130px 아이콘 배지, 90px 캡슐 아이콘, 134px 비즈니스 모델 배지, 72px SWOT 배지를 구별한다. 사진/3D 이미지는 지정된 연회색 placeholder이며 숫자·새 설명은 넣지 않는다.
- 차트: 면적과 선을 모두 보존하며, 막대 수·계열 수·분배 비율·상승 주석을 삭제하거나 합치지 않는다. 08은 반지름이 서로 다른 네 분면, 20은 35/15/20/30의 네 분할이다. 배경의 단순 곡선 화살표·핀·반원은 CSS/SVG로 그린다.
- 강조 문법: 제목의 일부, 문장 안의 필요한 구절, 핵심 수치에만 강조를 사용한다. 설명 전체를 두껍게 만들지 않는다. 같은 행의 카드 이름과 숫자 시작 높이를 예약한다. 칩과 캡슐은 실제 글자 기준으로 두 축 중앙 정렬한다.
- 이미지에 없는 요소도 밝고 얇은 선, 유리 면, 원/캡슐, 가는 설명과 명확한 숫자 위계로 설계한다. 관계 요소는 실제 선·화살표·빔·지지대·목표 tick을 갖는다.

컬렉션의 공개 구조는 56개 계약 요소와 foundation이다. 원본에서 반복된 조합은 정식 `--vitreous-050-*` 사설 토큰으로 치수와 조합 모드를 선언했다. 재조립의 body 직접 자식은12×6 grid 배치만 지정하며 추가 페이지 CSS를 두지 않는다. 검수용 source-palette는 원본 색 공급만 담당한다. 원본과 같은 물리 크기를 위해 호스트에서 합법적인 `--type-N`의 값만 조정한다.
