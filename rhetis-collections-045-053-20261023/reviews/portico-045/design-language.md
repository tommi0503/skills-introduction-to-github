# Portico 045 디자인 언어

## 관찰의 출처
제공된 slide_20 한 장을 먼저 독립 HTML로 재현했다. 원본은 종결 페이지이며 내지에 없는 요소는 아래 문법으로 추론했다. 샘플 컬렉션은 구조와 fixture 마크업만 참고한다.

## 형태와 위계
- 직각 사각형 모듈이 기본 단위다. 원본 사진 콜라주의 96px 격자를 모든 구성의 절제된 직사각 면·헤어라인·정렬에 확장한다.
- 선은 1px, 강조 경계는 2px. 카드 radius는 0, capsule 계열만 계약 의미를 살려 999px로 처리한다.
- 페이지의 수평 기준은 왼쪽 107px, 상단선 47px. 일반 내지는 상하 48px 여백과 12×6 그리드를 쓴다.
- 간격 단계 8/16/24/32/48px. 원본의 사진 모듈은 96px이며 장식 격자에만 사용한다.
- 대제목은 굵은 산세리프, 좌측 정렬, 대제목은 자간 0. 제목 96/64/48px, 부제 24px, 멤버명 24/20/18px, 설명 18/16px, 라벨 16/14/12px.
- 계약 표에서 가까운 실제 글꼴인 Pretendard Variable을 로드한다. 대제목은 96px·800·자간 0, 연락처는 Noto Sans KR 16px·26px 행간이 원본 래스터에 가장 가까웠다. 원본 영문 글꼴명은 이미지에서 확정할 수 없다.

## 팔레트 자리
- 원본의 거의 흰 페이지 → `--page`, 본문 검정 → `--ink`.
- 원본 파랑 CONTACT 라벨·끝 모듈 → `--a1`, 위의 글자 → `--a1-on`.
- 사진 placeholder·보조 면 → `--n-1`, 1px 선 → `--n-3`, 작은 보조 설명 → `--n-7`.
- 카드 강조는 한 멤버만 `--a1` 채움, 다른 멤버는 `--n-1` 또는 `--a1-1-soft` 면.
- 다중 계열은 `--a1`에서 `--a4`까지 순위만 사용한다. 원본 파랑을 컬렉션 CSS에 고정하지 않는다.

## 확장 문법
차트는 각진 막대와 가는 직선, 라벨은 플롯 바깥에 둔다. 관계도는 직각 사각 노드와 1px 연결선으로 구성한다. 작은 강조 라벨은 흰 여백 안에 독립한 채움 직사각형이며, 장식은 내용 뒤에 남기지 않는다. 다크는 page/ink와 중립 단계의 의미를 유지하고 강조 채움의 대비 짝을 보존한다.
