# EONU v3 아트디렉션 검토

작성일: 2026-10-21. 사용자의 마지막 6개 첨부 이미지를 대화에서 직접 관찰하고, v2의 12장 그리드 및 CSS를 확인했습니다. 이 문서는 제작 방향 제안이며 최종 제작 결과의 검수 기록은 아닙니다.

## 가장 큰 변경

v2는 거의 매 장이 제목 → 설명 → 본문 → 요약 → 긴 출처의 5단 구조이고, 03·05·09·12에서 같은 관계도가 반복됩니다. 회색 사진 면적은 늘었지만 화면에서 읽어야 하는 조각의 수는 줄지 않았습니다. 10·11장은 발표 슬라이드보다 검토용 문서에 가깝습니다.

이번에는 **짧은 주장 하나와 큰 시각물 하나**가 먼저 보이게 해야 합니다. 본문 2–11장의 제목 좌표는 고정하되 그 아래의 설명문을 필수 항목으로 만들지 않습니다. 출처·상세 검증 조건·미확정 입력 목록은 대본/근거 패널로 옮깁니다. 가설·설명용 화면·수치 미확정처럼 의미를 바꾸는 상태는 해당 시각물 옆에 한 줄로 남깁니다.

이미지는 무조건 더 많이 넣는 대신, 실제 사진/스크린샷 영역이 필요한 페이지에 크게 배치합니다. 이미지를 넣을 자리는 연회색 단색을 유지합니다. 의미 없는 반쪽 회색 면을 다시 표지/마지막에 반복하지 않습니다.

레퍼런스 합성 이미지의 바깥 투시·회전·큰 그림자는 여러 장을 보여주기 위한 목업 연출입니다. EONU의 실제 1280×720 장을 비스듬히 돌릴 필요는 없습니다. 참고해야 할 것은 장 안의 계층과 여백입니다.

## 시각 시스템 제안

- 배경 `#FAFAFC` 또는 `#F8F9FC`, 핵심 검정 `#202432`, 보조 회색 `#7C8492`, 주색 `#4778F5`, 연한 강조면 `#EEF3FF`, 이미지 placeholder `#E5E5E5`.
- 1280×720. 본문 제목 시작 x=64, y=88 또는 현재 y=96 중 하나로 통일. 작은 섹션 라벨 y=48, 본문 시각 무대 y=240 이후. 표지·마지막은 예외이며 섹션 라벨·페이지 번호 없음.
- 제목 40/52 또는 44/56px, 본문 20/28px, 라벨 16/24px, 최소 상태 표시 12/20px. 표지 60/72px 또는 64/76px. 큰 금액 88/96px. Pretendard만 사용.
- 좌우 64px, 큰 간격 48/64px, 카드 내부 32/40px. 카드 반경 24/32px, 배지 원 72/88px, 선 2px. 고정 px와 line-height 모두 짝수 정수.
- 내용 카드의 그림자는 `0 16px 40px rgba(28,40,80,.06)` 수준. 그림자와 테두리를 동시에 강하게 주지 않음. 레퍼런스의 공기감은 큰 반경보다 여백과 낮은 대비에서 나옴.
- 흰 카드가 뜨는 하단 회색 무대는 2·3·5·6·9 중 3~4장만 사용. 모든 장에 같은 반원을 넣으면 새로운 반복이 됨.
- 강조색은 한 장의 한 단어 또는 한 숫자/한 경로에 집중. 모든 소제목·아이콘·선·버튼을 같은 파랑으로 칠하지 않음.
- 사진 placeholder 안에는 작은 위치 라벨만 둠. 제품 설명은 이미지 밖의 짧은 라벨과 실제 HTML/SVG UI에 배치.

## 단순화 검수 기준

1. 멀리서 보았을 때 각 장에서 가장 큰 덩어리를 한 개만 지목할 수 있는가.
2. 제목을 뺀 본문의 텍스트 덩어리가 3개 이하인가. 06 UI 내부 항목은 예외지만 주화면 하나가 확실한가.
3. 3초 안에 한 문장으로 장의 주장을 말할 수 있는가.
4. 설명·주석을 가려도 시각물이 이야기의 방향을 보여주는가.
5. 같은 관계도·동심원·3카드가 연속/반복되지 않는가.
6. 화면을 채우기 위해 미확정 수치나 과장된 성장선을 넣지 않았는가.
7. 흰 카드와 회색 바닥의 대비는 느껴지지만 테두리/그림자가 정보보다 먼저 보이지 않는가.
8. 기존 12개 PNG와 나란히 보면 '색 변경'이 아니라 정보 구조와 시선의 우선순위가 달라졌는가.

**권장 중간 점검:** 01·02·06·11 네 장을 먼저 그리드로 놓고 기존과 나란히 보기. 이 네 장의 역할이 각각 브랜드/문제/제품/투자이므로, 이 조합에서 충분히 달라져야 나머지 8장으로 확장할 가치가 있습니다.
