현장 기록 확인
REVIEW권역 기초 기록 대조실 (OB-Review)
지점별 입력 기록을 같은 기준으로 분류
대조 결과에 따라 담당 부서에 재확인 요청
접수 파일과 증빙 문서를 함께 보관
누락된 항목은 관리 대장에 별도 표시
문서 수정 이력과 확인 책임을 구분
주요 차이의 처리 결과를 회의에서 공유
대상 범위: 매장·지역 거점·상담 창구·물류 지원실·권역 기획 조직
본사 자료 대조
REVIEW본사 회신 자료 협의실 (공통 서식)
월말 취합 자료를 제출 기한에 맞춰 확인
원본 문서와 본사 기록의 차이를 대조
기준 변경 사유를 담당자에게 서면 안내
권역별 질문 내용을 묶어 공통 답변 작성
담당자가 확정한 결과를 최종 기록에 반영
확인하지 못한 항목은 후속 회의에 상정
대상 범위: 영업 지점·본사 검토실·지원 조직·관리 사무소·기획 담당
