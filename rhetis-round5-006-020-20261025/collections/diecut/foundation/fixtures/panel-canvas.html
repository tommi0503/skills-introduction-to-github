PHASE 01.자료 범위 협의
(1~2일)

지역별 업무 범위와 담당자 확인
월말 기록의 제출 기한 협의
접수 문서의 보관 위치 지정
미확인 항목은 별도 목록에 기록

PHASE 02.서식 항목 정리
(2~3일)

지점별 입력 항목을 같은 형식으로 정리
필수 문서와 참고 문서 구분
공통 서식에 날짜와 책임자 기재
부서별 질문을 취합해 회신

PHASE 03.기초 기록 대조
(4~8일)

기준 수량과 접수 내역을 함께 대조
자료의 중복 여부 확인
표본 기록에 근거 문서 연결
결과를 검토 대장에 작성

PHASE 04.차이 원인 확인
(1~2일)

원본 기록과 회신 내용을 비교
다른 판단의 이유를 구분
확정된 내용은 관리표에 반영
검토하지 못한 건은 다음 회의로 이관

PHASE 05.결과 회의 진행
(1일)

자료 대조 결과를 담당자와 공유
수정 항목의 처리 기한 합의
다음 점검 일정을 회의록에 기록

PHASE 06.후속 과제 점검
(매월)

권역별 접수 자료를 매월 확인
예외 발생 사유를 다시 검토
서식 변경 내용은 담당자에게 공지
