# 덱 11 · 13 개별 시각 검수

담당 소스: `src/decks/d11.tsx`, `src/decks/d13.tsx`. 각 10장, 합계 20장. README.md 계약을 끝까지 읽었으며, 라이브러리 계약과 직접 재현 슬라이드의 역할을 구분했다.

## 검수 방식

- 참고 원본 20장을 모두 `view_image`로 각각 열어 텍스트, 색, 여백, 도형을 확인했다.
- Chromium 1280×720 / DPR 1에서 모든 페이지를 실제 렌더했다. `round1`, `round2`, `round3`으로 3회 비교·수정했다. 1차에는 구 서버의 폰트 미적용 상태를 확인하고 2차부터 실제 로드된 Poppins/Noto Sans KR로 비교했다.
- 최종 비교 이미지 `comparisons/11-01.png`~`11-10.png`, `13-01.png`~`13-10.png` 20개를 각각 열고 원본/결과를 나란히 검수했다. 연락처 시트만으로 끝내지 않았다.
- 페이지 경계, 텍스트 범위, 폰트, 크기 자동검사는 공통 `scripts/render.mjs`로 수행했다. 3차에서 발견한 덱11-05 문단의 수평 초과는 원본의 6줄 개행을 명시하여 수정했다. 이 마지막 수정이 루트의 전체 `final` 렌더에 반영된 것을 직접 열어 확인했다. 최종 `review/final/11-replica.json` 및 `13-replica.json`에서 두 덱 모두 10장, findings 0건, 브라우저 오류 0건, 폰트 실패 0건이다. 비교 PNG 20개도 `final` 렌더 기준으로 갱신했다.

## 의도한 차이와 판단

- 사진·복잡한 삽화는 사용자 요청에 따라 `#e5e5e5` 단색으로 바꾸었으므로 해당 영역의 픽셀 차이는 의도적이다.
- 원본 전체 이미지를 배경으로 사용하지 않는다. 차트, 도형, 폴더, 텍스트, 표는 실제 UI이며 원본 이미지는 비교 자료로만 사용한다.
- 원본 폰트 파일은 ZIP에 없었다. 영문은 형태가 가장 가까운 실제 로드된 Poppins 400/600/700/800, 한글은 Noto Sans KR 400/500/700로 해석했다. 좁은 본문의 원본 조판을 위해 일부 문단만 수평 글자폭을 조정했고 페이지/원본 이미지 비율은 왜곡하지 않았다.
- 덱11-09의 매우 작은 보조 Lorem ipsum 문구는 완전 판독이 어려워 같은 역할의 실제 라틴 문장으로 채웠다. 장식 선으로 텍스트를 대체하지 않았다.
- 덱13-03의 AI/모바일/커뮤니티 아이콘은 원본의 의미와 선 굵기를 보존하는 Lucide 아이콘으로 해석했다. 덱11-07의 가운데 손 아이콘도 Lucide로 표현했다.
- 까다로웠던 부분은 Poppins 표지의 시각적 폭, 한글 본문의 좁은 글자폭, 덱13-04 삼각형의 중첩, 덱13-08의 의도적 교차 배치였다. 최종 비교에서 레이아웃·선·색·공간 관계를 확인했다.
