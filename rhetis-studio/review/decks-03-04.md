# 덱 03·04 구현 검수

담당 소스: `src/decks/d03.tsx`, `src/decks/d04.tsx`. 원본 03의 14장, 04의 13장, 총 27장을 각각 직접 열어 확인했다. 좌표는 원본 1600×900의 0.8배로 옮겼으며 전체 결과는 1280×720이다. README 계약과 사용자 작업 요청을 구분해 읽었다. 라이브러리 계약은 별도 컬렉션 담당 범위이며, 여기서는 페이지 재현용 React 구성요소와 데이터 구조를 구현했다.

## 검수 절차

- Chromium에서 27장씩 렌더하여 `renders/round1/replica`, `round2/replica`, `round3/replica`에 기록.
- 1·2차의 원본/결과 나란히 비교 이미지 27장을 모두 개별 확인. 연락처 시트로 검수를 대체하지 않았다.
- 3차는 최종 폰트 크기와 기준선 보정 뒤 27장을 재렌더하고 변경된 표지·일반 제목·두 줄 제목을 개별 재확인했다.
- 1차 수정: 실제 serif 대체 폰트 적용, 전역 small 스타일에 따른 단위 줄바꿈 제거, 지표 넘침 제거, 텍스트 영역 확장, 목차 다이아몬드·차트 모서리 수정.
- 2차 수정: Nimbus Roman 실제 로딩 뒤 영문 표제 크기·기준선 보정, 04 표지의 큰 텍스트 비율·줄간격 보정, 일반 제목 크기 조정.
- 최종 03 자동 검사: 14장, 글자 영역 넘침/화면 초과 0개. 최종 04: 13장, 글자 영역 넘침/화면 초과 0개. PNG는 모두 1280×720. 폰트 체커에 Noto Sans KR 일부 subset의 로딩 시점에 따른 false 항목이 남아 있어 주 에이전트가 최종 font.load 검사로 재확인한다. 육안으로 한국어 글리프의 빈칸·깨짐은 없었다.

## 원본과의 의도적인 차이·판단

사진과 원본 배경 그래픽은 사용자 요청을 우선해 연한 회색 placeholder로 바꿨다. 03의 흐림 파랑·노랑 그래픽은 해당 모서리/측면 영역의 회색 직사각형으로 표시했다. 원본의 카드 안 그라디언트는 역할 색을 유지한 파랑·노랑 단색으로 해석했다. 04의 사진, 화면 사진, 인물, 사진 전체 배경도 단색 placeholder이다.

04의 기하 도형은 이미지 파일을 쓰지 않고 SVG의 원·아치·다각형·선으로 그렸다. 이 도형의 그라디언트는 옅은 단색으로 단순화했다. 일부 곡선 접합과 장식 비율은 원본과 미세하게 다르다. 03의 영문 표제는 실제 사용 가능한 Times 계열 Nimbus Roman, 본문은 실제 로드한 Pretendard, 04는 Noto Sans KR을 사용했다. 원본의 숫자용 고유 condensed 폰트를 식별할 수 없어 실제 Arial을 수평으로 좁혀 근사했다. 이 때문에 숫자 획 두께와 라틴 폭은 일부 차이가 남는다.

읽을 수 있는 문구는 원본대로 전사했다. 03-06의 본문 ‘5월 매출이 가장 높음’과 실제 1~3월 차트의 불일치, 03-13 도넛 label 및 테이블 금액의 불일치는 원본 자료에 있어 그대로 보존했다. 04 표지의 ‘2030년’과 메타의 ‘2036년’도 원본을 유지했다. 판독할 수 없어 가짜 선으로 대신한 문구는 없다.

## 사용자 SVG·그라디언트 추가 지시 반영

이 절은 앞선 ‘배경 그래픽 placeholder / 그라디언트 단색화’ 판단을 대체한다. 사진·복잡한 이미지 소재는 PH를 유지하고, 코드로 그릴 수 있는 배경과 그라디언트는 직접 구현하라는 사용자 추가 규칙에 따라 변경했다.

- 03: 기존 Base·표지·목차의 회색 배경 PH를 제거하고 SVG radialGradient의 파랑·노랑 광원을 페이지별 좌표/반경으로 직접 그렸다. 표지/감사에는 우측 큰 파랑, 좌상단 노랑, 하단 노랑을 배치했다. 일반 페이지는 원본마다 다른 위쪽/모서리 광원을 설정했다.
- 03: 공통 pill의 좌우 파랑/노랑→흰색 linear-gradient를 복원했다. KPI 세로 카드의 파랑 사선·노랑 가로 그라디언트를 복원했다.
- 04: SVG 기하 장식에 원본의 초록/흰색 linear·radial gradient를 적용했다. 팀 소개의 대각선 배경도 SVG 다각형과 linearGradient로 직접 그렸다. 달성 카드·고객 인용·캡슐·아치의 배경 그라디언트를 복원했다. 돋보기의 흰 바탕/초록 사람과 손잡이도 보정했다.
- 추가 요청 반영 렌더 `renders/gradient/replica`에서 27장을 모두 렌더하고 원본/결과 비교 `comparisons/gradient/{03,04}`의 27장을 개별 확인했다. 03·04 모두 자동 findings 0개(폰트 포함)이다. 추가 확인 후 04의 작은 장식에서 사분원 조각·단색 막대·짧은 chevron의 gradient 강도를 보정했으며 주 에이전트의 최종 통합 렌더에 포함한다.
- 직접 그린 그라디언트의 퍼짐 반경과 광원 강도에는 미세한 차이가 남는다. 첨부 원본 이미지를 배경으로 사용하지 않았다.
