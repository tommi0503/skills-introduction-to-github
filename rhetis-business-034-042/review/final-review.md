# 최종 통합 검수

## 범위와 지시 구분

참고 ZIP의 실제 이미지는 5개 덱, 91장이다. 034: 4장(06–09), 039: 30장, 040: 30장, 041: 20장, 042: 7장(01–07). 모든 원본은 1280×720이며 같은 크기로 구현한다. README는 사용자 요청에 따라 제작 계약으로 적용했으며, 이미지 속 “입력해 보세요” 등의 문구는 재현할 콘텐츠로만 취급했다. 예시 atlas/miri의 구조만 참고하고 디자인은 복사하지 않았다. 별도 새 폴더에서 작업했다.

## 구현 방식과 남는 차이

재현본은 독립 데이터 모델과 공통 텍스트·도형·선·SVG·Lucide·chip·placeholder 렌더러를 사용한다. 사진·복잡한 3D·기기 화면·이미지 로고는 연회색 단색이다. 단순 그래프·표·과정도·배경의 사선과 기하 모양은 실제 텍스트·도형·SVG다. 결과 UI에 원본 PNG를 배경이나 이미지로 넣지 않는다.

원본 편집 폰트 정보는 제공되지 않았다. Pretendard 300–900, Gmarket Sans 300/500/700, Montserrat variable 100–900의 실제 파일을 로드하고 폭·줄바꿈·글자 위치를 시각 비교했다. 글리프 모양과 일부 자간은 원본과 차이가 남는다. 작은 판독 불가 문구는 정상적인 한국어 비즈니스 문장으로 적었으며, 상세 위치와 해석은 각 deck 검수 기록을 따른다. 지도 윤곽은 원본 데이터가 없어 단순 벡터로 해석하거나 복잡한 지도 이미지를 placeholder로 처리했다. 원본의 불일치하는 수치·게이지 비율은 디자인 재현 원칙에 따라 보존한 부분이 있다.

신규 business-spectrum은 다섯 덱의 형태·강조 언어를 통합한 하나의 컬렉션이다. 독립 요소 31개와 light/dark 공유 토큰, foundation 및 수량·긴 문장 변형 fixture를 포함한다. 다크는 남색 표면, 밝은 잉크, 밝은 파랑 강조로 별도 설계했다. 샘플과 동일 디자인은 아니다.

재조립본은 collection CSS를 실제 로드하여 card·pill·metric·image-frame의 계약 마크업과 page overrides로 조립했다. 원본 위치·타이포·세부 색을 보존하는 overrides가 있으며, 복잡한 차트와 관계도는 여러 기본 단위와 SVG의 조합이다. 31종 전체의 의미 요소·반응형 동작은 독립 fixture 시트에서 검증한다.

## 검수 증거

각 담당자는 원본 전체를 개별 열람하고 실제 Chromium 렌더와 원본의 pair를 페이지별로 열어 2~3회 범위 안에서 비교·수정했다. `deck-034.md`, `deck-039.md`, `deck-040.md`, `deck-041.md`, `deck-042.md`에 페이지별 발견 사항과 결정을 기록했다. 최종 통합 검수 결과는 이 문서 아래에 추가한다. 연락처 시트는 탐색·제출용으로만 사용한다.

자동 검사는 캔버스 1280×720, 실제 글자 범위의 박스/화면 초과, 현재 사용 서체의 로딩, chip의 실제 글리프 시각 중심, 브라우저 오류, 원본 이미지 태그 삽입 여부를 확인한다. 최종 소스·공통 렌더러·HTML·PNG 해시를 확인하여 마지막 변경 후 결과가 최신인지 검사한다. 검사는 임의 요소 사이의 모든 의미적 겹침을 완전 판별하지 않으므로 개별 시각 검토를 함께 수행했다.

Rhetis importer 서버는 제공되지 않아 반입 성공을 주장하지 않는다. 제출 계약에 따른 로컬 정적 검사와 브라우저 fixture 검사를 수행한다.

## 주 에이전트 최종 통합 결과

주 에이전트가 최종 재현본91장의 원본/결과 pair를 한 장씩 직접 열어 검토했다. `primary-visual-review.csv`는 각 페이지와 근거 파일을 대응한다. 통합에서039/17 연결선의 가림 순서,040/18의 단순 기기 외곽·노치·버튼을 보완했다. 변경 페이지를 최종 브라우저 출력에서 다시 확인하며 다른 페이지의 최종픽셀 동일 여부도 검사한다. 모든 재조립본91장 역시 실제 Chromium으로 렌더했으며 픽셀 비교 증거는 `assembly-pixel-check.json`이다. 서로 동일한 픽셀의 페이지는 기존 개별 시각 검토를 함께 유효한 증거로 사용한다. 전체미리보기는 이 검수의 대체가 아니다.

최종 검사 결과는 `final-verification.json`과 `collection-contract-check.json`, `library-automatic-final.json`, `library-source-hashes.json`을 따른다. 라이브러리 최종340상태는 폰트·영역·겹침·텍스트 대비·chip 중앙검사0건, 검사한 최소대비5.02:1이다. PNG340개와 컬렉션 소스151개의 SHA가 최종파일과 일치했다.

재조립 비교에서는78장이 재현본과 픽셀 단위로 동일했다. 남은13장도 pair를 개별 열어 확인했다. 차이는 주로 회색 frame의 중첩 곡선 가장자리와 소수 SVG/글자 가장자리의 래스터라이징이며, 한 페이지에서 변경된 픽셀 비율은 최대0.2497%였다. 이 값은 재현본과 재조립본 간 비교이며 원본과의 유사도 점수가 아니다. `assembly-visual-review.csv`가 모든 페이지의 검수 방법을 구분한다.

최종 브라우저 검사에서 재현본·재조립본182장 모두0건, 모든 PNG1280×720,16개 PDF의 페이지 크기1280×720을 확인했다. 전체 슬라이드 PDF는 양쪽91쪽, 시트 PDF는 양쪽8쪽, 라이브러리 PDF는 양쪽85쪽이다. GitHub 원격 ZIP 재다운로드 증거는 저장소 최상위 `rhetis-business-034-042-github-verification.json`에 별도 제공한다(압축본의 자기 해시가 바뀌는 순환을 피하기 위해 완성 ZIP 밖에 둔다).

패키징 전 PDF의 중복 객체·폰트 스트림을 무손실 정리하여 ZIP 단일 파일 제한 안에 맞췄다. 이 과정은 PNG·글자·도형의 품질을 낮추지 않으며 정리 후 페이지 수와 크기를 다시 확인했다. 미리보기553개 로컬 링크와91개 이미지 로딩, 슬라이드 열기, 라이트/다크85 fixture 및 실제 Pretendard 로딩 검사를 통과했다.
