# 042 — MIRI COMPANY 사업 성과 보고서

## 범위와 구현
- 원본 `references/042/slide_01.png`부터 `slide_07.png`까지 7장을 모두 개별 이미지 뷰어로 열어 확인했다.
- 담당 소스는 `src/decks/042.mjs` 하나이며, 표지/목차와 공통 좌측 내비게이션을 포함한 보고서 5장을 1280×720 DOM 텍스트, CSS 면, SVG 기하 도형, Lucide 아이콘으로 제작했다.
- 원본 이미지 전체 또는 일부를 결과 이미지로 덮어 쓰지 않았다. 이 덱에는 사진·3D·기기 화면이 없으므로 회색 미디어 placeholder를 추가할 대상이 없었다.
- 공통 페이지 셸, 체크 제목, 이중 콘텐츠 카드, KPI 행, 전략 카드, 실행률 카드를 재사용한다. 원본에서 모든 주요 문구를 판독할 수 있어 문구를 임의로 창작하지 않았다.
- 원본 폰트 파일·정확한 이름이 첨부되지 않아 실제 로드 가능한 Pretendard 굵기별 웹폰트로 근사했다. 영문 표지 폭과 한글 본문 폭을 따로 조절했다. 원본의 세부 픽토그램은 Lucide 선형 아이콘으로 재해석하여 형태 차이가 남는다.
