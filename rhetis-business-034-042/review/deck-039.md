# 039 — 심플하고 깔끔한 비즈니스 기획서 검수

담당 범위: `src/decks/039.mjs`, 본 검수 기록. 원본은 `references/039/slide_01.png`–`slide_30.png` 30장이다. 원본 전부를 각각 `view_image`로 열어 확인했고, 실제 Chromium으로 렌더한 1차·2차 원본/결과 비교 이미지 30장씩도 각각 열어 확인했다. 연락처 시트만으로 검수하지 않았다.

## 구현 판단과 제약

- 흰 패널, 위쪽 연청색/아래쪽 남색 외곽, 반원 챕터 배지, 연한 블루 면, 원형 아이콘, 둥근 단계 막대를 덱 내부 함수로 재사용했다. 사진·기기 화면·복잡한 인물 삽화는 사용자 요청에 따라 연회색 단색 placeholder로 처리했다. 단순한 스마트폰 외곽은 SVG로 제작했다.
- 모든 텍스트는 실제 DOM 텍스트이고 로컬 Pretendard 실제 굵기를 사용한다. 원본의 폰트 메타데이터는 이미지에 없으므로 동일 폰트라고 단정하지 않는다. 제목 자간과 위치를 원본 폭·베이스라인에 맞춰 보정했다. 본문 줄바꿈에는 남아 있는 소폭 차이가 있다.
- 원본의 가는 다중선 아이콘은 의미가 대응하는 Lucide 아이콘으로 재구성했다. 세부 아이콘 모양은 원본과 다르다. 단순 회사 심벌은 흰색 SVG 선으로 직접 구성했다.
- 14 지도는 사진이 아닌 평면 도식이다. 단순 영역 외곽을 24개 SVG 다각형으로 재작성하고 원본의 밝은 회색/라벤더 영역 강조, 핀 위치를 유지했다. 픽셀/전체 이미지 삽입은 없다. 원본의 정확한 행정구역 명칭·용도는 제공되지 않아 지명은 임의로 붙이지 않았다.
- 22 기기 화면과 23 인물 삽화는 placeholder라 원본과 큰 시각 차이가 의도적으로 있다. 사진은 전부 동일 규칙으로 비워 두었다.
- 원본14 범례는 마지막 두 항목 모두 `키워드 1`로 보이므로 그대로 두었다. 26 하단 문장 중 작게 보이는 `한별로`는 보이는 문구로 옮겼으며, 데이터 의미가 추가되지 않도록 했다. 판독 불가능한 기기 화면 속 텍스트는 화면 전체가 placeholder 대상이므로 만들지 않았다.

## 자동 검사 및 빌드 상태

- `node --check src/decks/039.mjs` 통과.
- `node tools/build.mjs --deck 039`: 30장 빌드 성공.
- `python tools/render.py --deck 039 --round 1`: 30장 렌더, 자동발견 5건. 숫자/% 분리, 문구 너비·높이 조정으로 수정.
- `python tools/render.py --deck 039 --round 2`: 30장 렌더, 자동발견 3건. 03 장문 너비, 11 인용부호 Range 높이, 21 인지과정 본문 줄바꿈을 최종 소스에 수정했다.
- 1·2차에서 폰트로딩 실패, canvas 밖 텍스트, chip 중앙정렬 오류는 보고되지 않았다. 전부 1280×720 페이지다.
- 최종 지도 구획/마인드맵 연결점 및 자동3건 수정은 root의 통합 final 빌드·렌더에서 확인한다. 본 기록은 아직 실행되지 않은 최종검사를 통과했다고 주장하지 않는다.
