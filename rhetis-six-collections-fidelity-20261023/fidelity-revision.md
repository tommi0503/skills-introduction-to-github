# 사용자 지적에 따른 재작업 기준

2026-10-23: 사용자가 현재 결과의 원본 충실도가 부족하다고 지적했다. 기존의 완료 판단과 패키징을 중단했다.

기존 자동 검사는 구조와 렌더 안정성을 확인했지만 원본과 같은 디자인인지 판정하지 못했다. 특히 기울임 타원→원, 산형 차트→일반 카드, 원형 통계→도넛, 계단→수평 단계, 원본 파랑→주황, 큰 제목 축소를 '정규화'로 허용한 판단을 철회한다.

## 새 시각 검수

각 1280×720 페이지를 원본·replica·재조립으로 직접 비교한다. 허용된 이미지 placeholder와 판독 불가 문구를 제외하고 다음을 확인한다.

1. 페이지 외곽, 제목/본문/도형의 위치·면적·간격·정렬.
2. 원본 폰트에 가까운 실제 로드 글꼴, 굵기·시각적 글자 크기·자간·행간·줄바꿈.
3. 색의 역할과 원본 팔레트. 라이브러리 검사용 기준 팔레트와 원본 비교용 호스트 팔레트를 구별한다.
4. 도형의 곡률·기울기·겹침·선·연결 방향·상하 순서. 계약으로 표현할 수 있는 원본 형태를 임의의 다른 요소로 바꾸지 않는다.
5. 장식·구분선·범례·데이터·원본 텍스트를 빠뜨리거나 임의 추가하지 않는다.
6. 숫자와 멤버 수를 보존한다. 단순 도형은 placeholder로 대체하지 않는다.

새 페이지 전용 CSS를 덧대지 않고 요소/kit/foundation을 고친다. README의 실제 제한과 원본이 충돌하는 경우 그 사실을 따로 기록하며, 시각적 차이를 단순히 '정규화'로 완료 처리하지 않는다.

수정 전 화면을 보존하고 대표 원본|이전|수정 비교를 만든다. 부모 에이전트가 모든 페이지의 최종 화면을 개별 검수한 후에만 패키징한다. 자동 검사 0건은 원본 충실도 판정의 대체물이 아니다.
