# Dockside — 디자인 언어

대상: `016_1j5ap_파랑_깔끔_아이디어_피칭_기획서`, 30장. 밝은 운영체제의 도크와 유리 패널을 연상시키는 시스템이다. 레퍼런스 컬렉션의 CSS는 사용하지 않았다.

## 반복 관찰

- 페이지: 1280×720, 왼쪽 104px 도크 영역. 주 제목 시작 x=143px. 본문은 제목 옆 또는 아래에서 시작하며, 페이지당 한 가지 핵심 시각화를 크게 둔다.
- 선: 일반 분리선 1px, 패널 외곽에 2px 밝은 림. 관계도 연결은 1–2px 곡선 또는 직교선. 주요 궤도는 얇은 실선+점선의 이중 원.
- 모서리: 패널 18–24px, 이미지 안쪽 16–18px, 작은 아이콘 판 8–12px. 챕터·짧은 기능명은 999px 캡슐. 큰 패널에 일률적으로 둥근 모서리를 주기보다 바깥/안쪽 radius를 구분한다.
- 여백: 작은 간격 12px, 기본 24px, 큰 간격 40px. 패널 padding 24px. 기능 카드 제목·설명 시작선이 같은 높이에 놓인다. 3열·4열 구성은 등분하되 가운데 핵심 패널은 필요에 따라 조금 위로 올라간다.
- 타이포: 가장 가까운 계약 폰트는 `'Pretendard Variable'`. 제목 56–60px / 굵기600 / 자간 -1.5px / 행간1.14. 본문 패널 제목 20–24px/600, 설명 16–18px/400/1.55, 챕터14px/400. 표지 중심 제목은80–100px. 숫자는44–64px/600, 단위는16–20px.
- 강조: 전체 문장을 칠하지 않고 제목의 핵심 낱말만 강조한다. 챕터는 작고 진한 캡슐. 기능 라벨은 강조색 채움과 밝은 림, 원형 보조 컨트롤은 진한 면에 얇은 선 아이콘. 기능 카드에는 수평 강조띠가 위에 붙을 수 있다.
- 면/선/채움: 연한 면과 밝은 림이 전면, 그림자는 중성색의 낮은 단계만 사용한다. 강조색으로 큰 바탕을 채우는 경우는 핵심 요약·단일 선택 등으로 제한한다. 기본 패널은 페이지와 거의 같은 밝기로 유지한다.
- 장식: 원본의 우측 사선 질감과 하단 빛은 복잡한 그래픽 배경으로 분류한다. 단순한 반투명 대각 밴드는 gradient/mask로 직접 그렸고 넓은 빛의 변화도 토큰 gradient로 근사했다. 표지·목차·키워드 페이지는 하단 전체, 본문은 오른쪽 끝의 좁은 영역으로 분기한다. 왼쪽 도크가 페이지를 묶는다. 도크의 3D 아이콘과 사진은 회색 자리로 치환한다. 원·도넛·막대·연결선은 데이터로 그린다. 임의의 별·스티커는 추가하지 않는다.

## 팔레트 자리

| 역할 | 토큰 |
|---|---|
| 페이지 | `--page` |
| 기본 제목 | `--ink` |
| 제목 핵심 단어 / 활성 지표 | `--a1-7` (텍스트 대비), 채움 `--a1` |
| 기능 캡슐 | `--a1` + `--a1-on` |
| 챕터 캡슐 | `--ink` + `--page` |
| 기본 카드 면 | `--n-1` |
| 카드 밝은 림 | `--page` |
| 연한 강조 면 | `--a1-1-soft` / `--a1-2-soft` |
| 구분선 / 궤도 | `--n-3` / `--a1-3-soft` |
| 설명 | `--n-7` |
| 제2 시리즈 | `--a2` |
| 배경의 넓은 기운 | `--a1-1-soft` / `--a1-2-soft` / `--a2-1-soft` |
| 다크 카드 | 동일 의미 단계. 대비는 별도 렌더로 확인 |

컬렉션은 원본 파랑을 소유하지 않는다. 기준 미리보기 팔레트가 다른 색을 공급해도 위의 역할과 형태가 유지되어야 한다.
