# Confluence — 산학협력 연결의 언어

020 원본 4장과 DOM replica를 관찰했다. 가벼운 큰 면, 넓은 제목 띠, 위에 걸친 숫자 원, 중앙 원과 네 주제의 균형을 기본 언어로 쓴다. 샘플은 구조와 fixture 형식만 참고했다.

|문법|관찰|색과 공유 토큰의 자리|
|---|---|---|
|바탕|거의 흰 면에 매우 약한 세로 색조와 중앙의 밝기|--page, --a1-1-soft, --a2-1-soft|
|강조|연속 단어의 2순위 강조, 번호의 교대|--a1 / --a2, 채움 위 --aN-on|
|제목|각진 넓은 800~900 획, 표지는 촘촘하고 작은 제목은 더 열린 자간|--type-40/60/64/128, --title-weight, --confluence-hero-track|
|위계|영문은 작은 대문자에 넓은 자간, 본문은 가벼운 회색|허용 --type-8/10/12/14/16, --label-track-latin, --n-*|
|면|흰 카드에 아래로만 얕은 그림자, 상단 강조 띠|--page, --n-2, --a1 / --a2|
|모서리|큰 카드 약17, 안쪽 띠6~8, 제목 카드10|typed shared radius extensions|
|선|1px 구획선, 카드 내부 점선, 원의 넓은 바탕색 링|--n-2, --a1-2, --page|
|간격|목차 열27/행47, rail 카드 열20/행23, 페이지 가장자리94|typed shared length extensions와 margin 토큰|
|강조 처리|53px 번호 원, 넓은 직사각형 제목 띠, 367px 중심 원|모양은 실제 요소 CSS, 숫자/글자 중심정렬|
|장식|바닥8px 양분선, 머리말 양옆의 가는 선, 원을 통과하는 축|foundation과 hub의 pseudo shape|
|확장|원본에 없는 관계도·차트도 같은 면·띠·가느다란 연결선|기준 light/dark palette의 역할 토큰|

디자인은 특정 색을 소유하지 않는다. 원본의 값은 review의 host palette에서만 공급한다. 원본 재조립의 밝은 강조와 낮은 대비는 진하게 정규화하지 않는다. 라이브러리의 기준 light/dark palette는 README 도구가 공급하며 별도 검수한다.

12×6을 원본과 다른 균등 행으로 강제하지 않는다. rail 페이지는 원본 제목 띠와 카드의 높이를 보존하는 6행을 사용한다. 4주제 hub는 넓은 캔버스와 좁은 칸을 @container 단계로 나누며 fig/name을 숨기지 않는다. 사진·3D·QR은 번호가 가운데 놓인 회색 seat다.
