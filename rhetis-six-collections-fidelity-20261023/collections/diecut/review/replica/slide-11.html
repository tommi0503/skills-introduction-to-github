용접 자동화
SOLUTION
아크용접 로봇 셀 (MR-Arc 200)
  • 3D 시임 트래킹 → 모재 변형 실시간 보정
  • 용접 파라미터(전류·전압·속도) 자동 최적화
  • 스패터·흄 흡진 시스템 통합
  • 용접 비드 품질 비전 자동 검사
  • 다층 용접·위빙 패턴 자동 생성
  • MES 용접 이력 실시간 DB 연동
  • 적용 업종: 자동차 부품·철구조물·압력용기·선박부재·건설기계
도장 자동화
SOLUTION
도장 로봇 시스템 (7축 MR-Cobot Pro)
  • 3D 포인트클라우드 기반 경로 자동 생성
  • 도막 두께 실시간 측정·피드백 제어
  • 분체·수성·UV 도료 건 자동 교체
  • 도장 부스 연동 음압·온습도 자동 제어
  • 도장 영역 3D 비전 사전 스캔·검증
  • 도장 후 외관 자동 비전 검사 통합
  • 적용 업종: 가전 외장·자동차 차체·산업기계·가구·건자재
