# Afterglow — 디자인 언어

덱 015의 9장을 먼저 개별 HTML로 재현하고 원본과 1:1 병렬 비교했다. 1차 비교에서 강제 줄바꿈 주변의 예기치 않은 추가 줄과 대형 Service의 기준선 차이를 수정하고 2차 렌더를 완료했다.

- 페이지는 바깥 27px 은색 띠와 1px의 밝은 테두리, 약 16px 모서리를 갖춘 하나의 검정 화면이다. 안쪽의 내용 시작선은 60px, 상단 소형 내비게이션은 48–56px에 놓인다.
- 바닥의 얇고 강한 빛이 위쪽으로 약 64px 사라진다. 면 전체의 장식보다 하단의 억제된 강조를 우선한다.
- 강조 섹션에서는 같은 프레임의 내부 전체를 하나의 선명한 강조 면으로 채운다. 1px 수평선은 화면 폭 전체를 가르고, 원형 목차들은 그 선 위에서 균일한 크기로 배치된다.
- 카드 모서리는 12–16px, 선은 1px이다. 검정 바탕 위 밝은 카드는 내부 이미지와 텍스트를 나누며, 원형 검정 숫자 표식이 이미지와 이름 사이를 잇는다. 목록의 강조 표식은 작은 원 안의 선형 화살표다.
- 간격 단계는 4/8/12/16/24/32px이며 내부 사진 카드 여백 8–10px, 일반 카드 여백 16–24px, 카드 사이 12–16px, 큰 블록 사이 32–48px다. 라이브러리는 공유 pad/gap의 배수로 표현한다.
- 글꼴은 원본의 담백한 산세리프에 가까운 Pretendard Variable을 실제 로드한다. body 14–16px, label 11–14px, 이름 18–24px, 소형 영문 제목 20–22px, 본문 제목 32px, 표지 46–48px, 큰 수치 128px까지 단계화한다. 큰 Service는 SUITE 400의 176px와 가장 가까워 별도 등록 폰트 자리 `--afterglow-font-section`을 쓴다. 라이브러리에서는 128px 단계를 균등 1.375배 표시하여 같은 글자 크기를 유지하며 페이지나 글자의 가로·세로 비율을 늘리지 않는다.
- 제목은 얇은 영문 소제목과 굵은 한국어 강조 문장의 두 층이다. 본문은 보통 굵기와 느슨한 1.5 행간을 쓴다. 수치는 아주 얇고 크게 대비시킨다. chip과 원형 표식은 flex/grid 중심 정렬하며 line-height를 1로 둔다.

## 색의 자리

디자인은 파랑이나 검정을 저장하지 않는다. 원본의 색은 아래 역할로 이동한다.

|원본에서의 역할|팔레트 자리|
|---|---|
|화면 바탕|`--page`|
|기본 글자|`--ink`|
|은색 바깥 띠·중립 면|`--n-4` / `--n-1`|
|프레임 밝은 선|`--n-6`|
|제목 강조·작은 강조 글자|`--a1-7`|
|하단 빛·원형 화살표·강조 면|`--a1`|
|강조 채움 위 글자|`--a1-on`|
|조용한 채움·차트 면|`--a1-2-soft`|
|보조 시리즈|`--a2`, `--a3`, `--a4`|
|보통 연결선|`--n-4`|
|보조 설명|`--n-7`|

원본에 없는 복합 관계도와 차트에도 동일한 프레임, 원형 관절, 1px connector, 하단 강조선을 사용한다. 선과 원이 관계를, 단색 면이 강조를 담당한다. 임의의 별·잎·사선 장식을 추가하지 않는다.

## 검수로 확정한 보완

기본 강조색은 reference palette의 밝은 주황에서도 글자 대비를 확보하도록 foreground는 깊은 7단계, 채움과 선은 기본 강조 자리로 나눴다. 숫자 단위 small은 주위 수치의 색을 상속한다. 4열 도넛은 좁은 칸에서 2×2로 바뀌고, 세로 단계·연혁은 이름과 수치를 남겨 둔 채 간격과 타입 단계를 줄인다. 카드 이름과 설명에는 공통 행 높이를 두어 설명 길이가 첫 제목 위치를 움직이지 않게 했다. 코드에는 공유 확장 폰트 토큰으로 Nanum Gothic Coding을 쓴다.

원형 목차의 지름은 160px, 장 첫머리의 전폭 구분선과 마지막 원형 진행 화살표는 foundation의 반복 장식이다. 사진 자리는 중립 반대편 단계 `--n-8` 위 `--n-1` 글자로 두어, source의 어두운 화면에서 연회색 자리로 보인다.
