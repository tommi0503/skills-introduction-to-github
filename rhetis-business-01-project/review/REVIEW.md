# 최종 검수 기록

원본 105장을 각 담당자가 개별 열람하고 실제 Chromium에서 1280×720으로 렌더했습니다. 덱별 디자인 비교·수정은 3라운드 이내로 마쳤습니다. 주 에이전트는 원본/결과 개별 비교 이미지 105개를 다시 열어 통합 검수했습니다. 전체 미리보기는 탐색용이며 개별 검토를 대신하지 않았습니다. 최종 소스 동결 뒤 납품용 캡처를 만들었습니다.

## 반영한 수정

- 공통 수평선의 0 높이로 인한 누락, chip 테두리가 글자 stroke로도 적용되던 오류를 수정했습니다.
- chip·배지의 중앙 정렬, 제목 폭, 본문 줄바꿈·행간, 표의 행 높이, 차트의 수치·범례·배치와 강조 색을 보정했습니다.
- 폰트를 명시적으로 로드하고 렌더 완료 후 촬영합니다. 일부 연속 이미지 도구 화면에서 반복 헤더가 생략되어 보였던 현상은 PNG 실제 픽셀과 반복 촬영 비교로 헤더가 존재함을 확인했습니다(`d03-paint-diagnosis.json`).
- 단순 원자를 빈 카드·개별 metric으로 감싸던 초기 재조립을 실제 정보 블록의 `card.parts` 구조로 개선했습니다. 카드 159개, pill 73개, frame 56개를 사용하며, 나머지 텍스트는 foundation 역할, 복잡 벡터는 페이지 장식으로 보존합니다.
- 라이브러리 최소 칸의 텍스트 넘침, 과도한 inline 요소 높이, 다중 Venn·hierarchy·flowchart 연결선을 수정했습니다. 주 통합 검수에서는 flowchart의 분기 뒤 불필요한 배경/그림자 블록도 제거했습니다.

## 확인한 범위

- 재현 105 PNG, 재조립 105 PNG, 라이브러리 158 PNG의 크기는 모두 1280×720입니다.
- 글자의 실제 DOM Range와 영역 경계, 폰트 로딩, chip의 렌더 중심, JavaScript·리소스 오류를 자동 검사합니다.
- 컬렉션 31개 요소·79개 fixture의 라이트·다크, 전체/최소 칸 총 316개 배치를 검사했습니다. 지정한 22개 텍스트/배경 조합의 최소 대비는 4.552입니다.
- 최종 PNG 해시와 PDF 페이지 수·크기, 원본 SHA, ZIP CRC를 확인합니다. 실제 최종 수치와 성공 여부는 `verification.json`, `collection-contract.json`, `collection-render.json`을 기준으로 합니다.
- GitHub 업로드 ZIP은 원격에서 다시 다운로드한 뒤 SHA-256과 ZIP 내부 CRC를 확인합니다. 그 결과는 `github-download-verification.json`에 별도로 남깁니다.

## 판단과 차이

- 원본에 서체명이 없으므로 자형의 완전 일치는 확정할 수 없습니다. 로컬 폰트를 명시적으로 번들해 재현 환경을 고정했습니다.
- 사진·인물·펜·기기·지도 등은 단색 placeholder로 대체했습니다. 밝은 placeholder 위에서 읽히지 않는 일부 사진 overlay 텍스트는 검정으로 바꾸었습니다.
- 바인더·종이의 접힘과 단순 배경은 SVG/CSS로 그렸습니다. 원본의 금속 광택, 사진 질감, 작은 로고와 복합 아이콘 일부는 단순화했습니다.
- d02 도넛 원본 비율 합계는 110%입니다. 표시 숫자는 유지하고 호의 각도만 전체에 맞춰 정규화했습니다. d04의 20주년/30주년 및 시간·참석 수의 상호 모순도 원본 콘텐츠로 보존했습니다.
- 참고에 없는 31개 라이브러리 요소의 세부 형태는 얇은 프레임, 정갈한 여백, 청록 위계와 파랑·빨강·노랑 보조톤으로 설계했습니다. 다크 팔레트는 별도로 설계했습니다.
- 재조립본은 실제 카드/필/프레임 계약과 foundation을 사용하지만, 원본의 복잡한 차트·표를 모두 각 의미 계약으로 변환하지는 않습니다. 해당 데이터는 편집 가능한 원본 벡터와 텍스트로 남아 있습니다.

덱별 판독 불가능한 문구·차이·수정 내역은 `d01.json`~`d05.json`, 재조립의 구조와 토큰 반응 검증은 `assembly-review.json`, 주 에이전트가 확인한 개별 파일 해시는 `main-review.json`을 참고합니다.
