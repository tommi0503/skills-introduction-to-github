# Shared presentation model

Each deck lives only in `src/decks/deck-005.mjs` (etc) and exports default `{id:'005', title:'...', slides:[{id:'slide_08',title:'...',background:'#fff',elements:[]}]}`. Coordinates and font sizes are native 1280×720 pixels. Import helper functions from `../primitives.mjs`. Every helper's final extra argument can override defaults. Use genuine readable text and explicit line breaks. Never embed reference images, traced text paths, full-slide raster, or complex illustration images.

Text T(x,y,w,h,text,size,extra): color,weight (default400),font (default 'Noto Sans KR'; supported 'Pretendard','Noto Serif KR','Inter','Nanum Myeongjo'),lineHeight (number default1.35),letterSpacing (px default-0.5),align ('left'/'center'/'right'),valign ('top'/'middle'/'bottom'). Actual supplied local fonts loaded. `lines` use `\n`. No text scaling. R/C rectangle/ellipse: fill,stroke,strokeWidth,radius. L has x,y,x2,y2. P placeholder flat #e5e5e5, optional radius. I Lucide PascalCase name, strokeWidth default1.5. Path d uses viewBox 0 0 100 100 by default, extra viewBox:'0 0 W H',fill,stroke,strokeWidth; vectorEffect non-scaling. Extra rotate permitted on isolated elements only. Chip uses optical text centering. Table rows string[][], headerFill,fill,color,border,size,weight,colWidths (percent),align. Bars values,labels,colors,max,horizontal,showValues,size; Donut value0-100,color,track,innerRatio,label,size. Any element can carry `el` semantic folder such as 'card','metric','chart-bar' for reassembly.

Build static browser app via npm run build; `npm run dev -- --port 5301 --host 0.0.0.0`. Routes `?deck=005&slide=slide_08` or additionally `&mode=assembled`. Main handles renderer, do not modify shared files. Agents may write only their deck module, deck-specific script if needed under work/, and `review/deck-005.md`. All source images `public/reference/005/slide_08.png`. Per-deck render `node scripts/render.mjs --deck=005 --round=1`. Final source/review records must be honest about what was inspected. Once actual render exists open every individual side-by-side comparison via image viewing; maximum total 2–3 visual refinement rounds per deck. Main will send follow-up when render tools available.
