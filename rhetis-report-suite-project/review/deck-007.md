# 007 — 베이지 폴더 문서 템플릿 검수

담당 범위: `src/decks/deck-007.mjs`, 슬라이드 01–30(30장). 모든 결과는 1280×720 CSS 픽셀 좌표로 구성하며, 참고 PNG를 렌더 결과의 배경이나 UI로 사용하지 않는다.

## 원본 확인 및 구현 판단

- `/workspace/work/reference-kit/README.md` 전체와 프로젝트 `src/MODEL.md`를 읽었다. 첨부 계약은 라이브러리 형식과 요소 범위를 규정하는 자료로 적용하며, 최상위 사용자 요청의 이미지 placeholder·검수·별도 폴더 조건을 우선한다.
- 원본 01–30을 각각 원래 1280×720 크기로 열어 제목, 문구, 텍스트 줄바꿈, 여백, 폴더 탭, 얇은 선, 차트 배치를 확인했다.
- 공통 외곽: x=26/y=22, 1228×676 회갈색 모서리 프레임, x=26–48 바인딩, x=48/y=35부터 흰색 본문, 오른쪽 세로 레일과 타원 로고 문구를 재사용한다.
- 사진·프로필·회의실·3D/돋보기 합성 그래픽·모니터 내부 이미지는 사용자의 조건에 맞춰 `#e5e5e5` 단색 placeholder로 교체했다. 모니터의 프레임/받침, 폴더, 연결선, 도넛, 피라미드, 일정표는 편집 가능한 벡터이다.
- 영문 serif는 로컬에서 실제 로드한 **Cormorant Garamond 400/500/600**, 한국어는 **Noto Sans KR 400/500/600**을 사용한다. 본문 숫자는 Cormorant의 `lining-nums`, 19/20/24의 원본처럼 폭넓고 낮은 대형 숫자는 `oldstyle-nums`를 별도로 적용했다. 원본의 정확한 폰트 메타데이터가 없으므로 동형 대체 폰트라는 한계가 있다.
- 얇은 아이콘은 Lucide를 사용하고, 원본의 적층 동전 형태는 직접 만든 재사용 SVG path로 보완했다. Lucide와 원본 아이콘의 세부 윤곽은 동일하지 않다.
- 22 지도는 원본 픽셀을 추적하지 않고 Natural Earth의 public-domain 지리 좌표를 shallow-globe 형태로 직접 투영한 SVG이다. 해안선과 투영은 원본과 완전 일치하지 않는다. 지리 데이터 획득 경로: `https://raw.githubusercontent.com/holtzy/D3-graph-gallery/master/DATA/world.geojson`.
- 읽을 수 있는 한국어 본문은 실제 텍스트로 전사했다. 20XX/00/000 같은 표기와 예시 연락처는 원본의 템플릿 표기를 유지했다. 장식용 가짜 글자 선이나 텍스트 경로는 없다.

## 최종 검수 상태

- 2차 clone 결과 30장을 모두 개별 비교했다. 긴 browser navigation 세션이 두 차례 시간 초과되어 22–30은 같은 source의 새 browser 세션으로 재개했다. 원본/결과 비교를 4차로 늘린 것이 아니라 기술적 캡처 재개이다.
- 3차에서 목차의 세 항목 자동 줄바꿈, Step 5 가림, 16 오른쪽 설명 줄바꿈, 작은 폴더의 탭 높이, 19/20 대형 숫자, 24의 70% 텍스트 박스, Thank You 기준선을 보완했다.
- `comparisons/3/clone/007-slide_01.jpg`–`007-slide_30.jpg` **30개를 모두 각각 열어 최종 비교**했다. Step 5 레이블과 4개 상승 카드 설명이 보이는지, 최종 수정한 숫자와 컷아웃이 실제 렌더에 반영됐는지 확인했다.
- `review/captures/007-3-clone.json`: 30장, 자동 findings **0**, 브라우저 예외 **0**, 실패 요청 **0**. 30 PNG 모두 **1280×720** 확인.
- 원본형 차트의 00%를 사실 수치로 오인하지 않도록 재조립용 막대 데이터는 0으로 유지하고 원본이 템플릿임을 설명한다. 선 그래프의 오른쪽 두 시리즈도 원본에서 읽힌 50/45/60, 40/50/75를 명시했다. 히트맵의 축 방향과 일정표의 1–3월/3–6월/6–11월/9–12월/11–12월 기간도 원본 도형에 근거해 메타데이터에 보존한다.
- 최종 source의 라이브러리 의미 데이터는 26장에 있으며 clone 배치와 분리했다. 나머지 4장(표지/부분확대/파트구분/마지막)은 foundation/실제 본문으로 보존한다.
- 3차의 지도 22에서 뉴질랜드 SVG가 흰 본문의 하단을 소폭 넘는 것을 개별 시각검수로 발견했다. 지도 viewBox를 220 높이로 복원하고 영역 높이를 196px로 제한해 최하단 지리 좌표가 685px 이내에 머물도록 수정했다. 메인 에이전트가 production 캡처에서 지도 22를 다시 확대 확인한다.
- 메인 에이전트가 production 빌드에서 최종 source hash와 출력 파일의 일치, 전체 ZIP/PDF를 통합 확인한다.

남는 차이: exact font metadata가 없어 serif/Korean의 세부 획과 자폭은 근사이며, 사진·인물·복잡한 합성 그래픽은 요청에 따라 의도적으로 회색 자리이다. 일부 원본 아이콘을 Lucide로 치환했고 지도는 원본과 다른 지리 투영이다. 판독 불가한 tiny text를 선으로 꾸미지 않았다.
