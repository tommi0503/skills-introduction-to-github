# 006·007 컬렉션 재조립 추가 QA

검수 대상은 `renders/2/assembled/006-*.png`와 `007-*.png`이다. 재조립은 원본의 자유 좌표를 복원하는 clone 모드와 달리, 컬렉션 계약의 기본 요소와 12×6 그리드 및 보조 문구로 구성한 표준형 결과다. 이 기록은 심한 겹침·잘림·원본 의미 데이터 누락을 확인하는 추가 검수이며 컬렉션 소스를 수정하지 않는다.

## 진행 상태

`renders/2/assembled/006-slide_01.png`~`006-slide_30.png` 및 `007-slide_01.png`~`007-slide_30.png` **60개 PNG를 모두 개별 열람**했다. 연락처 시트로 대체하지 않았다. 원본 수치와 월별 일정은 해당 원본 PNG를 다시 개별 열어 확인했다. 최초 렌더는 006-03 뒤에서 TimeoutError로 끝났으나, 메인 담당자가 문서 내부 DOM 교체 방식으로 수정한 뒤 60장이 정상 생성되었다.

아래 결과는 **round2**의 상태이다. 발견 사항을 메인 담당자에게 전달했고, 보조 문구 배치·아이콘·의미 데이터 수정은 후속 최종 렌더에서 확인하도록 요청했다. 컬렉션 소스와 공통 구현 파일은 편집하지 않았다.

## 소스 기반 선행 발견과 전달

1. **007-18 / 다섯 집합 중 두 항목 누락 위험**: 원본과 library 모델에는 제품·가격·유통·홍보·사람 다섯 항목이 있으나 venn 어댑터가 첫 세 항목만 출력했다. 중복 제거는 전체 library JSON 기준이므로 렌더하지 않은 홍보·사람이 보조 문구에서도 제거될 수 있다. 계약의 venn 최대 3개를 지키면서 3+2 구성이나 보조 문구로 보존할 필요를 전달했다.
2. **007-25 / 오른쪽 두 시리즈 누락 위험**: 원본은 왼쪽 [20,40,70], 오른쪽 [50,45,60]과 [40,50,75]이다. 모델은 왼쪽 세 값만 담았고, 일반 숫자 필터가 두 자리 수치를 제거하므로 오른쪽 여섯 값 보존이 필요하다고 전달했다.
3. **007-23 / 추정값 표시**: 원본의 양쪽 막대 수치 표기는 모두 `00%`인데 재조립 모델은 70/76/66/82를 사용했다. 추정 또는 예시값이라는 명시가 필요하다고 전달했다.
4. **006-14 / donut 멤버 수**: 모델은 다섯 연령대를 한 donuts root에 넣으나 계약 최대는 4개다. 3+2 등 별도 모듈 구성이 필요하다고 전달했다.
5. **006-18 / 본문 셀 nowrap 위험**: 표 어댑터가 첫 열을 제외한 모든 셀을 `.num`으로 처리한다. 이 페이지의 2·3열은 긴 본문이므로 숫자 전용 nowrap이 겹침을 유발할 수 있다. 실제 숫자 셀에만 `.num`을 부여하거나 재조립 표에서 줄바꿈하도록 전달했다.
6. **007-28 / 조직도 1+4**: 첫 항목을 root, 나머지 네 항목을 branch로 쓰는 어댑터 수정이 이미 반영된 소스를 확인했다. round2 결과 반영 여부는 최종 PNG에서 확인할 예정이다.

## 후속 최종 렌더에 요청한 수정

메인 담당자가 보조 문구의 강제 줄바꿈을 공백으로 접고, 4열 문자량 균형 분배와 필요 시 주요 3행/보조 3행을 적용한다고 알렸다. 반복 XX월 축 라벨을 제거하고, Lucide 이름을 실제 SVG로 바꾸는 공통 수정도 준비했다고 알렸다. round2 PNG에는 아직 반영되지 않았다.

007-26의 권장 축은 X=구매금액 낮음/높음, Y=구매빈도 낮음/높음이다. 007-27 원본을 다시 열어 확인한 월별 범위는 **기획 1–3월, 설계 3–6월, 홍보 6–11월, 운영 9–12월, 보수 11–12월**이다.

006-15는 원본에서 실제 숫자가 표기된 자사 7,000과 경쟁사 2,500 두 값을 해당 이름으로 연결하면 추정 없이 의미를 보존할 수 있다. 현재 2,500/4,000/4,500/7,000의 네 값은 원본 자사 막대 폭에서 추정한 수치이므로 실제 표기와 구분해야 한다.
