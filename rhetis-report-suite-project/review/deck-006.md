## 구조와 해석

회색 바깥 바탕, 흰 보고서 시트, 가는 회색 테두리, 상단 띠와 제본 표시, 오렌지색 긴 기준선, 굵은 검정 제목을 공통 함수로 구성했다. 카드·점선·원형 프레임·광학 중심을 보정하는 라벨·벡터 삽화·본문은 데이터와 primitive로 나뉜다. 30장 모두 `slide.library`를 제공하며 주요 모듈을 card/agenda/metric/steps/timeline/cycle/table/chart 데이터로 다시 조립할 수 있다.

폰트의 원본 파일명은 이미지에서 확정할 수 없어 한글은 실제 로드한 Noto Sans KR 400–900, 좁은 영문과 수치는 실제 로드한 Roboto Condensed Variable을 선택했다. 영문 표지 폭, 한글 제목 크기·자간·줄간격을 렌더 결과로 조정했다. 원본과 글리프의 세부 윤곽은 차이가 남을 수 있다.

사진 18개와 노트북 화면 1개는 사용자의 규칙에 따라 #e5e5e5 단색 placeholder로 처리했다. 원형 사진의 외곽선과 흰 여백은 별도 벡터로 유지했다. 원본 전체 이미지를 결과 슬라이드에 사용하지 않았으며 텍스트는 실제 글자다.

## 시각 비교 이력

1. 1차: Chromium으로 01–21을 캡처했으나 Vite 리로드와 겹쳐 22에서 timeout으로 종료되었다. 이때 생성된 21장의 개별 비교 이미지를 모두 열었다. 표지/제목의 폰트 크기와 자간, SVG 선 굵기, 숫자와 단위, 인포그래픽을 수정했다.
2. 2차: 30장 전체를 Chromium으로 렌더하고 `comparisons/2/clone/006-slide_01.jpg`부터 `006-slide_30.jpg`까지 30개의 개별 원본/결과 비교 이미지를 모두 열었다. 제목과 구도를 대조하고 지도 본문 초과 3건, 목차 점선 위치, 라벨 정렬, 삽화 색을 수정했다.
3. 3차: 최종 렌더와 최종 원본/결과 개별 비교를 수행한다. 최종 자동 검사 결과와 확인 범위는 아래에 기록한다.

## 남는 차이와 판독

원본 폰트 파일명이 제공되지 않아 글리프의 세부 형태를 완전히 확정할 수 없었다. 직접 그린 카누·퍼즐·버스·대화 삽화·한국 지도와 Lucide 대체 아이콘은 원본 선의 세부를 그대로 복제한 자산이 아니다. 모든 큰 문구와 본문은 읽을 수 있어 실제 텍스트로 옮겼다. 원본의 `XX월`, `20XX`, `000` 등 템플릿 표기는 임의의 실적이나 날짜로 바꾸지 않았다. 사진과 기기 화면의 차이는 명시적으로 요청된 placeholder 처리다.
