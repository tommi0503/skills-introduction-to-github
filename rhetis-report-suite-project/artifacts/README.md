# Rhetis Report Suite

Open `preview.html` directly in a browser; no installation is needed for the static review.

- `pdfs/recreated-slides.pdf`: all 121 source recreations, 1280×720 points per page.
- `pdfs/reassembled-slides.pdf`: all 121 genuine contract-component reassemblies.
- `contact-sheets/`: six slides per 1280×720 sheet, per deck and full set, in PNG and PDF.
- `preview.jpg`, `preview-assembled.jpg`: full-set posters.
- `../renders/final/`: every native PNG.
- `../comparisons/final/`: every individual original/result comparison.
- `../review/`: source identity, render hashes, browser checks, contract checks, and visual review records.

The collection ZIP has exactly one top-level folder, `rhetis-report-suite/`. The source-deliverable ZIP has exactly one top-level folder, `rhetis-report-suite-project/`. Detailed original artwork is replaced by flat light gray placeholders according to the requested scope. Reference PNG originals are excluded from the source ZIP; comparisons retain the originals alongside rendered results.
