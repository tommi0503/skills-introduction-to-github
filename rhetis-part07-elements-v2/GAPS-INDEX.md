# 계약으로 표현할 수 없는 구조 전체 목록

각 행은 `map.json`의 `unexpressible` 인스턴스 하나다. 원형이 다른 두 번째 디자인을 base CSS에 숨기지 않았다. 필요한 제안 마크업은 각 컬렉션의 연결된 `GAPS.md`에 있다. 조립본은 이 구조를 생략하거나, 기록된 단일 base의 데이터 표현으로 대체하여 원본과 다르게 보일 수 있다.
