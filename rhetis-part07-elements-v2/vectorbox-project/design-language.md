# Vectorbox의 형태 언어

1280×720 replica 02–13의 반복 규칙이다. 흰 열린 면, 가는 선택 테두리, 네 모서리의 짧은 손잡이, 큼직한 원형 아이콘 자리와 두꺼운 산세리프 제목이 중심이다. 디자인 CSS는 팔레트의 역할만 사용한다.

- 선: 선택 프레임 1px, 바깥 손잡이 14×6px L 두 개의 조합. 독립 아이콘 프레임은 7px 정사각형 손잡이다. 원형 강조는 원 지름에 비례하는 굵은 선이다.
- 모서리: 패널과 선택 영역은 직각, 범례의 작은 표식은 공유 radius-sm, 원형 mark는 완전 원이다.
- 여백: 12/24/36의 공유 단계. 4열 결과 카드의 실제 프레임은 245×394, mark 자리145×132, 이름29/750, note23/450이다. 각 요소의 자식은 자체 cqw/cqh로 비율을 이어받는다.
- 글자: Pretendard Variable. 제목60/850, 일반 이름26–30/650–750, 본문22–24/450, 라틴 kicker20/600 Montserrat. 모든 크기는 type 단계 또는 type 단계를 경계로 하는 clamp다.
- 강조: 원본의 파란 프레임·원·제목은 `--a1`/`--a1-7`, 짙은 core는 `--ink`와 `--page`, 두 번째 계열은 `--a2`, 일반 정보는 `--ink`, 보조 선은 `--n-3`/`--n-4`다. 작은 강조 문자에는 충분한 대비가 나는 깊은 역할을 쓴다.
- 면: 카드 자체는 열린 page 면에 얇은 외곽선, `.on`은 accent 면과 on 문자를 사용한다. `.quiet`는 바깥 프레임을 덜고 원형 mark의 테두리를 강조한다. `.line`은 아이콘 자체를 선택 프레임에 담는다.
- 장식: 감사표지는 하나의 기본 `.deco`가 화면 밖으로 잘린 선택 프레임 세 개와 회색 사진 면 두 개를 그린다. 진행 점열은 일반 foundation 장치다. 일반 페이지02/11의 별도 프레임 장식은 현재 foundation 계약에 슬롯이 없어 GAPS로 남겼다. 장식으로 콘텐츠 요소의 좌표나 내부 크기를 바꾸지 않는다.
- 미관측 요소: 독립된 숫자/도형 의미를 지키면서 같은 원·가느다란 선·직각 패널·외부 캡션 문법으로 확장한다.

원본04의 방사형 숫자는 b56/700 + small30/700의 두 층이다. 대표형은 이 비율을 유지하는 figure-only card.on이며, 일반 프레임 카드와 의미를 공유하는 계약 변형으로만 제공한다. 표지는 b76/850 + 본문104/900, kicker20/600의 위계다. 모든 팔레트 literal은 외부 source-palette.css 입력에만 있고, 컬렉션 CSS는 역할 변수로 색을 받는다.

06의 사각 외곽 트랙과 독립 중앙 원은 hub 계약이 아니다. 이 전체 관계는 GAPS에 분류하고, 미관측 hub는 같은 원·접힌 검은 중심·가는 선 언어로 중심→각 멤버의 실제 방사 연결을 추론했다. 각 spoke 선은 요소 자체의 좌표계 안에서 core와 mark의 실제 중심 anchor를 잇는다.
