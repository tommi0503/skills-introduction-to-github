# Vectorbox v2 검수 기록

이 버전은 변경하지 않은 replica HTML의 실제 좌표·문자 크기에서 다시 시작했다. 이전 컬렉션의 element.css는 읽거나 재사용하지 않았다. 요소마다 대표 base를 하나 두고, 계약에 있는 변형과 자기 부품·멤버 수만으로 형태를 정한다. 페이지·fixture 식별자나 이웃 요소에 의존한 선택자는 사용하지 않는다.

## 자료와 해석

- 원본 02–13의 가시 객체 236개와 페이지 배경 12개를 map.json에 기록했다. 화면 밖으로 나간 장식의 bbox는 화면에 보이는 범위이며, 자연 좌표는 unclippedBBox와 sourceMeasurements에 남겼다.
- 13은 본문 페이지가 없는 감사표지다. 큰 문구는 foundation.cover의 lockup, 연락처는 meta, 세 선택 프레임과 두 회색 사진 자리는 하나의 기본 deco 그래픽이다. headline/prose/image-frame의 실제 관측으로 분류하지 않는다. 이 요소들은 표지의 글자·프레임 언어에서 추론한 확장이다.
- 04의 방사형 강조 모양은 card.on의 figure-only 부품이고, 10의 동전/11의 헤드폰은 card의 mark-only 부품이다. 숫자와 아이콘의 의미를 섞지 않는다.
- 원본 04는 연도별 2계열 막대와 별도 축, 10은 6조각 도넛이다. 현재 계약 구조로 표현할 수 없는 이 두 차트 구조와 비표지02/11에 없는 배경 장식 슬롯을 GAPS.md에 적었다. 후속 의미 검수에서06의 독립 core와 외곽 사각 트랙도 hub가 아님을 확인하여 다섯 번째 gap으로 추가했다. 무관한 차트로 대체하거나 여러 one-share를 겹치지 않는다.
- 라이브러리 시트는 최신 요청대로 공식 preview 방식의 점선 아이콘 자리를 쓴다. 실제 Lucide 윤곽은 조립본에서 확인한다.
- source-shaped fixture는 원문 대신 새 한국어 업무 문구를 쓴다. golden의 구조/데이터는 유지하고, 원본과 6글자 이상 겹치는 문장이 발견된 경우 최신 문구 금지를 우선하여 fixture-text-replacements.json에 변경을 기록했다.

## 크기별 검수

sheets/*-checks.json은 실제 12×6 페이지의 각 grid 칸을 브라우저로 렌더한 기록이다. 최대 크기, 허용 중간 크기, fixture 최소 크기를 라이트·다크 모두 검사한다. 긴 내용에는 내용과 멤버 수를 수용할 수 있는 최소 크기를 명시한다. `.fig`/`.name`를 감추거나 숫자를 삭제하는 방식으로 통과시키지 않는다.

세부 완료 기록은 review-progress.json에 작성한다. 자동 후보는 sheet PNG 및 해당 native 셀과 대조한다. 대비는 실제 팔레트와 PNG의 배경을 기준으로 판단한다.

보조 note 해석: taxonomy는 멤버 수와 root/부품 이름을 명시하지만 requiredParts로 보조 note를 별도 강제하지 않는다. 원본에 번호·제목만 있는 목차와 이름만 있는 목록은 보조 note를 생략한다. 원문에 없는 설명을 만들어 조립본에 넣지 않았다. 중첩 list와 tag는 독립 data-el 및 정식 item/name 마크업으로 분리했다. hl은 tag 변형이 아닌 독립 계약 root로 작성했다.

## 원본과 남은 차이 및 판단

- 원본의 기능·수치를 바꾸는 페이지별 좌표 토큰이나 미명명 변형을 추가하지 않았다. 본문은 공통12×6 그리드이므로 원본의 임의 좌표와 위치·폭·간격의 양자화 차이가 남는다. 후속 의미 검수에서06은 현재 hub 계약과 다른 관계도로 판정하여 본문 전체를 GAP으로 남겼다.
- 공통 제목은60/850이다. 원본03은52/750인 예외가 있으나, 페이지 번호나 문구별 조건으로 제목을 분기하지 않아 차이가 남는다. 표지13은 별도 명명된 cover 문법이므로 원본의104/76 위계를 보존한다.
- 원본08의 `EXPETED RESULTS` 표기는 원문 그대로 조립했다. immutable replica05의 `표율적인 운영`도 원문 확인 자료의 표기로 보존했다. 원문 문구를 fixture로 재사용하지 않았다.
- 원본10의 여섯 항목은 각각25%로 적혀 합계150%다. 그림은 같은 수치를 따른 여섯 동일 조각으로도 보이지 않는다. 이를100%로 고쳐 쓰거나 임의의 정합 수치를 만들지 않고, 원문을 보존하고 다중 조각 차트 자체는 계약 gap으로 남겼다.
- 아이콘은 빈 `.icon[data-icon]` 슬롯과 실제 Lucide 렌더를 사용했다. 특히12의 원본 신분증 초상화·목선 모양은 `contact-round`의 사각 카드 윤곽으로 근사되어 다르다. 임의 SVG 부품으로 계약을 늘리지 않았다. 원본의 복잡한 이미지 자리는 연한 중립색 placeholder로 처리한다.
- `tag`는 부품 안의 라벨이고 `hl`은 별도 inline root다. 너비를 고정한 버튼처럼 만들지 않고 텍스트의 실제 폭을 쓰게 했다. 요금제 추천 라벨도 `.name` 부품 안에 독립 data-el로 둔다.
- golden callout-stack fixture의 원래 inline justify-content는 정확한 fixture 보존 요구에 따라 남겼다. 나머지 새 fixture와 조립본에는 grid 배치와 계약 수치 데이터만 inline으로 사용한다.

## 실제 검수에서 수정한 사례

여러 donut의 개별 기본 transform이 row 안의 링에 남아 중심을 벗어나던 문제를 제거했다. row 항목명은 작은 링 바깥 아래에 두어 링과 글자가 겹치지 않게 했다. 로고의 최소칸 멤버 배치, 연혁의 선과 점, 조직도 하위 행 상자, 원형 노드의 긴 이름, 피라미드·nine-box·시스템 계층의 내부 글자를 실제 크기에 맞춰 수정하고 재렌더했다. Journey의 강조 면이 감정 곡선을 가리던 순서를 고쳤다. 로드맵의 작은 보조계열 문자는 진한 면의 흰색 대신 얇은 선·옅은 면·ink를 써 양 모드 대비를 확보했다. 모든 내용과 수치는 유지했다.

## 관계 의미 교차검수 후 정정

최종 원본 대조 다음의 별도 기능 검수에서, 06 외곽 사각 트랙을 hub로 매핑한 해석 오류를 발견했다. 중앙 원은 외곽 네 점과 연결되어 있지 않으므로 hub.spokes가 아니다. map의06-hub를 unexpressible로 바꾸고 필요한 graph edge 마크업을 GAPS.md에 적었다. 조립본의 잘못된 hub도 제거했으며 원본에 없는 방사 연결을 추가하지 않았다. 이로써 gap은5개가 되었다. 원본 자체를 맞춘 replica는 변경하지 않았다. hub CSS는 원·검은 접힌 중심·가는 선만 같은 언어로 쓰는 inferred radial로 바꾸고 replica-06 fixture를 inferred-radial로 이름을 바로잡았다.

hierarchy는 각 branch 상단선이 gap에서 끊겼던 문제를 root 소유의 연속 bus와 실제 node로 내려오는 세로선으로 수정했다. swimlane 최소6×3에서 공통 .name28px가 작은 노드의 본문 크기보다 우선해 면 밖으로3줄이 나왔던 문제는 .node 자신의 cqw/cqh 제한 글자 크기를 .name에 그대로 적용해 고쳤다. wholeComponent 자동검사가0이어도 내부 node 면 밖 글자를 놓친 사례로 기록한다. map.roles에는 덱 공통의 색 역할을 한 번 정의하고, 기존 CSS의 page/ink/강조면/강조문자/관계선/보조문자 용도와 대응시켰다.

방사 선의 anchor 기준은 변형된 root 자체가 만든 containing block으로 고정했다. `position:fixed` pseudo는 viewport가 아닌 해당 root 좌표계에 속하며, 실제 native 크기에서 core/mark 중심을 이었다. 자신의 작은 spoke 박스를 기준으로 anchor를 잡으면 너비0으로 선이 사라지는 브라우저 동작을 실제 확인하고 교정했다.

관계 의미 교정 후 최종 재렌더: hub16·hierarchy24·swimlane24 cell을 라이트·다크에서 모두 직접 확인했고, 모든 자동 후보가0이다. 이어서12개 조립본 전체를 다시 렌더했으며06의 본문 공백은 의도적으로 선언한 관계도 GAP과 일치한다. 최종 map.roles는23개 공통 역할이며 마지막 정적 검사56요소 오류0·경고0·원본문구 중복0이다.

6멤버 hub를 실제로 추가 검수하자 중앙 원이 가운데 mark 두 개를 가려 해당 방사선이 안 보였다. 멤버5–6개인 경우 중앙 원의 비율을 줄여 분리 간격을 확보하고 중심 아이콘도 같은 비율로 줄였다. 새 inferred-six-members fixture를 넣어 계약 상한6개까지 실제 크기 검수에 포함했다.
