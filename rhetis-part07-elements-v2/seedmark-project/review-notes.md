## replica → 새 요소

- 선/영역의 처음 구현에서 flat 구간을 포함하는 양수 직사각형 앵커 수학을 확인했다. 실제 동일값44×6 fixture를 따로 추가했고, 상승·하강·평탄 선이 모두 연결되는 것을 확인했다.
- 카드 제목은 공통 track으로 맞췄다. 긴 이름·note에 따라 제목 시작점이 달라지던 부분, 작은 bullet/meter의 높이, area/radar의 겹친 계열명, 가로 bar의 긴 라벨을 교정했다.
- Venn 두 원이 넓은 칸에서 떨어지는 문제, journey 선이 끊기거나 변화 방향이 뒤집히는 문제, mindmap 링크가 core와 닿지 않는 문제, radar의 타원 왜곡을 실제 시트로 찾아 고쳤다.
- 작은 SWOT와 가격표의 기본 ul 여백, portrait/avatar의 범위, 반복 profile의 경력 목록, bare seat의 flex 늘어남을 확인했다. callout-stack의 실제 seat는574×263에서263×263으로 고쳤다. 명시적 frame/portrait는 이 규칙과 구분한다.
- CSS 수식의 공백 정리가 palette 이름까지 건드린 오류가 한 번 있었다. 실제 스크린샷 대비 검사가 이를 잡았다. 산술 리터럴만 처리하도록 수정하고 영향 시트를 다시 그렸다. 그 중간 시트는 최종 증거가 아니다.
- 시트는 제공된 기준 팔레트의 light/dark로 렌더한다. 원본의 검정/연두와 다른 것은 역할 색 검수이며 샘플 디자인을 차용한 것이 아니다.
- 실제 source 문구를 조립하자 작은 가로 카드와 3행 제목, 좁은 경력 목록에 추가 반응형 문제가 나타났다. 원문을 줄이거나 페이지를 옮기지 않고 요소 자신의 폭·높이와 부품 구조에서 해결했다.

## 조립 마크업과 고정 지도

21개 HTML을 지도에서 새로 만들었다. `.slide > .page > .body`의12×6 배치와 기존 계약 요소만 사용한다. 새 페이지 CSS, source 클래스, 기하용 외부 기본값, 위치용 inline 속성을 넣지 않았다. `v2-platform.css`는 호스트 reset·공식 type·JSON 기본값 공급뿐이다.

## 지도 design 서술 보완

211개 논리 요소·장치·바탕 모두에 원형의 구체적인 design 서술을 추가했다. 불변 replica21장을 실제 브라우저로 다시 읽어 bbox, 부모/inline 자식의 font·굵기·행간·자간·채움·테두리·radius를 designEvidence에 기록했다. base/variant는 실제 멤버와 선의 문법을 자세히 적고 same-as는 같은 모양과 이번 문구/줄 수 차이를 간결히 적었다. 미표현10건도 원통/기간 띠/파이 등 관찰 형태를 기록하며, 지도 설명을 요소 구현 완료나 픽셀 일치로 주장하지 않는다. 원본·배치·CSS는 수정하지 않았다.
