# Seedmark 디자인 언어

072 덱의 21개 불변 replica를 기준으로 만들었다. 다른 컬렉션의 CSS는 읽거나 가져오지 않았다. `map.json`에는 1280×720 좌표의 상위 원본 조각 544개, 가시 인스턴스 216개, 내부 b/span/small 실측 57개가 있다. 20개 요소에 측정 base가 있고, list는 원본의 `.divided`만 관찰되어 기본형을 추론했다. 그 밖의 기본형도 아래 문법으로 설계했다.

| 관찰 | 수치·비율 | 컬렉션 규칙 |
|---|---|---|
| 페이지 여백 | 좌우84, 상단64 | `--margin-x`, `--margin-y`; 본문12×6 |
| 가는 경계 | 대체로1–2px | `--stroke:1.5px`; 구획은 중간 무채색 역할 |
| 카드 모서리 | 약16px | `--radius`; 라벨은 `--radius-sm` |
| 캡슐 | 길이에 상관없이 둥근 끝 | 999px 형태, 이름·note를 안쪽 중앙 정렬 |
| 간격 | 12/24/36px 중심 | `--gap-sm`, `--gap`, `--gap-lg`; 내부 비례는 cqw/cqh |
| 제목 | 가벼운44px, 1.4행간 | Noto Sans KR 350; 강조 구절700 |

색은 고정 디자인이 아니다. 페이지는 `--page`, 글자는 `--ink`, 보조 표면은 `--n-1`, 구획선은 `--n-3`, 진한 띠는 `--n-7`을 쓴다. 선택 면은 `--a1`과 `--a1-on`, 비교 계열은 `--a2…4` 또는 그 soft 단계다. kit에는 page/ink 이외 색 값을 넣지 않았다. 원본 색은 외부 `assets/source-palette.css`만 공급한다. 복사되어 있던 `assets/source-defaults.css`의 기하 변수는 연결하지 않는다.

원본에 없는 구조도 가는 경계, 작은 원형 표식, 둥근 면, 강한 이름과 조용한 note로 만든다. 연결선은 모든 멤버를 가진 요소가 소유한다. line/area는 실제 점 보간, slope와 journey는 상승·하강·평탄 구간 모두 같은 수식으로 계산한다. source/fixture 이름이나 이웃 요소를 검사하는 CSS는 없다. root는 size container이며 실제 cqw/cqh 계산은 자식에서 한다.

foundation은 페이지 장치와 배치만 담당한다. 일반 `.seat`와 stack 안 bare seat는 정사각을 유지하며, 요소 root를 foundation에서 선택하지 않는다. 사진·일러스트·로고는 복잡한 원본 이미지를 넣지 않고 연한 단색 seat로 남긴다.

Grouped 비교막대 13·14·20은 독립 bar 기본형이 아니다. chart-bar는 덱의 선·면·타이포에서 추론하며 직접 대응으로 세지 않는다. 해당 원형3개는 map/GAPS에 보존한다.

사진틀의 직접 원형은17페이지의200×121/radius70 capsule이다. 내부seat도같은비율로차며 추론outline이나square장식은추가하지않는다. metric은150:398의두열 안에서figure/name을왼쪽위아래로두고 note를오른쪽에유지한다.
