# Crossrail

A fresh Rhetis collection derived from the 30-page 073 reference deck. It uses structural rails, square fields, fine rules, circular icon seats, connected chevrons and restrained outlined capsules. All element colours are palette roles; a host supplies the active palette and official type steps.

- `kit/` contains shared typography, spacing and page tokens.
- `foundation/` defines the 1280×720 page and 12×6 body grid, page furniture and image/icon placeholders.
- `elements/` contains all 56 contracted element families, scoped CSS, metadata, English design descriptions and fixtures.

Each element is a size container and responds to its own allocated box. Fixtures include basic cases, supplied golden cases and newly written Korean business copy based on the measured reference compositions. The accompanying review package contains the measurement map, rendered size sheets and explicit contract gaps. Those gaps are not represented by hidden values, unrelated markup or page-specific geometry.
