## 범위와 보존

078 덱 19장. 기존 replica HTML/CSS/PNG/PDF를 그대로 두고, 이번 컬렉션의 각 `element.css`를 새로 작성했다. 기존 컬렉션 CSS를 수정하거나 덧붙이지 않았다. `map.json`은 배경·foundation 장치·직접 표현 가능한 요소·계약으로 표현할 수 없는 부분을 구분하며, 픽셀 경계는 1280×720 replica의 DOM 실측이다. 글자 안쪽 b/small/span의 실제 크기까지 `source-subpart-measurements.json`과 지도에 보존했다.

## 소스 수치에서 바로잡은 사항

- 페이지 여백을 요소 여백으로 다시 넣는 오류를 제거했다. 목차937px, 순서1043/1098px, 목록977px 등은 각 요소의 상자 기준이다.
- 지표의 부모30px만 보고 놓치기 쉬운 내부 숫자43px/700와 단위30px를 각각 적용했다.
- 인용의 검은 인라인 강조와 Nanum Pen36px 서명을 별도 등록했다. 카드18의 세로 구분선155px, 카드11의 오른쪽 아래 아이콘, 카드14/19의 서로 다른 quiet 부품을 실제 수치로 작성했다.
- 다섯·여섯 멤버 순서에서 설명이 원 아래로 넘치는 것을 발견해 멤버 수 조건으로 글자 위계를 내리고, 좁은 칸에서는 부차적 설명을 숨겼다. 원본의 네 멤버 기준 수치는 유지했다.
- 6개 목차 멤버에서 높이 질의 때문에 번호 원이 지나치게 작아지는 것을 고쳤다. 번호는 캡슐 행 안에서 충분한 면적을 갖는다.
- 카드의 논리적 min-block-size가 뒤의 min-height:0에 지워지던 오류와, 긴 설명에 따라 숫자·제목의 시작 높이가 바뀌던 오류를 수정했다.
- 허용되지 않은 `callout.on`은 제거했다. 강조된 문장용 가짜 변형을 만들지 않는다.

## 계약 해석과 스스로 내린 결정

원본에 없는 note/avatar를 발명해 채우지 않았다. taxonomy가 멤버 수를 명시한 경우는 엄격하게 지킨다. 다른 요소인 `.list`와 `.tag`를 품으면 각각 실제 `data-el`을 부여한다. SWOT의 문단을 1항목 목록으로 속이거나, 패널을 callout으로 바꾸지 않는다.

모범 구성의 구조·숫자 데이터는 그대로 유지했다. 원본 reference의 `card-4`에는 비어 있지 않은 ✹ icon이 실제로 들어 있다. 이 파일만 동일 마크업이라는 더 구체적인 요구를 따랐으며 새 fixture는 빈 Lucide icon 자리만 사용한다. 모범 `callout-stack`의 원래 `justify-content:flex-end`도 같은 이유로 보존했다. 모범 문구가 replica와 6자 이상 겹친 한 note는 최신 문구 금지에 맞춰 새 사업 문장으로 바꾸고 구조·데이터는 유지했다.

원본의 밝은 회색 보조 글자는 원본 style에서 대비 기준을 충족하지 않을 수 있다. 컬렉션 시트는 README의 공식 light/dark 팔레트로 대비를 검수하며, 원본 style을 주입한 조립본의 차이는 별도로 기록한다. 원래 색 리터럴을 컬렉션 CSS 안에 넣지 않았다.

사진·복잡한 그림은 기존 replica의 연회색 placeholder를 유지한다. 세로 인물 사진은 주어진 그리드 안에서 원래 400:608 비율을 보존해 맞춘다. 페이지당 임의 보정 CSS나 새 클래스는 사용하지 않는다. 12×6 정수 그리드의 양쪽 경계를 최초 한 번 고정해 snap하므로 미세한 원본 좌표까지 동일하지 않으며, 계약이 허용하지 않는 패널·조직도·ring은 지도와 `GAPS.md`에 명시한다.

## 검수 근거

`sheets/*-checks.json`은 실제 1280×720 그리드 span을 바꿔 렌더한 각 fixture·크기의 경계, 잘림, 겹침, 부품, 로드된 폰트와 대비 검사다. `optical-checks.json`은 단독 채움 tag/pill의 실제 픽셀 글자 중심 검사이며 icon·note가 함께 있는 캡슐과 인라인 highlight를 그 범위에 포함했다고 주장하지 않는다. 최종 전체 통합 결과와 파일 해시는 별도 verification 기록에 남긴다. 자동 검사 0건을 원본과 픽셀 동일하다는 뜻으로 사용하지 않는다.

독립적으로 배치된 06의 좌우 문단과12의 상하 문단을 하나로 묶은 지도 추출 오류2건을 각각 실제 경계의 독립 prose로 분해했다. CSS를 맞추려 한 문장을 쪼갠 경우가 아니며, 원래 sourceNodes 소유는 한 번씩 유지한다.
