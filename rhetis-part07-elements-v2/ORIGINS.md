# 요소별 출처

지도에서 `base`와 명명된 `variant:`만 직접 출처로 센다. `same-as:`는 반복 사용이며 새 원형이 아니다. base가 없는 요소는 추론이다. 그 경우 첫 CSS 주석을 인용하며, 주석에 적힌 source/경로를 해당 요소의 직접 원형으로 승격하지 않는다. 이 표의 출처는 시각적 동일성이나 계약 반입 성공을 뜻하지 않는다.
