# 주 에이전트 최종 통합 검수

지난 결과의 replica 112페이지는 소스·PNG·PDF를 포함해 변경하지 않았다. 기존 버전과 새 작업을 별도 폴더에 보존한다. 이 검수는 컬렉션 사용성 및 계약 대응 검수이며, 조립본이 원본과 픽셀 단위로 동일하다는 판정이 아니다.

## 원형 추출과 최종 판단

- 다섯 지도에서 관측 원형과 추론 요소를 구분했다. 출처는 [280행 상세표](ORIGINS.md)와 [56행 요약표](ORIGINS-COMPACT.md)에 기록했다.
- 연속 쉐브론과 서로 떨어진 쉐브론, 직사각 표와 캡슐 셀 표, 일반 범례와 키워드 캡슐은 같은 base의 폭 분기로 바꾸지 않았다. 의미가 맞는 기존 계약으로 옮기거나 미표현으로 기록했다.
- 둘 이상의 형제가 공유하는 선은 개별 카드에서 그리지 않았다. 시퀀스·그래프 전체를 가진 요소가 연결선을 소유하며, 현재 계약에 그 전체가 없으면 GAPS로 남겼다.
- 막대/선 차트의 숫자축은 공개 `--max`로 계산할 수 있어 미표현 판정을 철회하고 복원했다. 소수 축은 두 자리로 표현한다. 임의 새 at-rule이나 데이터별 선택자는 추가하지 않았다.
- Crossrail 30의 닫는 장면은 이미 허용된 foundation 의미 변형으로 표현할 수 있어 잘못된 미표현 판정을 철회했다. 원형의 실제 body를 기준으로 최초 grid 추출을 바로잡았다.
- Meridian의 다른 모양 표는 원래 데이터를 단일 캡슐 셀 base로 표현하지만 원본의 직사각 장식은 복원하지 못한다. 이 차이를 원형 동일성으로 주장하지 않았다.
- 작은 칸에서 note/kick을 줄이거나 숨기는 기준과 최소 칸은 각 fixture 첫 줄과 실제 시트에 있다. photo/icon placeholder는 공식 preview 방식으로 검사하고, 조립본은 실제 로컬 Lucide 런타임으로 다시 확인했다.
- 새 fixture 본문은 한국어 사업 문장이다. 원문 6자 연속 일치는 inline 자식 경계를 포함해 자동 검사했다. 원문은 조립 검증에만 사용했다.
- 모범 구성140개는 구조·속성·수치를 보존했다. 보이는 문구135개는 샘플과 같고, 실제 replica 6자 충돌이 있는5개만 문구를 바꿨다. 마감 중29개의 끝 공백·줄바꿈 차이를 문구 변경으로 잘못 분류한 검사 보고를 정정했다. 주 에이전트의 독립 대조도135/5를 확인했으며 이 오검출 때문에 소스를 수정하지 않았다. 서식 차이와 실제 문구 차이는 감사 보고서에서 별도로 기록한다.

## 직접 본 최종 화면

`root-visual-review.json`은 실제로 본 PNG의 SHA256을 저장한다. 최종 수정 뒤의 560개 라이트·다크 크기별 요소 시트, 79개 원형 대조 시트, 112개 원본 | replica | 조립 비교, 24개 foundation PNG, 합계775개 canonical 이미지를 확인했다. 긴 시트는 전체 배치와 개별 문제 영역의 native crop을 확인했으며, 모든 작은 글자를 축소 overview에서 읽었다고 주장하지 않는다. 담당자는 각자의 모든 크기 칸을 native로 확인했다. 최종 해시 대조 결과는 `root-visual-review-status.json`의 unseenOrStale 빈 목록이다.

## 계약 공백

[전체85개 인스턴스](GAPS-INDEX.md). 컬렉션별5/11/34/15/20개이며, 필요한 마크업 제안은 각 프로젝트 `GAPS.md`에 있다. 원본과 조립본의 큰 빈 영역은 이 공백을 포함하며 완료/동일로 숨기지 않는다. 자동 검사 통과는 Rhetis 실제 반입 실행을 뜻하지 않는다.

## 빌드와 게시 검증

최종 개수·렌더 fingerprint·폰트 로딩·원문 검사·모범 구성·PNG 크기·불변 replica 해시는 `integration-verification.json`과 연결 manifest를 기준으로 한다. ZIP 내부 CRC·파일 SHA·PNG chunk CRC·정확한 치수는 `deliverables/manifest.json`에서 확인한다. 게시 후 실제 ZIP을 다시 내려받은 결과는 `publication-verification.json`에 별도 저장한다. 내려받기 전에는 검증 완료로 표시하지 않는다.
