def monthly_churn(rows):

# 월별 해지율을 계산합니다

total = 0

lost = 0

for row in rows:

total += row["active"]

lost += row["cancelled"]

if total == 0:

return 0.0

return round(lost / total * 100, 2)

print(monthly_churn(load("2026-09.csv")))

prose / prose-cols min 10x5

국내 협업 도구 시장은 지난 3년 동안 연평균 18% 성장했습니다. 대기업은 이미 대부분 전환을 마쳤고, 성장의 중심은 직원 300명에서 1,000명 사이의 중견기업으로 옮겨 가고 있습니다.

중견기업이 도입을 미루는 가장 큰 이유는 가격이 아니라 기존 시스템과의 연동 부담입니다. 설문에 응한 담당자의 62%가 회계와 인사 시스템 연동을 첫 번째 걸림돌로 꼽았습니다.

그래서 우리는 연동을 제품의 기본 기능으로 다룹니다. 주요 ERP 다섯 종과의 연결을 미리 갖추고, 도입 첫 2주 안에 데이터 이관까지 마치는 전담 지원을 제공합니다.

올해 목표는 중견기업 고객 400곳 확보입니다. 산업별 사례를 먼저 쌓고, 파트너사와 함께 지역 거점 영업을 넓혀 갑니다.
