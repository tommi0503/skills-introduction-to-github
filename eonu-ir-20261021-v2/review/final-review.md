# EONU v2 최종 검수

작성일: 2026-10-21. 기존 v1과 프레젠테이션 폴더를 보존한 새 폴더입니다.

## 디자인 수정 범위

사용자의 후속 지시에 따라 이미지 영역과 시각적 중심을 강화하고 Pretendard 및 4px/2px 규격으로 재구성했습니다. 기존 제작 시안의 실제 렌더를 열어 확인한 참고 기록은 `design-references.md`에 있습니다.

- 와이어프레임과 시안 각각 12장. 6장은 데모 흐름.
- 표지와 마지막 장: 본문용 섹션 타이틀·페이지 번호·본문 헤더 없음. 뷰어의 빈 섹션 라벨과 구분선도 숨김.
- 본문 2–11장: 섹션 x=64, 제목 시작점 (64,96), 원본 캔버스 1280×720.
- 덱당 이미지 placeholder 12개, 9개 페이지에 배치. 전부 `#e5e5e5` 단색. 표지 46.25%, 마지막 45% 이미지 영역.
- 텍스트·글자 크기·행간·고정 px 단위는 짝수 정수. 전체 캔버스의 반응형 축소는 유지.
- HTML/SVG 관계도, 데모 UI, 시장 포함 관계, 사업 경로, 자금 표가 두 스타일 모두 구현됨.

## 내용의 확정 범위

이번 v2의 수정은 구도·타이포·이미지 비중·뷰어 표시 중심입니다. 12장 대본 2,106자는 v1과 동일합니다. 300초는 배분안이며 실제 발표 시간을 측정한 값이 아닙니다. 시장·가격·배분·실증·계약 등 원문에 없는 숫자와 성과를 추가하지 않았습니다. 미확정 입력란과 가설 상태는 기획 검토 문서와 슬라이드에 남겨두었습니다.

## 실행 환경

실제 동작은 localhost에서 검증했습니다. 관리형 Chromium 정책으로 `file://` 직접 실행이 차단되어 그 경로의 실동작 검증은 하지 못했습니다. 상대 경로, 로컬 폰트, classic JavaScript로 구성했고 외부 서비스 요청은 없습니다. README에 필요 시 로컬 서버 실행 방법을 안내했습니다.

ZIP 생성 시 CRC 및 내부 파일별 SHA-256을 확인합니다. 이후 실제 GitHub 업로드 파일을 다시 다운로드한 결과는 저장소 루트의 `eonu-ir-20261021-v2-github-verification.json`에서 별도로 확인할 수 있습니다.
