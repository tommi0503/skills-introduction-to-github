# EONU v2 — 기존 제작 시안 검토

검토 범위: `presentation4-clone/renders/final`의 실제 제작 시트 6개, `presentation5-clone/review/preview-pages`의 실제 제작 시트 12개, ZIP에서 추출한 제작 PNG와 기존 개별 PNG 11개를 직접 열람했습니다. 원본 참고 시트를 재열람한 것이 아니라 결과 렌더를 우선 확인했습니다. 기존 프레젠테이션 파일은 수정하지 않았습니다.

## 결론

첫 EONU의 약점은 밝은 배경 자체가 아니라, 모든 내용이 비슷한 크기의 라운드 카드로 분절되고 각 페이지에 충분히 큰 중심 시각요소가 없다는 점입니다. 사진 자리도 2장과 작은 대표 사진에 집중되어 실제 사진이 들어간 이후에도 덱 전체가 텍스트 표처럼 보일 수 있습니다.

추천 방향은 **표지/마무리 전용 hero 구성 + 본문 3가지 레이아웃 계열**입니다. 표지와 마지막에는 본문용 섹션 라벨·페이지 번호를 넣지 않습니다. 본문 2~11장의 섹션 타이틀 좌표만 통일합니다. 중간 장은 큰 사진과 설명의 2열, 큰 관계도와 짧은 설명, 넓은 단계 흐름으로 구분하되 좌우 여백과 타이포 위계는 공유합니다.

## 이미지 영역을 늘릴 위치

- 01: 큰 hero 이미지 1개. 제목과 동일한 시각적 무게를 갖도록 배치.
- 02: 네 장면을 현재보다 크게 구성하거나 1개 큰 병원 장면 + 3개 짧은 상황으로 리듬을 만듦.
- 03: 환자·보호자·의료진의 인물 이미지 자리 세 개를 역할과 연결. 도식보다 무겁지 않도록 같은 규격.
- 04: 의료진 또는 상담 장면 큰 이미지 1개와 도입 가치. 수익 가설은 짧은 흐름으로 아래에 정리.
- 05~06: 사진 대신 실제 UI/관계도 자체가 시각 중심. 이미지 부재를 작은 카드 수 증가로 메우지 않음.
- 09: 노년층/환자 일상 장면을 연구·확장 방향과 연결할 수 있음.
- 10: 현장 검토/데모 이미지 자리 1개, 나머지는 실제 상태와 다음 지표.
- 11: 대표 사진 영역을 의미 있게 확대하고 실행 역량 문장과 결합.
- 12: 표지를 되받는 hero 이미지와 마지막 문장. 본문 헤더/푸터 구조를 반복하지 않음.

실제 이미지 미제공 조건은 그대로 유지하며 모든 사진 자리는 연한 회색 단색 `#e5e5e5`입니다. 주석은 작은 회색 라벨로 표시하되 사진 자리 중앙을 큰 설명 문장으로 채우지 않습니다.

## 4px/2px 규격 제안

1280×720 원본 캔버스 기준입니다. 뷰어의 반응형 축소만 바깥 래퍼에 적용합니다.

- 바깥 여백 64px, 본문 유효 폭 1152px.
- 기본 간격 8/16/24/32/48/64px. 세부 보정 2/4/6/12px.
- 2열 예: 552 + 48 + 552, 또는 640 + 32 + 480.
- 3열 예: 368 × 3 + 24 × 2. 4열 예: 270 × 4 + 24 × 3.
- Pretendard: 표지 64/72/96px, 본문 제목 40/48px, 큰 메시지 28/32px, 본문 20/24px, 보조 16/18px, 출처 12/14px.
- 행간도 `line-height:1.42` 대신 24/28/32/40/48/56/72/80/104px처럼 짝수 픽셀로 선언.
- radius 12/16/24/32px, 테두리/도식선 2px, 강조선 4px, 아이콘 24/32/40/48px.
- SVG의 노드 위치·크기와 path 끝점도 2px 격자로 맞춤. 글꼴 크기를 13/15/17/21px로 쓰거나 개별 요소에 0.92배 변환을 쓰지 않음.
- 2~11장 섹션 라벨/메인 제목 좌표 고정. 표지/마무리는 독립 컴포넌트.
