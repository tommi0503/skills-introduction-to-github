# 084 · 전사 운영 효율화 전략 검수

## 범위와 구현

- 참고: `references/084/slide_01.png`부터 `slide_16.png`까지 16장. README 계약을 끝까지 읽은 뒤, 사용자 직접 지시와 구분하여 적용했다.
- 소스: `src/decks/084.mjs`. 공통 primitives API를 사용한 데이터 기반 구성이다. 이 덱을 위해 공통 renderer와 primitives 파일은 수정하지 않았다.
- 네이비 #050b20, 블루 #0665f5, 페일 블루 #9ec4fb, 흰 패널, 얇은 구획선, 캡슐, 선형/원형 수치 시각화를 중심으로 구현했다. 표·차트·화살표·패턴·조직도·프로세스는 텍스트/도형/SVG다.
- 원본 통이미지, 이미지 조각, 이미지 태그를 결과물에 쓰지 않았다. 자동 결과의 모든 `sourceImageTags`는 0이다.
- 12장의 회의 사진은 사용자 직접 지시를 우선하여 연한 회색 단색 PH로 대체했다. 통합 검수에서 어두운 반투명 오버레이를 제거하고, 회색 바탕 위 제목/설명을 네이비로 변경했다. PART 03의 파란색과 독립 하단 파란 바/흰 라벨은 유지했다. 사진의 인물·기기는 재현하지 않았다.
- 실제 로컬 Pretendard 폰트 파일을 사용했다. 본문 400, 제목/캡슐 700, 강한 표지 800을 중심으로 사용하며 인접 굵기 요청은 브라우저의 로드된 정적 face에 대응한다. 원본 파일에는 폰트 메타데이터가 없어 원본 서체의 완전한 동일성은 확정할 수 없다.

## 시각 검수 방법과 회차

각 회차에서 Chromium으로 실제 1280×720 PNG를 렌더했다. contact sheet만 검토하지 않고 **16장 각각의 2560×752 원본/결과 pair 이미지를 도구로 열어** 개별 확인했다. 총 3회: round1, round2, final. 그 후 통합 검수에서 12장만 회색 PH를 유지하도록 어두운 오버레이를 제거하고 제목/본문을 네이비로 보정했다. 별도 비교 회차를 늘리지 않고 빌드를 완료했으며, 통합 담당이 final 렌더에 반영한다.

- 1차: 16장 전체 개별 비교. 자동 6건. 04장의 목록에서 추가 줄바꿈이 발생한 부분과 + 문자 박스를 발견했고, 03장 본문 폭을 조정했다. 표지 텍스트 런 간격, 로고 이중 표시, 목차 장식의 불필요한 큰 화살촉, 11/15장의 아이콘과 레이블 간격을 보정했다.
- 2차: 16장 전체 개별 비교. 자동 4건. + 문자를 Lucide plus 벡터로 바꾸고, 섹션 표지 제목의 문자 박스를 확대했다. 표지 제목의 실제 잉크 위치, 계단식 장식의 경계, 표 구획선, 프로세스 강조 그라데이션과 후광, 예산/협업 다이어그램, 로드맵의 블루 강도를 보정했다.
- 최종(3차): 16장 전체 개별 pair를 다시 열었다. 글자 중복·잘림, 과도한 줄바꿈, 캡슐 라벨 중심, 패널 간격, 차트 수치, 배경 도형을 확인했다. 자동 findings 0건, 브라우저 errors 0건.

## 장별 최종 확인과 남은 차이

| 05 | 3개 KPI, 막대 85/76/68, 도넛 40/30/20/10, 양쪽 요약 박스 확인 | 요약의 파란 강조는 두 번째 줄 전체에 적용하여 원본의 부분 강조 범위와 차이 |
| 06 | 의사결정 트리, 3개 문제 항목, 35/42/23 막대, 설명 박스 확인 | 연결선 모서리를 직각으로 단순화. 요약 두 번째 줄 전체를 블루로 강조 |
| 07 | PART 02, 제목, 두 줄 본문, 블루 하단 바, 패턴 확인 | 원본의 희미한 빗금 농도/간격과 세부 텍스트 잉크 형태의 차이 |
| 08 | 5열 비교표, 4개 정량 행, 추이 화살표, 강조 열과 요약 확인 | 표의 아주 얇은 경계와 화살촉 형태를 SVG 선으로 근사 |
| 09 | 왼쪽 두 패널, 중앙 3개 원/진행 화살표, 우측 성과/성공 요인 확인 | 원 3개의 테두리와 겹침 간격, 그라데이션 분포를 직접 구성 |
| 10 | ROI 링, 4개 효과 카드, 상하 화살표, 가운데 소형 설명 확인 | ROI 외곽 점선은 CSS dashed 원으로 구성하여 대시의 세부 길이가 다름. 소형 설명의 부분 블루 강조는 통일된 검정 텍스트로 처리 |
| 11 | 4단계 프로세스, 3단계 강조/후광, 하단 2개 패널 확인 | 원본의 채움 아이콘을 Lucide 윤곽 아이콘으로 대체. 연결 화살표의 세부 노치 차이 |
| 12 | PART 03, 제목, 설명과 하단 바 확인 | 사진 전부를 연한 회색 단색 PH로 대체하고 제목/설명을 네이비로 변경한 것이 사용자 직접 지시에 따른 의도된 큰 차이. 파란 PART와 독립 하단 바/흰 라벨 유지 |
| 13 | STEP 1~5, AS-IS/TO-BE, 기간 바와 절감 브래킷 확인 | 아래 브래킷의 둥근 모서리를 직각 선으로 단순화 |
| 14 | 기존 자원, 통합 다이어그램, 3개 개선 구획, 예산 변화 막대 확인 | 조직 연결선 모서리와 소형 방향 화살표의 페이드 효과를 단순화 |
| 15 | 기존/개선 2개 패널, 3개 항목 캡슐, 협업 허브, 연결 배경 확인 | 채움 아이콘을 Lucide 윤곽 아이콘으로 대체. 협업 허브의 화살촉 크기/방향의 미세한 차이 |
| 16 | 4개 단계, 기간 캡슐, 블루 진행축, 각 단계 3개 활동 확인 | 활동 구분선·타이포의 세부 자폭에 미세한 차이 |

작은 문구는 최대한 원문을 읽어 입력했다. 도표의 `XX`, `XXX`, `20XX`, `이곳에…입력`은 참고 이미지에 실제로 있는 템플릿 문구로 보존했다. 읽히는 문구의 맞춤법은 의미를 유지하는 범위에서 정리했고, 판독 불가능한 내용을 선이나 가짜 글리프로 표현한 부분은 없다.
