# 최종 통합 검수

실제 입력은 5개 덱·106장입니다. 077 22장, 078 19장, 079 19장, 080 30장, 084 16장의 파일명과 크기를 `inventory.json`으로 대조했습니다. 모든 원본과 재현 페이지는 1280×720입니다.

담당 5명은 각 덱을 3차까지 개별 브라우저 비교하며 수정했고, 컬렉션 담당 1명은 별도 파일 범위에서 작업했습니다. 주 에이전트는 최종 원본/결과 비교 이미지 106개를 모두 개별로 직접 열어 배치·색·테두리·모서리·텍스트·표·차트를 통합 확인했습니다. 연락처 시트는 개요로만 사용했습니다. 장별 확인과 비교 이미지 해시는 `primary-visual-review.json`에 있습니다.

통합 단계에서는 079/04 차트의 중복 수치와 인접 라벨을 정리했고, 080/24·25 숫자/단위 간격, 080/30 리본의 한 줄 배치, 077의 마지막 본문 넘침 수정 반영을 확인했습니다. 084/12의 사진 배경은 사용자 지시에 따라 연회색으로 바꾸고 본문을 남색으로 바꿨습니다. 컬렉션 `.hl`이 큰 패널처럼 늘어나던 계약 오류를 inline highlight로 고쳤습니다. 이후의 재렌더는 이 기술적 수정과 최종 파일·해시 일치를 확인하기 위한 것이며 덱의 미관을 추가 반복하지 않았습니다.

재현본과 재조립본은 각각 실제 Chromium으로 106장씩 렌더했습니다. 글자 박스/화면 초과, 실제 폰트 로딩, 칩의 글리프 중심, 페이지 크기, 브라우저 오류를 검사했고 최종 검출은 0건입니다. 별도의 실제 텍스트 run 간 겹침 검사도 212페이지 모두 0건입니다. `automatic-final-*.json`, `text-overlap-audit.json`, `final-verification.json`에 결과와 소스/HTML/PNG SHA-256을 보관합니다.

재조립 시 image-frame의 작은 장식선과 원형 seat의 이중 배경 때문에 생긴 차이를 호스트의 placeholder override로 제거했습니다. 마지막 별도 브라우저 출력끼리 비교한 결과 **재현/재조립 106쌍 모두 픽셀이 같습니다**. 이는 두 구현 결과의 동등성 검사이며 원본과의 픽셀 일치율을 의미하지 않습니다. 따라서 원본/재현 106장의 개별 시각 검토는 동일한 재조립 픽셀에도 적용됩니다. 검증 세부는 `reassembly-pixel-comparison.json`에 있습니다.

컬렉션은 kit, foundation, 계약 요소 31종과 fixture 92개(요소90+foundation2)를 포함합니다. 라이트/다크, 전체/최소 크기 364개 뷰를 실제 브라우저에서 검사했고 모든 PNG는 1280×720입니다. 모든 요소 범위·토큰·타입 단계·2개 이상 fixture·반응형 규칙 검사가 통과했습니다. 의도한 텍스트/표면 토큰 조합의 대비 최솟값은 5.21:1입니다. 세부 기록은 `library.md`, `library-automatic.json`, `library-source-hashes.json`, `library-palette-contrast.json`입니다. 제공되지 않은 Rhetis 서버의 실제 importer 반입 검사를 실행했다고 주장하지 않습니다.

어려웠던 부분은 이미지 속 작은 글자와 서체 확정, 사진과 색 오버레이의 경계, 서로 다른 다섯 덱을 하나의 컬렉션으로 통합하는 일이었습니다. 사진/3D/이미지 로고·페르소나/기기 화면은 연회색 단색으로 바꿨고, Lucide로 표현 가능한 아이콘은 선 아이콘으로 구현했습니다. 판독 불가 문구는 정상적인 한국어로 대체했습니다. 078/07·08·10·11·14·15·18과 084/12의 회색 면과 일부 남색 전경은 명시된 placeholder 규칙에 따른 의도적 차이입니다.

남은 차이는 추정 서체로 인한 일부 자간·줄바꿈·숫자 굵기, Lucide 아이콘의 선과 원본 아이콘의 채움 차이, 작은 모서리·패턴선의 미세 차이입니다. 특히 080 리본 숫자는 원본보다 다소 굵고 일부 수치는 넘침을 막으면서 크기가 소폭 작아졌습니다. 078 일부 정보 패널의 높이·위치에는 소폭 차이가 있습니다. 이를 완전한 원본 픽셀 복제라고 표현하지 않습니다.

전체 PDF는 실제 DOM을 브라우저로 인쇄했으며 모든 PDF 페이지 좌표를 1280×720으로 정규화했습니다. 재현/재조립 전체 PDF 각각106p, 시트 PDF 각각9p, 컬렉션 라이트/다크 각각92p와 덱별 PDF를 포함합니다. 시트 PNG도1280×720입니다. 전체 미리보기 HTML은106개 이미지와 각 원본/결과/재조립 링크를 실제 브라우저로 확인합니다.

ZIP에는 전체 최종 PNG, 원본/결과 비교 이미지, 소스, 실제 폰트, PDF, 미리보기와 검수 기록을 함께 넣습니다. 독립 컬렉션 ZIP은 최상위가 `rhetis-spectrum/`인 소스 폴더 하나만 포함합니다. ZIP CRC와 SHA-256을 검사하고, GitHub에 commit·push한 뒤 원격 ZIP을 실제로 다시 다운로드해 일치 여부를 검증합니다. 기존 파일과 이력은 보존하며 강제 push를 사용하지 않습니다.

GitHub 파일 크기 제한을 맞추기 위해 전체 ZIP에서 픽셀이 동일한 재조립 비교 JPG의 중복만 제거했습니다. 원본/결과 비교 106쌍, 개별 PNG212개, 컬렉션 PNG364개를 유지하며 사진 원본106개도 포함합니다. 미리보기 링크는 포함된 공통 비교를 가리킵니다.
