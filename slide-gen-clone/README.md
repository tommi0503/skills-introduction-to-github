# Slide Gen Clone

첨부한 `presentation.zip`의 참고 이미지 32장을 바탕으로 만든 독립적인 프레젠테이션 UI 프로젝트입니다. 기존 `slides-clone`은 사용하지 않습니다.

## 실행

```bash
cd slide-gen-clone
npm ci
npm run dev
```

갤러리에서 덱을 선택할 수 있습니다.

- `#/deck/r01`: 덱의 슬라이드 모음
- `#/slide/r01/s01`: 단일 슬라이드, 정확히 1280 × 720
- `#/compare/r01`: 원본 참고 이미지와 구현을 나란히 보기
- `#/board/r01`: 원본의 패널 위치·간격·잘림을 보존한 모음

## UI 구조

`src/model.ts`는 슬라이드 콘텐츠와 배치 데이터의 계약입니다. 텍스트, 박스, 플레이스홀더, Lucide 아이콘, 구분선, 막대 차트, 도넛 차트, 표의 팩터리를 제공합니다. `src/ui.tsx`는 이 계약을 렌더링하는 공통 UI 라이브러리입니다. `src/decks/`의 덱은 콘텐츠·색상·배치 데이터를 전달하며, 갤러리는 `registry.ts`의 자동 등록으로 덱을 읽습니다.

모든 개별 슬라이드는 같은 16:9 크기이며 기울이지 않습니다. 사진, 휴대폰 화면, 복잡한 일러스트·그래픽은 연한 회색 단색 플레이스홀더입니다. 원본 이미지는 비교 화면에서만 표시하고, 구현 슬라이드에 배경으로 넣지 않습니다. 작은 글씨가 흐릿하거나 화면 밖으로 잘린 원본은 확인할 수 있는 내용과 배치를 기준으로 재현합니다.

## 검증과 렌더

```bash
npm run build
npm run render             # 모든 덱
npm run render -- r01 r02  # 특정 덱만
node scripts/verify.mjs   # 빌드와 렌더 후 브라우저·출력 최신성 검증
python3 scripts/package.py # PNG ZIP 패키징
```

렌더 스크립트는 Vite와 `/usr/bin/chromium`을 사용합니다. 슬라이드별 PNG와 덱별 모음을 `renders/`에 저장합니다. 원본에서 지정한 슬라이드 영역과 렌더를 나란히 비교한 이미지는 `comparisons/`에 저장합니다. 폰트 로딩을 기다리고, 브라우저 예외와 슬라이드 밖으로 나간 텍스트를 확인합니다.

시각 비교는 덱마다 2~3회로 제한합니다. 이번 재검수의 세부 기록은 `re-review-a.md`, `re-review-b.md`, `re-review-c.md`, `final-review.md`에 있습니다. 전체 일치도 수치는 사진·그래픽 플레이스홀더와 원본 해상도 때문에 유의미한 품질 지표로 사용하지 않습니다.

재검수 수정본은 32개 덱, 113개 개별 슬라이드입니다. 덱별 2회 비교·수정 후 통합 최종 검토를 진행했습니다. 누락 패널, 잘린 화면의 크기, 콜라주 배치, 타이포그래피와 차트를 수정했습니다. ZIP에는 개별 슬라이드 113개 PNG와 원본 배치 모음 32개 PNG, 원본 대조 이미지 145개, 검수 기록, 전체 미리보기 및 원본 파일 매핑이 포함됩니다. 원본 밖의 보이지 않는 영역은 단색 배경으로 유지합니다. 해상도가 낮아 읽을 수 없는 일부 작은 본문은 생략되었으며, 세부 차이는 재검수 기록에 명시했습니다.
