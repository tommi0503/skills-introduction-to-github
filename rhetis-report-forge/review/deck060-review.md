# Deck 060 — 주간 회의록 보고서 (30장)

검수 범위: slide_01.png–slide_30.png를 모두 원본 크기로 개별 열람했다. Chromium에서 1280×720으로 렌더한 후, 원본/결과를 좌우로 배치한 비교 이미지 30개를 1차와 2차에 모두 개별 확인했다. 마지막 3차는 최종 수정 반영 및 자동 검사용이다. 원본 이미지를 배경이나 결과물에 사용하지 않았다.

공통 설계: 60px 간격의 연한 녹색 노트선, 흰색에 가까운 바탕, 녹색 제목, 검정 표 머리글, 직각 정보 영역, 얇은 꺾인 끝 장식선을 React 컴포넌트로 만들었다. 본문은 설치된 Noto Sans CJK KR, 강조 수치는 실제 로드한 Pretendard 900을 사용했다. 원본 폰트 파일·메타데이터는 제공되지 않아 동일 폰트라고 단정하지 않는다. 원본의 각진 숫자 획과 실제 글자 폭에는 차이가 남는다. 가독성을 위해 텍스트를 그림 선으로 대체하지 않았다.

수정 기록: 공통 제목 폭을 조정했다. 12번 첫 pill 행의 32px 위치 차이, 19번 면적 그라디언트 참조 ID, 22번 오른쪽 본문 상자 폭, 29번 긴 본문 줄바꿈을 수정했다. 제목/큰 숫자의 글리프 linebox 자동검사 경고도 상자 높이를 늘려 제거했다. 16·19·20번의 다중행 배지를 단일 inline span으로 감싸 flex 익명 텍스트의 예상 밖 줄바꿈을 수정했다.

사진·지도 대체는 원본 누락이 아니라 사용자 지정 처리다. 장식 아이콘·차트는 코드로 구현했으며 원본 픽셀을 재사용하지 않았다. 본문 문장은 이미지에서 판독 가능한 문구를 옮겼고, 시각 검수 결과 확인된 줄바꿈은 명시적으로 유지했다.
