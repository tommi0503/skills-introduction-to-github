# Cycle / Hub 요소 추가 검수

수정한 컬렉션 파일은 `elements/cycle/element.css`, `elements/hub/element.css` 두 개다. HTML fixture, class, kit 토큰, 다른 요소, 주 미리보기 출력은 바꾸지 않았다.

## 도식 개선

- Cycle: 중앙 블루 core 주변에 하나의 실제 타원 순환선을 두었다. 3·4·5·6개 멤버 수마다 `:has()`로 다른 각도와 위치를 선택한다. 모든 멤버는 같은 타원 위에 놓이고, 각 멤버 다음 구간의 접선에 삼각형 화살표가 놓여 시계방향 순서가 드러난다. 선과 화살표 모두 CSS 가상 요소이며 이미지나 SVG 배경을 사용하지 않았다.
- Hub: 3개는 좌 1·우 2, 4개는 좌우 2, 5개는 좌 3·우 2, 6개는 좌우 3개로 배치했다. 모든 멤버의 중심 높이에서 직각 선이 출발해 root의 가로·세로 50% 위치까지 실제로 이어진다. 중심 박스가 마지막 선 구간을 덮고, 화살표는 각 멤버의 가까운 가장자리를 향한다. 왼쪽/오른쪽 두 선이 별개 세로 기둥이 되지 않도록 `cqw/cqh` 기반 길이를 사용해 같은 중심선으로 합쳤다.
- 컬렉션의 밝은 블루/짙은 블루 중심, 얇은 선, 거의 각진 카드, 토큰 기반 글자·간격을 유지했다. 다크 모드는 동일 geometry에 키트의 별도 다크 토큰을 적용한다.

## 실제 브라우저 확인

기존 `preview.py`로 별도의 라이트·다크 검수 HTML을 만들고, Chromium에서 각 fixture를 1280×720 전체 크기로 추출했다. root 도식 영역은 foundation의 1168×632이다. 실제 Pretendard 웹폰트 로딩을 최종 16/16 확인했다.

최종 검사에서 카드끼리의 겹침 0, 카드/core 겹침 0, 카드의 root 밖 이탈 0, `.mark/.name/.note`의 카드 밖 이탈/스크롤 초과 0이었다. 가상 요소 연결선은 의도적으로 카드 밖에 있으므로 부모 카드의 scrollWidth를 텍스트 잘림 판정에 사용하지 않았다. 카드의 실제 텍스트 상자와 root 경계를 직접 비교했다.

검수 중 hub의 카드 border-box 때문에 중심 줄이 약 10px 분리된 것을 발견해 root 컨테이너 길이로 고쳤다. 최종 렌더에서 위·아래의 세로 연결선은 모두 같은 중심 x 좌표에 모인다. 처음 별도 미리보기의 null-origin에서 폰트가 fallback된 문제도 정적 로컬 서버 origin으로 변경해 해결했다. 최종 PNG는 모두 실제 웹폰트 로딩 이후 캡처다.

색 리터럴 0, px 글자 크기 0, `url()`/`@font-face`/`@import` 0을 확인했다. 모든 선택자는 해당 `data-el`에 묶여 있다. `@container`의 720/430/280px 단계에서 타입/간격이 줄어들고 아주 좁거나 낮을 때 note를 숨긴다. 제공 fixture의 선언된 최소 칸은 모두 12×6이며 이 크기를 라이트/다크 모두 검수했다.

검수용 임시 HTML/PNG와 상세 geometry audit는 `/workspace/work/radial-review/`에 있다. `outputs/light.html`, `outputs/dark.html`은 담당 주 에이전트의 최종 재생성용으로 남겨 두었다.
