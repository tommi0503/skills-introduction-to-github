# 054 — 상반기 프로젝트 리뷰 검수

원본 20장 전부를 1280×720 원본으로 각각 열고 확인했다. README.md 계약 전체를 읽었으며, 계약은 라이브러리 제작 규칙으로 적용하고 이미지 안의 ‘입력해 보세요’ 문장은 지시문이 아닌 슬라이드 콘텐츠로 취급했다.

## 구현과 검수 방식

- 파일: `src/decks/d054.tsx`. 데이터 기반 목차·지표·표·단계·과제 카드와 공통 Page/Heading/Panel/Ribbon/Check/RoundStat 컴포넌트 사용.
- 원본 이미지를 결과 배경이나 캔버스로 사용하지 않았다. 텍스트는 실제 Pretendard를 로드한다. 차트·그래프·원·연결선·체크·간단 실루엣 아이콘은 CSS/SVG, 나머지 아이콘은 Lucide다.
- Chromium 1차 20장 렌더 → 원본/결과 비교 이미지 20개를 개별 열람 → 수정 → 2차 20장 렌더 → 비교 이미지 20개를 다시 개별 열람했다. 3차는 남은 표지 행간/연락처, 차트 캡션, 향상률 칩, 사진 설명 문장 줄바꿈 등을 고치고 전체 20장을 최종 렌더했다. 총 3회로 제한했다.
- 1차에서 발견된 04·05·08의 패널 내부 중첩 좌표 오류, 여러 줄 칩의 개행, 제목 크기, 상태 표 열 너비, 15쪽 종합 판단의 아이콘 충돌을 수정했다.
- 2차 자동 검사: 전부 1280×720, Pretendard 400/700 로드 통과, 화면 밖 텍스트 0, 높이/너비 넘침 0. 최종 결과는 `audit-054-replica.json`을 참조한다.
- 칩과 배지는 flex 중앙 정렬에 여러 줄의 실제 글자 행간을 적용하고 개별 비교에서 검토했다. 08쪽 체크 포함 칩과 18쪽 아이콘 포함 과제 칩은 글자와 아이콘에 별도 고정 영역을 지정했다.

## 판독 및 해석 결정

큰 제목·표·수치는 전부 판독 가능했다. 원문의 XX·XXX·2080·‘키워드 입력란’은 템플릿 문구이므로 그대로 보존했다. 작은 장식 아이콘은 의미에 맞는 Lucide 또는 간단 SVG로 해석했다. 사진은 03 배경 1개, 07 사진 2개, 14 사진 1개, 15 사진 1개, 19 사진 4개로 총 9개 영역을 단색 처리했다. 픽셀 단위 동일성은 주장하지 않으며, 허용된 placeholder와 작은 아이콘/폰트 렌더링 차이를 제외한 레이아웃을 가깝게 재현했다.

## 통합 검수 마지막 보완

주 에이전트의 최종 통합 검수에서 19쪽 과제 본문에 강제 줄바꿈과 자동 줄바꿈이 겹치는 현상을 발견했다. 본문 15px, 폭 210px, 행간 1.45로 맞추고 08/19쪽 비교 이미지를 재생성해 개별 확인했다. 19쪽 네 본문 모두 실제 높이 87px, 아래 경계 y=609로 카드 아래 경계 y=631 안에 22px 여유가 있다. 08쪽 체크와 글자는 별도 영역으로 겹침을 제거했다. 01쪽 큰 제목의 글리프가 줄상자보다 높아 발생한 자동 높이 경고는 명시 높이 220px로 제거했다.

최종 자동 검사 결과: 20장 모두 1280×720, Pretendard 로딩 성공, 화면 밖 텍스트 0·텍스트 높이/폭 초과 0. 최신 PNG와 comparison에 마지막 소스 수정이 반영됐다.
