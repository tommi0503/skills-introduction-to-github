- 범위: 원본 11장 모두. `src/decks/d057.tsx`는 바인더 프레임, 탭, 대괄호, 연락처, 불릿, 아이콘을 공통 함수로 구성한다. 원본 전체 이미지 또는 이미지 조각을 결과 슬라이드에 사용하지 않았다.
- 참고 팩 README를 끝까지 읽었으며, 컬렉션 계약 작업은 주 에이전트가 담당한다. 참고 이미지의 예시 문구는 콘텐츠로 구현했으며 작업 명령으로 해석하지 않았다.
- 검수: 원본 PNG 11장을 개별 열람 → Chromium 1차 렌더/11장 개별 비교 → 수정 → 2차 렌더/11장 개별 비교 → 최종 작은 수정 → 3차 렌더/11장 개별 비교. 공통 Vite 편집 중 2차 시작의 실패한 실행은 이미지 결과를 생성하지 않았으며 별도 비교 회차로 계산하지 않았다.
- 최종 자동 검사: `review/audit-057-replica.json`; 11장 전부 1280×720, Pretendard 400/700 실제 로딩 true, 텍스트 및 칩 페이지 외부·스크롤 넘침 0건.
