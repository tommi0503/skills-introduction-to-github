# 낮은 칸 제목 통합 수정

- source04의1000×132에서44px/66px 두 줄을 보존했다. h2 자체에서 min(4.4cqw,33.333333cqh)를 적용해 실제 할당 칸이 낮아지면 두 줄 합계가 높이 안에 들어간다. 최소 토큰은 type12이다.
- big 변형도 같은 높이 제약을 받으며, 기존 중복 on/색 규칙을 단일 구성으로 정리했다. 루트 font-size의 상위 컨테이너 참조를 없애고 실제 h2가 자기 root 크기를 참조한다.
- source04의 원문/줄바꿈은 수정하지 않았다. 실제 조립판 h2는92.34375px 높이에서30.776px/46.1641px 두 줄로 들어가 밖 글자/겹침/페인트 초과/폰트 오류0이다.
