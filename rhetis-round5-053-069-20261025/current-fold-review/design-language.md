# current-fold 디자인 언어

좁은 그라디언트 레일, 얇은 머리글 선, 작은 원형 아이콘과 접힌 면. 성장 단계는 높이가 다른 연한 기단·상단 면·돌출된 흰 원을 한 요소로 묶는다.

- 선: 작은 캡슐의 가는 외곽선, 구조도의 연결선, 페이지 배경의 원래 SVG 곡선. 의미 없는 떠다니는 장식은 추가하지 않는다.
- 여백과 비율: 보통 본문1093×472, 표지의 named lockup은 원본 수치를 사용한다. 원형 마크96px, 제품 카드 안 캡슐36px의 비율에서 반응형 크기를 유도했다.
- 글자 위계: Pretendard Variable. 보통 페이지 제목48px/700, 카드 제목22px, 본문16px/24px. 표지는80px의 두 줄 제목과76px 장 제목,116px 감사 제목을 구분한다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 주 강조 | `--a1-7` |
| 진한 단계 | `--a1-9` |
| 보조 단계 | `--a1-5` |
| 연한 단계 | `--a1-3-soft` |
| 아주 연한 면 | `--a1-1-soft` |
| 다섯 단계 면 1 | `--a2` |
| 다섯 단계 면 2 | `--a2-5` |
| 다섯 단계 면 3 | `--a2-7` |
| 다섯 단계 면 4 | `--a1-7` |
| 다섯 단계 면 5 | `--a1-9` |
| 흰 면 | `--page` |
| 일반 글자 | `--ink` |
| 회색 받침 | `--n-1` |
| 가는 선 | `--n-3` |
| 보조 글자 | `--n-7` |
| 레일 그라디언트 끝 | `--a2-7` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
