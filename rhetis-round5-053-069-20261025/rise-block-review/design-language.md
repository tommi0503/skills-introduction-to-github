# rise-block 디자인 언어

높이가 다른 단단한 사각 상단과 아래로 이어지는 연한 기단. 마지막 목표만 한 번 강조한다. 표지는 직교 모자이크와 큰 감사 문구다.

- 선: 가느다란 구분선과 왼쪽의 좁은 세로 띠. 관계는 독립 카드의 형제 조건이 아닌 전체 단계 root에서 소유한다.
- 여백과 비율: 성장 연혁의 실제 범위 80,136–1200,653을 기준으로 단계를 비례 배분한다. 카드는 같은 높이를 유지하고 기단의 시작 높이가 달라진다.
- 글자 위계: Pretendard Variable. 보통 페이지 제목40px/700, 단계의 큰 단어와 작은 연도·본문을 구분한다. 큰 감사 문구는104–108 단계다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 강조 채움·강조 글자 | `--a1-7` |
| 진한 단계 채움 | `--a1-9` |
| 흰 면·반전 글자 | `--page` |
| 일반 글자 | `--ink` |
| 회색 받침 | `--n-1` |
| 구획·프레임선 | `--n-3` |
| 보조 글자 | `--n-7` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
