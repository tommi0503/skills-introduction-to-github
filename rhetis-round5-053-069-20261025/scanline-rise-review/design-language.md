# scanline-rise 디자인 언어

중앙의 작은 진한 캡슐, 두 줄 페이지 제목, 평평한 강조 머리띠와 연한 본문 면. 상단 KPI 분류판과 아래 계층도는 각각 하나의 소유 root다.

- 선: 얇은 연결선과 작은 점, 헤더와 본문을 나누는 선. 원형 아이콘46px와 헤더110px를 카드의 실제 상자 비율로 옮긴다.
- 여백과 비율: 본문의 기본 범위119,275–1161,650. 페이지 표제와 본문 사이의 큰 간격을 유지하고, 작은 칸에서는 부차 문구부터 줄인다.
- 글자 위계: 제목은 Noto Sans KR40px/500, 본문은 Pretendard Variable. 카드 제목20px, 본문16px/24px이며 분류 캡슐은158×35px의 원본 비례를 따른다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 주 강조 채움·제목 | `--a1-7` |
| 연한 단계 1 | `--a1-1-soft` |
| 연한 단계 2 | `--a1-2-soft` |
| 연한 단계 3 | `--a1-3-soft` |
| 연한 단계 4 | `--a1-4-soft` |
| 반전 글자 | `--page` |
| 흰 면 | `--page` |
| 회색 카드 | `--n-1` |
| 회색 막대 | `--n-3` |
| 가는 선 | `--n-3` |
| 일반 글자 | `--ink` |
| 보조 글자 | `--n-7` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
