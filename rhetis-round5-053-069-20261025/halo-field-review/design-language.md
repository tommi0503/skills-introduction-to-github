# halo-field 디자인 언어

넓게 열린 면, 가는 상단 괘선, 접힌 피라미드·셰브론·공중 캡슐. 피라미드는 실제 tier 폭과34px 접힌 면, 점·점선·문구 위치를 함께 소유한다.

- 선: 보통1px의 가는 선과 점선. 강조 원형 점과 선의 끝이 실제 멤버에 닿도록 설계하고, 궤도 화살표는 cycle 안에서 그린다.
- 여백과 비율: 제목 여백54px. 본문은 왼쪽으로 돌출된 원까지 포함한46,245–1226,670의 공통 시각 범위다. 표지는 원본의 세로 원3개와 열린 궤도선을 쓴다.
- 글자 위계: 보통 제목Freesentation48px/700, 본문Pretendard Variable. 표지는 실제 소스의 Pretendard76px/400과 굵은 강조를 보존한다. 피라미드·연혁의 제목22px와 본문18px를 구분한다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 주 강조 채움·선 | `--a1-7` |
| 제목 강조 | `--a1-7` |
| 연한 바탕 | `--n-1` |
| 흰 면 | `--page` |
| 강조 위 글자 | `--page` |
| 일반 글자 | `--ink` |
| 회색 앞면 1 | `--n-2` |
| 회색 앞면 2 | `--n-4` |
| 회색 앞면 3 | `--n-6` |
| 회색 앞면 4 | `--n-8` |
| 회색 접힌 면 | `--n-5` |
| 가는 선 | `--n-3` |
| 보조 글자 | `--n-7` |
| 표지 회색 쪽의 배경 | `--n-7` |
| 표지 강조 쪽의 배경 | `--a1-7` |
| 표지 위 글자 | `--page` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
