# corner-signal 디자인 언어

옅은 페이지 면 위의 날카로운 판, 대각 노치와 두꺼운 상단 강조선. 포함 오각형은641×609의 원본 비율을 유지하고, 중성 원과 강조 원의 크기 차이를 남긴다.

- 선: 1px 표·축·외곽선과10px 상단 띠. 단계의 쉐브론·연혁의 겹침·접속 화살표는 각각 연결 전체를 가진 root 안에서 그린다.
- 여백과 비율: 제목의 왼쪽77px를 유지한다. 커다란 포함 도형이 본문 위쪽까지 올라오므로 공통 grid는71,28–1205,642의 시각 범위를 쓴다.
- 글자 위계: 일반 큰 제목56px/500. HTML 제목은 Montserrat, 원본 SVG 제목의 글꼴은 Pretendard로 named label 안에서 보존한다. 노치 카드의 제목25–26px, 본문14–17px를 실제 소스에 따라 구분한다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 주 강조 채움·제목 | `--a1-7` |
| 포함 오각형 바깥 | `--a1-2-soft` |
| 포함 오각형 중간 | `--a1-5` |
| 포함 오각형 안쪽 | `--a1-7` |
| 진한 페이지 면 | `--a1-9` |
| 흰 정보 판 | `--page` |
| 회색 채움 | `--n-2` |
| 회색 진한 채움 | `--n-7` |
| 좌표축·구분선 | `--n-3` |
| 설명 글자 | `--n-7` |
| 일반 글자 | `--ink` |
| 회사 강조 원 | `--a1-2-soft` |
| 강조 면 위 글자 | `--page` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
