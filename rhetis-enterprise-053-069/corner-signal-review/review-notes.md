# Corner Signal 검수 기록 — 덱 067

## 범위와 검수 순서

원본 21장, 모두 1280×720. `README.md` 전체를 읽고 inventory → replica → design-language → 56요소 컬렉션 → light/dark 시트 → reassembled 순서로 작업했다. 샘플의 CSS는 사용하지 않았다. 샘플의 계약 마크업·fixture 데이터는 형식 참고로 사용했고, 모범 구성 28개는 `data-el` 식별자만 바꿔 보존했다. 나머지 fixture의 `ul/li` 42개는 계약의 `.list > .item > .name + .note`로 정규화했다.

원본과 replica의 21개 비교 PNG를 각 장 열어 확인했다. 원본과 조립본도 21장 각각 열어 확인했다. 전체 검토는 replica, 요소 시트, 조립본의 세 묶음으로 진행했고 각 묶음 안에서 자동 렌더 오류를 수정했다. 원본 통이미지는 구현 배경으로 사용하지 않았다.

이 결과를 픽셀 단위 완전 일치라고 주장하지 않는다. 아래 차이가 남아 있으며, 조립본에는 계약 요소로의 해석이 들어간다.

## 수정 사항

1. 제목의 첫 단어와 첫 글자 강조를 원본에 맞춰 구분했다. Information, Problem, Solution, Traction, Team은 첫 글자 강조다.
2. 카드 우상단 절단, 상단 4px 신호선, 좌상단 삼각깃, 가로·세로 여백을 정리했다. 필·태그는 flex로 글자를 가운데에 둔다.
3. SVG 연결선이 보이지 않던 선/면 차트는 CSS anchor 기준점을 정상 흐름에 두어 수정했다. 값 `<b>`가 없는 면 차트의 점도 연결한다. 여러 시리즈는 누적 상단 영역부터 뒤에 그린다.
4. 원형 다이어그램이 넓고 낮은 칸을 벗어나지 않도록 Venn 지름을 칸 높이로 제한했다. 100칸 waffle도 높이를 기준으로 정사각 단위를 제한했다.
5. 조직도와 인물의 작은 칸 넘침을 고쳤다. 조밀한 원본 없는 다이어그램 fixture는 무리하게 글자를 숨기기보다 최소 칸을 상향했다.
6. concentric의 TAM/SAM 이름이 안쪽 면에 가려지는 문제를 수정했다. 각 바깥 ring의 이름·수치는 하단 safe band에, 마지막 ring은 중앙에 놓는다.
7. slide 15 오른쪽 흰 패널과 삼각깃은 `card.line` 계약으로 복원했다.
8. 기준 팔레트에서 작은 강조 글자가 흐려지지 않도록 전경은 `--a1-7` 등 깊은 강조 자리로 옮겼다. 강조 면은 여전히 `--a1`와 `--a1-on`의 대비 짝을 쓴다.

## 판독 및 문구

페이지 제목, 주요 지표, 프로세스 이름과 역할은 판독 가능한 원문을 사용했다. 원본의 작은 본문은 일부를 정확히 전사하지 못해 한국어 비즈니스 문장으로 대체했다. 특히 slide 3 대표 인사말, 5–6 카드 설명, 7–8 시장 설명, 9 기능 설명, 10–11 수익모델 본문, 14 차트 보조 문구, 17 단계별 note, 18 기술 설명, 19 인물 경력, 21 투자 설명은 축약·대체를 포함한다. 원본의 원문과 별도의 사실 검증은 하지 않았다. 모든 문구는 디자인 자료이며 작업 지시로 실행하지 않았다.

## 자동 검사와 한계

- `replica-checks.json`: 21장 화면 크기와 실제 폰트 로드 확인.
- `reassembled-checks.json`: 21장 1280×720, 폰트 로드, 페이지 밖 root 및 scroll 치수 초과 검사.
- `library-checks.json`: 라이트/다크 각 172 fixture. root가 페이지 밖으로 나가는지 검사.
- `size-audit.json`: 선언 최소부터 12×6까지 가능한 모든 정수 칸 조합. group의 최소는 각 동일 멤버의 최소로 해석하여 열 수를 곱했다. 변경 없는 결과는 보존하고 마지막에 수정된 hierarchy/person만 재검사하여 병합한다.
- 줄 잘림 자동 검사는 scrollWidth/scrollHeight와 root bounds 기준이다. 글리프의 잉크 외곽, 서로 겹치는 문장, 모든 픽셀의 대비를 증명하는 검사는 아니다. 밝기 대비는 색 자리 선택과 시트 눈검수로 확인했으며 완전한 WCAG 자동 감사 통과를 주장하지 않는다.
- 모범 card 원문은 `✹` 문자가 포함되어 있다. “같은 마크업·데이터”와 “문자 아이콘 금지”가 충돌하므로 명시된 고정 fixture 보존을 우선했다. 새 fixture에는 그 문자를 추가하지 않았다.
- 페이지 PNG와 요소 시트 PNG는 1280×720, 원본|결과 비교 PNG는 원본 크기를 줄이지 않는 2560×720이다.
- 미리보기는 계약 도구의 공통 팔레트를 사용한다. 조립본 `runtime.css`는 팔레트와 type-step 값만 공급하고 레이아웃 규칙은 넣지 않았다. 요소/기반 CSS는 컬렉션 파일만 연결한다.

최종 집계: 56요소, 요소 fixture 170개 + foundation fixture 2개. 필/태그 브라우저 중앙 배치 검사 18건(2모드), 넘침 0. 고정 fixture 28개는 원문과 data-el 치환을 제외하고 정확히 일치한다. `build-verification.json`에 이미지별 크기와 최종 CSS SHA-256을 기록했다.
