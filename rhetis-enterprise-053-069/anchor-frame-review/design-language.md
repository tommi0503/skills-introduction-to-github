# Anchor Frame — 디자인 언어

근거는 069 표지 1장이다. 내용의 외곽을 선택 영역처럼 감싼 얇은 직사각형과, 네 귀의 직각 앵커가 고유한 문법이다. 채움보다 테두리와 흰 여백을 우선하며 둥근 모서리나 그림자를 쓰지 않는다. 두 프레임을 조금 겹쳐 깊이보다 연결을 표현한다.

- 선: 1px 무게의 외곽선, 제목 앞의 8px 세로선. 선택된 데이터에는 2px 선을 쓴다.
- 모서리: 0; 앵커는 8–12px 직각 조각. 실제 라이브러리에서는 8px 사각 앵커를 내용의 패딩 바깥 안쪽에 둔다.
- 여백: 8 / 16 / 24 / 40 / 64px. 페이지 좌우 64, 위아래 48. 요소 안은 24, 작은 요소는 16. 선과 내용 사이를 반드시 확보한다.
- 타입: Noto Sans KR. 표지 76px 주 강조 제목 + 104px 검정 제목; library display 64/48, figure 48/36, name 24/20, body 20/16/14 단계. 굵기 400 본문, 600 라벨, 800 이름, 900 큰 제목. 제목 자간 -0.035em, 본문 -0.02em.
- 색 자리: 페이지는 `--page`, 본문/큰 제목은 `--ink`; 제목 앞의 세로선, 제목 강조, 선택 앵커, 한 개의 데이터 강조는 `--a1`; 가는 보조 테두리는 `--a1-3-muted`; 사진 자리와 조용한 패널은 `--n-1`; 보조 설명은 `--n-7`. 강한 채움이 필요할 때만 `--a1` + `--a1-on`.
- 면/선: 카드·표·단계·조직도는 프레임을 기본으로 한다. `.on`만 강한 채움. `.quiet`는 선을 무채색으로 낮춘다. `.line`는 면 없이 같은 프레임.
- 장식: 네 귀의 앵커는 영역을 가리키므로 내용과 겹치지 않는다. 차트에는 앵커를 플롯 외곽에만 사용하고 값/라벨 뒤에는 두지 않는다.
- 확장 판단: 원본에 없는 차트와 관계도도 둥근 덩어리보다 얇은 궤도/직각 프레임/한 곳의 강조를 사용한다. 원형 의미 자체가 필요한 도넛·벤·동심원만 원을 유지한다.
