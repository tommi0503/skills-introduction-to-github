# Current Fold · 디자인 언어

원본 055의 18장을 replica로 재현한 뒤 정리했다. 색상 자체는 컬렉션에 귀속하지 않는다.

- 선: 표와 헤더는 1px, 관계선은 1px로 조용하게 연결한다. 장식은 열린 곡선의 일부이며 내용 뒤로 침범하지 않는다.
- 모서리: 기본 패널은 거의 직각(2–4px), 기능 라벨은 999px 캡슐. 원은 사람·아이콘·중심 개념에 한정한다.
- 여백: 12 / 24 / 36px 단계. 원본의 왼쪽 좁은 레일, 넓은 안쪽 여백, 낮은 정보 밀도를 유지한다.
- 위계: 작은 kick → 44–52px 제목 → 18–22px 설명. 수치는 48–64px, 로드맵 단계는 간결한 헤더로 분리한다.
- 강조: 반복 패널 중 하나만 선명하게 채운다. 그림자 대신 옅은 면, 얇은 테두리와 글자 무게로 구분한다.
- 팔레트 역할: 세로 레일·핵심 수치 = `--a1`, 얕은 패널 = `--a1-1-soft` 또는 `--n-1`, 제목 = `--ink`, 보조문 = `--n-8`, 헤더 선 = `--a1-3-soft`, 진한 강조 글자 = `--a1-7`. 강조 채움 위 글자는 `--a1-on`.
- 배경: 원본의 복잡한 리본은 replica에서 SVG 곡선으로 근사하고, 컬렉션에서는 얇은 열린 모서리 곡선으로 절제했다. 토큰에 특정 파랑을 고정하지 않는다.
- 이미지에 없는 요소: 열린 연결선, 밝은 평면, 작은 반경, 지표 중심의 위계를 같은 방식으로 적용했다.
