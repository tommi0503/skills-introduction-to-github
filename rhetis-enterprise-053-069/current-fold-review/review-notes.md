# Current Fold · 검수 기록

## 범위와 제작 순서

055 덱의 첨부 이미지 18장만을 사용했다. 원본은 모두 1280×720이다. README 전체를 먼저 읽고, 이미지 목록 → replica → 디자인 언어 → foundation과 56개 요소 → 시트 검수 → 계약 마크업 재조립의 순서로 작업했다. 샘플 컬렉션의 CSS는 복사하지 않았다. 필수 fixture는 원래 마크업과 데이터를 보존하고 `data-el` 접두사만 바꿨다. 다른 요소는 샘플의 계약 구조를 참고하되 현재 컬렉션의 독자 CSS로 그렸다.

`replica/`의 PNG 18장과 `reassembled/`의 PNG 18장을 실제 Chromium에서 렌더했다. 각 원본과 나란히 붙인 36개 비교 PNG를 페이지별로 열어 검토했다. 연락처 시트만으로 검수를 마치지 않았다. PNG 페이지는 1280×720, 비교 PNG는 두 장을 붙인 2560×720이다. 요소별 시트는 1280×720으로 통일했다.

## 관찰과 수정

- 제목의 폭과 무게가 작았던 1차 replica를 보고 제목 크기와 음수 자간을 수정했다. 본문을 Pretendard Variable 실제 파일로 로드했다.
- 연혁의 내용 길이에 따라 계단 시작점이 달라지는 문제를 replica에서 고정 좌표로 보정했다.
- 6개 파트너십 지표에서 `width:100%`가 오른쪽 경계를 넘던 grid를 수정했다.
- 조직 구성의 막대 차트 위 선을 replica에 추가했다.
- 컬렉션의 작은 칸에서 architecture, funnel, gauge, bullet, metric 등의 내부 패딩과 타입 단계를 줄였다. 복잡한 관계도에는 실용적인 최소 칸을 명시했다.
- CSS anchor로 line/area를 연결하는 과정에서 right anchor가 좌측 좌표가 아닌 우측 inset 거리라는 점을 확인하고 수정했다. 영역 차트의 root padding과 content-box query 높이를 맞췄다.
- 3–8축 radar의 다각형을 축 수에 맞춰 별도로 정의했다. 원본에 없는 요소도 얇은 선과 열린 면의 문법으로 설계했다.
- 재조립 로드맵에서 STEP 라벨과 상세 문구가 사라지는 문제를 발견해 `.steps > .step`의 `.mark`, `.name`, `.note`에 원문을 다시 넣었다.
- 표지의 첫 줄을 가볍게, 두 번째 줄을 굵게 나눴다. 섹션·마지막 표지에는 foundation의 `.on` 변형을 사용했다.
- 초기 다크 모드에서 강조 면 속의 `.name`이 기본 ink를 상속하던 문제를 `--a1-on`으로 수정했다. swimlane 소유자 라벨은 `--n-8`로 대비를 높였다.
- pill 숫자 mark의 실제 텍스트 경계 중심을 측정해 flex 중앙 정렬을 적용했다.
- 비필수 pricing/versus 등의 예시에서 오래된 `ul/li` 표현을 현재 `.list > .item > .name + .note` 계약으로 정규화하고 품은 요소의 `data-el`을 추가했다.

## 원본과 남아 있는 차이

이 결과가 원본과 픽셀 단위로 완전히 같다고 주장하지 않는다. 정확히 재현되지 않은 부분은 다음과 같다.

| 페이지 | replica / 조립본의 차이 |
|---|---|
| 01·02·03·18 | 다중 리본 그래픽은 SVG 곡선으로 근사했다. 조립본은 열린 곡선 모서리로 단순화해 원본의 복잡한 리본과 다르다. |
| 04 | 인물은 요청대로 회색 placeholder다. 서명은 이미지 복제 대신 글자로 표현해 원본 필기 모양과 다르다. |
| 05 | 건물 사진은 회색 placeholder다. 조립본은 헤더와 body 그리드를 지키므로 사진이 페이지 상단까지 뻗지 않는다. |
| 06·09·13 | Lucide에 준하는 단순 선 아이콘으로 근사했다. 조립본의 방사 노드는 동일한 hub 계약으로 묶여 원본의 원형 아이콘과 설명의 배치가 다르다. |
| 07 | replica는 원본 계단 시작점을 따라 배치했으나, 조립본은 12×6 그리드의 정수 칸에 맞췄다. |
| 08 | replica에 막대·선 콤보가 있다. 조립본에는 막대와 조직도를 넣었으며 고객사 선 시리즈는 아직 누락되어 있다. |
| 10 | 원본의 세부 흰 캡슐 9개를 조립본에는 모두 보존하지 못했다. 핵심 3개 서비스 제목과 두 수치는 남겼다. |
| 11 | 조립본에 프로젝트 수와 재계약률 시리즈를 함께 넣었다. 원본의 두 면·두 선 스타일과 범례는 다르게 표현된다. |
| 12 | 원본의 제품별 세부 기능 문구 일부는 가독성 있는 한국어 비즈니스 문장으로 재작성했다. 원본 아이콘은 단순 도형 아이콘으로 대체했다. |
| 14 | 로고 이미지는 요청대로 번호가 있는 회색 좌석으로 대체했다. replica의 로고 모양은 단순 선 아이콘 근사다. |
| 15 | 인증서 이미지는 회색 placeholder다. 작은 인증서 내부 문구는 재현하지 않았다. |
| 16 | 조립본의 단색 면과 타입 위계는 원본의 옅은 gradient 면과 다르다. |
| 17 | STEP 1–5, 단계 이름과 상세 원문은 보존했다. 조립본의 step 높이는 내용에 따라 달라지며 원본과 같은 상승 계단을 재현하지 못했다. |

전체 배치와 타입 위계를 구현했지만, 특히 방사형 설명 레이아웃, 로드맵 계단 및 복잡한 리본을 공용 요소로 옮긴 부분은 재현 충실도가 낮다. 이 차이는 검수 자료에 그대로 남겼다.

## 판독 불가·재작성·결정

- 실제 원본 폰트를 식별할 수 없어 계약 글꼴 중 Pretendard Variable을 골랐다. 굵기와 크기·자간으로 가까이 맞췄지만 동일 폰트라고 단정하지 않는다.
- 작은 미션 설명, 경쟁력 설명, 제품 기능, 인증 안내, 파트너 소개의 일부 문구는 시각 자료를 보고 한국어 비즈니스 문장으로 보완했다. 조립본에서는 긴 설명 일부가 축약되었다.
- 사진·인증서·복잡한 로고는 회색 placeholder로 두었다. 이는 구현 누락이 아니라 사용자 지정 대체 규칙이다.
- 모범 card fixture에는 `✹` 글자 아이콘이 들어 있어 “같은 마크업 유지”와 “글자 아이콘 금지” 규칙이 충돌한다. 해당 필수 fixture는 원문 보존을 우선했다. 새로 만든 아이콘에서는 글자 모양을 쓰지 않았다.
- 레퍼런스 palette의 라이트·다크 시트는 주 강조가 주황색으로 나타난다. 이는 공통 팔레트의 평가 조건이다. 조립본에는 원본에 가까운 파랑 계열을 별도 페이지 style로 공급했다. 컬렉션 CSS에는 강조색 리터럴을 고정하지 않았다.

## 자동 검사와 한계

`replica-audit.json`, `reassembled-audit.json`은 페이지 크기, 글꼴 로딩, 텍스트 scroll overflow를 기록한다. `library-audit.json`은 모든 fixture를 선언한 최소 칸부터 12×6까지의 열·행 조합으로 바꿔 DOM 경계와 텍스트 scroll overflow를 검사한다. `contrast-chip-audit.json`은 단색 배경을 합성한 텍스트 대비와 실제 텍스트 범위의 칩 중심을 측정한다.

DOM 경계 검사는 요소끼리 서로 겹치는 모든 기하를 증명하지는 않는다. 대비 검사는 gradient나 반투명 차트 면의 모든 위치를 완전하게 검사하지 않는다. 공식 Rhetis 반입 도구가 제공되지 않아 실제 intake 성공을 주장하지 않는다. 최종 수치와 파일 크기는 `verification.json`을 참고한다.
