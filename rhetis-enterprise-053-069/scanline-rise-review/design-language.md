# Scanline Rise — 056 덱 디자인 언어

## 관찰 근거

18장 모두 1280×720이다. 01 표지는 좌측 상단 타이포와 우측 하단의 신호 막대가 대비된다. 02는 5개의 얇은 테두리 목차 카드다. 03–18은 중앙 섹션 캡슐, 중앙 2행 대제목, 하단의 얇고 연속적인 띠를 공통으로 사용한다. 03·06·16의 원형 관계도, 04·07·12·13의 단색 header 카드, 08·09·10·13의 얇은 차트가 반복된다.

## 형태·선·모서리

- 정보 상자의 외곽선은 1px이며 그림자를 넣지 않는다. 단계·비교의 구분선은 1px, 주요 연결선은 2px이다.
- 정보 카드의 코너는 8px, 작은 면·하위 상자는 5px다. 섹션 라벨과 칩은 999px 캡슐이다.
- 표의 본문은 격자 전체를 둘러싸지 않고 가로 구분선을 중심으로 정돈한다. 선택한 열만 얇은 강조선을 추가한다.
- 원은 관계도 core·node·아이콘 mark에서 쓴다. 중심 원 주위의 점선 ring은 순환/관계의 범위를 나타낸다. 칸이 가로로 길어져도 원을 타원으로 늘리지 않는다.
- 반복되는 세로/가로 선은 scanline 문법이다. 원본의 흐림과 빛 번짐은 라이브러리의 효과로 복사하지 않고, 조용한 반복선으로 추상화한다.

## 여백·타이포

페이지 기본 여백은 좌우 72px, 상하 36px이며 내용은 12×6 그리드다. 내부 간격은 12/20/32px, 내부 padding은 24px다. 원본 replica에서는 슬라이드별 실측 위치를 별도로 유지했다.

글꼴은 실제 파일이 제공되는 Pretendard Variable이다. 원본 font metadata가 없어 육안으로 가장 가까운 글꼴을 골랐다. 표지 80px, 본문 페이지 제목 40px, statement 56px, 이름 24px, 본문 18px, label 16px, 큰 수치 52–80px를 쓴다. 작은 칸에서는 20/18/16/14px 단계로 내려가며, kick을 먼저 줄이고 정말 작은 칸에서만 note를 생략한다. 코드에는 Nanum Gothic Coding을 실제 로드한다.

## 색의 자리

컬렉션은 색상 자체를 소유하지 않는다. 키트 CSS에는 `--page`와 `--ink`만 색 리터럴이 있다. 아래는 사용자의 style이 공급하는 팔레트 역할이다.

|역할|팔레트 자리|
|---|---|
|페이지 바탕·기본 글자|`--page`, `--ink`|
|제목의 상행 및 큰 수치 강조|`--a1-7`|
|주 강조 header·선택 카드·주 시리즈|`--a1`|
|강조 면 위의 글자|`--a1-on`|
|보조 카드의 조용한 면|`--n-1` 또는 `--a1-1-soft`|
|placeholder|`--n-2`|
|구분선·비강조 막대|`--n-3`, `--n-4`|
|보조 설명|`--n-7`|
|2–4번째 시리즈|`--a2`, `--a3`, `--a4`|
|상태·증감|`--good`, `--bad`|

원본 스타일의 색은 reassembled의 slide 최상위 팔레트 값으로 공급한다. 새 요소별/페이지별 CSS를 추가하지 않는다. 표준 library 시트는 계약의 공통 reference palette로 렌더하므로 원본의 파랑과 다른 색으로 보이는 것이 정상이다.

## 이미지에 없는 요소의 확장

새 요소에도 얇은 선, 작은 코너, 단색 header, 조용한 보조 면, 중앙 원형 core, 명료한 단일 강조를 사용한다. Sankey의 band, network의 link, journey의 곡선, radar의 polygon도 같은 선의 무게를 유지한다. 손그림 장식, 큰 그림자, 잎·별 등의 무관한 장식은 추가하지 않는다.
