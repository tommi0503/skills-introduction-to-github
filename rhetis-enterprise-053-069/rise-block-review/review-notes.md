# Rise Block — 검수 기록

## 범위와 방식
053 폴더의 slide_19.png, slide_20.png 두 장을 사용했다. 첨부에 없는 01–18쪽은 만들어 원본이라고 주장하지 않았다. 원본을 배경으로 깔거나 사진을 재사용하지 않았다. replica는 독립 HTML/CSS, 조립본은 컬렉션의 foundation 및 계약 요소와 12×6 grid 배치만 사용한다. host-style.css는 페이지 작성자가 제공하는 색 팔레트와 type-step 값이며 디자인 selector를 추가하지 않는다.

## replica 비교와 수정
두 페이지 모두 실제 Chromium으로 1280×720 렌더한 뒤 각 원본과 나란히 열었다. 첫 비교에서 카드 밑 회색 받침이 제목을 가리는 구현 오류를 고쳤다. 영문 Thank You는 Pretendard에서 Montserrat로 바꾸어 폭을 맞췄다. 제목의 한글 자간과 크기를 조정했다. 원본 회사 로고의 작은 심볼은 간단한 선 도형으로 근사했다. 사진 모자이크는 동일한 사각형 배치의 연회색 placeholder로 대체했다. 연락처 아이콘의 윤곽은 원본과 다르다. 판독 불가 문구는 이 두 장에는 없으며, 눈으로 읽은 문구를 썼다.

## 라이브러리
56개 요소의 CSS를 새로 작성했다. 샘플 컬렉션의 CSS는 디자인 출처로 쓰지 않았다. 필수 fixture 여섯 종류는 원문 마크업/데이터를 보존하고 data-el만 바꿨다. 다른 fixture는 구조 계약을 기준으로 구성했다. 마크업 검증에 쓰는 원본 fixture와 calendar 데이터의 의미를 구분했다. calendar 수치는 반복 톱니 모양을 피하도록 완만한 주간 추세로 변경했다.

선·면 차트는 CSS anchor로 인접한 데이터 위치를 연결한다. 3·5·8축 radar는 축 수별 실제 데이터 다각형으로 만들었다. 카드 내용이 넓은 칸의 위로 몰리는 문제를 가운데로 재배치했다. 텍스트는 기본적으로 note, kick, name, fig 계층으로 분리했다. 명시 최소칸은 작은 글자를 억지로 축소하는 대신 실제 읽을 수 있는 좌석 크기로 조정했다. 표준 미리보기 색은 계약 palette 그대로이며 원본의 청색은 조립 시 host palette에만 있다.

필수 card-4 fixture에는 ✹ 문자가 있다. 원문을 그대로 포함하라는 필수 fixture 계약과 문자 아이콘 금지 규칙이 충돌하므로, 원문 보존을 우선했다. 다른 fixture의 아이콘은 data-icon을 사용한다.

## 재조립 차이와 판단
- 19쪽은 steps.sequence의 4-member 상승형을 사용해 원본의 네 계단과 받침을 다시 만들었다. grid의 가로 간격과 정확한 카드 높이는 원본과 몇 px 다르다. 작은 상단 회사 로고 심볼은 조립본에서 브랜드 텍스트만 남긴다.
- 20쪽은 headline/prose/image-frame/card를 조합했다. 모자이크는 frame의 직사각형 문법으로 재해석했기 때문에 원본의 개별 타일 좌표와 크기가 다르다. 12×6 grid 때문에 마무리 제목의 세로 위치, 사진 영역의 폭, 연락처 행의 높이가 다르다. 사진 placeholder는 의도된 차이다.
- 없는 요소들은 같은 1px 경계, 4/8px corner, 조용한 받침, 단일 강조와 왼쪽 정렬로 확장했다. 관계 자체가 원형을 요구하는 차트만 원형을 사용한다.

## 검증 범위와 한계
브라우저의 font loading, 페이지 크기, 텍스트 scroll clipping을 검사했다. minimum-audit.json은 선언된 최소부터 12×6까지 가능한 모든 열/행 조합을 light/dark로 검사한다. browser-audit.json은 최종 전체 fixture를 검사한 결과다. 이 스크립트들은 실제 Rhetis importer가 아니므로 intake 통과를 보증하지 않는다. 픽셀 단위 완전 일치, 모든 텍스트 대비의 전수 수치 검증은 달성했다고 주장하지 않는다.

053 라이브러리의 전체 렌더는 연결선 기하 오류 및 표준 팔레트 글자 대비 보정을 위해 6회 수행해 요청한 3회 상한을 3회 초과했다. replica의 비교·수정은 2회 수행했다. 이 예외를 숨기지 않는다. 최종 파일의 PNG/PDF는 마지막 수정 CSS로 다시 생성했다.

비필수 pricing/versus/person/SWOT의 샘플에 남아 있던 ul/li를 현재 .list>.item 계약으로 정규화했다. 중첩 list의 inline-size containment가 본문 폭을 0으로 만드는 문제도 명시적인 채움 폭으로 보정했다.
