# Rise Block 디자인 언어

원본 053의 첨부 2장(slide_19, slide_20)에서 추출했다.

- 선: 왼쪽 페이지 rail 6px, 정보 경계 1px. 선은 화면을 기울이지 않고 수직/수평 질서를 만든다.
- 모서리: 주 패널 8px, 보조 면 4px. 캡슐은 의미가 작은 label에만 쓴다.
- 여백: 12 / 26 / 40px, 페이지 가로 74px. 다단 카드가 동일한 baseline의 plinth 위에서 단계적으로 상승한다.
- 타이포: 본문 Pretendard Variable, 영문 마무리 Montserrat. 제목 40–44, 카드 22–24, 본문16–18, 라벨14, 수치48–72. 제목과 수치는 가는 선보다 훨씬 강하게 둔다.
- 강조: 마지막 단계의 면 = --a1 및 --a1-on. 진한 보조 단계 = --a1-9 및 --page. 기본 텍스트 = --ink. 회색 받침/자료 영역 = --n-1. 제목의 핵심 동사 = --a1. 선 = --n-3. 색 이름이나 원본 청색 자체는 디자인의 일부가 아니다.
- 장식: 마무리 모자이크의 엇갈린 사각형과 좌측 rail만 사용한다. 의미 없는 별/잎/인용 장식은 추가하지 않는다.
- 이미지에 없는 요소: 같은 직각 축, 둥근 직사각형 면, 정렬된 수치와 단일 강조로 확장한다. 원형은 데이터의 비율/관계가 요구할 때만 사용한다.
