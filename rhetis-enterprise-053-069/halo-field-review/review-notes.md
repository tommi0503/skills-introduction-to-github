# Halo Field 검수 기록

## 범위와 순서

058_1ld2w 덱의 원본 15장(각 1280×720)을 대상으로 했다. README 전체를 먼저 읽고 이미지 목록과 계약 대응표를 작성한 뒤, 독립적인 replica를 먼저 만들었다. replica의 반복 규칙을 design-language.md에 옮긴 다음 foundation과 56개 요소를 만들고, 마지막으로 계약 요소만 사용한 reassembled를 만들었다. 기존 컬렉션의 CSS와 장식을 복사하지 않았다. 필수 모범 fixture는 지정된 샘플에서 마크업과 데이터를 보존하고 data-el 컬렉션 접두어만 바꿨다. 비필수 fixture는 구조를 참고하되 마케팅 맥락과 긴 문구를 섞었다. 중첩 list/tag에도 data-el을 부여했다.

## 비교와 수정

원본과 replica의 나란히 비교는 각 15페이지를 열어서 진행했다. 시각 비교 3회 범위 안에서 제목 크기, 카드 폭, 본문 크기, 표의 행 높이, 피라미드의 SVG 가시성 및 단계 형태, 07의 벡터 아이콘을 수정했다. 라이브러리와 조립본은 둥근 패널, 가로선, 단일 강조, 원형 프로세스의 공통 문법을 확인했다. 자동 검사에서 발견된 좁은 영역의 문제는 type 단계·간격·장식 위치를 조정하여 다시 렌더했다.

주요 수정은 다음과 같다.

- 면적 차트의 플롯 기준 높이를 series container와 일치시켜 데이터 점 사이의 연결을 바로잡았다.
- chart-line은 CSS anchor 좌표를 사용해 같은 fixture 데이터로 선과 점을 연결했다.
- radar는 3–8개 축 수에 따라 실제 값을 사용한 다각형을 그린다.
- 좁은 donut, 다단 funnel, 달력 heatmap, 긴 목록, treemap의 최소칸 넘침을 수정했다.
- 08페이지 pill은 등급만 담고 설명을 독립 prose로 분리하여 원본 수준의 가독성을 확보했다.
- steps는 6개 멤버에서 chevron 문법을, 그 외 가로 단계에서는 원형 고리 문법을 사용하여 원본 09·11의 두 방식에 대응한다.
- 밝은 강조색의 작은 글자는 a1-7 단계로 조정했고, 채움 위 글자는 a1-on을 사용한다. reassembled의 사용자 style도 밝은 채움 위에 어두운 글자를 선택했다.

## 자동 검사와 산출물

replica와 reassembled는 모두 1280×720, 원본 나란히 비교는 2560×720이다. 요소별 시트는 한 장의 1280×720 안에서 fixture별 12×6과 선언된 최소칸을 함께 보여준다. library-light.pdf와 library-dark.pdf는 foundation 1장과 요소 56장으로 구성한다. 최소칸/12×6 라이트·다크 검사의 자세한 결과는 minimum-audit.json, 브라우저 폰트·조립본 넘침 검사는 browser-audit.json에 남겼다. 실제 Rhetis intake 실행기는 레퍼런스 팩에 없으므로 이 작업의 검사 결과가 Rhetis의 최종 반입 승인을 대신하지는 않는다.

## 재빌드

작업 스크립트는 review 폴더에만 있다. collection 폴더는 .css/.json/.md/.html만 포함한다. 전체 생성 순서는 build_replica.py → render_replica.py → build_collection.py → refine_collection.py/fix_minima.py/final_design.py/finish_contract.py/normalize_nested.py 및 마지막 수정 → build_review.py → render_review.py → audit_minima.py → portable_fonts.py다. 중간 refine 스크립트는 제작 과정 기록이며 최종 collection 소스를 그대로 사용하는 것을 권장한다. review와 collection을 같은 부모 경로에 풀고 그 부모에서 HTTP 서버를 실행하면 상대 경로의 CSS와 포함된 글꼴을 불러온다.

최종 확인: 최소칸·12×6 라이트/다크 674건에서 넘침 0건, 조립본 넘침 0건, 명시적 400/700 글꼴 로드 실패 0건. 페이지 PNG 30장과 요소 시트 114장은 1280×720, 비교 PNG 30장은 2560×720이다. preview.png는 별도의 1280×720 요약 이미지다. `reassembled/style-palette.css`는 색·타입 단계 변수만 공급하는 사용자 style이며 배치나 요소 규칙을 추가하지 않는다. 마지막 CSS 수정 후 library와 reassembled PNG/PDF를 모두 다시 렌더했다.
