# Halo Field 디자인 언어

058 덱 15장의 replica를 바탕으로 한다. 단순한 환형 그래픽과 둥근 흰 패널, 얇은 가로선, 좌측 정렬 영문 제목이 핵심이다.

| 역할 | 규칙 | 색의 자리 |
|---|---|---|
| 페이지 | 54px 좌우 여백, 상단 작은 section, 104px 위치의 1–2px 수평선 | `--page`, 선 `--a1` |
| 제목 | 영문 44px/700, 한글 표지 80–88px; 좁은 칸에서는 32/24px 단계 | `--a1` 또는 기본 `--ink` |
| 본문 | 22px, 작은 설명 16–18px; Freesentation, 1.4–1.5 행간 | `--ink`, 보조 `--n-7` |
| 패널 | 20–26px 둥근 모서리, 32px 안쪽 간격, 같은 행 제목 수평 정렬 | `--page`, 바닥면 `--n-1`, 그림자 `--n-2` |
| 강조 | 한 데이터/마지막 단계만 진하게, 둥근 번호 탭이나 알약에 짧은 문구 | 채움 `--a1`, 글자 `--a1-on` |
| 선/연결 | 1px 선, 원형 노드, 여백을 가로질러 얇게 연결 | `--n-4`, 강조 `--a1` |
| 장식 | 내용 밖의 큰 고리와 반원, 작은 점, 원형 진행률; 불필요한 별은 라이브러리에서 제거 | `--a1-2-soft`, `--n-2` |
| 간격 | 8 / 16 / 24 / 32 / 48px 토큰 단계 | 해당 없음 |

색을 디자인의 고유 속성으로 저장하지 않는다. 원본의 민트색은 강조 1의 자리이며, 원본 회색 패널은 중립 단계의 자리다. 다크는 `--n-*`의 의미 단계를 유지하고 채움/글자 대비를 다시 확인한다. 원본에 없는 조직도·차트는 같은 둥근 노드와 얇은 연결, 단일 강조 원칙으로 확장한다.
