# Cinder Pulse — 054 덱의 디자인 언어

원본 20장, replica 20장을 각각 원본 옆에서 확인한 뒤 정리했다. 이 컬렉션의 정체성은 색상이 아니라 어두운 여백 속 밝은 패널, 가벼운 대형 제목, 작은 모서리, 가는 강조 레일과 긴 세로 캡슐이다.

|규칙|원본 관찰|컬렉션 적용|
|---|---|---|
|페이지|1280×720, 외곽 34px, 패널 사이 11px|`--margin-x/y`, `--gap-sm`|
|패널|흰 바탕, 10~11px 모서리|바탕 `--page`, `--radius`; 문서 캔버스 `--n-9`|
|세부 카드|연회색 면, 1px 윤곽, 7~8px 모서리|면 `--n-1`, 선 `--n-3`, `--radius-sm`|
|장식|세로 캡슐 112×440, 높이가 차례로 변함|표지 `.deco`, 조용한 `--n-7`, 마지막만 `--a1`|
|제목|한글 42px/가벼운 굵기, 표지 72px|`--type-44/72`, `--title-weight`, 좁은 자간|
|본문|16~20px, 1.4~1.6 행간|`--type-16/18/20`, `--body-line`|
|숫자|28px 안팎 중간 굵기, 핵심 수치만 강조|`--figure-weight`, `--a1`|
|강조|소제목 왼쪽 2px 레일, 원형 핵심, 짧은 띠|레일·띠 `--a1`; 강조 면 위 `--a1-on`|
|흐름|가는 회색 연결, 핵심 한 개는 채움|연결 `--n-4`, 선택 `.on`만 `--a1`|
|간격|패널 안 36~40px, 카드 안 24~28px|`--pad`, `--gap`, `--gap-lg`|

사진과 로고는 연회색 자리로 남긴다. 복잡한 이미지를 장식으로 베끼지 않는다. 표지의 다섯 캡슐과 원형 핵심을 차트·노드에 번역하되, 모든 차트를 원으로 만들지 않는다. 표는 조밀한 수평선, 캡슐형 진행 표시, 강조색 윗띠를 쓴다. 원본의 주황 강조는 `--a1`, 선택 열은 `--a1-2-soft`, 중립 카드 바탕은 `--n-1`로 이동한다. 팔레트가 바뀌어도 동일한 형태와 위계가 남아야 한다.

글꼴 원본 파일은 제공되지 않아 README 허용 글꼴 중 Pretendard Variable을 사용했다. 영문 표지의 각진 곡선, 대표 서명과 실제 인물 사진은 정확한 원본과 차이가 있다.
