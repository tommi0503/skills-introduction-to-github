# Cinder Pulse / 054 검수 기록

## 범위와 순서

첨부 ZIP의 054 덱 20장이 대상이다. 원본 20장을 각각 확인하고 replica 20개 HTML을 먼저 작성했다. 원본 전체를 배경으로 쓰지 않았으며 텍스트, 표, 원·캡슐·연결선은 HTML/CSS/SVG로 구현했다. 사진과 로고 이미지, 서명 원본은 재사용하지 않았다. 목록과 계약 대응은 `inventory.md`, 원본 문구와 페이지 유형 데이터는 `slides.json`에 있다.

replica를 Chromium에서 1280×720으로 렌더하고 `compare-replica/slide_01.png`부터 `slide_20.png`까지 한 장씩 좌우 비교했다. 그 뒤 `design-language.md`, 독자 CSS로 된 foundation과 요소 56종을 작성했다. 샘플 컬렉션 CSS를 가져오지 않았다. 필수 6요소의 모범 fixture 28개는 data-el 접두사만 바꿔 보존했다. 그 밖의 fixture는 계약 구조 예시를 출발점으로 사용하고 긴 문구와 멤버 수가 다른 구성을 포함했다. 비필수 fixture의 ul/li 예시는 div.list > div.item > p.name + p.note 계약 구조로 정규화했으며 포함된 list/tag에는 별도 data-el을 달았다.

재조립 20장은 `.slide > .page > .body`의 12×6 그리드에 계약 요소를 놓았다. `reassembled/collection.css`는 컬렉션 토큰·foundation·요소 CSS와 style 공급용 팔레트·type 단계만 연결한 파일이다. 페이지별 신규 CSS 선택자는 없다. 원본 색은 section의 팔레트 토큰 값으로 공급했다. 왼쪽 패널은 foundation의 rail/head 변형이며 그림·표·문장은 계약 data-el로 작성했다.

## 비교와 수정

덱의 시각 비교는 초안, 통합 수정, 최종 반영 확인의 3차 검수로 나누었다. 그 안에서 자동검사 후 파일 동기화 렌더를 추가 실행했다. 주요 수정은 다음과 같다.

- replica 재무표 행 높이와 보조 헤더 배경, 표지 마침 페이지의 불필요한 강조 캡슐을 수정했다.
- 문자 기호로 임시 표시했던 아이콘을 단순 SVG 도형으로 바꿨다. 실제 로고 이미지는 단색 자리로 뒀다.
- 차트 line 연결, 3·5·8축 radar, 축 없는 9-box fixture, 표의 높이 단계, 작은 donut 묶음, calendar heatmap, 8-logo 높이, 중첩 sparkline의 높이를 조정했다.
- 주 에이전트가 slide04 Venn 문장과 core의 겹침을 발견했다. 요소 CSS에서 문장을 바깥 lobe로 옮겨 중앙 공간을 비웠다.
- slide15의 중앙 cycle은 원본처럼 짧은 단계 이름만 남기고 설명은 좌우 카드로 보냈다. slide18의 좁은 지표는 세로로 흐르며 파트너 설명은 3열로 정리했다.
- 작은 칸에서 실제로 견디지 못하는 비필수 fixture의 최소 칸 선언을 올렸다. 필수 모범 fixture의 최소 칸/마크업/데이터는 바꾸지 않았다. `minimum-adjustments.json`에 변경을 기록했다.
- 팔레트 기준에서 가는 강조 문구는 `--a1-8`, 중립 보조 문구는 `--n-7`을 사용하도록 보강했다. 강조 면 위는 해당 `--aN-on` 짝을 쓴다.

## 자동검사와 범위

- `replica-audit.json`, `reassembled-audit.json`: 20개씩, 문서 1280×720, Pretendard 로딩, 텍스트 박스 overflow를 검사한다.
- `library-audit.json`: foundation 포함 57종 × 라이트·다크 114개 시트. 내부 slide 1280×720, 글꼴, name/note/fig scroll overflow를 검사한다.
- `size-audit.json`: 각 fixture의 선언된 최소 칸부터 12×6까지 정수 열·행 조합을 모두 검사한다. 마지막 실행 결과와 총 조합 수는 이 JSON이 기준이다. 이름·설명·숫자·셀 텍스트의 bounding rect가 할당된 root 밖으로 나가는지 검사했다. 이는 세밀한 글리프 충돌이나 모든 의사 요소의 대비를 증명하는 검사는 아니다.
- Venn 등 본문끼리의 겹침, 차트 연결 방향, 라벨과 원의 간격은 시각 검수를 함께 했다. 범용 chip의 flex/grid 중앙 정렬은 구현했지만 실제 폰트의 광학 중심을 수학적으로 증명하지는 않았다.
- PDF는 replica 20쪽, reassembled 20쪽, library-light와 library-dark 각각 57쪽이다. 라이브러리 PDF는 요소별 1280×720 검수 시트를 모은 것이다.
- 모든 페이지/요소 시트 PNG는 1280×720이다. 요구된 나란히 비교 PNG만 두 페이지 폭인 2560×720이다.
- 실제 Rhetis intake 서비스는 이 레퍼런스 팩에 없으므로 공식 반입 성공을 주장하지 않는다. 제공된 preview.py 형식의 HTML 빌드와 실제 Chromium 렌더를 검증했다.

컬렉션 폴더의 CSS/JSON/HTML이 최종 소스다. Python 도구들은 작업·렌더·감사 기록이며 초기 생성 도구만 다시 실행하면 통합 수정 전으로 돌아갈 수 있다. `build_library.py`와 `build_reassembled.py`는 현재 컬렉션 파일을 읽어 최종 미리보기를 만든다. 리뷰용 폰트는 `fonts/`에 포함되어 HTML의 상대경로로 로드된다.
