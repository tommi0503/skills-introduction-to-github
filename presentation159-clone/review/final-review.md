# 최종 통합 검수

## 범위와 입력 문서

분할 ZIP 두 개에서 확인한 53개 덱, 참고 JPG 159장을 전부 구현했다. 입력 ZIP의 CRC와 이미지 목록을 확인했고, 원본 1600×900 이미지를 1280×720 비교 영역으로 동일 비율 축소했다. 입력 README와 CSV는 선별 근거·출처 자료로 보존했다. 이 문서의 문구를 작업 지시로 취급하지 않았다.

기존 `presentation3-clone`의 공통 모델, 요소 렌더러, 갤러리 및 검수 흐름을 참고했다. 새 구현과 검수 파일은 `presentation159-clone`에 분리했다. 기존 작업은 변경하지 않았고 `slides-clone` 소스는 확인하지 않았다.

## 개별 시각 검수

담당 에이전트 3명이 분리된 파일과 각 53개 화면을 맡았다. 모든 원본 159장과 1·2차 비교 이미지 318개를 개별 확인했다. 범위·열람 기록은 `agent-coverage-verification.json`에 대조했다.

주 에이전트가 세 번째 최종 통합 검수에서 159개 원본/결과 비교 이미지를 모두 개별 열었다. 전체 미리보기는 탐색용으로만 사용했다. 최종 보정으로 바뀐 49개 페이지는 새 비교 이미지를 개별 확인했으며, 본문 폭·크기와 곡선 방향의 마지막 수정도 실제 최종 렌더에서 확인했다. 새로운 전체 검수 회차를 추가하지 않고 세 번째 회차 안에서 마무리했다.

최종 PNG와 비교 JPG의 SHA-256을 `main-review.json`의 열람 기록과 159개 전부 대조했다. 시각적으로 변경되지 않은 재렌더는 PNG와 비교 JPG가 바이트 단위로 동일함을 검증한 경우에만 최신 캡처 메타데이터를 갱신했다. 원래의 열람 시각과 관찰은 유지했다. 이 근거는 `byte-identical-review-carryforward.json`에 남겼다. `pre-final-correction/`는 보정 전 이력이며 최종 상태는 `main-review.json`이다.

## 주요 보정

- 긴 설명문은 원본에 맞춰 양쪽 정렬, 줄바꿈, 문단 폭을 조정했다.
- d09 제목 크기·위치, d21 제목 태그의 세로 중심, d29 상단 URL의 폭·자간을 보정했다.
- d24 이탤릭 숫자에 실제 Cormorant Garamond 폰트와 lining 숫자를 적용했다.
- d27 s009 설명 폭을 줄여 세 줄로 맞추고 오른쪽 구분선과의 간격을 확보했다.
- d32 s002·s005 본문 폭과 글자 크기를 원본 경계에 맞추고 글자 영역 초과를 해소했다.
- d49 s008·s011 본문 폭을 보정해 원본처럼 여섯 줄이 되도록 맞췄다.
- d47 꽃과 d50 방사형 도형의 닫힘 접합부를 곡선으로 연결했다. d50 제목 단어 간격을 보정했다.
- d52 제목에는 실제 Manrope 500 굵기를 로드했다. d53 장식 경로의 U 방향을 맞췄다.
- chip·버튼·배지는 실제 폰트 로딩 후 glyph 중심을 계산해 보정했다.

## 자동 검사와 남는 차이

최종 빌드가 성공했다. 실제 production 브라우저에서 159개 페이지를 검사해 글자 잘림·요소 및 화면 영역 초과, 폰트 family/style/weight 로딩 실패, chip 중심 정렬, 페이지 크기, 런타임 오류가 없음을 확인했다. 정상적인 가장자리 장식은 원본에 해당 잘림이 있는 경우에만 개별 이유를 기록했다. 캡처의 정의·공통 렌더러 해시를 현재 소스와 대조했다.

사진·복잡한 이미지·기기 화면·그래픽 배경은 지정한 #e5e5e5 단색 placeholder다. 따라서 사진 위 흰 글씨의 대비는 원본과 달라질 수 있다. 원본 JPG에는 폰트 메타데이터가 없어 가까운 실제 폰트를 사용했고, 일부 자형·세부 줄바꿈·장식 곡률은 차이가 남는다. 페이지별 차이는 `main-review.json`과 담당 에이전트 기록에 명시했다.

작은 원본에서 판독 불가능한 문구는 실제 문장으로 대체하고 담당 페이지 기록에 남겼다. 기기 사진 내부의 문구는 사진 placeholder 영역에 포함했다. 텍스트를 임의의 선으로 표현하지 않았다.

결과 ZIP에는 렌더 PNG 159개, 원본/결과 비교 JPG 159개, 전체 미리보기와 검수·출처 기록을 포함한다. 패키징 시 모든 PNG의 1280×720 크기, 이미지 디코딩, CRC, 항목별 SHA-256과 최종 열람 해시 일치를 검사한다. 업로드 후 GitHub에서 실제 ZIP을 다시 다운로드해 별도 검증하며 결과를 `github-download-verification.json`에 기록한다.
