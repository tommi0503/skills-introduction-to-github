# 최종 검수 — EONU IR

2026-10-21. 와이어프레임 12장 + 디자인 시안 12장.

## 결과

- 최신 MD의 12장 흐름을 유지하고 사용자 확정대로 6장 데모 진행 흐름을 포함했습니다.
- 콘텐츠와 대본은 공통 `src/slides.js`에서 관리하며 두 테마의 정보가 같습니다.
- 기존 `presentation5-clone`의 데이터/공통 렌더러 분리 및 전체 브라우저 검수 방식을 참고했습니다. 기존 프로젝트 파일은 수정하지 않았습니다.
- 24개 HTML 모두 1280×720, 제목 좌표 x=58/y=92, 섹션 라벨의 왼쪽 좌표 x=58이 일치합니다. 공통 헤더 top=34px입니다.
- 로컬 Pretendard 폰트 로딩, 5개 사진 영역의 #e5e5e5 단색, 래스터 이미지 없는 도식·아이콘을 확인했습니다.
- 최종 브라우저 검사에서 본문 경계 초과·가로 넘침·숨겨진 컨테이너의 텍스트 잘림·페이지 오류·실패 요청이 없습니다.
- 2장 스토리 카드 사이의 연결 화살표는 의도적으로 카드 경계를 넘어 간격에 배치됩니다. 본문 텍스트 넘침과 구분해 기록했습니다.
- 뷰어의 118개 기능 확인 항목과 390px 모바일 검사를 통과했습니다. 기획 검토 문서·두 PDF 링크도 정상입니다.
- 슬라이드 PDF 12+12페이지, 합본 24페이지를 확인했고 본문 텍스트 추출이 가능합니다. 기획 문서 PDF는 10페이지입니다.

## 시각 확인

주 제작자는 양쪽 12장 그리드와 주요 개별 슬라이드(표지, 병원 도입 가설, 솔루션, 데모, 시장, 자금계획)를 열람했습니다. 별도 검수자가 두 버전의 24개 최종 PNG를 모두 개별로 열람했습니다. 페이지별 기록과 PNG 해시는 `independent-visual-review.md`에 있습니다.

초기 검수에서 5·9·10·11장의 카드가 공통 본문 영역을 넘고, 6장의 UI 도식 하단 버튼이 잘리는 문제를 확인했습니다. 카드 간격·패딩을 줄이고 UI 내부 간격을 조정했습니다. 관계도 화살표 끝이 중앙 노드에 가려지는 부분도 수정했습니다. 수정 후 전체 24장을 재생성하고 재검수했습니다.

## 출처·수치·표현

아이 사례는 재구성한 예시, 제품 UI는 설명용 도식입니다. 특정 기관 협력, 실증·계약, 임상효과, 비급여 전환 성과를 입증된 것으로 추가하지 않았습니다. TAM/SAM/SOM은 포함 관계와 산정식을 구현했고, 미확정 금액의 비율을 임의로 그리지 않았습니다. 예산은 원문 총액 1억 원과 미확정 항목을 분리했습니다.

기획 검토는 첫 고객 선정, 기존 대안 비교, 검증 지표, 가격·제공 원가·CAC, 시장 정의, 자금과 산출물을 보완했습니다. 최신 자료의 미확정 입력값은 발표 전 확정해야 합니다. 발표 목표 300초는 시간 배분안이며 실제 낭독 실측값은 아닙니다.

## 검수 범위의 한계

관리형 브라우저가 file:// 탐색을 차단하여 실제 뷰어 검수는 localhost HTTP로 수행했습니다. 배포 HTML은 로컬 상대 경로·classic JS·로컬 폰트를 쓰며 외부 런타임 요청이 없습니다. 실제 서비스 기능/의학적 효과/계약 증빙을 검증하는 작업은 이번 디자인 제작 범위에 포함되지 않습니다.
