# p055 · p060 · p100 · p105 검수 기록

담당 142장: p055 16장, p060 16장, p100 32장, p105 78장. 원본 시트 6개와 모든 142개 독립 crop을 확대하여 개별 확인했다. 브라우저에서 1차 142장과 2차 142장을 렌더하고, 각 원본/결과 비교 이미지를 개별로 확인했다. 연락처 시트만으로 검수를 대체하지 않았다.

차트·기하·표·연결선은 clean semantic primitives와 실제 SVG 경로, 문구는 DOM 텍스트로 구성한다. 반복 구조는 표·막대·donut·전구·hex·텍스트·chip 공통 factory를 사용하며 페이지별 데이터와 배치가 분리돼 있다. 원본 통째 이미지는 결과 UI에 사용하지 않는다. 생성 코드는 `review/group-b-extra-build.py`, 데이터는 `src/decks/group-b-extra-data.json`, 덱 registry는 `src/decks/group-b-extra.ts`에 있다.

Roboto, Montserrat, Poppins, Kaushan Script는 공통 실제 로딩 font를 사용한다. 폰트 크기·굵기·줄바꿈·줄간격은 작은 원본의 육안 관찰을 기반으로 맞췄으며 정확한 font 원본 정보가 없는 부분은 추정이다. 작은 본문은 정상적인 lorem prose로 대체했다. 사진·일러스트·화면·그래픽 배경·브랜드 image icon은 지정된 #e5e5e5 placeholder다. 지도는 복잡한 artwork placeholder이고 그 위 수치·도형·연결선·캡션은 실제 UI다. 3D 차트의 shading은 일부 2D semantic 차트로 근사했다.

두 검수 회차에서 발견한 수정사항과 판독 불가능한 영역은 아래 페이지별 기록과 `group-b-extra-review.json`에 보존한다. 2차 수정 후 자동 브라우저 감사는 `group-b-extra-final-audit.json`에서 확인한다. 주 에이전트의 production 통합 렌더 뒤 담당 142개 결과물과 원본을 모두 개별로 열람했다. 15개 보정 페이지의 마지막 재캡처도 다시 실제 개별로 확인했고 모든 SHA를 확정했다.

p105/s03-25는 실제 세로 원본(218×377)이다. 원본 비율을 유지해 1280×720 stage의 가운데에 배치하고 좌우를 흰 여백으로 처리했다. 잘린 원본은 알려진 위치를 유지하되 누락된 영역을 복원하므로 해당 부분의 완전한 동일성은 검증할 수 없다.
