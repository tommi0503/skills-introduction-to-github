# Presentation 5 품질 개선본 검수

첨부한 두 ZIP의 117개 참고 이미지에서 분리한 47개 덱, 1,057개 독립 페이지를 다시 구현·비교했습니다. 첨부 문서의 내용은 참고 자료로 취급했으며 작업 지시는 사용자 요청을 따랐습니다. 기존 프로젝트와 이전 제출 ZIP은 보존했습니다.

## 개선 내용

원본과 대조해 제목·본문·숫자의 크기 비율, 굵기, 자간, 줄간격, 줄바꿈, 정렬과 여백을 보정했습니다. 실제 폰트 파일의 normal/italic 및 필요한 굵기를 로드하고 합성 굵기·기울임을 비활성화했습니다. chip은 실제 렌더된 글자 경계로 시각적 중심을 검사합니다.

재사용 가능한 SVG 컴포넌트로 지도 경계, 리본, 기기 외곽, 그래픽 장식, 입체 도형, 배지와 브랜드 아이콘 등을 복원했습니다. SVG가 표현할 수 있는 단순 구조와 차트는 벡터로 구현하고, 사진·기기 화면·복잡한 사진 기반 일러스트는 연한 회색 placeholder로 유지했습니다. 결과 화면에 원본 이미지를 통째로 삽입하지 않습니다.

기존 제출 소스와 비교해 1,037페이지의 정의가 변경되었고, 1,006페이지에 텍스트·chip의 스타일 또는 배치 보정이 있습니다. 449페이지에 SVG 장면 786개가 사용되며 placeholder 요소는 1,298개에서 996개로 줄었습니다. 세부 수량은 `change-summary.json`에 있습니다. 이 수량은 수정 범위를 나타내며 시각적 유사도 점수는 아닙니다.

## 실제 브라우저와 개별 비교

6명의 담당 에이전트가 파일과 화면을 나누어 모든 개선 페이지를 새 브라우저 렌더와 원본의 개별 비교 이미지로 확인했습니다. 덱별 두 차례 비교·수정 후 주 에이전트가 전체 47개 덱의 대표 페이지와 발견한 수정 페이지 172장을 개별 통합 검수했습니다. 마지막 검사에서 발견한 국소 변경은 영향받는 덱만 production으로 다시 렌더하고 해당 페이지를 재확인했습니다. 연락처 시트는 탐색과 전체 미리보기 용도입니다.

현재 최종 PNG를 직접 다시 열람한 경우와, 새로 실제 검토한 PNG·원본의 바이트가 최종 파일과 완전히 같은 경우를 검수 기록에서 구분했습니다. 비교 이미지의 상단 라벨만 바뀐 경우에는 디코딩한 페이지 영역도 정확히 일치하는지 확인하고 당시 열람한 비교 파일을 ZIP에 보존했습니다. `owner-*-completion.json`, `root-review-journal.json`, `../visual-review.json`, `../root-review-coverage.json`에 페이지별 경로·SHA·검수 방법이 있습니다.

최종 production 빌드의 전체 소스 스냅샷과 각 캡처의 출처는 `production-builds.json`에 기록합니다. 공통 렌더러와 최종 덱 정의가 현재 소스와 일치하는지 검사하므로 마지막 수정이 반영되지 않은 캡처는 제출 검사에서 실패합니다.

## 자동 검사와 제출 검증

`../verification.json`은 전체 1,057페이지의 실제 production 브라우저 검사를 담습니다. 페이지 크기, PNG 해시, 글자 잘림·영역 초과, 폰트 파일 및 굵기·기울임 로딩, chip 중심, SVG 등록 및 경로 오류, 원본 스크린샷 삽입, 비율 왜곡, 갤러리 탐색과 참고 이미지 로딩을 검사합니다. 원본에 의도적으로 잘린 장식은 일반 오류와 구분해 사유를 기록합니다.

`../archive-integrity.json`에는 전체 PNG의 개수·1280×720 크기·SHA와 ZIP CRC 검사 결과가 있습니다. GitHub 게시 후 ZIP을 HTTPS로 실제 다시 내려받아 검사한 결과는 `../github-download-verification.json`에 별도로 남깁니다.

## 남은 차이와 판독 한계

작은 원본에서 판독하지 못한 문구는 정상적인 대체 문장으로 작성하고 담당 기록에 표시했습니다. 71개 참고 타일에는 원본 자체의 가장자리 누락이 있어 인접 페이지를 근거로 복원한 가정을 기록했습니다.

원본 폰트 메타데이터가 없는 일부 글꼴은 실제 로드한 유사 글꼴로 근사했습니다. 특히 p127의 Clash Display는 공식 파일 취득 시 HTTP 403으로 Inter를 사용했습니다. p112·p119·p127의 56페이지, 텍스트 78개에는 원본 자폭을 근사하기 위한 수평 glyph 폭 보정(1.02~1.35)이 있습니다. 이는 캔버스·원본 이미지·사진·SVG를 늘리는 처리가 아니며, 정확한 원본 글꼴 재현으로 주장하지 않습니다. 자동 검사는 이 텍스트 보정을 별도 목록으로 기록하고 화면 전체의 회전·스케일 및 원본/비텍스트 비율 변경은 계속 거부합니다.

일부 작은 브랜드 배지 처리, 미세한 3D 곡률·반사광·질감에는 원본과 차이가 남습니다. 구체적인 내용은 `root-remaining-differences.json`과 담당별 보고서에 있습니다.
