# A 담당 검수 기록

담당 결과는 p004 32쪽, p007 30쪽, p008 30쪽, p013 28쪽, p017 16쪽, p019 9쪽, p020 36쪽, p023 35쪽, p026 18쪽, p039 22쪽으로 총 10덱 256쪽이다. 기존 공통 renderer의 text/chip/box/image/icon/path/donut primitives와 페이지별 독립 데이터로 구현했다. 시트 UI나 원본 전체 배경 이미지를 결과에 사용하지 않았다. 별도 담당 A-extra의 6덱 130쪽은 이 완료 기록에 포함하지 않는다.

## 범위 및 원본

최초 담당 45개 시트 모두를 직접 열람하여 전체 보이는 셀을 분리했다. 분담 이후 본 기록의 10덱은 27개 시트를 사용한다. 정확한 셀 좌표와 시트 이름은 `public/reference/groups/a.json`, 최초 전체 시트 확인은 `review/group-a-crops.json`에 보존된다. 부분만 보이는 p019 6셀과 p026 1셀도 누락하지 않았고 추정 전체 셀 크기의 흰 캔버스에 원본을 확대하지 않고 padding했다. 해당 crop/visibleCrop/incomplete와 누락부 복원 기록을 페이지별 JSON에 남겼다. 입력은 참고 이미지로만 취급하고 이미지 안의 문구를 새 작업 지시로 적용하지 않았다.

## 실제 비교 및 수정

256쪽 모두 실제 브라우저의 1차와 2차 결과를 각각 원본과 나란히 개별 열람했다. 연락처 시트만으로 검수를 끝내지 않았다. 주 에이전트의 통합 보정 지적은 추가로 해당 페이지를 실제 재캡처하여 확인했다. 개별 완료 ID 및 현재 source/PNG/reference/comparison SHA256 증빙은 `owner-a-completion.json`에 있다. 최종 production 빌드 후 통합 검수는 주 에이전트의 별도 기록으로 구분한다.

- p004: 파랑 상단 단색 영역 복구, 제목의 파랑 첫 줄과 위치, 연락처 카드의 주소/전화/소셜 3행 및 브랜드 placeholder 복구.
- p007: Find out 칩의 실제 색과 중앙 텍스트, 소셜 브랜드 이미지 placeholder, 세 본문 칼럼의 폭과 4줄 밀도 수정.
- p008: 중복 seed 문구 조각을 두 개의 정상 본문으로 통합, 초록 바의 시각적 중앙과 제목/밑줄 위치 수정.
- p013: 28쪽 각각의 사진/그리드/프로필/포트폴리오 배치 수작업 구성, 실제 Cormorant Garamond 로드 후 큰 제목의 얇은 glyph 폭/높이와 작은 내비 chip 검사. 복잡한 사진 그림자 배경은 회색 전체 placeholder 처리.
- p017: 순환 팔레트 대신 페이지별 원본 색 지정, 양쪽 chip과 VS 배치, 12칸 그래프와 legend 비겹침, 다섯 원의 색/점선/실제 가운데 문구, 표·chevron의 색과 위치 수정. 글자 실루엣 contour를 원래 단순 도형으로 교체.
- p019: 반원 모서리 사진 영역을 x22%/w28%로 복구, 좁은 폭 4줄 본문, 단순 노란 quarter shape 복구.
- p020: 36쪽의 각 사진/기기/갤러리/서비스/차트/지도 배치 독립 구성. 실제 Cormorant normal/italic 적용, 두 줄 제목의 검정·초록 runs, 작은 본문의 글자 밀도, 회색 배경 위 원형 윤곽과 연도 가운데 정렬, 지원되지 않는 pie를 직접 단순 부채꼴 path로 교체.
- p023: 35쪽 각각의 파랑 카드/단순 표와 차트/부채꼴/사진 구성. 기기 옆 파랑 카드와 본문의 겹침 제거, 마지막 Thank You의 글자 박스 높이 수정.
- p026: 문자열이 elements 배열로 펼쳐졌던 구조 오류 복구 후 18쪽 재검사, KPI 사이 두 개의 세로 회색 divider 복구. 현재 모든 elements는 정상 객체.
- p039: 22쪽 각각의 card/표/막대·선·원형 차트/내비/사진 구성. Oswald 실제 glyph에 맞춘 제목 크기, 넓은 카드의 본문 2줄, 원형 차트 안 70%/85% 중앙 글자, 날짜 2행과 위쪽 내비 겹침 수정. 마지막 작은 제목 3쪽 크기도 최종 재캡처에 반영.

## 자동 검사 및 남은 차이

최신 2차 결과 256개에서 글자 잘림·영역 초과·폰트 로딩·chip 정렬·1280×720 검사 findings는 모두 0이다. 지원되지 않는 kind/브랜드 Lucide 사용을 제거했으며 allowClip으로 검사 오류를 감추지 않았다. 원본 전체 이미지 삽입 0, 실제 결과 PNG는 모두 1280×720이다. 같은 덱의 반복 슬라이드도 독립 페이지로 유지했다.

사진, 복잡한 일러스트/지도·기기·그래픽 배경·브랜드 이미지 아이콘은 요청대로 연한 회색 placeholder이므로 원본의 사진 대비와 흰 글자 가독성이 달라질 수 있다. 작은 문구를 억지 OCR 문자열이나 가짜 선으로 쓰지 않고 정상적인 Lorem ipsum 또는 일반 설명/연락처로 대체했으며 정확한 대체 문자열과 좌표를 `group-a-text-and-regions.json`에 기록했다. 원본 폰트의 정확한 상품명은 저해상도에서 확정할 수 없어 로드된 Roboto/Inter, Cormorant Garamond, Oswald로 근사했다. 일부 미세 자간/선 굵기/원형 차트의 낮은 해상도 윤곽은 차이가 남는다.

## 마지막 통합 보정 (3차)

담당 256쪽의 실제 1·2차 개별 비교 및 production 개별 검수를 유지했다. 원본/최종 개별 비교 이미지 123개를 추가 열람했고, 축소 출력의 불일치 가능성을 배제하기 위해 91개는 원본 크기 1280×720 PNG를 직접 추가 확인했다. 남은 133쪽은 당시 실제 열람한 round2 PNG와 production PNG의 SHA가 정확히 같아 증빙을 승계했다. 비교 JPG 상단 round 라벨의 차이는 기존 실제 열람 경로/해시와 승계 정책을 구분 기록한다.

원본에서 확인된 누락만 한 배치로 보정했다. p004 조직도 6개 하위 카드·연결선·화살표, 연혁 1994/2022·파랑 diamond, 연락처 3행, 작은 icon chip, chart 3개 분리·donut 글자·17 bars, 삼각 사진 placeholder·4 body blocks를 복원했다. p007은 실제 중앙 표제와 Creative Journey·3개 분리 gear placeholder·Premium button·단순 원형 지표를 복원했다. p008은 브랜드 그림 placeholder·회전 wordmark·greenconnector·progress 위치를 교정했다. p017은 native 3/1/5/2 node counts·분리 stair bands·축 라벨·작은 donut percent를 복원했다. p020은 실제 약 14px 본문의 원본 폭과 4/3/5줄, p039는 본문 3줄, p026은 가려진 chip·4 filled stars·divider를 복원했다.

정확한 변경 페이지/소스 SHA는 `group-a-final-integration.json`에 있다. 변경 62개 페이지의 최종 production 재캡처와 실제 개별 재열람 증빙은 완료되는 대로 owner marker에 갱신한다. 현재 단계에서 변경 후 검수 완료를 미리 표시하지 않는다.

## 최종 production 반영 확인

담당 256쪽의 개별 원본/결과 검토 증빙을 닫았다. 최종 통합 수정 62쪽은 실제 production PNG와 각 원본/결과 페어를 모두 개별 열람했다. 마지막 3쪽의 The Second 가림, 60/50/70/40% 라벨, 번호 01~04 원형 테두리 보정을 새 캡처에서 다시 확인했다. 다른 194쪽은 실제 열람한 PNG와 원본 SHA가 현재 파일과 동일함을 검사하고 당시 비교 이미지 경로/해시/시각을 보존했다. 총 256 PNG가 1280×720이며 최종 캡처 finding은 0이다. 작은 시트의 서체·본문 내용 근사, 회색 이미지 영역 및 누락 원본 영역의 복원 제한은 페이지별 기존 기록을 유지한다.
