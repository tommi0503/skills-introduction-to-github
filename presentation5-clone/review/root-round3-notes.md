# 주 에이전트 3차 통합 검수

담당자별 1·2차 비교 이후 같은 3차 통합 과정에서 발견한 문제를 묶어서 수정했다. 마지막 수정의 재캡처 확인은 이 통합 검수의 일부이며 별도의 전체 4차 비교로 세지 않는다. 담당자는 1,057개 최종 화면 전체를 개별 원본과 비교하고, 주 에이전트는 47개 덱에서 3개 이상의 독립 비교 이미지(2쪽짜리 p180은 두 쪽 모두)와 직접 요청한 수정 페이지를 확인한다. 최종 수량과 실제 파일 해시는 root-review-coverage.json 및 visual-review.json에 기록한다. 아래는 발견·보정 과정의 기록이다.

- p110: 20쪽 모두 개별 비교. 본문 줄 수, 불필요한 카드 배경, 사진 radius, Milestone 번호 명암/본문 위치 수정. 마지막 통합 수정으로 원형 녹색 배경과 흰 북서 화살표 요청. 사진은 단색 placeholder, Lucide의 선 형태와 Manrope의 미세한 원본 폰트 차이는 기록 대상.
- p119: 18쪽 모두 개별 비교. 읽을 수 있는 `Title Here` / `Your Title Here` 분기를 바로잡고 본문을 2줄로 맞춤. 6카드 및 일부 4카드의 금색/크림/갈색/회색 순서 오류를 발견해 원본별 팔레트 요청. 중앙 3D 구체 및 복잡한 배경 장식은 단색 placeholder로 단순화.
- p112: 31쪽 모두 개별 비교. DATA/전략/카드/NOTE 본문 줄 수, 표지 REPORT/MEDIA/THANK/YOU 좌표, 사진 placeholder 박스·회전, 작은 chip 너비·회전·위치, 누락 Lucide 아이콘과 URL badge, 차트 축·숫자·격자·선 노드 및 단순 funnel 면을 보정 요청. 동일 원본을 반복한 페이지는 각각 열어 확인했으며 같은 템플릿의 수정도 모든 변형에 적용하도록 요청.
- p034: 13쪽 모두 개별 비교. 말풍선/육각형 본문 줄 수와 읽을 수 있는 제목, 번호 크기, 연락처 주소, 상단 사진 2개 박스, 인물 소개 6줄 본문, 서비스 3줄 본문, portfolio 영역 높이, 4타일 절단 방향/중앙 빈 공간을 보정 요청. 오른쪽 인물 사진의 갱신된 round2 캡처는 정상 full-width로 재확인.

각 수정은 담당자의 최종 소스 확정 뒤 배포용 빌드에서 캡처한다. 원본에서 판독 불가능한 문구는 정상 임의 문장으로 구현하며 문자 윤곽이나 선으로 대체하지 않는다.

## 전체 덱 통합 수정

제목·본문의 실제 폰트/굵기/줄 수/자간/정렬, 수치·날짜, 표 헤더 색, 도넛 면 순서와 범례, 월·분기 축, 카드·세로 구분선·타임라인 끝점을 보정했다. chip 중앙과 실제 가림도 PNG에서 확인했다. 사각 chip이 원 테두리를 덮는 문제, 작은 숫자쌍 간격, 숫자 위 도형, 사용할 수 없는 브랜드 아이콘 및 p026 무효 문자열 객체를 정리했다. p105 불규칙한 타일과 p092 원본 여백 포함 crop을 바로잡았다.

## 실제 픽셀 확인과 잘못된 요청 철회

넓은 비교 이미지를 도구로 볼 때 작은 글자가 빠진 것처럼 보인 사례에서는 원본 크기 PNG·영역 확대·실제 데이터 객체를 함께 확인했다. p017 일부 제목, p064 헤더, p127 설명, p162 헤더, p167/s02-09·s02-16 제목은 이미 렌더되어 중복 추가하지 않았다. p023/s04-09 화살표도 확대 PNG에서 우하향임을 확인했고 잘못된 방향 변경 요청을 철회했다. 파일 캐시 혼동을 피하기 위해 비교 SHA가 들어간 임시 경로로 열었다.

이전에 실제 열람한 브라우저 PNG와 원본이 최종 파일과 byte 단위로 같은 경우 실제 증빙을 보존한다. JPG round 표기만 바뀐 경우 최종 PNG·원본 전체 SHA와 비교 페이지 영역의 decoded pixel 일치를 독립 검증한다. 당시 열람한 JPG도 ZIP의 review/carried-comparisons에 포함하며 세부 내용은 identical-pixels-review-carry.json에 기록한다.

## 남는 차이와 복원 가정

저해상도 raster에는 편집 파일의 폰트 메타데이터가 없다. 판독 불가 문구는 정상 문장으로 대체했고 담당자별로 차이를 기록했다. 모든 글자의 완전한 일치를 주장하지 않는다. p127의 Clash Display는 올바른 파일과 라이선스를 확보하지 못해 실제 로드한 Inter로 근사했다.

사진·기기·이미지 로고·복잡한 일러스트·그래픽 배경은 사용자 지시대로 연한 회색 단색이며 원본의 질감과 흰 글자 대비는 달라진다. 일부 작은 곡선·3D 표현에도 근사 차이가 남는다. 단순 도형·차트·표·Lucide는 요소로 구현했다.

71개 가장자리 타일의 native 비교 픽셀은 흰 padding으로 보존한다. 결과에서 덱 스타일로 누락 영역을 복원한 경우 담당자 기록에 추정을 명시했다. 세로형 p105/s03-25는 한 페이지로 유지하고 1280×720 안에서 비율을 보존했다.
