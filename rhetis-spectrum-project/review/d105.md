# 덱 105 · SNS마케팅 전략 제안서

## 구현과 해석

원본 10장을 각각 열어 확인한 뒤 모든 화면을 1280×720의 데이터와 공통 primitive로 구현했다. 원본 이미지를 배경 또는 결과 이미지로 사용하지 않았다. 이 덱에는 별도 사진이 없으며 기기 외곽, 회로형 장식, 카드, 도표, 겹원, 말풍선은 편집 가능한 도형이다. 아이콘은 Lucide를 사용했다.

폰트 이름과 원본 서체 파일은 제공되지 않았다. 한글은 실제 로드한 Noto Sans KR 400/500/600, 영문은 Inter를 사용했으며 제목의 크기·자간과 두 줄 제목의 행간을 원본에 맞췄다. 서체 고유 글리프와 작은 아이콘의 실루엣에는 차이가 남는다. 내용은 판독 가능한 문장을 그대로 옮겼으며 원본에 들어 있던 안내용 반복 문구도 보존했다. 판독 불가능해서 새로 만든 큰 문구는 없다.

## 수행한 검수

- 원본 10장을 개별 `view_image`로 확인했다.
- 1차 실제 Chromium 렌더 10장을 개별로 읽어 원본과 비교했다. 자동 검사에서 세로 안내문 2건의 상자 초과를 찾아 수정했다.
- 2차 실제 Chromium 렌더와 원본을 좌우로 배치한 10개 개별 비교 이미지를 모두 읽었다. 자동 검사는 10장 모두 0건이었다.
- 본문 획 굵기와 08번 표 열 너비를 마지막으로 보정하여 3차 실제 Chromium 렌더 10장을 다시 원본과 나란히 개별 확인했다.
- 최종 자동 검사 결과: 10장 모두 지적 사항 0건, 모든 PNG 1280×720, 모든 사용 폰트 로드 확인.  폰트 로드, 그려진 글자 영역, chip 광학 중심, 이미지 포함 여부를 공통 audit로 검사한다. 결과는 `review/captures/105-round3-clone.json`에 보존한다.

렌더 이력은 `renders/round1/clone`, `renders/round2/clone`, `renders/round3/clone`의 105-01…105-10이다. 최종 패키징은 3차 결과를 사용한다.
