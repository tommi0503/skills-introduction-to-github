## 비교·수정 기록

1. round1: 모든 장을 실제 Chromium으로 렌더하고 개별 원본/렌더 이미지를 열어 확인. Arial 제목의 폭이 원본보다 좁은 점, SVG에서 CSS gradient 문자열을 막대 fill로 사용해 검게 나온 점, 원형 차트 형태 차이를 확인했다. 04·09 다행 텍스트의 박스 높이 초과 2건도 검출했다.
2. round2: 실제 Inter Variable로 제목을 교정하고 파이 차트를 SVG sector 3개로 직접 구성했다. 막대 색, 배경 페이드와 레이어 순서, bullet의 시각적 크기, 다행 텍스트 박스 높이를 수정했다. 폰트 교체에 따른 제목 5개의 자동 줄바꿈이 검출되어 제목 박스만 25px 확장하고 구분선 위치는 유지했다. 06의 막대차트 축·수치·막대를 원본 좌표로 직접 재구성하고 07 막대 비율을 수정했다.
3. round3: 19장 전체를 다시 렌더. 원본과 결과를 각각 1280×720 그대로 나란히 붙인 개별 비교 이미지 19개를 `work/d104-compare/`에 생성해 모두 열어 최종 확인했다. 제목 단일행, 차트, chip 시각적 가운데, 장별 내용 흐름을 확인했다. 마지막 수정 후의 렌더가 `renders/round3/clone/104-*.png`에 반영되었다.

## 어려웠던 요소와 결정

- 원본 세로줄 배경은 흐림·광택·반투명 곡면이 겹친 형태라 텍스처를 그대로 가져오지 않고 반복 선형 그라디언트, 페이드, 타원 clip-path의 조합으로 재구성했다. 화면이나 원본 이미지 전체를 결과 배경으로 깔지 않았다.
- AI·기업·휴대전화 아이콘과 경쟁사 마크는 복잡한 이미지 아이콘을 복사하지 않고 의미가 대응되는 Lucide 도형으로 구성했다.
- 본문 대부분은 판독 가능했다. 정확한 원본 폰트 이름, 매우 작은 구두점·띄어쓰기, 일부 짧은 문구는 시각 판독과 문맥으로 결정했다. 확정되지 않은 문구를 선이나 가짜 문양으로 대신하지 않았다.
- 원본은 수치·기관·서비스명이 미정인 사업 제안 템플릿이다. XX/XXX, [서비스], [관련 기관] 등은 임의의 실제 회사 정보로 바꾸지 않았다.
