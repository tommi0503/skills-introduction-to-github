- 범위: `public/references/103/slide_01.png`–`slide_10.png`, 총 10장.
- 소스: `src/decks/d103.mjs` (공통 primitives/renderer 사용).
- 모든 원본을 개별 이미지로 열람한 뒤 작성했다. 사진을 화면에 깔거나 원본 이미지를 구성 요소로 재사용하지 않았다.
- 기준 색: 원본의 최빈 단색을 확인하여 강조색 `#ef4241`(239,66,65), 연회색 페이지 배경 `#f7f6f9`(247,246,249), 사진 placeholder `#e5e5e5`를 사용했다.
- 폰트: 로드된 Pretendard Variable을 한글 본문/제목에, Arial을 영문 로고/러닝 헤더에 사용했다. 원본에 폰트 메타데이터가 없어 자간·크기·행간을 렌더 결과에 맞춰 조정했다.

## 검수 회차

1. 1차: Chromium으로 10장을 모두 1280×720 렌더하고 원본/결과를 개별 열람했다. 자동검사 findings 0건. 제목 폭, 로고, 도넛 크기, 본문 행간과 색을 검토했다.
2. 2차: 원본 색상을 정확히 반영하고 커버 자간/제목 기준선, 좌측 섹션 제목 크기, CEO 제목 자간, 핵심 목표 강조, 도넛 지름/위치, MVP 수치 크기, 마지막 슬라이드 문장 폭을 수정했다. 10장을 다시 렌더했다. 10개의 원본/결과 나란히 비교 이미지를 각각 열어 최종 검토했다.

2차 자료: `renders/round2/clone/103-01.png`–`103-10.png`, `comparisons/round2/103-01.jpg`–`103-10.jpg`, `review/captures/103-round2-clone.json`.

## 장별 확인 및 차이

| 장 | 구현·확인 내용 | 해석/남은 차이 |
|---|---|---|
| 01 | 빨간 커버, 비스듬한 흰 면, 두 줄 제목, 상단 러닝 헤더, 하단 URL·로고 | 로고 심볼은 벡터 경로로 다시 그렸다. 원본과 곡률이 미세하게 다르다. |
| 02 | 목차 6개 항목, 빨간 번호, 두 단계 제목 위계, 전체 여백 | 문구는 모두 판독해 유지했다. 일부 글리프의 모양은 대체 폰트 차이가 있다. |
| 03 | CEO 인사말, 빨간 이름, 배경 워터마크, 대각 강조 면, 이름/서명 | 인물 사진을 연회색 직사각 placeholder로 대체했다. 서명은 단순 경로로 근사했다. 사진 외부의 흰 여백과 배경 대각선은 유지했다. |
| 04 | 섹션 사이드바, 큰 원형 목표 구조, 중앙 캡슐, 3개 Keyword 설명 | 원의 텍스트 침범 부분은 배경색 면으로 가렸다. ‘중요한 목표’를 빨강으로 강조했다. |
| 05 | 겹치는 원 3개, 점선 연결, 하단 긴 캡슐과 중앙 정렬 문구 | 3개의 원과 점선 위치를 데이터 반복으로 생성했다. 읽히는 문구를 그대로 유지했다. |
| 06 | 위쪽 외곽선 원과 아래쪽 빨간 원 3쌍, 6개 지표 | 원본의 ‘평균 MOU’, ‘가입자 수 10만회’ 등 어색한 표현도 원문대로 유지했다. |
| 07 | 연도 비교 카드, 부드러운 그림자, 단계 점, 빨간 점선 외곽, 별점 3개/5개 | 별은 Lucide Star로 구현했다. 원본보다 별 모서리 형태가 약간 다르다. 4.6점에서 별5개라는 원본 표현을 유지했다. |
| 08 | 부서 카드 3×2, 88%/90% 도넛, 우측 정렬 제목/본문 | 도넛은 SVG 기반 데이터 컴포넌트다. 회색/빨간 경계의 안티앨리어싱 차이가 있다. |
| 09 | MVP 소개, 4개 지표, 빨간 원형 아이콘, 대각 면 | 직원 인물 사진을 연회색 placeholder로 대체했다. 엄지/재생/확성기/차트는 Lucide의 대응 아이콘으로 표현해 원본 아이콘과 세부 획이 다르다. |
| 10 | 빨강 전체 배경, 흰 종이, 검정 클립보드 선, 로고, 중앙 두 줄 문장 | 클립은 벡터 경로이며 원본 둥근 모서리를 근사했다. 원본의 ‘2099년 다음 목표’를 그대로 유지했다. |

판독 불가능한 주요 문구는 없었다. 사진·서명과 로고의 미세 곡률, 원본 아이콘의 세부 획, 폰트 글리프 차이를 제외한 구조·색·배치·문구를 재현했다.
