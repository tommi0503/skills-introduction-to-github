# 선택 화면 최종 검수

현재 포함 화면은 p01, p02, p03, p04, p05, p06, p07, p08, p11, p12, p13, p14, p15, p16, p17, p18, p25, p26, p27, p28의 20개입니다. 사용자 지정 목록 외 16개 화면의 구현 데이터·원본 이미지·렌더·비교 캡처를 제거했습니다. 갤러리, 원본 manifest, 렌더 패키징도 이 목록만 사용합니다.

남긴 화면은 최초 구현 시 에이전트의 두 차례 개별 비교·수정과 주 에이전트의 세 번째 통합 검수를 완료했습니다. 이번 작업은 화면 선택 변경이며 남긴 화면의 정의·폰트·배치·글자 크기를 수정하지 않았습니다. 기존 최종 렌더와 남긴 소스 및 공유 렌더러의 해시 일치를 검증합니다. 시각 검수 횟수를 추가하지 않았습니다.

p27의 작은 기울임 번호는 최초 통합 검수에서 실제 Bodoni Moda italic 400, 원본 좌표 기준 16px로 조정한 결과를 유지했습니다. 칩은 로딩이 끝난 폰트의 실제 글자 경계로 좌우·상하 중심을 보정합니다. 모든 PNG는 1280×720이며 기울어지지 않습니다.

사진·기기 화면·복잡한 일러스트·특수 이미지 로고·그라데이션 및 그래픽 배경은 사용자 지시에 따라 단색 #e5e5e5 placeholder입니다. p26의 흰 제목은 배경의 회색 대체로 대비가 낮아졌습니다. 원본 편집 파일과 폰트 정보가 없어 p03 픽셀 한글과 p05 질감 글꼴 등의 모양 차이가 남습니다. 화면별 검수 내역은 group-a.md, group-b.md, group-c.md에 남겼습니다.

최신 빌드·갤러리·폰트·칩·해시 검증 결과는 verification.json에 저장합니다. 삭제한 화면의 구현 데이터와 참고 폴더, 최종 캡처가 남지 않았는지 확인하고, 삭제한 16개 화면 경로에서 슬라이드가 렌더되지 않는지도 브라우저로 검사합니다.

프로젝트 ZIP은 presentation3-clone/ 폴더 하나만 포함합니다. 소스, 지정한 화면의 원본과 최종 렌더·비교·검수 기록을 포함하며 node_modules, dist, 중간 검수 캡처는 제외합니다.

선택 변경 후 최종 결과: 20개 화면만 존재, 남긴 화면의 소스/렌더러 해시 일치, 빌드 성공, 83개 칩 중심 오류 0건, 글자 영역 오류 0건, 브라우저 오류 0건입니다. 삭제한 16개 화면 경로에서는 슬라이드가 렌더되지 않았습니다.
