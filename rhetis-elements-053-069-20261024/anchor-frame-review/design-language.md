# anchor-frame 디자인 언어

넓은 흰 면, 큰 두 단계 문구, 가는 편집 프레임과 정사각 선택 핸들. 사진은 중성 placeholder로 두고 프레임 전체와 사진이 차지하는 부분을 구분한다.

- 선: 1px 외곽선과 실제6px 핸들. 핸들까지 포함한 시각 상자 안쪽3px에 프레임을 두어 칸 밖으로 나가지 않는다.
- 여백과 비율: 표제 여백62–77px, 큰 문구 y190. 본문 grid는 위쪽 프레임까지 포함하도록 y49로 확장하되1168px 가로 범위를 유지한다.
- 글자 위계: Pretendard Variable. 첫 큰 줄72px/750과 두 번째 줄100px/850, 부제24px, 메타20px. 표면을 채우기보다 글자 크기와 가는 프레임으로 강조한다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 주 강조 글자·핸들 | `--a1-7` |
| 얇은 선택 프레임 | `--a1-3-soft` |
| 흰 면 | `--page` |
| 일반 글자 | `--ink` |
| 보조 글자 | `--n-7` |
| 회색 자리 | `--n-1` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
