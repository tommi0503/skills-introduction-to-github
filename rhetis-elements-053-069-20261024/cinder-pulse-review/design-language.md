# cinder-pulse 디자인 언어

진한 바깥 면 안의 둥근 흰 판. 가로 머리글과 세로 레일을 구분한다. 목차는 별도 흰 레일 없이 열린 제목과 흰 판4개다. 긴 캡슐과 원형 마크를 쓴다.

- 선: PART 옆 세로 강조선, 얇은 표 괘선, 캡슐을 가르는 작은 간격. 큰 판의 반경11px과 작은 내부 면의 반경을 구분한다.
- 여백과 비율: 바깥34px, 가로 머리글123px, 세로 레일355px. 본문 흰 판 안쪽은36–37px이며 요소는 별도 칸에서 자기 비율로 맞춘다.
- 글자 위계: Pretendard Variable. 페이지 제목42px/400, 표지72px/300과 감사88px/300, 작은 PART16px와 제목20px의 대비다.

## 색 역할

실제 색은 style이 공급합니다. 아래 자리는 덱 전체에서 같은 의미로 사용하며, 구조를 색 리터럴로 고정하지 않습니다.

| 역할 | 팔레트 자리 |
|---|---|
| 강조 면·선 | `--a1` |
| 강조 글자 | `--a1-7` |
| 진한 페이지 면 | `--n-9` |
| 흰 판 | `--page` |
| 회색 카드 | `--n-1` |
| 원·보조면 | `--n-2` |
| 겹친 원 중간면 | `--n-4` |
| 겹친 원 진한면 | `--n-5` |
| 가는 선 | `--n-3` |
| 일반 글자 | `--ink` |
| 설명 글자 | `--n-7` |
| 강조 면 위 글자 | `--a1-on` |
| 진한 표지 위 강조 글자 | `--a1-3` |

요소마다 실제 source 수치를 자기 상자/멤버 크기의 비율로 옮깁니다. 부모가 이어지는 멤버 전부를 소유하고, 부품의 유무와 멤버 수에만 반응합니다. 작은 칸에서도 핵심 이름·수치는 유지하고, 정직한 min은 실제 크기별 시트로 검증합니다.
