# current-fold 검수 기록

상태: 최종 검수 완료

## 원본 보존과 판단

- 기존 replica HTML·PNG·PDF는 수정하지 않았습니다. 시작 시점의 203개 파일 SHA-256을 replica-lock.json에 기록하고 다시 대조합니다.
- 원본 HTML의 실제 수치를 우선했습니다. 보존된 PNG와 새 읽기 전용 HTML 렌더는 95장 중 93장이 픽셀까지 같았습니다. corner-signal 07·15는 이전 작업의 마지막 글꼴/푸터 반영 시점 차이로 평균 RGB 차이가 각각 0.67018·0.72944였습니다. 기존 PNG는 교체하지 않았습니다.
- 조립 비교 PNG의 순서는 원본 이미지 | 보존된 replica PNG | 새 조립본입니다. 요소 대조 시트의 crop은 보존 HTML의 새 읽기 전용 렌더를 사용합니다.
- 사진·이미지 아이콘은 연한 중성 placeholder, Lucide로 표현할 수 있는 아이콘은 빈 data-icon 슬롯입니다. 요소 시트에서는 계약 도구와 같은 점선 아이콘 슬롯으로 보입니다.
- 본문 compound의 이름·설명이 별도 텍스트 인스턴스로도 측정된 경우 contained_by로 소유 관계를 남겼습니다. 연결 도식과 그 안의 문구를 독립 grid root로 두 번 그리지 않습니다.
- 12×6 격자 배치는 map의 bbox를 가장 가까운 격자선에 투영합니다. 원본의 임의 픽셀 위치와의 차이는 reassembly-projection.json에 숫자로 남겼습니다. 페이지별 CSS나 fixture 조건으로 감추지 않았습니다.
- 원문을 읽을 수 없어 새로 지어낸 조립 문구는 없습니다. 기존 replica의 판독 결과를 그대로 사용하며 새 fixture에는 별도로 작성한 한국어 비즈니스 문구만 넣었습니다.

## 계약 충돌에 대한 결정

- 모범 card fixture의 엔터프라이즈는 replica에도 존재하는 6자 문구여서, 최신 요청의 전체 fixture 원문 중복 금지에 맞춰 그 단어만 대규모조직으로 바꿨습니다. 카드 수·나머지 문구·의미 구조는 유지했습니다.
- 모범 card-4의 ✹ 문자는 README의 빈 Lucide 아이콘 슬롯 규칙과 충돌합니다. sparkles data-icon 슬롯으로 최소 교체했습니다.
- code 계약의 고정폭 글꼴은 element.json의 --current-fold-code-font 기본값으로 Nanum Gothic Coding을 지정했습니다. 덱의 body/display 글꼴은 그대로입니다.
- 최신 요청이 명시적으로 허용한 type token을 경계로 하는 clamp와 cqw/cqh 비율을 사용했습니다.

## 검수 근거

- 크기별 시트: fixture마다 한 줄, 허용 목록 중 min 이상인 칸과 min 자체를 실제 1280×720 foundation 그리드에서 렌더했습니다. 라이트·다크를 각각 저장했습니다.
- 자동 검사: 텍스트 영역 초과/잘림, 텍스트 겹침, 이름·수치 숨김, 실제 픽셀 배경 대비, 폰트 로딩 오류, 페이지 크기, 캡슐 글자 잉크 경계의 중앙 정렬을 검사합니다. 배경 없는 architecture 본문 chip은 배지가 아니므로 중앙 정렬 강제 대상에서 제외하되 측정값은 보존합니다.
- 이름·수치는 작은 칸에서도 숨기지 않습니다. 부차 문구는 실제 가독성이 유지되는 최소 크기를 기준으로 단계적으로 줄이거나 생략합니다.
- audit의 sourceSha256은 CSS·JSON·fixture·kit·foundation·해당 map과 렌더 스크립트를 함께 해시합니다. 마지막 수정 후 렌더인지 검증합니다.
- 원본과 표현 계약이 다른 디자인은 GAPS.md에만 모아 두었습니다. 지원되지 않는 부분은 비슷한 카드로 대체하지 않고 조립본에서 비워 두었습니다.

## 이번 재작성에서 확인한 차이와 수정

- 10의 세 기본 카드, 두 추세 카드,11의 네 작은 수치 카드,15의 네 인증 카드,16의 여섯 수치 카드를 각각 새 fixture로 분리했습니다. 같은 .parts와 원본의 합법적인 자식 조합으로 모양을 고릅니다.
- 10 카드 안의 캡슐 아홉 개는 카드가 소유합니다. 독립 pill CSS와의 렌더 격리를 별도로 검사했습니다.
- 05 표의 첫 열 강조700, 얇은 강조 괘선,10px 흰 열간격과47px 행을 복원했습니다. fixture에는 새 거점 프로필을 썼습니다.
- 14 로고 아홉 칸은70px 정사각형과 점선 격자를 복원했습니다. 로고 아래 캡션은 logos 계약에 부품이 없어 별도 미지원으로 기록했습니다.
- 설명이 있는 check 항목은 이름·note 두 줄이 들어갈 높이를 갖게 했습니다. 원본12의 빈 note를 가진24px 체크 행은 유지됩니다.
- 주 검수에서 page11 독립 legend와 chart-area 자체 범례가 두 번 렌더되어 카드 뒤에 글자가 남는 것을 발견했다. 범례 인스턴스를 chart-area의 contained_by로 명시해 의미 소유권을 지도에서 바로잡았다. 원본 문구·계약 마크업·grid 투영은 바꾸지 않았다.
- versus 내부 list.check의 긴 note가 9x5에서 넘쳐 side를 세로 flex로 다시 쓰고 목록에는 머리글을 제외한 남은 높이만 배정했습니다.
- 페이지11의 카드에서 검출된 17픽셀은 형제 chart-area 선의 재래스터화였습니다. 검출 후보를 형제 요소를 숨긴 독립 상태에서 다시 검사하도록 공통 페이지 검사기를 보완했으며 카드 네 개의 실제 소유 넘침은 0입니다. 원인·첫 검출·독립 검사 결과를 paintOwnershipChecks에 모두 보존합니다.
- 최종 계약 대조에서 logos.row@1은 seat.logo만 허용하고 캡션 부품을 허용하지 않음을 확인했습니다. 잘못 추가했던 label CSS·fixture·조립 마크업은 제거했습니다. 14의 별도 캡션은 기존 map의 unexpressible로 유지하며 새 클래스나 부품을 반입하지 않았습니다. 로고 fixture는 6개·9개 멤버로 검수합니다.

## README 품질 항목별 확인

- 잘림·겹침: 크기별 텍스트 경계와 실제 paint 범위를 함께 검사하고 마지막 수정 뒤 재렌더했습니다.
- 대비: 실제 렌더 배경을 샘플링하여28px 미만4.5, 그 이상3 기준을 검사했습니다. 팔레트가 명시한 --a1-on은 해당 채움의 전경 역할로 사용했습니다.
- 아이콘: 실제 Lucide의 비율·stroke를 요소가 지정하며 원 안의 아이콘은 대체로50–60%입니다. 이미지 아이콘은 중성 placeholder로 둡니다.
- 정렬·남은 장식: 카드 제목·수치 기준선과 캡슐의 실제 글자 잉크 중심을 검토했습니다. 연결선·노치·탭은 해당 compound가 소유합니다.
- 차트: 라벨·선·점·막대의 겹침을 검사하고 작은 칸의 보조 라벨을 단계적으로 줄입니다.
- 한 디자인·중복 금지: samples의 디자인은 사용하지 않았습니다. 각 컬렉션의 원본 수치와 요소 출처는 PROVENANCE/map에 연결했습니다.
- 다크: 별도 팔레트로 전체 지원 크기를 다시 렌더했습니다. 시트의 바탕색만 바꾼 이미지가 아닙니다.

최소 크기를12x6으로만 적었던37개 fixture는 별도로 양 모드 아홉 크기를 시험했고36개를 더 작은 min으로 수정했습니다. 최종 판정은 full paint/contrast 검사와 직접 시트 확인을 함께 사용했습니다. 상세 상태와 판단은 루트 minimum-probe.json에 있습니다.
