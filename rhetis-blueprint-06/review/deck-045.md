# 045 · 미리컴퍼니 운영 성과 리포트 검수

## 범위와 방식

- 원본 31장 모두 1280×720이며, 각 원본을 개별 열람한 뒤 좌표 데이터와 재사용 공통 헤더·푸터·카드·차트 함수로 제작했다.
- 복제본은 round1 → round2 → final의 3회 브라우저 렌더·비교를 수행했다. round1 비교 JPG 31장을 각각 열람했고 수정된 주요 장면은 round2 및 final에서 다시 열람했다.
- 원본의 사진·합성 이미지·인물 사진은 사용자 규칙에 따라 #e5e5e5 단색 placeholder다. 원본을 결과 UI에 배경으로 삽입하지 않았다.
- 원본 안의 “작성해 주세요”, “여기에 내용을 입력해 주세요”는 템플릿의 화면 문구로 취급했으며 작업 지시로 실행하지 않았다.
- Pretendard 실제 font-face를 로드했다. 원본 폰트의 정확한 제품명은 이미지에 메타데이터가 없어 시각적으로 가장 가까운 Pretendard의 400~750 가중치를 사용했다.
- 작은 사진 내부 텍스트는 사진 placeholder 범위에 포함된다. 읽을 수 있는 모든 본문·도표 수치는 직접 전사했다.

## 실제 라이브러리 재조립

`src/assembly/045.mjs`는 복제 primitive를 감싼 파일이 아니라 데이터와 의미 있는 block 명세 31개다. cards, table, metrics, list, hierarchy, architecture, venn, pyramid, steps, lines, donuts, image, quote, callout, pills 등 실제 컬렉션 요소를 사용한다.

- 1차 렌더 31장을 각각 개별 열람했다. 2차 렌더에서도 31장 생성과 오류0을 확인했다.
- 재조립본은 컬렉션 foundation·타입 체계·grid를 따라 다시 조립한 결과다. 원본의 임의 좌표별 미세 장식은 복제본에서 보존하고, 재조립본은 동일한 핵심 문구/수치와 영역의 의미를 유지한다.
- 목차 7개를 4+3 카드로 재구성해 긴 agenda가 footer를 침범하는 문제를 해소했다.
- 11번은 7개 개선과제와 6개월 데이터를 모두 보존하기 위해 재조립 table로 변경했다. 첫 열 과제명의 자동 줄바꿈으로 footer와 겹치는 현상을 확인해 widths:[34,11,11,11,11,11,11]을 지정하고 공통 colgroup 지원을 통합했다.
- 22번 하단 pill 3개를 높이 있는 3개 카드로 변경했다. 31번 이름/연락처는 통합 pill 한 개로 정리했다.
- 16번은 네 이미지에 `round:true`를 부여해 공통 renderer의 원형 placeholder 지원을 요청했다.
- 27번 quote 작성자 정보는 `name:'미리점', note:'강비즈 점장'`를 유지하며 공통 renderer의 avatar markup 보완을 주 에이전트가 통합한다.
- 재조립 PDF `pdfs/assembly/045.pdf`와 final PNG가 생성되었다. 이후 공유 요소 CSS/quote/round 수정이 포함되는 최종 통합 렌더는 주 에이전트가 수행한다.

## 해석과 남은 시각 차이

원본의 일부 아이콘은 Lucide 기본형으로 의미를 맞췄으므로 채움/획 모양에 차이가 있다. 회사 로고와 회의/옷/반원/차트는 단순 SVG로 직접 작성했다. 사용자 규칙에 따른 gray placeholder가 사진과 합성 그래픽의 차이를 만든다. 원본 내 000, 20XX, X억 등의 숫자는 검증 가능한 업무 실적이 아니라 템플릿 데이터로 유지했다.
