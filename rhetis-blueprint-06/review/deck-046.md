# Deck 046 검수 기록

범위: references/046/slide_01.png–slide_30.png, 30장. 모든 원본을 개별 열람했으며, Chromium 1280×720 실제 렌더에서 round1과 round2의 비교 이미지 30장을 각각 개별 검토했다. 3차(final)에서는 표지 글상자와 마지막 THANK YOU의 수정 반영을 직접 재확인했다. 연락처 시트만으로 검수를 마치지 않았다.

## 구현과 해석

- 공통 page/sidebar, 가로선 패턴, 제목, 배지, 수치, 차트, 표, 원형 카드와 프로세스를 재사용 가능한 데이터/함수로 구현했다. 전체 원본 이미지를 화면 배경에 넣지 않았다.
- 남색/라벤더 색상 단계, 213px 챕터 영역, 흰 패널의 좌측 상단 36px 곡률, 회색 여백을 기준으로 맞췄다. 가로선 패턴은 SVG로 직접 그렸다.
- 사진·기기 사진·복잡한 일러스트는 #e5e5e5 단색 placeholder다. 단순 인물 픽토그램·차트·도형은 직접 구현했고, 아이콘은 Lucide로 바꾸었다. 원본의 채움형 아이콘과 획/세부 모양 차이는 있다.
- 원본에 폰트 메타데이터가 없으므로 실제 로딩된 Pretendard의 굵기·자간·행간을 시각 비교로 맞췄다. 특히 제목은 1차 대비 58→62px, 자간 -2.5→-1.6px로 보정했다. 미세한 glyph 차이는 남을 수 있다.
- 대부분의 본문은 판독할 수 있었다. 줄바꿈과 띄어쓰기는 화면 폭에 맞춰 조정했다. 판독 불가 문구를 선으로 그린 부분은 없다.
- 25번의 원본 도넛 호 길이는 표시된 20%·80%와 정확히 일치하지 않는다. 복제본은 원본 호의 시각적 비율(약 12.5%, 91%)을 유지하고 숫자 20%·80%를 보존했다. 의미 기반 재조립에서는 실제 데이터 20/80/30으로 그린다.
- 22번은 비관 시나리오의 대응 문구를 부정적 변화로 해석했다. 원본 작은 글자의 '긍정적/부정적' 해석이 갈린 부분이며, 핵심 시나리오 구조와 조치 내용을 보존했다.
