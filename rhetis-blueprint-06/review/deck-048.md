# 048 개별 검수 기록

원본 4장 모두 개별 열람, 브라우저 렌더 1차 비교 후 수정, 2차 비교 완료. 원본과 결과를 좌우에 놓은 이미지로 검수했다.

| 슬라이드 | 확인 및 수정 | 남은 해석 차이 |
|---|---|---|
| 01 | 영문 제목·한글 부제·연락처·사선 경계·하단 띠 위치 확인 | 실제 원본 폰트 정보가 없어 Montserrat/Pretendard의 폭과 굵기로 근사 |
| 02 | 5개 목차의 위치·번호·밑줄·줄바꿈 확인 | 오른쪽 사선 사진은 단색 placeholder |
| 03 | 3개 카드·중앙 원·제목·구분선 확인, 번호 박스 높이와 본문 줄바꿈 수정 | 원본 선 아이콘은 같은 의미의 Lucide로 교체 |
| 04 | 강조 문구 겹침을 실제 inline span으로 수정, 차트·벤·체크 목록 비교 | 연도/금액은 원본 자체의 20XX/XXX 표기를 보존 |

자동 검사: 1차 4건(Oswald 숫자 박스 및 작은 화살표 높이)을 수정. 2차 0건. 원본 PNG를 UI 배경으로 사용하지 않았다.

재조립본은 원본의 핵심 콘텐츠를 계약 foundation과 agenda/card/list/venn/chart-bar 요소로 구성한 별도 슬라이드이다. 미세한 좌표를 유지하는 재현본과구별되며 라이브러리의 실제 재사용을 보여준다.
