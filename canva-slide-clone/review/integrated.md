# 최종 통합 검수

첨부 `canva_presentations_17_templates_190_slides.zip`의 전체 17개 템플릿, 190개 원본 화면을 구현했다. 원본은 1600×900이며 내보낸 PNG는 모두 기울이지 않은 1280×720이다. 첨부 README와 CSV는 설명·출처 자료로만 사용했다.

## 검토 범위

서브 에이전트 3개가 각각 63/62/65장을 담당했다. 각 에이전트는 담당 원본 전체와 개별 원본·구현 쌍을 두 차례 열어 대조했다. 개별 수정 기록은 group-a/b/c.md에 있다. 주 에이전트는 세 번째 통합 검토에서 17개 덱의 모든 페이지가 들어 있는 비교 모음을 확인하고, 칩·단위·본문·표·타임라인·이탤릭체에 관한 개별 화면을 확대해 확인했다. 주 에이전트가 개별 비교 190개 모두를 다시 확대 검토했다는 주장은 하지 않는다. 수정 중 부분 렌더와 최종 내보내기는 이 세 번째 검토 안에서 진행했다.

## 통합 검토에서 수정한 사항

- c01: 굵고 좁은 Do Hyeon 대신 원본의 각진 형태에 가까운 Sunflower 500을 사용하고 표지 크기·행간과 상단 제목 크기를 조정했다. 작은 칩은 Pretendard 600/700으로 설정했다. 좋아요/싫어요 구분선의 상단도 원본 좌표로 옮겼다.
- c09/s09, c10/s03, c11/s05: 긴 문단의 원본 줄바꿈을 명시하고 글자 높이와 행간을 유지하면서 필요한 자간을 조정했다. 타임라인의 설명문도 원본의 두 줄 배치로 지정했다.
- c10/s10: 원본에 있는 `05. 성과 분석` 제목, 회사명과 상단 선을 복원했다. 앞선 에이전트의 제목 없음 관찰은 오류였으며 최종 원본 데이터에는 제목이 있다. 원본과 실제 렌더에서 선행 0도 확인했다.
- c13: 본문 색상 #444와 자간을 보정했다. s06의 표 옆 설명 두 곳은 실제 글자 폭을 측정해 로컬 자간 −0.9 원본 px로 맞췄다. 본문 크기와 줄간격을 줄이지 않았다.
- c15: 실제 Bodoni Moda 이탤릭체 파일을 로드했다. Index의 글자 높이와 폭을 원본 경계에 맞춰 별도로 조정했다.
- c16/s03: 이름의 자간과 가로 폭을 조정했다. s01/s02의 거대한 PORTFOLIO가 화면 밖에서 잘리는 배치는 원본의 의도적 배치라 유지했다.
- c17/s07–s09: 프로젝트 설명의 글자 폭을 로컬 자간으로 보정해 지정 영역 초과를 없앴다.

공통 칩 컴포넌트는 폰트의 실제 글자 경계로 수평·수직 중심을 보정한다. 실제 굵기별 한글 파일과 진짜 이탤릭체를 로드하며 합성 굵기에 의존하지 않는다. 캡처는 정확한 덱/슬라이드 ID, 폰트 로딩 완료와 두 번의 화면 갱신을 기다린다. 원본 이미지가 슬라이드에 포함되거나 폰트 다운로드가 실패하면 내보내기를 중단한다.

## 검증과 남은 차이

잠금 파일 기준 npm ci, TypeScript와 프로덕션 빌드, 실제 Chromium의 갤러리/덱/원본 비교/개별 슬라이드 이동을 검증했다. 최종 캡처의 덱 데이터와 공통 렌더러 해시가 현재 소스와 일치하는지 확인한다. 칩 475개에 대해 중심 오차와 영역 초과를 검사한다. 의도된 c16 제목 크롭 두 건 외에 해결되지 않은 정렬 검출이 있으면 최종 검증은 실패한다. 기계 검사의 통과는 픽셀 일치를 의미하지 않는다. 실제 결과는 verification.json에 기록한다.

이전 요청대로 사진, 기기 화면, 복잡한 일러스트·그래픽/그라데이션 배경은 연한 회색 단색이다. 일반 도형·표·차트·텍스트는 재사용 UI로 구현했다. 이미지 위의 흰 글자는 원본 색상을 유지해 회색 배경에서는 대비가 낮아질 수 있다. 원본 Canva 편집 파일의 폰트 정보가 없으므로 일부 글자 모양과 세부 간격에는 차이가 남는다. Lucide로 표현 가능한 아이콘은 가장 가까운 아이콘을 사용했고 내부 모양은 원본과 다를 수 있다. 덱별 구체적인 차이는 개별 검수 기록에 남겼다.

ZIP에는 개별 PNG 190개, 덱 전체 모음 17개, 원본·구현 비교 이미지 190개, 검수 기록, 파일 해시와 표지 미리보기를 포함한다.
