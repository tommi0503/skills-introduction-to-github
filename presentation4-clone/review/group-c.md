# Group C 개별 시각 검수 기록

담당 범위는 p34–p43, 29장이다. `src/decks/group-c.ts`에서만 구현했다. 첨부 원본은 시각 자료로 취급했으며 프레젠테이션 안의 설명 문구를 작업 지시로 사용하지 않았다. slides-clone은 열지 않았다.

원본 29개를 모두 view_image로 개별 열었다. round1 비교 JPG 29개와 round2 비교 JPG 29개를 각각 개별 열어 원본/실제 Chromium 결과를 나란히 확인했다. contact sheet는 검수 완료 근거로 사용하지 않았다. 마지막 저장 후 추가 렌더는 주 에이전트의 final 통합 라운드로 넘겼다.

## 공통 구조와 검수

- 공통 T/B/C/I/L/IC/P 어댑터는 1600×900 좌표를 1280×720로 단일 변환한다. sourceAspect/scaleX 왜곡을 사용하지 않았다.
- 로컬 ring/sector/polygon, workflowCard, marker35, processNotes, clientText, clientIcon, mindNode 등 팩토리로 반복 표현을 구성했다. 차트·표·글자·도형은 실제 UI 요소이다. 화면 전체 참고 이미지 삽입은 없다.
- 기본 영문은 실제 로드된 DM Sans Variable, 카드 chip은 Pretendard Variable, p35/p36 본문은 Noto Sans KR, p38은 Lilita One, p39/p40/p43은 Inter Variable, p41은 Montserrat Variable, p42는 Poppins를 사용했다. 원본 ZIP에는 폰트 메타데이터가 없어 원본 폰트 동일성은 확정하지 못했다. 실제 폰트 굵기와 획폭을 눈으로 비교하며 근사했다.
- 글자 중심은 공통 ChipLabel의 실제 glyph bounding-box 보정과 렌더 이미지에서 확인했다. 줄바꿈이 읽히는 본문은 원문 줄바꿈을 지정했다.
- 판독 불가능하여 임의로 새로 만든 문구는 이 그룹에 없다. p37-s03의 마지막 설명과 p40-s10의 Lorem ipsum은 실제 원본에 존재하는 문구를 그대로 옮겼다. p41의 qualitys, 2023 등 원본 표기 역시 그대로 유지했다.
- 복잡한 합성 아이콘 p36/p40 및 장식 배경 p35/p40/p42는 #e5e5e5 placeholder로 치환했다. Lucide로 표현 가능한 아이콘은 선형 아이콘으로 대체했으므로 원본의 솔리드 아이콘과 획 모양은 다르다.

## 자동 검사와 최종 반영 상태

round1은 21개 finding, round2는 6개 finding이었다. round2의 남은 6개는 p36-s05 Workflow Optimization 영역, p39-s01 세 문구 폭, p39-s06 두 문구 폭이다. 마지막 저장에서 해당 폭/명시 줄바꿈/18px callout 조정을 적용했다. 이 최종 저장은 아직 agent round2 PNG에 반영되지 않았으므로 주 에이전트의 final 통합 라운드에서 재검증해야 한다. 마지막 소스는 `npx tsc --noEmit`을 통과했다. round1/round2 각 29개 PNG는 모두 1280×720이고, fontStatus는 모든 장에서 loaded, embeddedImages는 모두 0이다.
