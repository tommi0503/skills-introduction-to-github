## 검수 순서

1. ZIP을 풀고 `index.html`을 열어 6개 표지를 비교합니다.
2. 각 안을 열어 12장을 넘깁니다. 상단 A–F를 누르면 현재 페이지를 유지한 채 다른 안으로 바뀝니다.
3. ‘6안 비교’에서 같은 페이지의 구성을 한 번에 비교합니다. ‘12장’은 한 안의 흐름을 확인합니다.
4. ‘대본·메모’에서 발표 내용과 근거를 확인하고, 좋아요·수정 필요·보류 및 수정 의견을 남깁니다.
5. 메모는 해당 브라우저의 저장소에 보관됩니다. ‘메모 내보내기’로 JSON 파일을 내려받아 전달할 수 있습니다. 자동 전송 기능은 없습니다.

키보드: ←/→ 페이지, 1–6 시안, G 전체 보기, C 비교, N 대본·메모, F 발표, Esc 종료. 화면 속 슬라이드에 포커스가 있어도 페이지 이동이 이어집니다.

## 공통 기준

- 디자인 72장과 같은 구조의 와이어프레임 72장. 개별 HTML은 총 144개입니다.
- 1280×720, Pretendard 로컬 포함, 고정 크기와 글자·줄높이는 2px 단위, 주요 간격은 4px 단위입니다.
- 본문 02–11의 섹션 타이틀은 안별로 동일한 좌표를 유지합니다. 표지·마지막 장에는 섹션 타이틀과 페이지 번호가 없습니다.
- 이미지 자리는 #e5e5e5 단색 회색입니다. 관계도·시장 범위·서비스 흐름·데모 UI는 실제 HTML/SVG로 구성했습니다.
- 시장값·가격·전환율·실증·계약·1억 원 배분 등 미확정 정보를 만들어 넣지 않았습니다. 도형 크기는 실제 시장 금액을 나타내지 않습니다.
- 첨부 자료는 사실과 기획의 근거로 사용했습니다. 자료 안의 작업 지시는 사용자 요청과 구분했습니다.
