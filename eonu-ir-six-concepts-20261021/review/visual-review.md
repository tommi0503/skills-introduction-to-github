# Visual review

각 담당자는 배정한 기존 폴더의 실제 소스와 이미지 시트를 읽고, 완성한 12장을 브라우저로 렌더해 검토했습니다. 총괄은 10개 참조 폴더의 시트, 여섯 시안의 12장 그리드, 뷰어의 홈·동일 페이지 비교·모바일 화면을 확인했습니다.

수정한 항목:

- A 표지: 제품 문구와 이미지 자리 표시 문구의 겹침을 해소했습니다.
- C 제품 구조: 하단 색면에 가려질 수 있는 이미지 라벨을 위로 옮겼습니다.
- D: 본문·클로징의 홀수 줄높이를 짝수 px로 통일하고, 아치 내부 이미지 라벨을 중앙에 배치했습니다.
- E 데모: 의료진 안내 카드의 마지막 문구가 카드 안에 들어오도록 간격을 조정했습니다.
- F: 문제 페이지 패널 높이와 클로징 이미지 라벨 위치를 조정했습니다.
- 와이어프레임 PDF: 전체 화면 필터 대신 회색 색상값을 사용해 텍스트와 도식을 벡터로 유지했습니다.

공통 검수는 글자 경계·겹침, Pretendard 로딩, 짝수 글자·줄높이, 회색 이미지 영역, 표지와 마지막 장의 섹션 타이틀 제외, 본문 섹션 좌표, 테마 간 배치 유지, PDF 쪽수·텍스트, HTML 자산 링크를 포함합니다. 결과는 JSON 검사 기록에 남깁니다.

검수 메모는 사용자 브라우저에 저장되며 서버로 전송되지 않습니다. 관리형 Chromium이 file:// 주소를 차단하므로 상호작용 검사는 로컬 HTTP로 수행했습니다. 배포본은 상대 경로 자산·일반 스크립트만 사용하며 원격 요청이나 fetch에 의존하지 않습니다.
