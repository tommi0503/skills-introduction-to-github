# B — 그린 에디토리얼

실제 소스와 프리뷰를 함께 읽고, 보고서의 정보 밀도를 발표용 한 문장/한 시각 구조로 줄였다.

- `rhetis-business-01-project/src/decks/d01.js`: `paper()`, `base()`의 짙은 녹색 세로 바, 민트 헤더 영역, 좌측 장 번호와 챕터 구조를 확인했다. `rhetis-business-01-project/deliverables/preview-d01.jpg` 전체 프리뷰에서 표지 대형 제목, 왼쪽 제본 레일, 사선 종이 모티프, 넓은 종이 여백을 확인했다. B는 짙은 녹색 레일을 본문 10장에 고정하고, 그림자/접힌 종이/세부 메뉴를 덜어내 큰 타이포와 흰 종이 공간으로 단순화했다. 표지는 레일을 넓은 초록 면으로 확장하고 사선 라임 조각을 절제해 사용했다.
- `rhetis-strategy-048-053/src/decks/d048.js`: `frame()`의 왼쪽 챕터 레일, 16번 프로세스, 17번 원형 단계 타임라인, 18번 역할 조직도를 실제로 읽었다. `rhetis-strategy-048-053/public/reference/048_1i94c_파랑_모던_비즈니스_전략_기획서/slide_17.png`에서 원형 마일스톤과 관통선, 각 단계의 하단 설명 배치를 확인했다. B의 7장 검증 경로는 이 원형 타임라인 문법을 4단계로 단순화하며, 분기 B2G는 별도 점선 경로로 구분했다. 3/5/9장의 역할 연결은 조직도처럼 실제 SVG/HTML 선과 노드를 사용한다.

B는 표지와 마무리에서 좌측 대형 녹색 면+우측 이미지 영역을 사용한다. 본문은 크림 종이 바탕, 좌측 챕터 레일, 좌측 정렬 제목, 비대칭 이미지/정보 블록을 유지한다. A의 흰색/보라색 중심 정렬 및 기존 청색 카드 시스템과 다른 방향이다. 이미지 영역은 모두 #e5e5e5의 의도된 자리표시자이며 외부 이미지를 사용하지 않았다.

모든 발표문·주석은 `shared/content.js`에서 보존한다. 2026-10-20 MD의 12개 주제와 계약의 사실 제약을 적용했다. 본문 시장 수치·가격·협력 실적·자금 배분을 만들지 않았다. 와이어프레임은 기하와 도식을 보존하고 무채색으로 바꾼다.
