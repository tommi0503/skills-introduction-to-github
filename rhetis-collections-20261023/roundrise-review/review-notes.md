# Roundrise 검수 기록

## 범위와 방식

원본 24장, replica 24장, 재조립 24장을 1280×720으로 만들었다. 각 원본과 렌더를 나란히 놓은 개별 비교 PNG를 확인했으며 주 에이전트도 24장을 각각 통합 검수했다. 최초 재현, 계약·요소 검수, 원본 좌표·ink를 다시 계측한 통합 보정의 세 차례로 검수했다. 마지막 보정 중 영향받은 컴포넌트는 개별 재렌더했다.

## 주요 수정과 계측

- 원본 제목이 약 11% 넓다는 문제를 추측으로 처리하지 않고 PNG의 검정 ink bbox로 확인했다. 03은 원본 341×58px / 수정 replica 340×59px, 05는 459×58 / 456×59, 09는 391×58 / 390×59, 11은 423×58 / 419×59였다. 컬렉션은 허용 타입 단계 68과 공유 자간·행간을 사용한다.
- 06 차트 패널 원본 [432,113,766,530], 조립 [431,113,767,530]. 축의 0/50/100/150, 84/96/112/136 막대, 범례와 분기 이름을 복원했다.
- 07의 78/92/98/118은 실제 CSS anchor의 면적·선·점으로 그렸고, 11은 max100과 20/50/70/100으로 교정해 지표와 같은 넓은 패널에 담았다.
- 08 도넛은 398px, 둥근 양 끝, 94%의 실제 각도로 구현했다. 긴 이름과 0/100% fixture도 함께 검사했다.
- 10·17은 짧은 가로 카드의 작은 모서리와 가는 화살표, 설명 보통 굵기와 수치 굵은 글자를 복원했다. 10의 Challenge/Response 제목을 추가했다.
- 13의 축 라벨을 전체 회전하고 브랜드 도형·점 위치를 맞췄다. 15의 긴 제목이 세 줄로 고립되지 않도록 유효 폭과 왼쪽 여백을 고쳤다.
- 16은 STEP 캡슐+3D 좌석+이름, 19는 3개 그림 카드+아래 타임라인으로 조립했다. 18의 handshake/chart/briefcase/puzzle 아이콘을 단순 벡터로 구현했다.
- 20은 원형 노드, 꺾인 연결선과 중앙 원의 흰 접점 4개를 복원했다. 21은 원형 카드 세 개와 +, 24는 별도 흰 패널 없이 제목과 회색 3D 좌석을 사용한다.
- 중첩 :has가 브라우저에서 무효인 선택자를 발견해 단순한 구조 선택자로 교체했다. 브라우저 CSS.supports(selector())로 전체 선택자를 확인한다.
- 실제 요소 시트에서 가로 막대 라벨의 한 글자 줄바꿈, 긴 도넛 이름의 원 밖 확장, 6-spoke 허브 설명의 원 밖 확장, inline tag의 size containment를 발견해 교정했다.

## 자료의 해석과 차이

- 이미지 안의 템플릿 문구는 자료로 재현했으며 지시로 해석하지 않았다. 주요 문구와 수치는 읽을 수 있었다. 작은 보조 설명은 원본의 템플릿 의미에 맞는 한국어 문장으로 채웠다.
- 사진·3D·복잡한 그래픽은 요청대로 같은 자리에 연한 회색 단색 seat로 바꿨다. 이 차이는 원본 이미지 사용을 피하기 위한 의도된 처리다. 원본 전체를 배경으로 사용한 페이지는 없다.
- 브랜드는 단순 기하 획으로 재현했다. Pretendard를 실제 로드했다. 원본 글꼴 파일이 제공되지 않아 래스터의 작은 획과 굵기에는 차이가 남는다.
- 밝은 회색으로 바꾼 22 사진 배경에는 검은 글자를, 23 회색 3D 좌석 위 로고에는 진한 강조색을 사용해 대비를 유지했다.
- 23 Q&A는 replica에서 원본 162px로 재현했다. 컬렉션은 README의 --type-N 상한 128을 준수하며 이 크기 차이는 남는다. 문구·위치·줄바꿈은 원본과 대응한다.
- 원본과의 남은 작은 차이는 요소별 공유 여백·타입 단계, 래스터 글꼴 획, 회색으로 단순화한 복잡한 외곽선이다. 차트 수치와 내용의 누락으로 이 차이를 대신하지 않았다.

## 검증 자료

56개 요소, fixture 175개와 foundation fixture 2개를 포함한다. 필수 모범 fixture의 마크업·데이터를 보존했다. source-manifest.json/validation.json은 최종 렌더와 동기화한 소스 해시, PNG 크기, PDF 페이지 수, 폰트·넘침 결과를 기록한다. 최소 칸에서 12×6까지의 라이트·다크 상태 검사는 browser-audit.json, 대비는 contrast-audit.json, 칩 중앙은 chip-audit.json에 보관한다. ZIP은 파일 종류·단일 루트·CRC를 검사한다. Rhetis 공식 intake 환경은 제공되지 않았으므로 공식 반입 성공을 주장하지 않는다.

## 전체 요소 의미 기능 최종 점검

56개 라이트·다크 요소 시트를 개별 확인했다. 여정의 mood 점을 실제 좌표의 선분으로 연결하고, mindmap의 곡선을 중심 원까지 연결했다. Sankey는 source에서 각 가중 branch로 끊김 없이 이어지며 중첩 분기도 각 값에 비례한다. Cycle은 3/4/6개 노드의 순환 궤도와 진행 방향을 갖는다. Hierarchy와 decision tree는 뿌리·분기·잎의 연결을 복원했다. 기본 slope의 점·라벨·선은 A/B 실제 값에 놓인다. Sparkline 기본형은 선이며 .bars는 막대다. Stacked area는 누적 층을 모두 보이고 stack은 서로 다른 팔레트 슬롯으로 구분했다. Waffle 단위는 정사각형이며 3-set Venn은 공통 교집합을 가진다. 일반 hub 연결은 노드 중심 사이에서 원 뒤로 이어지고, 원본 20번의 꺾인 선·접점은 보존했다. Funnel 색면 폭은 v%이며 0은 0이다. 라벨은 폭과 독립된 고정 위치에 둔다.

표준 다크 모드는 바탕 역할 --roundrise-dark-surface의 기본값 --page에서 시작해 --a1-2-soft로 이어진다. 원본 비교에서는 같은 역할에 --a1을 공급하여 원본의 진한 전환 페이지를 보존한다. 기능 보완 후 원본 조립 24장의 PNG SHA256은 보완 전과 24/24 동일했다.

일반 예시 데이터의 waterfall-6 합계를 1,088+79+60+32−18=1,241로 맞췄다. Treemap-5는 기존 면적 비율 34/26/18/12/10을 유지하고 같은 총액 1,284억에 맞는 예시 수치 437/234/100/132/99/154/128억으로 구성했다. 모범 fixture의 데이터는 바꾸지 않았다. 허용 범위를 벗어난 bullet 104를 98로 바꿨다. 일반 card의 문자 장식은 Lucide sparkles 좌석으로 교체했다. 프리뷰 도구는 README에 따라 Lucide 좌석을 점선 원으로 표시하며 실제 아이콘은 Rhetis가 채운다.

최종 PDF 4개는 JPEG 재압축 없이 최종 PNG를 MuPDF로 삽입하여 만든다. Replica·조립본은 페이지별 PNG와 PDF 래스터를 1280×720에서 대조한다.

최종 자동 검사: 175개 요소 fixture의 최소 칸~12×6 라이트·다크 8,626상태에서 영역 오류 0, 대비 우려 0, 칩 중심 50개 오류 0, 유효 선택자 3,393개/무효 0, 정적 계약 오류·경고 0. 별도 semantic-audit.json은 여정 연결 끝점 오차 최대 0.45px, Sankey 높이/가중값 비례 오차 0.001 이하, Funnel 0/24/100의 실제 색면 폭과 Cycle 3/4/6개의 방향촉을 기록한다. Replica·조립 PDF 48페이지의 PNG 대조 픽셀 오차는 0이다.
