# Nightchamfer 디자인 언어

## replica에서 읽은 규칙
- 상단 45px 기준선, 오른쪽에서 28px 아래로 한번 접히는 1px 중립 선. 내용은 84~95px 안쪽에서 시작.
- 패널은 1px 중립 윤곽과 약 22px 모서리. 작은 라벨은 12px, 짧은 카테고리 캡슐은 완전한 알약.
- 여백 단계 12 / 24 / 28 / 40px. 패널 내부는 가운데에 무게를 두되 제목과 수치는 동일 높이.
- 기본 서체 Pretendard Variable. 제목 28/44px, 표지 108/120px, 수치 48/64px, 이름 22px, 본문 16~20px, 보조 12~14px. 제목 700, 본문 400, 라벨 600.
- 핵심 노드는 두꺼운 저채도 외곽 링과 선명한 원판. 연결선은 1px 점선 또는 절곡선. 화살표는 넓은 단순 실루엣.
- 강조는 하나의 원판/막대/캡슐에 집중하고 주변은 중립 면. 3D 광택 오브젝트는 내용과 분리된 이미지 자리.

## 색의 자리
- 페이지 바탕 = --page, 기본 글자 = --ink.
- 제목 강조 글자 = --a1-7, 핵심 원판·마지막 막대 = --a1, 그 위 글자 = --a1-on.
- 핵심 원판의 외곽 링 = --a1-2-muted.
- 카드 면 = --n-1, 테두리·축 = --n-4, 보조 글 = --n-7.
- 하단 발광층 = --a1-6-muted → --a1-3-muted → --a1-1-muted → 투명으로 이어지는 넓은 타원 면.
- 앞으로 진행하는 화살표는 --a2, 보조 시리즈는 --a2 / --a3 / --a4 순위를 사용.
- 원본의 검정·파랑을 요소에 고정하지 않고 랭크와 깊이로만 정의.

## 이미지에 없는 요소
레이더·네트워크·코드 등도 절곡선, 중립 hairline, 짧은 중심 라벨과 하나의 강조를 유지한다. 복잡한 장식은 추가하지 않는다.
