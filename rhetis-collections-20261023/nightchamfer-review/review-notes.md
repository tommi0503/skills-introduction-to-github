# Nightchamfer 검수 기록

## 범위와 제작 순서
덱 005의 18장(1280×720)을 각각 관찰하고 replica를 먼저 제작했다. 원본 전체 이미지는 HTML 배경으로 사용하지 않았다. 3D 리본·광택 아이콘·사진·이미지 로고는 연한 회색 단색 자리로 바꾸고, 텍스트·표·차트·타원·절곡선·점선·화살표는 직접 구현했다.

그 뒤 kit, foundation, 56개 요소와 172개 fixture(요소 170, foundation 2)를 만들었다. README의 모범 fixture 28개는 data-el 접두사만 변경하고 마크업·데이터를 보존했다. 원본 조립은 컬렉션 CSS의 결합본과 계약 마크업만 사용한다. 페이지에 별도 CSS를 추가하지 않았으며, body 자식의 12×6 grid-column/grid-row로 배치했다. section의 palette 변수 값은 원본 스타일 데이터다.

## 비교·교정 기록
초기 replica 비교, 요소 시트·최소 칸 검수, 원본/조립 통합 검수의 세 단계로 진행했다. 초기 조립의 도형 비율과 정보 위계 차이가 커 통합 검수에서 반려되었으며, 이를 통과로 기록하지 않고 원본 좌표를 다시 계측하여 수정했다. 특히 아래 항목을 고쳤다.

- 03: 중심 256px 원판과 26px 링, 네 패널의 위치·크기, 꺾인 연결선과 끝점을 복원했다.
- 04: 원본에 없는 delta 문구를 제거하고, 상단 메시지 패널·하단 두 설명·곡선 몸통과 fade를 가진 위쪽 화살표로 조립했다.
- 05: 300/520/820/1,300억의 막대 높이, 4개 기준선, 제목, 세 성장 포인트의 직사각형 행과 강조 배지를 맞췄다.
- 06: 왼쪽 603×426 패널과 오른쪽 431×426 사진 자리, 본문 400 굵기, 점선 및 기능별 배지를 복원했다.
- 07/13: 설명을 제목과 같은 줄로 놓는 foundation label을 사용했다. 07의 미사용 막대는 회색 track의 왼쪽 50% 채움이며 라벨을 채움 가운데에 놓았다. 13의 1.5만/5만 막대는 72/240px 비율로 그렸고 상승 곡선 화살표를 복원했다.
- 08/15: 패널 위쪽 위치, 제목·설명·그림 자리의 기준선, 카드 사이 점선을 복원했다. 원본에 없는 자리 번호는 조립본에서 비웠다. 라이브러리 fixture의 자리 번호는 계약대로 가운데에 유지한다.
- 09: 과금 패널 안쪽의 세 원, 원 사이 점선, 왼쪽이 밝은 강조 띠, 아래쪽 화살표를 복원했다.
- 10: 타원을 214/324/422/504px 너비, 72/106/136/156px 높이로 겹쳐 쌓고, 오른쪽 설명·점선의 기준선을 맞췄다.
- 11: 상대 좌표를 원본 점 위치로 환산하고, 축의 capsule·점선·자사 주위 반투명 halo를 복원했다.
- 12: 63px 원형 분기와 78px 상승 간격, 제목·설명 시작선, 수평 연결과 진행 화살표를 맞췄다. 줄바꿈과 글자 크기를 함께 조정하여 한 글자만 고립되는 줄을 제거했다.
- 14: 타원으로 찌그러졌던 CEO를 176px 원으로 고치고, 173×48 부서 배지와 220×117 하단 leaf, 글자 22/20/18px을 맞췄다.
- 16: 좌측 별도 위험 명칭 rail과 두 본문 패널, 세 행의 점선, 윤곽 capsule을 복원했다.
- 17: 두 258px 원과 양방향 화살표, 흰색에서 저채도 강조색으로 변하는 협력사 원판을 복원했다.
- 01/02/18: 표지 제목·gradient·meta·연락처 SVG, 목차 기준선·점선을 맞췄다. 표지의 회색 3D 자리는 글자와 겹치는 상단 왼쪽 부분을 비워 제목 가독성을 확보했다.
- 공통 하단 glow는 중심 y700 색을 원본 (37,81,158), 조립 (37,82,156)로 계측하여 보정했다. 넓은 수평 타원과 screen 합성으로 하단 패널에도 빛이 얹히도록 했다.

## 남는 차이·판독·결정

|06|건물 사진을 회색 자리로 대체했다.|
|07|Mi 이미지 로고를 회색 자리로 대체했다. 막대의 50/100 값은 원본 도형 비율을 재현한 값이며 새 시장 통계를 만들지 않았다.|
|08/15|세 광택 3D 아이콘을 각각 회색 자리로 대체했다.|
|10/13/17|그라데이션과 벡터 실루엣을 CSS/SVG로 근사했다. 원본 제작 도구의 미세한 색 보간과 글꼴 안티앨리어싱은 브라우저와 차이가 남는다.|
|전 장|원본에 글꼴 메타데이터가 없어 제공 글꼴 표의 Pretendard Variable을 선택했다. 원본과 획의 세부 형태·한글 폭에 작은 차이가 남는다.|

대부분의 본문은 판독할 수 있어 그대로 옮겼다. 원본에 “이곳에…”로 남아 있는 안내 문장은 자료의 글자로 재현했으며 작업 지시로 실행하지 않았다. 형태를 알아볼 수 없는 미세 로고·3D 아이콘의 문구나 상표를 새로 추측하지 않았다.

## 라이브러리 검수
라이트·다크 sheet는 제공된 preview.py로 생성했다. 편집용 `.frame`의 스타일이 계약 요소 `.frame`에 번지는 충돌은 시트 HTML의 편집용 스타일만 `article>.frame`으로 좁혀 해결했다. 폰트는 번들 안 상대 경로 WOFF2를 실제 로드한다.

제목·수치의 토큰 위계, 여러 카드의 동일한 이름/설명 공간, 긴 note, 모든 tone/상태, 위·아래·좌·우 connector를 검사했다. 기본 sparkline은 실제 mini-line, .bars는 막대, slope.dumbbell은 값 위치에 따른 수평 연결, timeline.alt는 위·아래 교대 배치로 구현했다. 면적 차트는 선형 면, radar는 3~8축 다각형이다. 기준 palette의 강조 문자에는 aN-7을 써 대비를 보완했다.

## 검사 자료
- replica/checks.json: 18장 크기·폰트 로딩.
- library/checks.json: 라이트·다크 344 fixture 렌더·폰트·페이지 밖 영역.
- reassembled/checks.json: 18장 크기·폰트·페이지 밖 영역.
- 일반 페이지와 요소별 시트 PNG는 1280×720. 비교 PNG는 두 페이지를 붙인 2560×720.
- 최소 칸부터 12×6까지의 상태 검사는 최종 source 해시와 함께 별도 geometry 감사 기록에 보존한다.

최종 자동 검사: 170 fixture의 9,882 grid/모드 상태에서 글자 영역 초과 0, 폰트 오류 0. chip 51개 중심 검사에서 4px 허용 범위 밖 후보 0. plain-color 대비 검사에서 남은 두 건은 headline-big의 background-clip 글자이며, 실제 gradient 양 끝의 대비는 light 6.13~16.82, dark 7.07~16.41로 큰 글자 기준 3:1 이상이다. `library/gradient-contrast.json`에 계산을 보존했다. 밝은 모드 하단 합성에서 글자를 씻어 버리던 문제는 page 바탕과 약한 multiply 합성으로 고쳤다.

최종 요소별 화면 검수에서는 원본에 없는 그래프의 실제 연결도 별도로 보완했다. Sankey의 source→branch→중첩 branch 띠는 각 끝점까지 연결되고 share 값에 따라 두께가 달라진다. Mindmap은 좌우 가지에서 중심까지 곡선이 닿는다. Cycle은 3~6개 노드를 둘레에 놓고 타원의 접선 방향 촉으로 시계방향을 표현한다. Journey는 mood/next 값의 실제 점 좌표를 연결하며, network와 slope도 hypot/atan2로 끝점 기하를 계산한다. Concentric은 가로로 긴 칸에서도 같은 지름의 동심원을 유지한다. 4~5층 architecture, 5개 timeline, 3·5개 agenda에는 원본 특정 멤버 수의 절대 배치를 적용하지 않아 서로 겹치지 않는다. 이 보완은 일반 fixture에 적용하고 원본 재조립에 쓰는 2층/4개 멤버 배치는 유지했다.

추가 최종 교차검수에서 Venn 3집합을 삼각 배치해 실제 삼중 교집합을 만들고 각 집합 이름을 다른 원이 덮지 않는 바깥 영역에 뒀다. Calendar는 가로·세로 제약을 함께 계산하는 같은 셀 변수를 사용해 모든 셀을 정사각형으로 만들었다. 두 fixture를 최소 칸부터 12×6·두 모드까지 98상태 측정해 원/셀의 폭·높이 오차 0.1px 미만, 삼중 교차 및 이름의 독립 영역을 확인했다. Waterfall-6은 중간 변화 합계에 맞춰 최종값을 1,241로 고쳤다. Funnel의 30% 최소폭은 제거해 작은 값과 0도 그대로 폭에 반영하고 문자를 채움 밖에서도 보이게 했다. 이 요소들은 원본 18장에 사용하지 않는다. 중첩 :has 때문에 무시되던 표지 선택자는 유효 문법으로 고쳐 18번 회색 자리를 replica와 같은 x599/y292로 맞췄으며 1번의 기존 회색 영역과 글자는 유지했다.

동일 교차검수에서 조직도의 root border 때문에 생기던 줄 끝 18px 공백을 root 실제 지름·테두리와 rail 좌표로 보정했다. 14번 원본의 원과 rail도 실제로 연결되어 있어 해당 도형 연결만 수정했다. 중첩 sparkline에는 실제 높이 좌석을 부여해 작은 추이선이 눌리지 않게 했고, waffle의 `.u.tone-3`·`.tone-4`도 각각 다른 팔레트 자리를 사용하도록 보완했다. chart-stack의 1px 분할 간격은 같은 1px 값의 `--stroke` 토큰으로 바꿨다.

최종 추가 기능 실측: funnel의 0·1·24·100 값 폭은 기대 비율과 0.02px 이내, hierarchy의 4×3·4×6·12×6 stem/rail 접점은 0.02px 이내, 중첩 spark의 추이 y변위는 작은 칸14.16px/큰 칸30.11px다. `library/functional-audit.json`에 수치를 보존했다. 유효 CSS 선택자 2,816개에서 무효0, 정적 계약 검사 오류0·경고0이며, 다른 담당자의 라이트56장·다크56장 개별 교차검수에서 보고한 기능5건을 모두 고친 뒤 해당 화면을 재확인했다.

마지막 조직도 선 시작점은 원 테두리 바깥 끝으로 옮기고 rail 끝점을 유지했다. 실제 14번 조립본에서 원 외곽 bottom과 선 시작이 모두 y362.59375, 선 끝과 rail이 모두 y397.59375다. 전체 170 fixture·9,882상태 검증 직후 이 선의 pseudo-element만 바뀌어 hierarchy 세 fixture의 144상태를 다시 검사했다. 감사 JSON의 incremental_revalidation에 변경 파일·기준 해시·재검증 범위를 명시했으며 최신 source 해시와 일치한다.
