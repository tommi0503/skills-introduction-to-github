# Fluxweave 디자인 언어

원본 002 덱 18장을 replica로 재현한 뒤 추출했습니다.

- 1px 머리선은 표·연혁·연결에, 강조 연결에는 2px 선을 쓴다.
- 12px 카드 모서리, 6px 작은 면, 999px 캡슐, 완전한 원을 구분한다.
- 페이지 바깥 여백 80px, rail 212px, 내용 내 10·20·32px 단계를 반복한다.
- 본문 제목 52px/750, 표지 영문 88px/900, 숫자 56~64px/800, 이름24px/700, 설명18px/400, label14px/600. Pretendard Variable을 실제 로드한다.
- 섹션 레일과 흰 원형 탭, 약한 점무늬, 얇은 직물 곡선은 내용의 빈 구역에만 배치한다. 도형이 의미를 갖는 곳에는 원형 hub와 넓은 둥근 면을 쓴다.
- 제목 강조 = --a1-7, 주 강조 채움 = --a1 및 글자 --a1-on, 카드 바탕 = --n-1, 조용한 대비면 = --a1-1-soft, 연결 = --a1-3-soft, 일반 선 = --n-4, 설명 = --n-7. 원본의 파랑·보라라는 이름은 컬렉션에 남기지 않는다.
- 원본의 복합 웨이브는 replica와 foundation의 deco SVG 경로로 직접 그렸다. 선의 채색은 외부 palette 역할에서 공급한다.
- 다크는 동일한 색 단계의 역할을 유지하며, 사진 자리·표의 선·강조면의 글자 대비를 따로 검수한다.


최종 조립에서 흰 면+중첩 chart/organization 구성, 두 종류 hub, rich-text 인사말 패널, 겹친 가운데 원형 파트너십, 상승 계단 steps를 요소의 구성 분기로 추가했습니다. 곡선은 foundation의 SVG deco이며 원본 팔레트는 review에만 공급됩니다.

최종 적용 폰트는 본문·제목 모두 Pretendard Variable이다. 표지 weight900, 본문 제목 weight750, 숫자 weight800을 공유 토큰으로 사용한다. 자산에는 Montserrat face도 포함되지만 최종 CSS가 선택하지 않는다.
