최종 반입 원본은 collection 폴더의 CSS/JSON/HTML입니다. tools의 생성 스크립트는 제작 중간 기록이며 추가 검수 수정은 최종 CSS에 반영되어 있으므로 초안 생성 스크립트로 최종 CSS를 덮어쓰지 않습니다. 기존 최종 collection을 렌더할 때는 reassemble.py → README preview.py 두 모드(글꼴 링크를 ../assets/fonts.css로 교체) → render_library.py → render_replica.py reassembled 순서로 실행합니다. 스크립트는 제작 환경의 /workspace 경로를 사용하므로 다른 환경에서는 경로 상수를 해당 폴더에 맞춥니다. 폰트는 review/assets에 포함되어 있습니다. 최종 컬렉션 파일 자체가 반입을 위한 원본이며, 이 도구들은 별도 검수 자료입니다.
