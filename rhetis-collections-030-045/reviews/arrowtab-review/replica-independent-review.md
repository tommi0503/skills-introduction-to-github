## 공통

- 제목은 실제 검은 글자 픽셀 bounds로 원본 약43px 높이, 현재42px; 현재 폭은 다수 페이지에서 약7~9% 좁고 y가3px 높다. 03의 원본415×43px 대비 replica383×42px, 12의351×43 대비326×42다. 기존48px/-1.5px/700을 실제 폰트50px/-.5px/600으로 보정한다.
- 일반 페이지23px 회색 rail은 실제 픽셀 검사 결과 이미 있다. 초반 구두 보고의 '누락'은 중앙 이음부와 혼동한 것으로 정정한다. 표지/끝표지 rail의 상단15×158px만 원본 빨강과 달리 연한핑크다.

## 마지막 수정 묶음 완료 / 최종 렌더

- replica HTML20개와 replica.css만 수정했다. compare-replica20개 및 replica/replica.pdf20페이지를 모두 다시 만들었다. collection/reassembled/library/공유fonts/043 원본builder에는 손대지 않았다.
- Pretendard Variable을 실제 로드한 Chromium에서 모든20장을1280×720로 렌더했고,20/20 폰트 로드 성공·페이지 밖 DOM0을 확인했다. 최종20개 비교 PNG를 개별 열람했다. 마지막02/06 국소 보정 후 해당 비교도 다시 열람했고, 마지막02 타이포 보정 뒤 나머지19개 PNG의SHA256는 이전 개별열람본과 동일함을 확인했다.
- 실제 원본 좌표에서 표지 사선의 평행 두께/큰 제목·목차/03의8줄/04불릿/05divider/07아이콘/08z-order/09원형아이콘/10행 위치/11연결점/13O,T/14색 순서/15축 띠/16표·화살표폭/17도넛색/19연결선/20연락처 리듬을 복구했다. 검수 중 발견한06의 임시 중복 문구도 제거하고 원본3줄을 확인했다.
- 마지막 CSS 이후 모든 페이지 PNG를 다시 생성했다. 최종 캡처·비교·PDF는 `/workspace/work/agents/030/arrowtab-replica-final-metadata.json`에 SHA256, 크기,UTC시각, 브라우저 결과로 기록되어 있다. 최종 시각2026-10-23T10:00:52Z.

## 남는 실제 차이

원본 폰트 메타데이터가 없어 Pretendard를 가장 가까운 실제 글꼴로 유지했다. 여러 큰 제목은 원본43px glyph 높이와 최종44px의1px 차이, 몇px의 글자 폭/획 차이가 남는다(03 폭은415→411px; 초기383px에서 개선). 표지·머리띠 bevel의 흐림과 미세 음영, 원본 아이콘의 세부 곡선·채움은 같은 기하와 의미의 SVG/CSS로 근사했다. 일부 작은 본문 줄바꿈·화살표 탭 글자의 미세 위치(예:16의 아이콘 포함 행label)는 아직 완전한 픽셀 일치라고 주장하지 않는다. 사진의 회색 대체는 사용자 지정이다. 전체 원본 이미지를 배경에 넣거나 화면을 늘이거나 기울이지 않았다.

현재 replica HTML/CSS가 최종 소스다. 이전043 replica_build.py를 다시 실행하면 이번 독립 보정이 덮어써지므로 실행하지 않는다.
