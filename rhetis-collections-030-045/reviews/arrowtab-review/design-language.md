# Arrowtab — 디자인 언어

원본 043의 20장을 HTML로 재현한 뒤 추출한 규칙입니다. 원본의 빨강은 디자인의 고정색이 아니라 팔레트의 1순위 강조 자리입니다.

| 규칙 | 원본 관찰 | 라이브러리 자리 |
|---|---|---|
| 상단 띠 | 68px 평면 리본, 우측 V 홈 | --a1 / --a1-on |
| 좌측 레일 | 일반23px·표지15px 회색 세로 띠 | --n-4 |
| 카드 | 반경 0, 평면 중성면 | --n-1, --n-2 |
| 강조 패널 | 옅은 강조면, 좁은 화살표 탭 | --a1-2-soft, 탭 --a1 |
| 주요 숫자 | 큰 굵은 검정 또는 강조색 | --ink / --a1-8 |
| 선 | 표/차트 1px, 강조 2–5px | --n-4 / --a1 |
| 장 제목 | 잉크 사각 라벨 14px + 제목50–52px | --ink / --page |

모서리는 기본0, 원은 비중·순환·프로필에만 씁니다. 간격 단계12/24/28/32px, 페이지 여백98px. 제목50–52, 본문18 또는16, 설명14, 지표56–64. 본문은 좌측 정렬, 장 제목은 중앙. 탭 글자는 flex 중앙 정렬하며 좌우 화살촉 공간을 포함합니다. 사진은 회색 seat. 장식 화살표는 방향을 나타낼 때만 사용하며 숫자와 텍스트 위에 남기지 않습니다. 폰트는 실제 로드한 Pretendard Variable로 원본의 고딕 계열에 근접시켰습니다.

원본에 없는56종도 각 기능에 맞는 데이터 기하를 먼저 유지하고, 정사각 패널·작은 방향탭·얇은 직선·한 가지 강조로 통일합니다. 라이트/다크는 팔레트의 상대 단계와 대비 짝을 유지합니다.


공통 제목은 중앙축640px에, 좌측 제목은104px에 놓는다. 일반 body는98px에서 시작하며 실제 원본의 오른쪽 여백에 맞춰 비대칭 폭을 허용한다. 전체 폭 compound에서 내부 행/열을 실측한다. 리본의 V 홈은 흰 경계와 중성 끝면을 겹쳐 만든다. 표지는77px 안쪽 사선 두께와32px 바깥 중성 offset을 유지한다. 원형은 고리·관계·비중에 한정하고, 일반 카드 반경은0이다.

작은 화살표 탭은 중간 중성면 `--n-7`/`--page`, 강조 탭은 `--a1`/`--a1-on`이다. 옅은 면은 `--a1-2-soft`, 표·막대의 중간 강조는 `--a1-4-soft`, 작은 흰 글자가 필요한 면은 더 깊은 `--a1-7`/`--page`를 사용한다. 큰 pale initials는 full English label과 중복되는 장식이며 pseudo content로 표현한다. 도넛의 옅은 조각 안 값은 ink를 써 읽힘을 유지한다.
