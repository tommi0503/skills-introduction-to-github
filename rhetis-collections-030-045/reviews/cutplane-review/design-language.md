# Cutplane 디자인 언어

분석 대상은 033 제조 디지털 전환 제안서 15장이다. 원본 슬라이드 15장을 HTML로 재현하고 각 원본|replica 비교 이미지를 개별 확인한 뒤 이 규칙을 정리했다.

| 반복 규칙 | 원본 관찰 | 라이브러리에서의 자리 |
|---|---|---|
| 면 | 넓은 흰 면과 선명한 강조 면을 크게 분리 | 기본 바탕 `--page`, 주요 강조 `--a1`, 강조 위 글자 `--a1-on` |
| 모서리 | 사진·카드·표는 각진 직사각형, 페이지 장식만 대각선으로 절단 | `--radius:0px`, `--radius-sm:0px`; 배경 귀퉁이와 일부 계층 면은 polygon |
| 선 | 표·연결선은 1px, 주요 궤도는 굵게 | `--stroke:1px`; 도식 연결선은 얇고 차트 핵심선은 3~6px |
| 여백 | 슬라이드 외곽 약 80~110px, 항목 간 24~36px, 카드 내부 약 32px | `--margin-x`, `--margin-y`, `--gap-sm`, `--gap`, `--gap-lg`, `--pad` |
| 타이포 | 압축된 산세리프, 강한 제목과 차분한 본문, 핵심 어절만 굵게 | 실제 로드한 `'Pretendard Variable'`; 제목 40~44, 요소 이름 24~28, 본문 16~20의 타입 단계 |
| 위계 | 작은 강조색 kicker, 한 줄 또는 두 줄 제목, 데이터는 가장 크고 굵게 | kicker=`--a1-7`, 제목=`--ink`, 숫자=`--a1` 또는 `--ink` |
| 카드 | 밝은 카드와 강조 바탕 위 선 카드가 번갈아 배치; 그림자 없음 | 기본=`--n-1`, `.line`=`--page`+가느다란 선, `.on`=`--a1` |
| 도식 | 가는 연결선, 원형 아이콘, 계층의 수평 면에만 대각선 | 선=`--n-5`, 비강조 면=`--n-2`, 원형 badge 내부 아이콘 55% |
| 차트 | 주요 시리즈 하나는 선명, 비교는 회색, 보조선은 희미 | 주 시리즈=`--a1`, 비교=`--n-3`, 보조 시리즈=`--a2`, 눈금선=`--n-2` |
| 표 | 강조색 머리행과 얇은 수평선, 격행의 아주 옅은 면 | 머리행=`--a1`, 머리글=`--a1-on`, 격행=`--n-1`, 강조 열=`--a1-1-soft` |
| 장식 | 좌상단과 우하단 대각선 삼각 면, 이중 절단선; 본문을 침범하지 않음 | foundation 귀퉁이 장식, 상단 헤더와 본문 공간 분리 |

색 이름과 원본의 파랑 값은 replica와 source-palette preview에만 있다. 컬렉션은 팔레트의 자리만 사용하며 표준 라이트·다크 미리보기에서는 계약 palette.json이 색을 공급한다. 원본에서 사용하지 않은 요소는 얇은 선, 무그림자 직각 면, 작은 kicker, 큰 숫자와 절단된 대각선 면의 문법으로 확장했다. 라운드 카드·장식 점·입체 그림자는 도입하지 않았다.
