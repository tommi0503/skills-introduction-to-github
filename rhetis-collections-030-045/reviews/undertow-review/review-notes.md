# Undertow 검수 기록

원본: `031_1hfha_검정_미니멀_비즈니스_제안서`, 13장. 원본/replica/조립본은 모두 1280×720입니다.

## 최종 제작과 검수

1. 원본 13장 전체를 개별 열람하고 페이지 유형과 계약 요소를 `inventory.md`에 적었습니다. replica는 이미지 배경을 통째로 사용하지 않고 HTML, 실제 텍스트, 도형과 데이터 차트로 만들었습니다.
2. 원본|replica 비교 PNG 13장을 각각 열어 검토했습니다. 원본의 실측 경계·폰트 위계·줄바꿈을 맞췄으며, 마지막에는 01/02의 밝은 민트, 04 lightbulb, 06 SAM/SOM 라벨, 07 한 줄 Result, 09 범례·흰 상승 곡선, 12 본문 잘림, 13 작은 pie 라벨·말풍선 삼각형을 수정했습니다.
3. 디자인 언어를 추출한 후 키트, foundation, 56종 요소, 요소 fixture 174개와 foundation fixture 2개를 제작했습니다. README 모범 fixture는 data-el 접두사만 바꾸어 마크업/데이터를 유지했습니다. 샘플 CSS는 복제하지 않았습니다.
4. light/dark 시트를 만들고 176 fixture씩 렌더했습니다. 요소별 57폴더(56요소+foundation)의 시트를 개별 열람하고 최소·중간·12×6 크기의 자동 검사를 병행했습니다.
5. 첫 조립본에서 grid의 제약으로 원본 구성을 단순화한 판단이 원본 동일성 요구에 부족하다는 피드백을 받았습니다. 해당 판단을 철회하고 원본 실측 경계로 재조립했습니다. 12×6은 유지하며, foundation은 기존 data-el 구성에 따라 비균등 track을 정합니다. 페이지별 새 클래스/ID나 자유 좌표 x/y/w/h 확장 API는 사용하지 않습니다.
6. 조립 HTML에는 새 요소 CSS가 없습니다. `collection-preview.css`는 실제 컬렉션 CSS와 미리보기 호스트의 팔레트·타입 변수만 연결한 파일입니다. body 기본 margin 제거 역시 호스트 처리입니다. 모든 요소는 계약 마크업과 data-el을 사용합니다.
7. 수정 후 원본|조립본 13장을 다시 개별 비교했습니다. 요소 CSS의 변경은 light/dark 시트에 반영하고 최종 PNG/PDF를 다시 생성했습니다. 독립 검수는 주 에이전트가 수행합니다.

## 자동 검사

- `replica/checks.json`, `reassembled/checks.json`: 13장씩 폰트 로드, 1280×720, 텍스트 scroll 검사.
- `library/checks.json`: 176 fixture × 두 모드, 폰트 로드와 최소/중간/12×6의 텍스트 scroll 검사.
- `library/alignment-checks.json`: capsule/chip/tag 37개 × 두 모드의 글자 중심 검사. 3px 초과 후보는 0개였습니다.
- 산점도 `.dot`, roadmap `.mile`의 외부 라벨은 작은 도형의 scrollWidth를 의도적으로 초과합니다. 도형 밖의 라벨을 바로 잘림으로 판정하지 않고 실제 슬롯·페이지 경계와 text range를 별도로 봅니다.
- 주 에이전트의 독립 검사는 실제 grid slot과 text range의 경계·겹침·대비를 추가로 확인합니다. 이 검사를 Rhetis intake 통과로 주장하지 않습니다. 레퍼런스에는 intake 실행기가 없습니다.
- `automatic-checks.json`은 최종 소스 checksum, PNG 개수·치수, 폰트 및 잘림 검사의 요약입니다.

## 최종 경계 검사 결과
담당 에이전트가 주 검수의 동일한 text-range/slot-boundary/overlap/contrast 검사기를 별도 출력 경로로 실행했습니다. 최종 결과는 라이트 522개 경우·다크 522개 경우, overflow/overlap 0, 대비 후보 0입니다(`library/boundary-audit.json`). 주 에이전트의 최종 통합 검사는 별도로 진행합니다. 회귀는 페이지 문맥으로 숨기지 않고 계약 부품의 차이(다중 chip, mark 포함 spoke, 프로필 하단 메시지, 숫자 축의 span, 강조 유무)에 따라 범위를 좁혀 해결했습니다.


## 주 에이전트 최종 통합 검수

초기 재조립의 큰 배치 차이를 그리드 제약으로 남긴 판단을 철회하고, 원본과 각 페이지를 개별 비교해 원본 비율·위계·연결선·표 구조로 수정했다. 최종 비교 PNG의 SHA-256을 시각 검수 기록에 묶어, 검수 뒤 파일이 바뀌지 않았는지 확인했다. 폰트 정보가 없는 원본은 실제 로드한 제공 글꼴로 맞췄으며, 남는 글자 윤곽·작은 아이콘·대비 보정의 차이는 위 기록을 따른다.

최종 소스의 180개 페이지를 브라우저로 다시 렌더해 저장 PNG와 픽셀 단위 일치를 확인했고, 모든 페이지의 1280×720·폰트 로드·텍스트 경계·요소 박스·텍스트 캡슐의 실제 글리프 중심을 검사했다. 라이브러리는 라이트/다크 최소·중간·12×6 검사와 CSS 범위/계약 검사를 수행했다. 가상요소·그라디언트로 인한 대비 후보는 실제 화면을 확인해 별도 기록했다.

모범 card-4의 원문 ✹와 모범 callout의 배치는 같은 마크업·데이터 보존 요구를 우선했다. 다른 아이콘은 빈 Lucide slot이며, 다른 fixture의 최상위 배치는 12×6이다. 페이지 PDF는 마지막 PNG로 무손실 조립하고 PDF를 다시 래스터화해 같은 픽셀인지 확인했다. 라이브러리 PDF는 최종 fixture 전체를 포함한다.

`lead-integration.json`은 독립 최종 검사와 대비 판정, `lead-final-files.json`은 최종 파일 크기·SHA-256의 기준이다.
