# Undertow 디자인 언어

031 검정 미니멀 비즈니스 제안서 13장 replica에서 추출했습니다.

- **구도**: 얇고 조용한 회색 페이지와 바깥의 진한 세로 띠, 대칭 중심 제목. 표지는 큰 왼쪽 타이포와 낮은 정보 띠.
- **선**: 1px 구획선과 차트 축. 카드에는 그림자 없이 4–6px 상단 경계 또는 작은 진한 제목 띠. 연결선은 1–2px, 직선·점선, 끝점은 작은 원.
- **모서리**: 카드/표/면은 직각(0). 역할 라벨만 999px capsule. 시장 규모/기술/핵심 수익/프로필 아이콘은 완전한 원.
- **여백**: 페이지 좌우 60–84px, 위아래 36–48px; 콘텐츠 사이 12/24/36px, 카드 내부 20–28px.
- **위계**: 표지 영문 112px(보통/굵게 대조), 장 제목 44px 500, 카드 이름 24–28px 700, 수치 36–48px 750, 본문 16px 400, 작은 안내 12–14px. Pretendard Variable을 실제 로드합니다.
- **강조**: 한 덩어리만 강조 채움 또는 원으로; 라벨은 작고 진하며 중앙 정렬. 숫자는 큰 굵기, 단위는 작은 글자로 붙입니다.
- **면/선**: 기본 카드 `--page`, 카드의 조용한 주변 `--n-1`, 경계 `--n-3`; 표지 제목 강조 = `--a1-8` (기준 팔레트의 글자 대비를 위한 자리; 원본 미리보기는 밝은 강조 값을 공급), 핵심 원/진한 패널 = `--a1-7`, 위 글자 = `--page`; 작은 진한 띠 = `--ink`, 글자 = `--page`; 부드러운 보조 강조 = `--a1-2-soft`; 기본 본문 = `--ink`, 안내 = `--n-8`.
- **장식 문법**: 넓고 긴 곡선은 사진과 섞인 그래픽이므로 replica에서 회색 placeholder. 컬렉션은 사진의 광택을 흉내내지 않고 세로 띠와 큰 원의 대비로 같은 언어를 유지합니다. 의미 없는 작은 장식은 추가하지 않습니다.
- **확장**: 원본에 없는 차트도 얇은 축, 하나의 강한 시리즈와 조용한 면, capsule 범례로 설계. 관계형 요소는 직각 패널과 원형 핵심, 가는 연결선을 반복합니다.

## 팔레트 독립성
원본 민트/검정/회색은 자리로만 이전합니다. 라이브러리 시트는 README 기준 palette, 재조립은 원본에 가까운 preview palette를 별도 공급합니다. 컬렉션 CSS는 색 이름을 갖지 않습니다.

## 조립의 문법
반복되는 2분할, 3패널, 포함 원, 계단형 전략의 경계는 foundation의 비균등 12열/6행 트랙으로 표현합니다. 선택 조건은 기존 data-el 구성입니다. 새 페이지 ID나 자유 좌표 확장은 두지 않습니다. 포함 원의 지름, single-share의 시작각·구멍 크기·극좌표 라벨 반지름처럼 실제 도형의 의미를 가진 비색상 확장은 각 metadata에 등록합니다.
