# Chalkline 디자인 언어

## 근거
030 덱의 비교·FAQ 원본 2장과 HTML replica를 페이지별 나란히 검토한 후 추출했습니다. 색을 제외한 형태의 반복이 핵심입니다.

- 선: 1px 단색 수평 규칙. 표 머리에는 1px 테두리, FAQ에는 면 없이 텍스트만.
- 모서리: 표·카드·데이터 면은 0px. 분류 라벨만 999px 알약, 안내 마크만 원형.
- 여백: 8 / 24 / 40px 세 단계. 페이지 좌우 67px, 상단 45px. 제목 레일 190px, 본문과 40px 간격.
- 위계: masthead 20px / 좌측 제목 48px 750 / FAQ 이름 26px 750 / 안내 20px 500 / 본문 18px 400 / 비교행 16px / 분류 12–14px. 한글 자간은 약 −0.018…−0.025em, 본문 행간 1.46.
- 강조: 두꺼운 제목과 한 개 채움 라벨 또는 비교표 머리의 대비. 대형 그림자·입체 장식은 없음. 원형 아래 chevron은 다음 설명으로 시선을 이끄는 기능만 가짐.
- 면: `--page` 전체, `--n-1` 비교행·정보면, `--n-2` 대체 이미지 자리.
- 선: `--n-5` masthead·표 머리, `--n-3` 보조 구획. 글자 `--ink`, 보조 `--n-7`.
- 채움: 원본 검정 알약과 비교군 머리의 역할은 `--ink` 채움 / `--page` 글자. 라이브러리의 `.on` 카드·주 데이터는 `--a1` / `--a1-on`. 차트의 부 시리즈는 `--n-5`나 `--a1-3-soft`.
- 원본에 없는 관계도·차트: 직각 면, 얇은 연결선, 작은 원 노드, 알약 이름표를 사용. 장식만을 위한 배경이나 둥근 카드 프레임을 추가하지 않음.

## 설계 결정
글꼴 원본 메타데이터가 없으므로 제공된 Pretendard Variable을 실제 로드하여 400/500/700/750을 맞췄습니다. 원본 컬렉션은 2p 조각이므로 표지 및 54종에 가까운 미관찰 요소는 반복되는 규칙을 확장한 저자의 설계입니다. 기준 palette의 색은 원본 흑백과 다를 수 있으며 컬렉션 CSS에는 팔레트 역할만 존재합니다.

최종 실측 보정: 제목48px/1.32. body의 위 두 트랙은72px씩, 다음 두 트랙은80px씩이며 남은 높이를 아래 두 트랙이 나눈다. 6열 단위의 텍스트 열은428/448px로 비대칭이다. 비교 요소는50px 머리와 총340px의 조밀한 행 블록을 사용한다. 페이지별 예외 CSS 없이 이 리듬을 foundation과 요소에 반영했다.
