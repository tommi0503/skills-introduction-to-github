# blockweave — 디자인 언어

원본 045 19장과 HTML replica의 반복 문법을 바탕으로 한다. 사진·서명·상표는 회색 placeholder로 둔다.

- 페이지: 1280×720. 상단 52px에서 1188px 길이의 1px 수평선. 왼쪽 가장자리에 폭10px·높이89px의 짧은 강조 바. 내용 영역은 좌우80–102px, 위110px에서 시작한다.
- 모양: 기본은 직각 사각형, 일부 서비스 패널만 작은 모서리. 표지의 96px 정방형 모자이크는 이미지와 빈 칸을 교차하며 오른쪽 가장자리에만 놓인다. 배경에 의미 없는 도형을 추가하지 않는다.
- 선: 기본1px, 중심 원과 강조 연결2px, 일정 핵심선3–4px. 보조 구분은 dotted 1px. 표는 세로선 없이 행 구분선과 채움으로 정렬한다.
- 여백 단계: 8 / 16 / 24 / 40px. 본문 카드 사이 18–24px. 같은 줄의 이름과 수치는 같은 높이에 놓고 문장 길이는 아래로 흘린다.
- 타이포: Pretendard Variable 실제 파일 로드. 표지80–92px, 제목40–48px, 강조 수치40–64px, 요소명20–24px, 본문16–18px, 표13–16px. 제목 굵기750–800, 본문400, 강조650–700. 원본 미식별 폰트의 대체이며 줄바꿈 오차는 기록한다.
- 강조: 제목 전체 채색보다 핵심 단어 또는 숫자만 `--a1`. 가로 헤더 띠·단계의 상단막대는 `--a1`+`--a1-on`. 보조 단계는 `--n-2`, 본문 `--ink`, 조용한 설명 `--n-7`. 중심 원은 `--a1`, 주변 원은 `--n-1` 또는 `--a1-2-soft`. 시리즈2는 `--n-5`, 다음 시리즈는 `--a2` 순서.
- 면/선: 내용 카드는 `--n-1`과 무테 또는 얇은 `--n-2` 선, 페이지 `--page`; 대비가 필요한 대체면 `--n-1`. 진한 보조 띠는 `--n-8`+`--page`에 의존하지 않고 `--ink`+`--page` 쌍으로 두 모드에서 대비를 확보한다.
- 장식: 모자이크는 cover에만. 업무 다이어그램은 원+정돈된 사각 텍스트 패널. timeline은 점과 가는 수평선, 성장 단계는 위로 한 칸씩 오르는 직사각형. 의도 없는 그림자·입체·잎·별은 사용하지 않는다.
- 확장: 원본에 없는56계약도 동일한 짧은 위쪽 강조막대, 모서리 절제, 넓은 여백, 원 중심 관계도와 행 구분을 사용한다. 색 이름/원본 리터럴은 컬렉션에 넣지 않고 팔레트 역할만 사용한다.

원본 동일성 재검수에서 확정한 구성: 좌우 318×130 무테 패널과 170px 중심원·94px 노드를 쓰는 6단계 cycle, 208px 채움 core의 문화 hub와 202px 선형 core의 사업 hub, 실제 3원 교집합과 문자 칩, 모서리 없이 위아래로 묶인 흰 복합 패널. 이 구성들은 각각 독립 source fixture로 포함한다. 작은 강조 문구는 기준 팔레트 대비를 위해 `--a1-8`, 모양/띠는 `--a1`+`--a1-on`, 조용한 진한 띠는 `--n-8`+`--page` 쌍을 사용한다.
