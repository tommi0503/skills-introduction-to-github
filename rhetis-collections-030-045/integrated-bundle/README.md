# 전체 컬렉션·복제본 코드 통합 ZIP

[통합 ZIP 다운로드](https://github.com/tommi0503/skills-introduction-to-github/releases/download/rhetis-030-045-all-in-one-20261023/rhetis-collections-030-045-all-in-one.zip)

6개 컬렉션(요소336종), replica90장과 라이브러리 조립본90장의 전체 코드, 원본 이미지, 라이트·다크 검수 시트 및 PDF, 비교 PDF, 폰트, 계약, 도구, 미리보기를 포함합니다. ZIP 최상위 폴더는 `rhetis-collections-030-045/` 하나입니다.

압축을 푼 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8000/`을 열면 미리보기를 볼 수 있습니다. 복제본 코드는 `reviews/<name>-review/replica/`, 조립본은 같은 경로의 `reassembled/`, 컬렉션은 `collections/<name>/`에 있습니다.

개별 ZIP12개의 중복 사본, 게시 영수증, Python캐시는 제외했습니다. 개별 ZIP 다운로드 링크는 원격 원본으로 연결됩니다. ZIP 내부 `bundle-manifest.json`에는 모든 포함 파일의 크기와 SHA-256이 있습니다. [verification.json](verification.json)은 전체 ZIP의 SHA-256·CRC·구조 검증 결과입니다.
